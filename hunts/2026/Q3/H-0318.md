# H-0318: WMI Event Subscription Persistence via New-CimInstance and mofcomp

## LEARN: Prepare the Hunt

### Hypothesis Statement

Adversaries create permanent WMI EventFilter, EventConsumer, and FilterToConsumerBinding objects to execute payloads on system events (SystemBoot, ProcessStart), achieving fileless persistence that survives reboots and evades AV. Detectable via WMI-Activity Event ID 5861, Sysmon IDs 19/20/21, and unusual spawning of PowerShell, mofcomp.exe, or wmic.exe from non-administrative processes.

### Threat Context

WMI subscriptions are a favored persistence mechanism for APT groups (APT29, Lazarus) and ransomware operators because they leave minimal on-disk artifacts and bypass many AV solutions. Our environment has Windows Server 2016-2022 and Win10/11 endpoints with AD. Sysmon WMI event logging is available in the SIEM endpoint_data index.
