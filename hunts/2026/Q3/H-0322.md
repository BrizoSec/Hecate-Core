## LEARN: Prepare the Hunt

### Hypothesis Statement

Adversaries create permanent WMI EventFilter, EventConsumer, and FilterToConsumerBinding objects to execute payloads on system events (SystemBoot, ProcessStart), achieving fileless persistence that survives reboots and evades AV. Detectable via WMI-Activity Event ID 5861, Sysmon IDs 19/20/21, and unusual spawning of PowerShell, mofcomp.exe, or wmic.exe from non-administrative processes.

### Threat Context

WMI subscriptions are a favored persistence mechanism for APT groups (APT29, Lazarus) and ransomware operators because they leave minimal on-disk artifacts and bypass many AV solutions. Our environment has Windows Server 2016-2022 and Win10/11 endpoints with AD. Sysmon WMI event logging is available in the SIEM endpoint_data index.

## OBSERVE: Expected Behaviors

### What Normal Looks Like

- `WmiPrvSE.exe` spawning `scrcons.exe` for legitimate script consumers (AV, monitoring agents)
- `mofcomp.exe` run by `SYSTEM` or `TrustedInstaller` during software installation
- Sysmon Event 19/20/21 from known software deployment tools (SCCM, Ansible, monitoring agents)
- WMI-Activity Event 5861 for known subscription names registered by enterprise software

### What Suspicious Looks Like

- Sysmon Event 19 (EventFilter) + 20 (EventConsumer) + 21 (FilterToConsumerBinding) in rapid succession from a user-context process
- `mofcomp.exe` launched by `powershell.exe`, `cmd.exe`, or a browser process
- `WmiPrvSE.exe` spawning `powershell.exe`, `cmd.exe`, `wscript.exe`, or any LOLBin
- WMI subscription names that don't match known enterprise tooling (random strings, typosquatted names)
- Event 5861 containing obfuscated PowerShell or encoded commands in `CommandLineTemplate`

### Expected Observables

- **Processes:** `mofcomp.exe`, `wmic.exe` spawned from non-SYSTEM users; `WmiPrvSE.exe` → `powershell.exe`/`cmd.exe`/`wscript.exe` child chains
- **Files:** `.mof` files dropped in temp directories (`%TEMP%`, `C:\Windows\Temp`) before `mofcomp.exe` execution
- **Registry:** Changes under `HKLM\SOFTWARE\Microsoft\WBEM\ESS` at time of subscription creation
- **WMI Namespace:** New objects in `root\subscription` — `__EventFilter`, `__EventConsumer`, `__FilterToConsumerBinding`
- **Authentication:** Subscription creation from non-admin accounts or service accounts that shouldn't use WMI

### Hunting Queries

#### Query 1 — Baseline: Count WMI Subscription Events (COUNT-FIRST)

```spl
index=endpoint_data EventCode IN (19, 20, 21) earliest=-7d latest=now
| stats count by EventCode
```

**Result:** [Record counts per EventCode. If 0, Sysmon WMI logging may not be enabled.]
**Decision:** [If counts look reasonable, proceed to Query 2. If 0, pivot to WMI-Activity log.]

---

#### Query 2 — Sysmon Triad Detection: EventFilter + Consumer + Binding

Look for hosts where all three subscription events (19, 20, 21) appear within a short window — indicates a full subscription registration.

```spl
index=endpoint_data EventCode IN (19, 20, 21) earliest=-7d latest=now
| bin _time span=10m
| stats dc(EventCode) as event_types values(EventCode) as codes count by host _time
| where event_types >= 2
| sort -count
| head 50
```

**Result:** [Record hosts and time windows with multiple WMI event types]
**Decision:** [Hosts with all 3 event codes (19+20+21) in 10 minutes warrant deep-dive in Query 3]

---

#### Query 3 — Deep Dive: WMI-Activity Event 5861 with Command Inspection

```spl
index=windows_logs source="*WMI-Activity*" EventCode=5861 earliest=-7d latest=now
| rex field=Message "CommandLineTemplate\s*=\s*\"(?P<cmd_template>[^\"]+)\""
| where isnotnull(cmd_template)
| eval suspicious=if(match(cmd_template, "(?i)(powershell|cmd|wscript|mshta|regsvr32|rundll32|certutil|bitsadmin|base64|encodedcommand)"), "YES", "NO")
| table _time host User cmd_template suspicious
| sort -suspicious _time
| head 100
```

**Result:** [Record any CommandLineTemplate values that contain LOLBins or encoded content]
**Decision:** [Flag rows where suspicious=YES for investigation]

---

#### Query 4 — WmiPrvSE Child Process Spawning (High-Fidelity Signal)

```spl
index=endpoint_data ParentImage="*WmiPrvSE.exe" earliest=-7d latest=now
| stats count values(CommandLine) as cmd_lines by Image host User
| where NOT match(Image, "(?i)(scrcons\.exe|WmiApSrv\.exe)")
| sort -count
| head 50
```

**Result:** [Record any unexpected child processes of WmiPrvSE.exe]
**Decision:** [Any powershell.exe, cmd.exe, wscript.exe, or LOLBin spawned from WmiPrvSE is high-confidence suspicious]

---

#### Query 5 — mofcomp.exe Non-SYSTEM Execution

```spl
index=endpoint_data Image="*mofcomp.exe" earliest=-7d latest=now
| where NOT match(User, "(?i)(SYSTEM|TrustedInstaller|NETWORK SERVICE)")
| table _time host User ParentImage CommandLine
| sort _time
| head 50
```

**Result:** [Record any mofcomp.exe executions by non-system accounts]
**Decision:** [Any result here is potentially suspicious — mofcomp.exe rarely needs to run as a user account]
