## LEARN: Prepare the Hunt

### Hypothesis Statement
Adversaries use the native Windows Command Shell (`cmd.exe`) for reconnaissance, lateral movement, and execution, often leaving traces of their activity in process execution logs. We can detect this anomalous behavior by looking for `cmd.exe` instances with suspicious parent processes (e.g., Office applications), unusual command-line arguments, or those performing chained discovery commands.

### Threat Context
Many threat actors (e.g., FIN7, APT29) and commodity malware leverage `cmd.exe` as part of their execution chain. It is a native "living-off-the-land" binary (LOLBin) that blends in with legitimate administrative activity, making it a popular choice for all phases of an attack. Adversaries use it to run discovery commands (`whoami`, `net user`, `ipconfig`), execute payloads, or manipulate files, often as a child process of a compromised application like Microsoft Word.

## OBSERVE: Expected Behaviors

### What Normal Looks Like
`cmd.exe` is commonly launched by `explorer.exe` (interactive user sessions), `services.exe` (system services), `taskschd.dll` (scheduled tasks), or legitimate management/deployment scripts (e.g., SCCM). Its usage patterns should be relatively consistent on specific server groups or among users with the same role. It is not typically spawned by Office applications or web browsers.

### What Suspicious Looks Like
- **Anomalous Parent-Child Relationship:** `cmd.exe` spawned by an Office application (e.g., `WINWORD.EXE`, `EXCEL.EXE`), a web browser (`chrome.exe`), or a PDF reader. This is a classic indicator of successful phishing.
- **Obfuscated Commands:** `cmd.exe` command lines containing excessive carets (`^`) for obfuscation, or base64-encoded commands passed to a child PowerShell process.
- **Rapid Discovery:** A single parent process spawning `cmd.exe` to run a series of discovery commands in quick succession (`whoami`, `net user`, `systeminfo`, `ipconfig /all`, `netstat -an`).
- **Unusual Child Processes:** `cmd.exe` spawning network tools (`ncat.exe`, `curl.exe`), credential access tools, or `bitsadmin.exe` to download further payloads.

### Expected Observables

- **Processes:** [Process names, command lines]
  - **Parent Processes:** `WINWORD.EXE`, `OUTLOOK.EXE`, `CHROME.EXE`, `ACRORD32.EXE`
  - **Process:** `cmd.exe`
  - **Child Processes:** `whoami.exe`, `net.exe`, `ipconfig.exe`, `nltest.exe`, `powershell.exe`, `bitsadmin.exe`
- **Network:** Outbound network connections originating from a `cmd.exe` process (highly suspicious).
- **Files:** Creation of temporary batch files (`.bat`, `.tmp`) in public-writable directories like `C:\Users\Public\`.
