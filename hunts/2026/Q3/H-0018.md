# H-0018: Kerberoasting via SPN Enumeration and Offline Hash Cracking

## LEARN: Prepare the Hunt

### Hypothesis Statement

Adversaries enumerate SPNs across the domain and request TGS tickets for service accounts to extract RC4-encrypted hashes for offline cracking, enabling credential theft without triggering lockout policies.

### Threat Context

Kerberoasting requires no special privileges — any authenticated domain user can enumerate SPNs. Hashes cracked offline yield plaintext service account credentials, often with elevated privileges. No prior hunts exist for this technique in this environment.

### ABLE Scoping

| **Field**   | **Your Input** |
|-------------|----------------|
| **Actor** *(Optional)* | APT groups and commodity ransomware operators targeting AD environments (e.g., Mimikatz Invoke-Kerberoast, Rubeus) |
| **Behavior** | Anomalous volume of TGS requests (EventID 4769) for RC4 encryption (0x17) from a single user across multiple service accounts in a short time window |
| **Location** | Windows domain-joined endpoints and domain controllers |
| **Evidence** | Windows Security Event Log EventID 4769 (Kerberos Service Ticket Operations), CrowdStrike process telemetry for tools like Rubeus, Mimikatz, or GetUserSPNs.py |
