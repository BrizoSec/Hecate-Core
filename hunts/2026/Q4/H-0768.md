### Justification

This hunt addresses a specific, active campaign targeting cryptocurrency users via compromised browser extensions. The threat intel confirms that 16 malicious extensions are actively stealing credentials (private keys/mnemonics) by intercepting data during wallet import flows and sending it to C2 infrastructure (`icy-star-f45c.workers.dev`). Hunting for this behavior is critical because standard endpoint protection often misses browser extension-based theft, and the use of legitimate Cloudflare Workers infrastructure allows the traffic to blend in with normal web activity, evading simple domain-based blocks if not monitored for specific query parameters or subdomains.
