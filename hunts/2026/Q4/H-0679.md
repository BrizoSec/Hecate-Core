### Justification

The GrelosGTM group specifically targets Magento CMS platforms by abusing legitimate Google Tag Manager functionality to inject malicious scripts. This behavior is critical because it bypasses traditional web application firewalls and allows for the stealthy delivery of multi-stage JavaScript payloads via WebSocket connections, which can evade standard HTTP-based monitoring. Hunting for this specific injection pattern and subsequent WebSocket traffic to known malicious domains is essential to detect active skimming campaigns before financial data is exfiltrated.
