# New RemControl Android Banking Trojan Steals PINs Using AI-Built Phishing Overlays

![](data:image/svg+xml;base64,PHN2ZyBoZWlnaHQ9Ijg2OSIgd2lkdGg9IjE2MDAiIHhtbG5zPSJodHRwOi8vd3d3LnczLm9yZy8yMDAwL3N2ZyIgdmVyc2lvbj0iMS4xIi8+)
![RemControl Trojan Steals Banking PINs](https://i2.wp.com/blogger.googleusercontent.com/img/b/R29vZ2xl/AVvXsEig5j4xeUhz1c9fmTHJzzb4MXKVUqpeS6dkkoyAUFbkRfPxAZy5yUta0CFVOXR7p1zPz1w-IfvATgfx3WNf2OxAcF2gHiAE0jzokQQ5noXZCynLSTc1G3bqJB_AOVbaRpBFae9ps6CVPFLRJe_2bM5oZ-R9w3MJSI15b8vTETf8efeie9SWuSJQ6LF7FPWO/s1702/fc2b3567-626d-4ca5-9805-62bf92a4d9fd.webp?fit=1600,869&ssl=1 "RemControl Trojan Steals Banking PINs")

The malware targets customers in Western Europe, the Middle East, and Canada. Researchers confirmed phishing overlays for more than 30 financial institutions.

First observed in samples from July 2026, RemControl is distributed through fake Google Play Store pages advertising TVTap, an IPTV app.

Group-IB identified malvertising as one delivery channel. In an Italian campaign, the download pages showed the [malicious APK](https://cyberpress.org/hackers-deploy-apk-malware/?amp=1) only to visitors using mobile devices with Italian IP addresses.

The downloaded dropper presents a TVTap update screen. When a user starts installation, it launches a local VPN service that blocks network traffic from the Google Play Store app, interfering with real-time Play Protect checks.

It then creates a new signing certificate for the malware payload on each installation, making certificate-based detection harder, before installing the payload.

## **RemControl Trojan Steals Banking PINs**

Once installed, RemControl asks the user to enable Android’s Accessibility Service. If granted, that permission lets the trojan detect which app is open, read interface content, and perform actions on the device.

When a targeted banking app appears, RemControl displays a full-screen phishing page supplied by its [command-and-control (C2)](https://cyberpress.org/hackers-abuse-grok-and-microsoft-copilot/?amp=1) server. The page can request a PIN, mobile banking code, or card expiry date.

After submission, it closes and reveals the real banking app beneath it.

The malware can also capture screenshots, stream the screen’s interface structure, log typing-related events, and remotely tap, swipe, or enter text.

Group-IB found code designed to capture lock-screen patterns on several Android device types. RemControl also tries to prevent victims from opening settings used to remove the app or revoke its permissions.

Instead of storing a fixed C2 address in the app, RemControl retrieves an encrypted address from a Telegram page. This lets operators change servers without rebuilding the malware. Its main connection uses [WebSocket](https://cyberpress.org/salat-abuses-websocket-channels/?amp=1), with HTTP as a fallback.

[Group-IB found](https://www.group-ib.com/blog/remcontrol-android-banking-trojan/) publicly accessible API documentation for both a C2 proxy and an operator panel.

The panel exposed features for managing infected devices, editing phishing overlays, recording remote-control sessions, and generating APK builds with affiliate tags. These features indicate a Malware-as-a-Service operation.

The investigation also found signs of AI-assisted development. API documentation described banking credential submissions as “quiz answers,” while one phishing page contained a complete AI assistant response accidentally left in its HTML.

These artifacts support AI involvement in building parts of the infrastructure and overlays; they do not show that AI independently selected victims or ran the campaign.

### Justification

The RemControl trojan specifically abuses Android's Accessibility Service to overlay fake banking interfaces over legitimate apps, capturing PINs and codes in real-time. The malware also installs a local VPN to evade Google Play Protect detection during installation. Hunting for these specific behaviors is critical because standard endpoint security often misses the credential theft phase once the app is installed and permissions are granted, as the actual data exfiltration occurs via WebSocket C2 channels rather than direct file access.
