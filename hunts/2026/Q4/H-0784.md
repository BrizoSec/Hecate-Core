### Justification

The Kimsuky 'GitPower' campaign specifically targets Ukrainian diplomacy and security experts using spear-phishing emails with malicious LNK attachments or fake Zoom installers. Post-exploitation involves PowerShell execution to download payloads from GitHub repositories, masking C2 and exfiltration traffic as legitimate development activity. Hunting for this specific chain (LNK/Installer -> PowerShell -> GitHub) is critical because standard EDR rules often miss the initial LNK execution if it points to a temp folder, and network logs may not flag GitHub traffic as malicious without correlating it to suspicious PowerShell command lines.
