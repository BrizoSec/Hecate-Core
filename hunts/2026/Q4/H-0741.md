### Justification

This hunt targets a sophisticated supply-chain style attack where 31 malicious Chrome extensions masquerade as legitimate VPN tools. The threat actor's goal is traffic interception via a proxy farm, enabled by dynamic configuration updates from remote sources like GitHub Pages and Telegram. This matters because it bypasses traditional extension store vetting and allows real-time C2-like behavior without software updates. The organization risks data exfiltration or credential theft if employees install these extensions to access blocked services (e.g., RuTracker, YouTube). The lack of visibility into outbound HTTPS requests from chrome.exe to dynamic config endpoints creates a blind spot for this specific TTP.
