### Justification

This hunt targets a sophisticated delivery chain that bypasses standard signature-based detection. By hiding payloads in plain sight within legitimate-looking images (steganography) and using cloud storage (Firebase), attackers avoid suspicious file downloads or known malicious domains. The use of environment variables for staging allows the payload to exist only in memory, evading disk-based forensics, while MSBuild.exe execution provides a trusted binary cover for final payload launch. Hunting this behavior is critical because it represents a high-evasion initial access and execution vector that can lead to full system compromise via DCRat.
