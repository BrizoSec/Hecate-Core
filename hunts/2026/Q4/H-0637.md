### Justification

The MacSync campaign specifically targets macOS professionals by abusing the 'ClickFix' technique, where victims are coerced into pasting malicious curl/osascript commands into the Terminal. This hunt is critical because it addresses a sophisticated delivery mechanism that bypasses standard GUI-based security warnings and Gatekeeper by leveraging user interaction. The malware's ability to execute in-memory via AppleScript and persist as legitimate-looking plist files (e.g., com.google.keystone.plist) makes it difficult to detect with static signatures alone, requiring behavioral hunting for the specific command-line patterns and file system artifacts described in the threat intel.
