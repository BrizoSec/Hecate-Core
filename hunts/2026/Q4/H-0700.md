### Justification

The threat intel describes a specific campaign (MovieReaper) distributing malware via the compromised itorrents.org repository. The unique aspect of this threat is the use of the Solana blockchain for C2 address resolution, which bypasses traditional network-based detection mechanisms like IP blocklists or domain blacklists. Hunting for this behavior is critical because standard network monitoring will fail to detect the initial C2 communication if it only looks for known malicious IPs/domains, missing the blockchain RPC calls that deliver the actual C2 infrastructure.
