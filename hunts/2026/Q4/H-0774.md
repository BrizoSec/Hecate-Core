### Justification

The NEBULA campaign specifically targets software supply chains via malicious npm packages. The threat intel confirms the delivery mechanism is an 'obfuscated installation hook' within these packages, which executes a payload that bypasses DLL import monitoring by using direct syscalls. This behavior is critical to hunt because standard EDR controls relying on API hooking or import table analysis will miss the initial execution and subsequent C2 communication from the masquerading conhost.exe process. Hunting for anomalous npm/node processes spawning unexpected child processes (like conhost.exe) and outbound connections to the identified C2 infrastructure addresses this specific supply chain risk.
