### Justification

The BraZetsu framework, attributed to the Exilware group, specifically targets financial infrastructure by harvesting Brazilian CNAB transaction files and digital certificates. It utilizes Nuitka compilation to disguise Python code as standard executables (like msedge04.exe) to evade detection and employs WebSocket-based Command and Control (C2) for communication. Hunting for these specific artifacts is critical because standard endpoint telemetry often fails to distinguish between legitimate Python scripts and Nuitka-compiled payloads, while network controls may miss WebSocket traffic on standard ports if domain reputation isn't checked against known C2 infrastructure like infect.online.
