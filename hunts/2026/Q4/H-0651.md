### Justification

This hunt targets a specific vulnerability in the default configuration of AWS AgentCore Harness where the 'shell' tool is enabled by default, allowing an attacker to bypass agent isolation. By forcing the model to execute a payload (e.g., curl piped to python3), the adversary gains code execution within the harness environment. The critical risk is that the harness runs as root and resolves credentials in memory; reading /proc/1/mem allows direct extraction of plaintext IAM tokens (Bearer JWTs) which are then exfiltrated to external C2 domains like webhook.site. This represents a high-severity credential access and exfiltration scenario specific to agentic AI workloads.
