### Justification

The Djinn Stealer threat specifically targets cross-platform environments (Windows, macOS, Linux) by leveraging a Node.js loader (TaskWeaver) to access high-value credentials in non-standard locations like AI assistant configs (~/.claude, ~/.gemini) and cloud provider settings. Standard endpoint protection often misses this because the activity appears as legitimate JavaScript execution, but the specific combination of Node.js spawning file reads from developer/AI config directories followed by outbound network connections to known malicious IPs (96.126.130.126) indicates active credential theft and exfiltration.
