### Justification

The 2CLoader threat intel explicitly describes a sophisticated loader using Hell's Gate (indirect syscalls) to bypass API hooking and storing encrypted payloads in PE resources. This technique is critical to hunt because standard EDR signatures often miss the initial execution phase when syscalls are resolved dynamically from kernel memory rather than through standard Win32 API calls. Hunting for these specific evasion tactics allows detection of the loader before it decrypts and delivers the Vidar/Remus stealers, which target sensitive credential data.
