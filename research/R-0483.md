## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries with privileged network access exploit adversary-in-the-middle (AiTM) attacks to modify real-time network traffic, enabling them to intercept and manipulate communications between systems without detection. This technique is particularly concerning in ICS environments where it can disrupt critical infrastructure operations.

### Key Findings
- Privileged network access is a prerequisite for executing AiTM attacks effectively.
- Real-time modification of network traffic allows adversaries to perform actions such as data exfiltration and manipulation of control systems without raising immediate alarms.
- AiTM techniques are increasingly being used in conjunction with other tactics like man-in-the-middle (MITM) attacks, enhancing their effectiveness.
- Indicators of AiTM activity include anomalous network behavior, unexpected traffic patterns, and discrepancies between expected and observed data flows.
