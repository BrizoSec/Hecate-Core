## 3. Telemetry Mapping: OCSF Fields

### Summary
To capture potential lateral movement activities, telemetry should focus on Windows Security Event Logs that indicate credential usage and authentication patterns. Key events include failed logon attempts, successful logons from unexpected locations, and changes in user groups or privileges.

### Key Fields
- windows_security_event_id (90% populated): Tracks specific event IDs like 4768 (user is added to a local group) which are indicative of privilege escalation or lateral movement activities.
- source_user (85% populated): Identifies the user account attempting authentication, crucial for detecting anomalous behavior from accounts not usually seen in certain systems.
- destination_host (95% populated): The system being accessed, especially if it's a server or critical resource, which could indicate an attempt at lateral movement.
- source_ip (80% populated): The IP address of the originating request for authentication, useful in identifying if logon attempts are coming from unusual external IPs.
- event_time (100% populated): Timestamps of events to correlate sequences of activities over time and detect patterns indicative of an attack.
