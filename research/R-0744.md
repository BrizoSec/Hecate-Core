## 1. System Research: How It Works

### Summary
MovieReaper is a modular, multi-stage malware framework that infects users by distributing malicious loaders disguised as popular movies (e.g., 'The Odyssey') via compromised torrent repositories like itorrents[.]org. The malware employs sophisticated evasion techniques such as fileless execution, UAC bypass, and manual API resolution to establish command and control (C2) communication through the Solana blockchain network.

### Key Findings
- The infection chain originates from a supply chain compromise of the public torrent repository itorrents[.]org, where attackers replaced or injected malicious loaders into files disguised as popular movies.
- The malware utilizes the Solana blockchain network to retrieve C2 addresses, providing resilient and decentralized command and control infrastructure that is difficult to disrupt via traditional IP blacklisting.
- Technical execution involves a multi-stage process including an initial loader with anti-sandbox checks, shellcode for C2 resolution, UAC bypass mechanisms for privilege escalation, and a final file manager module for comprehensive file system access.
- The campaign leverages advanced evasion techniques such as vectored exception handling, in-memory execution, and manual API resolution to avoid detection by security sensors.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
The adversary distributes a modular multi-stage malware framework named MovieReaper by compromising the public torrent repository itorrents.org, which allows malicious files disguised as popular movies like 'The Odyssey' to spread across multiple trackers. This campaign leverages fileless execution and anti-sandbox checks to evade detection while using the Solana blockchain network for resilient Command and Control (C2) infrastructure.

### Key Findings
- The initial infection vector involved compromising itorrents.org, enabling the distribution of malicious loaders disguised as popular film torrents to users across Russia, Turkey, Japan, Kenya, Uganda, Colombia, Spain, the Netherlands, Belgium, and Germany.
- MovieReaper is a modular framework that utilizes fileless execution techniques, including shellcode retrieval of C2 addresses directly from the Solana blockchain to ensure infrastructure resilience.
- The malware employs sophisticated evasion methods such as manual API resolution, vectored exception handling, in-memory execution, and anti-sandbox checks within its initial loader stage.
- The infection chain includes a UAC bypass mechanism for persistence followed by a final file manager module that provides the adversary with comprehensive access to the victim's file system.
- Kaspersky’s GReAT team identified this previously unknown crimeware campaign in September 2026, detecting the threat as HEUR:Trojan.Win64.Agent.gen.

## 5. Research Synthesis

### Executive Summary
MovieReaper exploits compromised torrent repositories to distribute a modular, fileless malware framework that resolves Command and Control (C2) infrastructure directly via the Solana blockchain, bypassing traditional network blacklists. The attack chain utilizes advanced evasion techniques including manual API resolution, vectored exception handling, and UAC bypass to achieve privilege escalation and deploy a persistent file manager module in memory.

### Recommended Hypothesis
> Adversaries use compromised torrent distributions and Solana blockchain-based C2 resolution to establish resilient, fileless persistence on Windows endpoints without relying on traditional IP infrastructure.

### Gaps Identified
- Current network telemetry lacks capability to inspect or decrypt encrypted Solana RPC requests, rendering blockchain-hosted C2 addresses invisible to standard URL/IP blocklists.
- Endpoint detection systems likely miss the initial loader and shellcode execution because manual API resolution and vectored exception handling obscure native system calls from static analysis hooks.
