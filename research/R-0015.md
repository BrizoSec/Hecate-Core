## 1. System Research: How It Works

### Summary
Perturbation probing is a diagnostic method for assessing the fragility of safety mechanisms in large language models (LLMs) by identifying which layers are particularly sensitive to changes. This technique highlights that small perturbations can lead to significant shifts in model behavior, underscoring the need for robust external security measures.

### Key Findings
- The refusal mechanism within LLMs is fragile and resides in a thin neural layer.
- Perturbation probing reveals that minor changes can trigger harmful outputs from models.
- There is a critical need for multi-layered, external security to protect against model vulnerabilities.
