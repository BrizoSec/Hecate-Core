## 1. System Research: How It Works

### Summary
RSS is a web feed format that allows users and applications to access updates from websites in a standardized XML file format. It enables automatic delivery of content such as news articles or blog posts to subscribers via RSS readers or aggregators.

### Key Findings
- RSS provides an efficient way for website owners to distribute their content to a wide audience without requiring readers to manually check for updates.
- Users can subscribe to multiple RSS feeds through an aggregator, which compiles and presents the latest updates in one place.
- The XML format used by RSS is standardized, allowing for compatibility across different platforms and applications.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries exploit DNS manipulation to redirect users from legitimate sites or push additional malware, while also compressing and encrypting data for exfiltration to obfuscate the collected information and reduce network traffic.

### Key Findings
- Manipulation of victim DNS settings to facilitate malicious activities such as preventing access to secure websites or pushing more malware
- Systematic targeting of specific organizations by threat groups like OilRig, indicating strategic intent behind their attacks
- Use of compression and encryption for data exfiltration to avoid detection and minimize network traffic
- Chaining multiple vulnerabilities and leveraging trusted identities to execute sophisticated and multi-staged attacks
