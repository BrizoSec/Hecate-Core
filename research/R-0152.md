## 1. System Research: How It Works

### Summary
MISP is an open-source threat intelligence platform designed for the secure sharing of indicators of compromise (IOCs) among security professionals. It provides utilities and documentation to enhance threat detection and analysis, supporting various data fields such as IP addresses, URLs, and hashes.

### Key Findings
- The `feed_name` field in MISP IOC logs is typically set to the value of `event_source_org`, unless this field is empty, in which case it defaults to `MISP`.
- IP addresses are mapped from the `ip` field if it contains valid IP address information.
- URLs and URIs are directly mapped as attributes when their type matches `uri` or `URL`.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries abuse the pass-the-hash (PtH) technique by leveraging stolen password hashes to gain unauthorized access and maintain persistence within a network without needing clear-text passwords, thereby bypassing traditional authentication mechanisms.

### Key Findings
- Pass-the-Hash attacks allow adversaries to authenticate using NTLM or Kerberos ticket-granting service tickets without the need for actual user credentials.
- The medium threat level indicates that while not highly critical, this attack method can lead to significant data breaches and operational disruptions if left unchecked.
- Organizations like Krawczyk Industries Limited are tracking such events through MISP (Malware Information Sharing Platform) to enhance their security posture.
- Indicators of compromise include unusual network traffic patterns, particularly related to the use of Windows authentication protocols in unexpected contexts or from unfamiliar IP addresses.
- Tools commonly associated with PtH attacks may also serve as indicators, including Mimikatz and other post-exploitation frameworks designed to extract and manipulate password hashes.
