## 2. Adversary Tradecraft: Attack Techniques

### Summary
The HelloNet campaign exploits the ViPNet update system through an adversary-in-the-middle (AiTM) technique, allowing adversaries to intercept and manipulate network traffic for malicious purposes. The exact identity of the threat actors remains undisclosed.

### Key Findings
- Adversaries are leveraging an AiTM technique to compromise the integrity of ViPNet updates, potentially injecting malware or altering update files in transit.
- The attack likely involves monitoring and manipulating HTTPS traffic to exploit vulnerabilities within the ViPNet software's update mechanism.
- Indicators of Compromise (IoCs) may include unexpected changes in system configurations following an update, unusual network connections during the update process, and signs of malware injection through legitimate channels.

## 3. Telemetry Mapping: OCSF Fields

### Summary
The HelloNet campaign targets organizations using the ViPNet update system, likely exploiting vulnerabilities or misconfigurations within it. To detect such activities, focus on Windows Security Event Logs and endpoint process monitoring to identify unusual updates, service changes, and network communications indicative of malicious activity.

### Key Fields
- windows.security.event_id (70% populated): Event IDs like 4624 for account logon attempts, 4688 for process creation events, which are critical for identifying potential malware execution or unauthorized access to systems involved in the update mechanism of ViPNet.
- network.http.request.uri (50% populated): Monitoring HTTP request URIs can help identify unusual patterns that might signify malicious updates being downloaded by the affected system or attempts to exfiltrate data from compromised endpoints.
- windows.process.create.command_line (60% populated): Command-line arguments and paths associated with process creation events can reveal if known malware binaries or suspicious update scripts are running on targeted systems, especially those related to ViPNet services or files.
- file.modify.path (45% populated): File modification logs at specific paths related to the ViPNet software installation or configuration could indicate changes made by attackers to disable security features or deploy payloads.
