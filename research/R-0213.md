## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries often employ social engineering tactics to deceive employees into divulging sensitive information, commonly through phishing emails and other forms of communication. They exploit human behavior by creating realistic scenarios that trigger actions such as clicking on malicious links or attachments, thereby compromising the security posture of an organization.

### Key Findings
- Adversaries use sophisticated social engineering techniques to manipulate employees into performing unauthorized actions.
- Phishing attacks are prevalent and can be delivered through various channels including email, instant messaging, and phone calls.
- Regular simulated phishing tests help identify vulnerable individuals and measure the effectiveness of security awareness training.
- Employees often lack knowledge about common security risks such as identity-based attacks like pass-the-hash, which can lead to significant breaches if left unaddressed.

## 3. Telemetry Mapping: OCSF Fields

### Summary
To detect behaviors indicative of reduced human risk, focus on capturing telemetry related to network connections initiated by users, privilege escalations, process creations, and authentication failures. These logs will help identify anomalies such as suspicious login patterns or unexpected software installations.

### Key Fields
- User-Initiated Network Connections (80% populated): Monitors external IP addresses accessed by users, useful for detecting phishing activities.
- Privilege Escalation Events: Tracks user account creation and permission changes indicating potential unauthorized access attempts.
- Process Creation Logs (90% populated): Detailed logs of new processes on endpoints to identify malware execution or unusual software launches.
- User Authentication Failures: Records failed login attempts, crucial for identifying brute-force attacks targeting user credentials.
