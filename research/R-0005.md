## 1. System Research: How It Works

### Summary
Remote Desktop Protocol (RDP) is a proprietary protocol developed by Microsoft that allows users to access and control the desktop of a remote computer over a network connection. It typically requires authentication via user credentials, and attackers may exploit weak RDP configurations or compromised credentials for lateral movement within a network.

### Key Findings
- Attackers commonly use weak RDP configurations to perform lateral movement by accessing additional systems within a network with stolen or weak credentials.
- Implementing multi-factor authentication (MFA) and network segmentation can significantly reduce the risk of RDP-based lateral movement attacks.
- Organizations should monitor for unusual RDP activity, such as multiple login attempts from unfamiliar locations or times.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries exploit the Remote Desktop Protocol (RDP) technique T1021.001 to gain unauthorized access to systems by using valid account credentials, allowing them to remotely control system desktops and perform lateral movement within a network.

### Key Findings
- Adversaries leverage RDP with valid user accounts to move laterally across the network without detection.
- Once inside a system via RDP, adversaries can install additional malware or tools for deeper exploitation.
- RDP abuse is often accompanied by credential theft techniques like Pass-the-Hash (PtH) to gain access.
- Network monitoring and logging of RDP sessions are critical to detect suspicious activities early.
- Implementing multi-factor authentication (MFA) on RDP can significantly reduce the risk of unauthorized access.

## 3. Telemetry Mapping: OCSF Fields

### Summary
Telemetry for detecting Remote Desktop Protocol lateral movement (T1021.001) should focus on capturing remote logins via RDP and subsequent actions taken by the logged-in user. This includes monitoring of login events, process creation activities, network connections from/to RDP servers, and any unusual behavior that deviates from baseline activity.

### Key Fields
- event_id (90% populated): Security event logs containing specific Event IDs such as 4624 for successful logon attempts via RDP, 4778 for user rights management changes related to RDP access, and 4768 for account login events.
- process_name (85% populated): Tracks the creation of processes initiated by RDP logins, which might include remote shell or administrative tools invoked after a successful RDP session.
- network_protocol (95% populated): Identifies network connections established via Remote Desktop Protocol (TCP port 3389) to detect lateral movement across systems using RDP.
- user_id (70% populated): Monitors the user accounts logging into remote desktop sessions, helping identify if the logged-in users are valid or if there is any misuse of credentials.
