## 1. System Research: How It Works

### Summary
Open recursive DNS servers are designed to allow any client on the internet to query them for domain name resolution. This functionality is typically abused by malware to exfiltrate data by encoding sensitive information into DNS queries or using large volumes of requests to bypass network restrictions.

### Key Findings
- Malware often uses open recursive DNS servers because they provide an unfiltered channel to the internet, enabling data exfiltration without needing direct outbound connections from a compromised system.
- Data can be encoded within DNS query parameters and sent to malicious or controlled domains, allowing attackers to retrieve stolen information remotely.
- The use of DNS for exfiltration is difficult to block as it relies on common network protocols that are usually allowed through firewalls and other security measures.
