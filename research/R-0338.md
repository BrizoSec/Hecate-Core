This includes monitoring of specific event IDs from Windows Security Event Logs indicating user logon events (4624), process creation events (4688), and other security-relevant actions.

### Key Fields
- eventID: Indicates a particular Windows Security Event ID, such as 4624 for logon events or 4688 for process creations.
- processName: The name of the process that was created or modified (e.g., powershell.exe).
- parentProcessGuid: A unique identifier for the parent process of the suspicious activity.
- targetFilename: Indicates which files were targeted by the malicious activity, such as scripts or executables.
- networkConnection: Details of network connections made during an attack, including destination IP addresses and port numbers.
