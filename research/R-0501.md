## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries with privileged network access can conduct Adversary-in-the-Middle (AiTM) attacks to intercept and manipulate real-time network traffic, enabling them to block, log, modify, or inject data into communications. This technique is particularly concerning in ICS environments where it can lead to significant operational disruptions or safety hazards.

### Key Findings
- Adversaries use AiTM techniques such as ARP poisoning and proxy usage to intercept network traffic on both mobile and industrial control systems (ICS).
- AiTM attacks are facilitated by tools that exploit vulnerabilities in network configurations, allowing attackers to manipulate data flows and gain unauthorized access.
- Encrypting network traffic and ensuring devices run the latest operating system updates can mitigate AiTM risks by reducing interception opportunities.
- The Triton Safety Instrumented System Attack highlights a severe instance of AiTM abuse within ICS environments, illustrating potential safety threats from such attacks.
