## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries are increasingly leveraging advanced phishing tactics that incorporate AI to create more convincing and sophisticated attacks, targeting both users and identity systems. These tactics exploit the vulnerabilities in multi-factor authentication (MFA) processes and traditional security measures, emphasizing the need for phishing-resistant MFA solutions and zero-trust strategies.

### Key Findings
- Phishing attacks are evolving to use AI technologies that can personalize emails and web pages with high accuracy, making it harder for users to detect fraudulent content.
- Adversaries exploit identity supply chain weaknesses by compromising trusted systems like Microsoft Active Directory, leading to broader network access and control over organizational assets.
- Next-generation phishing tactics aim at bypassing traditional multi-factor authentication methods, underscoring the need for more robust MFA solutions that are resistant to AI-driven attacks.
- Attackers are adopting a multifaceted approach, combining social engineering with technical exploitation of identity systems to achieve deeper and prolonged access within targeted networks.

## 3. Telemetry Mapping: OCSF Fields

### Summary
To detect advanced phishing attacks that leverage social engineering and sophisticated delivery methods like malicious macros or fileless execution, relevant telemetry should include network traffic analysis, endpoint behavior monitoring, user activity tracking (particularly for web requests), and email content inspection.

### Key Fields
- network.http.request.method (95% populated): Tracks HTTP request methods used by endpoints. Suspicious patterns could indicate malicious web interactions or phishing attempts.
- endpoint.process.creation (80% populated): Monitors process creation events on endpoints, critical for identifying fileless malware execution and unusual application launches that may be part of a phishing attack payload.
- email.message.headers (65% populated): Inspects email headers to detect social engineering tactics such as spoofed sender addresses or urgent action prompts designed to bypass user caution.
- user.action.file_download (70% populated): Monitors file download activities, important for detecting scenarios where users might be tricked into downloading malicious payloads through phishing emails or web pages.
