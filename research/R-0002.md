## 1. System Research: How It Works

### Summary
ValleyRAT is a sophisticated Remote Access Trojan (RAT) that spreads by masquerading as adware or legitimate software. It operates entirely in memory, executing shellcode from the registry to load and run its payload without writing files to disk, making detection difficult.

### Key Findings
- ValleyRAT installs shortcut (.lnk) files like CompMgmtLauncher.lnk and eventvwr.lnk in user-writeable locations such as the Startup folder.
- The malware manipulates Windows registry keys to execute its payload from memory without leaving traces on the disk.
- Once executed, ValleyRAT employs reflective DLL injection techniques to load and run its malicious code directly into processes, avoiding traditional file-based detection methods.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
ValleyRAT is a sophisticated remote access Trojan (RAT) disguised as adware, primarily targeting Chinese-speaking users. It leverages tactics such as DLL hijacking and process injection to evade detection by security software.

### Key Findings
- ValleyRAT spreads through SEO poisoning campaigns that impersonate legitimate Microsoft Teams installations.
- The malware uses masquerading techniques, including the abuse of signed executables for payload delivery via DLL side-loading (T1574.002).
- Process injection is employed to maintain persistence and evade detection (T1055).
- ValleyRAT often arrives disguised as adware or other benign software during initial infection stages.
- The malware targets WPS Office executables for payload injection, exploiting vulnerabilities in the DLL search order.
- Detection methods include identifying suspicious certificate thumbprints and validating executable integrity.

## 3. Telemetry Mapping: OCSF Fields

### Summary
To detect ValleyRAT, which spreads disguised as adware, security telemetry should focus on identifying suspicious network connections, unusual process behaviors, and potentially malicious file activities. Key indicators include unexpected outbound connections to known malicious IP addresses or domains, execution of processes from non-standard locations such as temporary directories, and the presence of obfuscated or unusual executable files.

### Key Fields
- process_name (10% populated): Identifies specific executables that are commonly associated with ValleyRAT's infection mechanism, often running in conjunction with adware-like behaviors. This helps in early detection by correlating known bad binaries with network activities.
- network_connection (35% populated): Tracks unusual outbound connections from affected systems to IP addresses or domains linked to ValleyRAT's command and control servers or malicious download sites. Monitoring these connections is crucial for identifying exfiltration attempts and lateral movement within the network.
- file_create_event (20% populated): Detects file creation activities that are indicative of malware installation, such as the sudden appearance of executable files in temporary directories or downloads folders without user interaction.

- process_parent (20% populated): Identifies parent-child process relationships where suspicious executables spawn from legitimate but compromised processes, a common tactic used in adware and RAT infections to evade detection.
