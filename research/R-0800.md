## 1. System Research: How It Works

### Summary
PaperCut MF is a print management solution where the server application runs on a Java-based architecture, typically exposing web interfaces for user interaction and administration. In this specific incident, the legitimate Java loader functionality was abused via zero-day vulnerabilities to execute malicious payloads in memory and establish persistent access.

### Key Findings
- The primary exploitation vector involved two zero-day vulnerabilities (CVE-2026-82078 and CVE-2026-81578) affecting PaperCut MF version 24.0.2, allowing threat actors to deploy an in-memory Java loader that established a web shell.
- The malicious activity included the delivery of a trojanized Microsoft Copilot binary containing the AdaptixC2 implant, which connected to C2 infrastructure hosted on Alibaba servers (IP: 156.227.0.13).
- Post-exploitation behavior involved credential dumping from memory and registry, enabling Windows Restricted Admin mode for pass-the-hash attacks, and extracting the NTDS.dit database to achieve complete domain compromise.
- Indicators of Compromise include specific file hashes associated with trojan.loader/qwexlafiba (Java loader/web shell) and trojan.adaptixc2/malgent (C2 implant), as confirmed by VirusTotal and MISP incident 4990.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries exploited two zero-day vulnerabilities (CVE-2026-82078 and CVE-2026-81578) in PaperCut MF to deploy an in-memory Java loader and web shell, which delivered a trojanized Microsoft Copilot binary containing the AdaptixC2 implant. Following this initial access, attackers performed Active Directory enumeration, stole domain service account tokens, and achieved complete domain compromise by dumping credentials and extracting the NTDS.dit database from a compromised domain controller.

### Key Findings
- The intrusion leveraged two zero-day vulnerabilities in PaperCut MF version 24.0.2 to bypass initial defenses and establish a foothold on an internet-facing print server.
- Attackers utilized a trojanized Microsoft Copilot binary to deliver the AdaptixC2 implant, which communicated with command-and-control infrastructure hosted on Alibaba Cloud servers (IP: 156.227.0.13).
- Post-exploitation activities included a dormant period of approximately one day, followed by Active Directory enumeration and lateral movement to a domain controller using stolen tokens from a privileged service account.
- The attackers achieved full domain compromise by enabling Windows Restricted Admin mode for pass-the-hash attacks and extracting the NTDS.dit database containing password hashes for all domain accounts.
- Indicators of Compromise (IoCs) include specific file hashes associated with trojan loaders and web shells labeled 'qwexlafiba' and 'malgent', as well as CVEs 2026-81578, 2026-82078, 2026-88771, and 2026-88772.

## 5. Research Synthesis

### Executive Summary
Threat actors exploited CVE-2026-82078 and CVE-2026-81578 in PaperCut MF to deploy an in-memory Java loader and web shell, subsequently delivering a trojanized Microsoft Copilot binary hosting the AdaptixC2 implant connected to C2 infrastructure at 156.227.0.13. Post-exploitation activities included Active Directory enumeration, lateral movement via stolen service account tokens, and complete domain compromise through NTDS.dit extraction and Windows Restricted Admin mode activation.

### Recommended Hypothesis
> Adversaries use in-memory Java loaders and trojanized legitimate binaries to establish persistent web shells and deliver C2 implants on internet-facing PaperCut MF servers to achieve full domain compromise.

### Gaps Identified
- Standard endpoint telemetry may miss the initial in-memory Java loader execution if it lacks specific command-line or parent-process correlation for 'jakarta.java' or 'mscopilot.exe', while network detection fails to identify C2 traffic encrypted over standard ports to Alibaba Cloud ASN 149440.
