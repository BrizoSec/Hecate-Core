## 1. System Research: How It Works

### Summary
Legitimate ConnectWise ScreenConnect software functions as a remote access tool for IT administration, typically establishing persistent connections via standard protocols to authorized management servers. The malicious variant exploits this trust by masquerading as a holiday event invitation, using social engineering and fake CAPTCHA pages to trick users into executing the installer.

### Key Findings
- The payload is identified as 'ScreenConnect.ClientSetup.exe' (MD5: 739a54032b89432bb4c9c33969f6b383), a legitimate ConnectWise installer weaponized to deploy a Remote Access Trojan (RAT).
- The initial infection vector involves a fake invitation page hosted on the domain 'theinvitationestateco.vu', which redirects users through a fake CAPTCHA verification step before delivering the malicious executable.
- Post-execution, the RAT establishes an active remote connection indicated by an unassuming taskbar icon, leveraging legitimate software behavior to avoid detection.
- The campaign infrastructure includes payload delivery from IPs 104.21.73.121 and 172.67.162.73, with the primary C2 or download URL located at 'https://theinvitationestateco.vu/EdesktopInvite/RsvpNow/invitedetails.php'.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries are distributing a Remote Access Trojan (RAT) disguised as a legitimate ScreenConnect installer by exploiting holiday-themed phishing emails that redirect victims through fake CAPTCHA verification pages. The campaign leverages social engineering and domain impersonation to trick users into executing 'ScreenConnect.ClientSetup.exe', which establishes unauthorized remote access under the guise of an event invitation.

### Key Findings
- The attack vector relies on social engineering within legitimate-looking emails featuring generic subject lines about special gatherings, utilizing a fake CAPTCHA verification page hosted on the newly created domain 'theinvitationestateco.vu' to bypass user caution.
- The malicious payload is a weaponized version of the legitimate ConnectWise ScreenConnect installer, specifically named 'ScreenConnect.ClientSetup.exe', which delivers full remote access capabilities disguised as an eInvite file download.
- Indicators of Compromise include specific file hashes (MD5: 739a54032b89432bb4c9c33969f6b383; SHA256: f3aab811ae8163e09db40db201facc7e189d1a1b161be265202ca54b39b5e6cc) and infrastructure IPs (104.21.73.121, 172.67.162.73) associated with the payload distribution.
- The campaign demonstrates the abuse of trusted software by repurposing ScreenConnect.exe for malicious remote access, indicated by an unassuming taskbar icon that reveals an active connection to the attacker.
- External threat intelligence enrichment for the provided hashes returned negative or error results in VirusTotal and Abuse.ch (ThreatFox), suggesting the artifacts may be recent, ephemeral, or not yet widely indexed by public scanners.

## 5. Research Synthesis

### Executive Summary
Adversaries are deploying a weaponized ConnectWise ScreenConnect installer via holiday-themed phishing and fake CAPTCHA redirections to establish persistent remote access. The campaign leverages trusted software binaries and low-profile infrastructure (Cloudflare IPs) to evade initial detection, requiring specific endpoint and network telemetry analysis for identification.

### Recommended Hypothesis
> Adversaries use social engineering disguised as event invitations and fake CAPTCHA verification pages to trick users into executing a weaponized ScreenConnect.ClientSetup.exe installer for establishing unauthorized remote access.

### Gaps Identified

- Inability to distinguish between benign Cloudflare-hosted content (104.21.73.121, 172.67.162.73) and malicious payload delivery without correlating domain reputation or file hash telemetry against known threat intelligence feeds.
