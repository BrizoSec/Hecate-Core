## 1. System Research: How It Works

### Summary
This operation utilizes a malware builder named 'Underground' to deploy an Aotera/Tedy loader that evades analysis by checking for 67 monitoring tools. The loader injects a Vidar-class stealer into Windows processes, which then hijacks Chrome or Edge sessions to execute malicious scripts and drain cryptocurrency assets through fake overlays and clipboard manipulation.

### Key Findings
- The infrastructure relies on seven gate domains fronted by Cloudflare to facilitate rapid rotation of C2 domains, outpacing reputation-based detection systems.
- The attack chain involves trojanized lure archives that deploy a loader performing anti-analysis checks against 67 specific monitoring tools before establishing persistence.
- Crypto theft is executed via two primary methods: automated draining of exchange accounts through fake security overlays injected into browser sessions, and a clipboard clipper targeting approximately two dozen cryptocurrencies to replace copied wallet addresses.
- The operation has drained approximately $100,000 across 80+ destination addresses on 23 blockchain networks from 350-430 victims since October 2023.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries operate an underground malware builder named 'Underground' that deploys Aotera/Tedy loaders to inject Vidar-class stealers into browser processes, enabling the automatic drainage of cryptocurrency holdings. The operation utilizes fake security overlays, email modification, and clipboard hijacking to convert victim assets to Bitcoin and exfiltrate funds across multiple blockchain networks.

### Key Findings
- The attack infrastructure relies on a malware builder called 'Underground' active since October 2023, utilizing seven gate domains rotated behind Cloudflare to evade reputation-based detection faster than they can be flagged.
- Initial access is achieved via lure archives containing trojanized files that deploy an Aotera/Tedy loader performing anti-analysis checks against 67 specific monitoring tools before injecting the Vidar stealer into Windows processes.
- Once inside browser sessions (Chrome/Edge), the malware employs fake security overlays to drain exchange accounts, modifies withdrawal confirmation emails to prevent victim awareness, and automatically converts holdings to Bitcoin.
- A clipboard clipper component targets approximately two dozen cryptocurrencies by replacing copied wallet addresses with operator-controlled addresses, contributing to a total theft of ~$100,000 from 350-430 victims across 23 blockchain networks.
- Key indicators include the IPv4 address 95.164.53.76 and domains quick-neo.com and easybooters.com, with associated URLs pointing to logging endpoints such as http://95.164.53.76/new/log/048466C5/startCrypt.
