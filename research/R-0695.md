# R-0695: Malicious Twitch Browser Extension Exposes 30,000 Users' OAuth Tokens to Russian Bot Service Research

## 1. System Research: How It Works

### Summary
The 'Twitch Enhanced Viewer | JeetBot' browser extension captures live Twitch OAuth session tokens from the page's Authorization header and exfiltrates them to operator-controlled proxy infrastructure. This is achieved by appending the token as a cleartext `&auth=` query parameter in network-layer redirects of video playlist requests.

### Key Findings
- The extension uses content scripts to read the user's Twitch OAuth token from the `Authorization` header and passes it to the background worker, which validates the token against Twitch’s own endpoint to confirm its account-scoped nature.
- Exfiltration occurs via HTTP GET requests where the stolen token is embedded in the URL query string (`&auth=<token>`) of proxy redirects targeting domains like `enhanced.jeetbot.cc` and `proxy.morphilina.me`, leaving the credentials in server request logs.
- The malware maintains a hardcoded allowlist of ten specific Russian-language streamer channels to exempt from token theft, while capturing and forwarding credentials for all other watched channels.
- Legacy versions of the extension (v4.x) utilized POST requests to dedicated collection endpoints on `deno.dev` and `deno.net`, whereas current versions (v85.x) rely on inline query parameters during video playlist redirects.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries abused the legitimate software extension mechanism (T1176) by publishing a malicious browser plugin, 'Twitch Enhanced Viewer | JeetBot,' to major marketplaces to secretly extract users' live Twitch OAuth tokens. These credentials were exfiltrated via cleartext query parameters in network requests redirected through operator-controlled proxy infrastructure, granting the adversary unauthorized access to thousands of user accounts.

### Key Findings
- The extension 'Twitch Enhanced Viewer | JeetBot' compromised approximately 30,000 Chrome users and 552 Firefox users by masquerading as a quality-of-life tool for ad-blocking and region-unlocking.
- The malware exfiltrated account-scoped OAuth tokens (granting access to chat, whispers, and settings) rather than just narrow stream-playback tokens by reading the 'Authorization' header from the Twitch web client.
- Tokens were forwarded in cleartext as an '&auth=' query parameter within network-layer redirects to proxy servers hosted on infrastructure controlled by the Russian bot service JeetBot.
- The attack leveraged standard extension APIs, specifically content scripts for data capture and declarativeNetRequest (Chrome) or webRequest listeners (Firefox) for traffic redirection.
- The operator implemented a hardcoded allowlist that exempted ten specific Russian streamer channels from token exfiltration, indicating targeted operational security measures.
- Remediation involved stripping the auth-token parameters and hardcoding the auth argument to empty, though older extension versions continued to leak tokens until updated by users.

## 5. Research Synthesis

### Executive Summary
Adversaries leveraged the legitimate browser extension mechanism (T1176) via 'Twitch Enhanced Viewer | JeetBot' to exfiltrate account-scoped Twitch OAuth tokens from approximately 30,552 users by intercepting HTTP traffic through operator-controlled proxy infrastructure. The attack utilized content scripts to capture Authorization headers and modified network-layer redirects to embed stolen credentials in cleartext query parameters, bypassing standard encryption protections inherent in HTTPS by exposing data at the application layer log level.

### Recommended Hypothesis
> Adversaries use malicious browser extensions to intercept and exfiltrate authenticated session tokens via cleartext query parameters in proxied network requests to achieve unauthorized account access.

### Gaps Identified
- Lack of visibility into extension-specific HTTP header modifications (specifically the presence of 'auth' or 'Authorization' parameters in outbound proxy redirects) within standard endpoint telemetry, as HTTPS encryption blinds payload inspection to infrastructure logs unless specific extension APIs are monitored.

### Key Findings
- Hypothesis: Adversaries use malicious browser extensions to intercept and exfiltrate authenticated session tokens via cleartext query parameters in proxied network requests to achieve unauthorized account access.
- Gap: Lack of visibility into extension-specific HTTP header modifications (specifically the presence of 'auth' or 'Authorization' parameters in outbound proxy redirects) within standard endpoint telemetry, as HTTPS encryption blinds payload inspection to infrastructure logs unless specific extension APIs are monitored.
- Focus: Correlate browser process activity with outbound network connections to known proxy domains or those exhibiting regex substitution patterns typical of declarativeNetRequest rules, specifically looking for OAuth token structures in URL query strings.
- Focus: Monitor content script execution contexts and background worker memory states within Chromium/Firefox processes for the extraction of Authorization headers from Twitch client APIs, as a precursor to data exfiltration.
