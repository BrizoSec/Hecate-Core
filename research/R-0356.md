## 1. System Research: How It Works

### Summary
AiTM phishing campaigns intercept user credentials and session cookies during login attempts to bypass multi-factor authentication (MFA), allowing attackers to impersonate legitimate users. These campaigns often use sophisticated kits like Tycoon2FA, which mimic trusted sign-in pages to relay MFA codes entered by victims.

### Key Findings
- AiTM phishing leverages user sessions and cookies to persist access beyond initial login credentials theft.
- Sophisticated phishing kits can impersonate legitimate brand sign-in pages with high fidelity, tricking users into entering their MFA codes directly.
- Attackers use intercepted session tokens or cookies to maintain persistent access even when MFA is enabled.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries are leveraging an Adversary-in-the-Middle (AiTM) technique to intercept and manipulate network traffic between users and legitimate websites, particularly focusing on procurement-themed phishing campaigns. This enables them to capture credentials and session data for further exploitation.

### Key Findings
- Evilginx2 is a commonly used tool by adversaries to perform AiTM attacks, enabling interception of user credentials and session tokens.
- Adversaries are targeting high-value assets such as procurement systems where the impact of credential theft can be substantial.
- CloudTrail logs and S3 buckets in AWS environments are potential data sources for detecting anomalies indicative of AiTM activities.
- Real-time network traffic modification is a critical phase in AiTM attacks, often used to manipulate legitimate communications between parties.
- The use of phishing emails with procurement themes helps adversaries lure victims into clicking on malicious links that lead to AiTM interception points.

## 5. Research Synthesis

### Executive Summary
Adversaries are employing sophisticated AiTM phishing techniques, particularly targeting procurement systems, to intercept user credentials and session cookies. They utilize tools like Evilginx2 and Tycoon2FA to mimic legitimate sign-in pages with high fidelity, capturing MFA codes and maintaining persistent access.

### Recommended Hypothesis
> Adversaries use AiTM techniques to deploy multi-stage malware on procurement systems by intercepting user credentials and session cookies through sophisticated phishing kits like Evilginx2 and Tycoon2FA.

### Gaps Identified
- There is a lack of detailed telemetry data for real-time network traffic modifications, which could help in detecting the critical phase of AiTM attacks where legitimate communications are manipulated.
- Current coverage does not fully address cloud environment monitoring (e.g., AWS CloudTrail logs) to detect anomalies indicative of AiTM activities, especially concerning procurement systems.

### Key Findings
- Hypothesis: Adversaries use AiTM techniques to deploy multi-stage malware on procurement systems by intercepting user credentials and session cookies through sophisticated phishing kits like Evilginx2 and Tycoon2FA.
- Gap: There is a lack of detailed telemetry data for real-time network traffic modifications, which could help in detecting the critical phase of AiTM attacks where legitimate communications are manipulated.
- Gap: Current coverage does not fully address cloud environment monitoring (e.g., AWS CloudTrail logs) to detect anomalies indicative of AiTM activities, especially concerning procurement systems.
- Focus: Enhance real-time network traffic analysis tools to capture and analyze data during the manipulation phase of AiTM attacks.
- Focus: Expand telemetry collection to include detailed monitoring of cloud environments, particularly for signs of AiTM activity targeting procurement-related services.
