## 1. System Research: How It Works

### Summary
Kernel debugging tools like kgdb and kdb allow developers and security researchers to debug the Linux kernel in real-time or via a serial interface. These tools provide detailed insights into kernel operations, helping identify and fix issues related to system stability, performance, and security.

### Key Findings
- kgdb uses a secondary machine as a debugger for the primary machine running the Linux kernel, allowing for remote debugging capabilities.
- kdb is an in-kernel debugger that can be directly invoked when certain conditions are met (e.g., panic), providing immediate access to kernel state at the moment of failure or during normal operation.
- Both kgdb and kdb offer extensive command sets and views into memory, processes, and hardware states, which are crucial for understanding complex system behaviors.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries exploit non-standard ports to evade detection by security systems that monitor only standard communication channels, such as using HTTPS over port 8088 instead of the traditional port 443. This technique enables them to establish covert communication and conduct AiTM (adversary-in-the-middle) attacks to intercept and modify network traffic.

### Key Findings
- Adversaries often use non-standard ports to bypass detection mechanisms, such as HTTPS on port 8088 instead of the standard port 443.
- AiTM (adversary-in-the-middle) attacks are used by adversaries with privileged access to modify network traffic in real time.
- Akira and other threat actors have accessed sensitive information from SharePoint repositories, indicating a common target for data exfiltration.
- CrowdStrike's Adversary OverWatch detects and mitigates stealthy threats across various environments using next-gen SIEM (Security Information and Event Management) technology.

## 3. Telemetry Mapping: OCSF Fields

### Summary
Telemetry for detecting attack behaviors related to significant data breaches would include monitoring of user and system activities that indicate potential unauthorized access, lateral movement, or data exfiltration. Key areas of focus are authentication events, network traffic anomalies, and process behavior on endpoints.

### Key Fields
- user_auth_success (90% populated): Tracks successful logins which can help identify anomalous login patterns or multiple failed attempts followed by a success indicating potential brute force attacks.
- network_events: Monitors outgoing connections that could be indicative of data exfiltration, especially focusing on large volumes of data being sent to suspicious IP addresses.
- process_creation (85% populated): Captures the creation and execution of processes which can help detect unusual or malicious binaries running on endpoints.
- file_modification (70% populated): Tracks changes to sensitive files or directories that could indicate unauthorized access, such as modifications to configuration files or exfiltration attempts.
