## 1. System Research: How It Works

### Summary
npm (Node Package Manager) is a popular package manager for JavaScript and Node.js projects, which allows developers to install, share, and reuse code within their applications. The ecosystem relies on trust among maintainers to ensure the integrity of packages and their installation scripts.

### Key Findings
- npm packages are regularly updated by maintainers, who can introduce new versions or modify existing ones via preinstall hooks.
- Attackers exploit npm's trust model and package dependency structure to inject malicious code during the preinstallation phase of a vulnerable package.
- Malware like Shai Hulud leverages obfuscated scripts to steal credentials and propagate across other dependent packages, potentially affecting hundreds of projects.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
The Shai-Hulud campaign has returned in August 2026, utilizing the CHAINDROP worm to compromise npm packages by first gaining control of a maintainer's credentials for keyv. This allowed the attackers to deploy malware across more than 400 packages, highlighting ongoing risks in supply chain attacks on JavaScript package managers.

### Key Findings
- Attackers compromised the keyv maintainer’s account and used stolen credentials to propagate CHAINDROP worm.
- The CHAINDROP worm targeted over 400 npm packages post-compromising keyv maintainer, affecting a wide range of standalone packages maintained by the same accounts.
- Malware was executed during preinstall phases via scripts like setup_bun.js, dropping obfuscated payloads that are hard to detect and analyze.
- Immediate credential rotation is advised for npm users after such supply chain attacks.

## 5. Research Synthesis

### Executive Summary
The Shai Hulud campaign, which compromised npm packages through the keyv maintainer's credentials, has re-emerged in August 2026, spreading CHAINDROP malware across over 400 packages. The attackers exploit preinstall hooks to inject obfuscated scripts that steal credentials and propagate within affected projects.

### Recommended Hypothesis
> Adversaries use compromised npm maintainer accounts to deploy the CHAINDROP worm via preinstall hooks, targeting a wide range of dependent packages to distribute malware and exfiltrate data.

### Gaps Identified
- Current telemetry lacks comprehensive coverage for identifying obfuscated payloads executed during the preinstallation phase of affected packages.
- There is insufficient monitoring in place to detect unusual outbound network traffic indicative of command-and-control communications or data exfiltration attempts from compromised npm installations.

### Key Findings
- Hypothesis: Adversaries use compromised npm maintainer accounts to deploy the CHAINDROP worm via preinstall hooks, targeting a wide range of dependent packages to distribute malware and exfiltrate data.
- Gap: Current telemetry lacks comprehensive coverage for identifying obfuscated payloads executed during the preinstallation phase of affected packages.
- Gap: There is insufficient monitoring in place to detect unusual outbound network traffic indicative of command-and-control communications or data exfiltration attempts from compromised npm installations.
- Focus: Enhance detection capabilities by focusing on process execution and file creation events related to npm installations, especially during the preinstall phase.
- Focus: Increase visibility into network activity initiated by npm-related processes to capture any unusual outbound connections that may indicate malicious behavior.
