## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries in the network environment often employ Adversary-in-the-Middle (AiTM) attacks by leveraging privileged access to manipulate real-time network traffic, allowing them to intercept and alter data exchanges between entities without detection. This technique is particularly concerning for Industrial Control Systems (ICS) due to their critical infrastructure nature.

### Key Findings
- AI-driven social engineering and phishing attacks are becoming more sophisticated through the use of machine learning algorithms that can personalize content and evade traditional security measures.
- Ransomware continues to be a significant threat, with attackers increasingly using AI to enhance evasion techniques and improve targeting precision.
- Adversaries exploit network vulnerabilities by deploying AiTM attacks in ICS environments, which are critical for infrastructure control but may lack robust cybersecurity protocols.
- Mitigation strategies must evolve to incorporate AI-driven defense mechanisms that can counteract the sophisticated nature of modern cyber threats.

## 3. Telemetry Mapping: OCSF Fields

### Summary
Malware execution is detected through process creation events, network connections initiated from suspicious binaries, and file access/modification patterns.

### Key Fields
- process.name (50% populated): The name of the executable or script that was launched which may be a common malware binary indicator.
- network.destination.ip_address (30% populated): The IP address to which the process is attempting to connect, often associated with known malicious domains or C2 servers.
- file.path (60% populated): The path where suspicious files were created or modified, indicating potential malware installation or data exfiltration.
- process.parent_pid (45% populated): The parent process ID that spawned the suspicious child process, helping to trace back to initial infection vectors.
