## 1. System Research: How It Works

### Summary
The system utilizes Cross-Project Search (CPS) to allow a central Elastic Security project to query telemetry from up to 100 linked projects without moving data, thereby preserving tenant isolation. Detection rules are executed exclusively on the origin project to prevent duplicate alerts, while Kibana interfaces maintain distinct space names for each linked project.

### Key Findings
- Centralized alert triage is achieved by linking one Elastic Security 'origin' project to multiple other projects, enabling a single view for SOC operations without data migration or tenant isolation breaches.
- To ensure data integrity and avoid confusion from duplicate alerts, all detection rule execution is strictly confined to the origin project rather than being split across linked projects.
- The architecture employs metadata tagging at the time of linking and constructs hunting queries based on this metadata to filter and organize results across the distributed environment.
