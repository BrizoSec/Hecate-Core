## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries, such as the OilRig group, abuse system network connections and automated collection techniques to deploy advanced malware like NeedleStealer and ISMInjector. These tools enable them to exfiltrate sensitive data while remaining undetected through sophisticated obfuscation and encryption methods.

### Key Findings
- OilRig uses new delivery documents and injector Trojans, such as ISMInjector, to inject payloads into processes using obfuscation techniques.
- NeedleStealer automates the collection of files for exfiltration by exploiting system features, making it difficult to detect and mitigate.
- Adversaries like OilRig leverage encrypted channels through asymmetric cryptography to securely communicate with command-and-control servers.
- Automated data collection methods are employed by adversaries to gather personally identifiable information from SQL databases using custom tools.
