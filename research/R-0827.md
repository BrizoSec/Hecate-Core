### Summary

Under normal circumstances, it executes standard installation scripts to configure its environment without persisting system-level tasks or exfiltrating sensitive credentials.

### Key Findings

- Legitimate operations of the TensorLake SDK do not involve creating Windows scheduled tasks (such as 'ONLOGON' running monitor.ps1) or establishing persistence mechanisms like the 'gh-token-monitor' service.
- Under normal functionality, the application does not poll external APIs such as api.github.com/user for token validity checks, nor does it harvest npm tokens, GitHub tokens, AWS credentials, or SSH keys from the host system.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
The Shai-Hulud adversary compromised the TensorLake npm SDK (v0.5.144) via a supply chain attack, injecting obfuscated payloads that harvest credentials from diverse environments including cloud providers and AI development tools. The malware employs a worm-like propagation mechanism by republishing itself to other packages under the victim's identity, while maintaining persistence through scheduled tasks and using Ethereum contracts for command-and-control resolution.

### Key Findings
- The attack utilizes a preinstall hook in package/lib/setup.mjs (SHA-256: 25a0735d0db7dc40e5d45ce42d9c106067e6a66e184d967cfecfab17c3bcb5ef) to invoke an obfuscated loader that executes the payload using Bun.
- The core malicious payload resides in package/lib/Math_Symbol.js (SHA-256: b50a00900399ba99fb6ce1fc151519cb99d44320ef2a631f2237e1aea0ad6fec), which functions as a credential-stealing worm capable of harvesting npm, GitHub, AWS, HashiCorp Vault, Kubernetes, SSH, and AI tool credentials.
- Self-propagation is achieved by the malware republishing compromised versions to other packages associated with the victim's publishing identity, extending the infection across the npm ecosystem.
- The adversary implements a 'dead-man switch' that monitors stolen GitHub tokens via api.github.com/user; if a token is revoked, it triggers destructive actions to prevent detection or forensic analysis.
- Persistence is maintained through Windows scheduled tasks (specifically an ONLOGON task running monitor.ps1) and the gh-token-monitor service, which can be stopped and deleted to mitigate the attack.

## 5. Research Synthesis

### Executive Summary
The TensorLake npm SDK v0.5.144 has been compromised by the Shai-Hulud adversary, injecting a worm-like payload via `preinstall` hooks that harvests credentials from cloud and development environments while establishing persistence through Windows scheduled tasks and Ethereum-based C2 resolution. Detection requires correlating specific file drops in npm cache directories with anomalous process spawning and outbound network connections to GitHub APIs and blockchain explorers.

### Recommended Hypothesis
> Adversaries use obfuscated npm package hooks and credential-stealing scripts to establish persistence via scheduled tasks and exfiltrate sensitive infrastructure secrets on compromised build environments.

### Gaps Identified
- Lack of visibility into `preinstall` hook execution contexts prevents detection of the initial loader invocation, while standard network monitoring often misses encrypted Ethereum transaction traffic used for C2 resolution.
- Endpoint detection systems typically do not correlate npm cache file artifacts (setup.mjs/Math_Symbol.js) with subsequent persistence mechanisms like `schtasks.exe` creation or GitHub API polling behaviors.
