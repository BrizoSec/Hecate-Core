## 1. System Research: How It Works

### Summary
AvisLoader is a Windows malware loader that utilizes the Tox encrypted peer-to-peer messaging network for command-and-control communications, allowing operators to maintain control by shifting infrastructure without updating client configurations. The infection begins with a ClickFix social engineering lure delivered via Cloudflare, which tricks users into executing malicious commands that establish the initial foothold.

### Key Findings
- The malware communicates over the Tox network (via statically linked c-toxcore), eliminating reliance on fixed domains or centralized servers and complicating traditional takedown efforts.
- Delivery relies on a ClickFix lure hosted on Cloudflare Workers, impersonating a DocuSign verification process to trick users into pasting and executing commands that download code from trycloudflare.com.
- The loader employs persistence by modifying desktop and taskbar shortcuts, using a helper named VLCAssistant and auto.exe to launch the malware while masquerading as legitimate applications like VLC.
- Stealth capabilities include hmn_hook.dll, which hooks NtQuerySystemInformation to filter specific process names from system information queries, potentially hiding the malware's presence.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries abuse the Malicious Copy and Paste technique (T1204.004) through 'ClickFix' social engineering, where victims are tricked into copying and executing malicious commands disguised as document verification steps. This method allows attackers to bypass traditional file download defenses by leveraging trusted infrastructure like Cloudflare to deliver payloads directly via the command line.

### Key Findings
- AvisLoader utilizes a ClickFix lure mimicking DocuSign verification prompts hosted on Cloudflare Workers, instructing users to paste commands into terminals or the Windows Run dialog to execute code from trycloudflare.com addresses.
- The malware employs the Tox encrypted peer-to-peer messaging network for Command and Control (C2), enabling operators to maintain control by transferring a Tox save file rather than relying on fixed domain infrastructure susceptible to takedowns.
- Payload delivery involves a 3.4 MB Windows executable that masquerades as packed files using names associated with Themida, VMProtect, Enigma, and UPX to confuse identification, while statically linking the c-toxcore library.
- Persistence is achieved by modifying desktop and taskbar shortcuts (T1547.009) and backing up legitimate application shortcuts, such as those for VLC, to launch the malware when the user attempts to open the intended application.
- The loader includes helper tools like auto.exe, which references UACME method 41 to attempt User Account Control bypass via the ICMLuaUtil COM interface, and hmn_hook.dll to hide processes by hooking NtQuerySystemInformation.

This behavior is captured by telemetry watching for suspicious command-line arguments invoking remote code execution (often from Cloudflare domains), process creation events where a script interpreter or shell launches network-bound executables, and subsequent file system activity such as the creation or modification of shortcuts in user directories.

## 5. Research Synthesis

### Executive Summary
AvisLoader leverages ClickFix social engineering to force users to paste and execute commands that download payloads from Cloudflare infrastructure, establishing C2 via the Tox P2P network to evade traditional domain-based takedowns. The loader employs stealth mechanisms including UAC bypass helpers, process-hiding DLLs, and shortcut persistence to maintain access while masking its activity.

### Recommended Hypothesis
> Adversaries use malicious copy-paste commands disguised as document verification steps to execute remote code from Cloudflare domains, subsequently establishing persistent C2 via the Tox encrypted P2P network on Windows endpoints.

### Gaps Identified
- Standard EDR telemetry often fails to detect the initial T1204.004 execution if the pasted command is short or obscured within standard shell context, and lacks visibility into the parent-child relationship between the user's browser session and the spawned interpreter.
- Network detection systems typically cannot inspect the payload content of Tox traffic due to its end-to-end encryption, creating a blind spot for C2 commands and exfiltrated data despite the presence of the protocol itself.

### Key Findings
- Hypothesis: Adversaries use malicious copy-paste commands disguised as document verification steps to execute remote code from Cloudflare domains, subsequently establishing persistent C2 via the Tox encrypted P2P network on Windows endpoints.
- Gap: Standard EDR telemetry often fails to detect the initial T1204.004 execution if the pasted command is short or obscured within standard shell context, and lacks visibility into the parent-child relationship between the user's browser session and the spawned interpreter.
- Gap: Network detection systems typically cannot inspect the payload content of Tox traffic due to its end-to-end encryption, creating a blind spot for C2 commands and exfiltrated data despite the presence of the protocol itself.
- Focus: Hunt for unusual child processes spawned from cmd.exe or PowerShell.exe that contain URLs pointing to trycloudflare.com or workers.dev, specifically looking for code retrieval patterns typical of ClickFix lures.
- Focus: Monitor for the creation or modification of shortcuts in Desktop and Taskbar directories (T1547.009) that reference known UAC bypass helpers like 'auto.exe' or process-hiding DLLs such as 'hmn_hook.dll', indicating post-execution persistence attempts.
