### Summary
LabubaRAT is a custom, unsigned 64-bit Rust-based remote access trojan that masquerades as legitimate NVIDIA software on Windows systems. It provides operators with comprehensive file management functions and persists by disguising itself under trusted NVIDIA names.

- Provides file management capabilities, including uploading, downloading, deleting files, creating directories, and compressing or extracting archives

## 2. Adversary Tradecraft: Attack Techniques

### Summary
LabubaRAT is a custom remote access trojan developed in Rust that masquerades as legitimate NVIDIA software to infiltrate Windows systems. It provides adversaries with comprehensive remote control capabilities and uses multiple communication methods, including HTTPS, WebView2, and DNS tunneling.

### Key Findings
- LabubaRAT disguises itself as a legitimate NVIDIA executable named 'nvidia-sysruntime.exe'.
- It leverages Rust programming language to create a custom, unsigned binary that provides remote access capabilities without hardcoding C2 server details.
- The malware supports various communication channels such as HTTPS, WebView2, and DNS tunneling for maintaining persistence and evading detection.
- First observed in July 2026, LabubaRAT targets Windows systems by masquerading as legitimate software to evade security measures.
