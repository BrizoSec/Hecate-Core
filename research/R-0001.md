## 1. System Research: How It Works

### Summary
ValleyRAT is malware disguised as adware that installs itself on Windows systems and uses scheduled tasks and scripts to maintain persistence. Removal often requires manual intervention beyond typical antivirus scans.

### Key Findings
- ValleyRAT disguises its presence as legitimate adware, making detection challenging.
- The malware reinstalls via scheduled tasks and maintains persistence through script execution.
- Effective removal may require running specialized tools like Windows Defender Offline and using FRST64 to clean up startup entries and scheduled tasks.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
ValleyRAT is a sophisticated malware that spreads through phishing emails disguised as tax notifications, primarily targeting organizations in Russia and India. It uses a Rust-based loader to deliver the malware payload along with a new backdoor named ABCDoor.

### Key Findings
- ValleyRAT spreads via phishing emails masquerading as legitimate tax notifications.
- The malware employs a Rust-based loader to execute its payload, indicating advanced coding and evasion capabilities.
- A novel backdoor component called ABCDoor is utilized by ValleyRAT to maintain persistence and exfiltrate data from compromised systems.
- Targeted organizations in Russia and India suggest geopolitical motives or operational efficiency for the attackers.

## 3. Telemetry Mapping: OCSF Fields

### Summary
ValleyRAT is an advanced RAT (Remote Access Trojan) spreading disguised as adware, which typically involves suspicious network activities, unauthorized modifications to system files, and attempts to evade detection. Telemetry should focus on detecting unexpected changes in the system's registry, file system operations by unknown executables, network connections established with C2 servers, and unusual process activity.

### Key Fields
- process_name (90% populated): Identifies executable names of processes that do not match known good binaries. ValleyRAT may use common adware filenames to blend in, but process monitoring can detect deviations from baseline behavior.
- file_change_event (85% populated): Tracks file creation, modification, or deletion events which could indicate malicious activities such as creating or modifying executables, configuration files, or registry keys.
- network_connection (92% populated): Monitors network connections initiated by suspicious processes to identify communication with command and control servers. ValleyRAT may establish outbound connections on non-standard ports or use domain generation algorithms.
- registry_change_event (75% populated): Detects modifications in the Windows Registry that are not part of normal software installation routines, such as creation of new keys or values indicative of malware persistence mechanisms.
- dns_query (80% populated): Tracks DNS requests made by suspicious processes to identify attempts at domain generation or querying for known malicious domains.
- process_parent (70% populated): Identifies the parent process responsible for spawning a child process. ValleyRAT may be dropped and executed by other malware or scripts, making it crucial to trace back to initial infection vectors.
