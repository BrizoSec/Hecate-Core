## 1. System Research: How It Works

### Summary
XMRig is an open-source Monero (XMR) miner that can be configured to mine other cryptocurrencies as well. It operates by being installed on compromised systems, typically through exploitation of vulnerabilities or social engineering tactics, and uses the system's computational resources to generate cryptocurrency for the attacker.

### Key Findings
- XMRig is primarily used for mining Monero but can also target other Proof-of-Work (PoW) cryptocurrencies.
- The malware often deploys stealth techniques to avoid detection by security solutions and minimize its impact on system performance.
- In recent campaigns, XMRig has been observed leveraging trusted access mechanisms within networks to gain deeper infiltration.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries often use the T1027 Obfuscated Files or Information technique to deploy cryptominers like XMRig covertly, which involves encoding payloads to evade detection and using trusted access mechanisms. This strategy leverages compromised systems to execute secondary malicious payloads.

### Key Findings
- XMRig uses obfuscation techniques such as encryption or compression of payload files to avoid detection by security tools.
- Abuse of legitimate system utilities like modprobe for enabling write access to Model Specific Registers (MSRs) is employed to facilitate the cryptomining process.
- Indicators of compromise include specific hash values of XMRig binaries and unusual process names such as 'kswapd0'.
- Trusted access mechanisms are exploited, indicating a sophisticated approach to gaining initial footholds within networks.

## 5. Research Synthesis

### Executive Summary
XMRig is a sophisticated cryptominer that leverages trusted access mechanisms and employs obfuscation techniques to avoid detection. It uses encryption, compression, or encoding of payloads to evade security tools while deploying via compromised systems within networks.

### Recommended Hypothesis
> Adversaries use obfuscated files or information (T1027) to deploy XMRig covertly and establish persistent mining operations on compromised hosts with trusted access.
