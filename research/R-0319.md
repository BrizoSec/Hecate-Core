## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries with privileged network access abuse the Adversary-in-the-Middle (AiTM) technique by intercepting and modifying real-time network traffic, which can be used to manipulate data flows, inject malicious content, or redirect communications to attacker-controlled servers.

### Key Findings
- ARP poisoning is a common method used in AiTM attacks to redirect traffic through the attacker's machine.
- Attacker tools often include custom scripts and software for ARP spoofing, DNS manipulation, and packet injection.
- Indicators of compromise (IOCs) such as unusual DNS requests, unexpected ARP table changes, and unauthorized network proxy connections are critical signs of AiTM activity.
- ThreatFox shares timely IOCs to help detect and mitigate AiTM threats by providing real-time updates on suspicious IP addresses and domain names.
