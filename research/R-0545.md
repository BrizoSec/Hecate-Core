## 1. System Research: How It Works

### Summary
AsyncAPI is an open-source specification for defining asynchronous APIs (like MQTT, WebSockets, gRPC), allowing developers to describe and document their systems in a machine-readable format. The npm supply chain typically involves developers importing various modules from a public repository where packages are trusted based on community contributions and maintenance history.

### Key Findings
- AsyncAPI specifications help in creating clear documentation for asynchronous API interactions, facilitating better integration between different services.
- In the context of npm (Node Package Manager), package integrity and security heavily rely on developer practices such as regular updates, dependency audits, and use of trusted sources.
- Import-time payload delivery refers to when a malicious or compromised module executes its payload upon being imported by another application, which is a common tactic in supply chain attacks.
