## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries exploit the CitrixBleed 2 vulnerability (CVE-2025-5777) to gain unauthorized access to Citrix systems, subsequently leveraging downgrade attacks and lateral movement techniques to propagate within a network. This often leads to the deployment of Dragonforce Ransomware, which encrypts critical data and demands ransom payments from victims.

### Key Findings
- Adversaries use adversary-in-the-middle (AiTM) attacks to intercept and manipulate network traffic in real-time after exploiting CitrixBleed 2.
- Exploitation of the PrintNightmare vulnerability is observed, with adversaries using WMIEXEC.py via proxychains for lateral movement within networks.
- Dragonforce Ransomware employs downgrade attack techniques to weaken security measures and facilitate unauthorized access to systems.
- Command-line tools like CMD.exe and PowerShell scripts are utilized by attackers to execute malicious actions such as file encryption and credential harvesting.
