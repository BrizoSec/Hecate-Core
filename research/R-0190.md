## 1. System Research: How It Works

### Summary
Code signing is a security measure used by operating systems such as macOS and Windows to verify the authenticity of software applications. It involves digitally signing an application with a trusted certificate, which helps ensure that the software has not been tampered with and comes from a known, legitimate source. Malware like Vidar Stealer can abuse this system by obtaining code signing certificates through various means or exploiting vulnerabilities in the process to sign malicious binaries as legitimate.

### Key Findings
- Malware developers obtain or exploit trusted digital signatures to masquerade their malicious applications as legitimate software from reputable sources.
- Code signing is used by Vidar Stealer and similar malware to evade detection by security software that relies on signature verification for threat identification.
- Techniques such as file inflation (increasing the size of files) are employed by Vidar Stealer to make analysis more difficult, potentially confusing automated tools into ignoring or misclassifying suspicious binaries.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries are abusing code signing to legitimize Vidar Stealer, using reflective code loading and file inflation techniques to evade detection mechanisms. These methods make it challenging for traditional security solutions to detect and block the malware.

### Key Findings
- Vidar Stealer exploits legitimate code signing certificates to masquerade as trusted software, thereby bypassing common signature-based defenses.
- Reflective code loading is employed by Vidar Stealer to execute its malicious payload directly in memory without writing it to disk, thus avoiding file system and network-based detection mechanisms.
- File inflation tactics are utilized by adversaries to inflate the size of malware files, making them appear less suspicious and harder for security systems to analyze efficiently.
- The rise of Vidar Stealer highlights a shift from declining threats like LummaC2 and Rhadamanthys, indicating an ongoing evolution in adversary tactics to evade detection.
