## 1. System Research: How It Works

### Summary
MISP is an open-source threat intelligence platform designed to facilitate the sharing of indicators of compromise (IOCs) among organizations. It allows entities like Krawczyk Industries Limited to share and consume IOCs in real-time, enhancing their security posture by providing timely threat information.

### Key Findings
- The `feed_name` attribute for MISP logs is typically set to the value of `event_source_org`, or defaults to `MISP` if this field is empty.
- IP addresses and ports within MISP logs are mapped based on specific fields such as `ip_address` and `ports`, ensuring that network-related IOCs can be effectively analyzed.
- URLs in MISP logs are automatically mapped when the attribute type is designated as `uri` or `URL`, aiding in the identification of malicious web activity.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries employed the pass-the-hash (PtH) technique to gain unauthorized access to Krawczyk Industries Limited's network, leveraging Mimikatz to extract NTLM hashes from compromised systems. This method allows attackers to authenticate to services and resources without knowing user passwords.

### Key Findings
- Pass-the-Hash attack was utilized to escalate privileges within the network by using stolen NTLM hashes.
- Mimikatz tool was used to steal NTLM authentication credentials, compromising system integrity.
- The medium threat level indicates a significant impact on Krawczyk Industries Limited's security posture but not an immediate critical risk.
- Monitoring for suspicious activities related to hash extraction and credential misuse is crucial in mitigating PtH attacks.
