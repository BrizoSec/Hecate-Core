## 1. System Research: How It Works

### Summary
The described system utilizes a sensor script to parse TTY logs generated by user interactions on honeypot systems, correlating command execution hashes with actor IP addresses. This telemetry is transmitted daily to a SIEM for analysis, revealing that identical malicious behaviors (specifically crontab configurations) are executed by thousands of distinct actors across diverse global networks.

### Key Findings
- TTY logs from compromised or honeypot systems are parsed into hashes and correlated with specific transaction IDs to identify repeated attack patterns across different actors over a 90-day period.
- A single transaction hash (f904275333aeac48d7df6cf53fe5fb9212c7d132a7d37253d2ab9321ba2690d8) corresponds to identical crontab commands executed by more than 3,130 unique IP addresses.
- Threat intelligence enrichment indicates these actors originate from residential and mobile ISP networks in regions including Nigeria, Vietnam, Iraq, and the United States.
- The telemetry pipeline integrates data from Cowrie honeypot events into Elasticsearch using ES|QL for statistical analysis of event hashes and transaction identifiers.

This behavior indicates widespread automated infrastructure leveraging residential and mobile ISP networks across Nigeria, Vietnam, Iraq, and the US to maintain footholds post-exploitation.

### Recommended Hypothesis
