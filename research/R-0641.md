## 1. System Research: How It Works

### Summary
KREMLIN malware bypasses standard Chromium integrity checks by manually injecting its malicious extension into the browser's profile directories and forging the associated HMACs and encrypted hashes within the `Secure Preferences` file. This technique allows the malware to operate as a legitimate, installed extension without user approval or publisher signatures, enabling it to steal live banking session cookies.

### Key Findings
- KREMLIN forges Chrome/Edge integrity checks by manually copying the extension into profile directories and regenerating the required HMACs and encrypted hashes in the `Secure Preferences` file to satisfy Chromium's verification mechanisms.
- The malware evades detection by sideloading its unsigned main payload through a legitimate SentinelOne binary, impersonating the file 'SentinelAgentCore.dll'.
- KREMLIN performs sandbox and virtual machine evasion by scanning running processes and checking specific machine hardware properties before executing its payload.
- Rather than stealing credentials alone, KREMLIN targets live session cookies to allow attackers to reuse authenticated banking sessions without triggering login or MFA challenges.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
The KREMLIN adversary group abuses a vulnerability in Chromium-based browsers by forging Chrome's native integrity checks, allowing them to install and operate malicious browser extensions without user consent or legitimate verification. This technique enables the theft of authenticated banking sessions via live cookies, bypassing multi-factor authentication protections.

### Key Findings
- Adversaries forged Chrome's own integrity checks to verify malicious code, effectively tricking the browser into trusting unauthorized extensions that the user never approved.
- The KREMLIN group operated across seven distinct campaigns over a period of 15 months, primarily targeting Brazilian banks.
- Attackers utilized Ethereum smart contracts to host Command and Control (C2) configuration data for the malicious extension.
- The malware steals live session cookies rather than just credentials, allowing attackers to reuse authenticated sessions and bypass multi-factor authentication.
- The malicious extension monitors internet browsing activity and redirects users to fake websites to facilitate credential theft.

## 5. Research Synthesis

### Executive Summary
The KREMLIN threat group bypasses Chromium integrity checks by manually injecting malicious extensions and forging HMACs in the `Secure Preferences` file, enabling silent persistence and live session cookie theft. This technique allows attackers to impersonate legitimate installed extensions and bypass MFA protections by reusing authenticated banking sessions via Ethereum-based C2 configurations.

### Recommended Hypothesis
> Adversaries use forged Chromium integrity checks and manual profile injection to silently install malicious browser extensions for stealing live banking session cookies on Windows endpoints

### Gaps Identified
- Current telemetry lacks visibility into `Secure Preferences` file modifications (specifically HMAC/encrypted hash regeneration) which is the critical persistence mechanism, as standard endpoint sensors often ignore internal configuration files unless explicitly monitored.
- Standard process monitoring fails to detect the initial loader because the malware utilizes a legitimate SentinelOne binary (`SentinelAgentCore.dll`) for sideloading, blending malicious execution with trusted vendor processes.

### Key Findings
- Hypothesis: Adversaries use forged Chromium integrity checks and manual profile injection to silently install malicious browser extensions for stealing live banking session cookies on Windows endpoints
- Gap: Current telemetry lacks visibility into `Secure Preferences` file modifications (specifically HMAC/encrypted hash regeneration) which is the critical persistence mechanism, as standard endpoint sensors often ignore internal configuration files unless explicitly monitored.
