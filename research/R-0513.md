## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries are increasingly leveraging social engineering tactics combined with sophisticated malware to breach organizations, often through phishing emails containing malicious attachments or links that install backdoors. Once inside a network, they use lateral movement techniques and privilege escalation to gain deeper access to sensitive data.

### Key Findings
- Phishing campaigns targeting employees remain the primary method for initial compromise.
- [UNCERTAIN] Advanced Persistent Threat (APT) groups are suspected of using custom malware with multi-stage infection capabilities.
- Malware distribution via compromised websites and malicious advertisements is on the rise, indicating an increase in drive-by-download attacks.
- Lateral movement techniques such as Pass-the-Hash and Mimikatz are frequently employed to move laterally within a network.
- Cobalt Strike beacons and other remote access tools (RATs) are widely used for maintaining persistence and conducting further reconnaissance.
- Encryption of stolen data before exfiltration is becoming more common, complicating recovery efforts.

## 3. Telemetry Mapping: OCSF Fields

### Summary
Telemetry should capture unauthorized modifications to scheduled tasks on Windows systems and associated process creations. This includes monitoring for new or modified task scheduler events (Event ID 4698, 4699) as well as process creation events indicating execution of suspicious binaries (Event ID 4688). Additionally, network activity from these processes should be monitored to identify C2 communication.

### Key Fields
- event_id (50% populated): Event IDs such as 4698 and 4699 indicate changes made to scheduled tasks in the Windows Task Scheduler.
- process_name: Indicates the binary executed by a process creation event, which can be used to identify potentially malicious executables.
- parent_process_name: The parent process of the suspicious process may reveal if the execution is part of an attack chain (e.g., `powershell.exe` or `cmd.exe`).
- user_id: Identifies the user account associated with the creation/modification of scheduled tasks and the process creations.
- network_protocol: Used to identify C2 communication patterns, such as HTTP/HTTPS requests made by malicious binaries.
- dst_ip_address (70% populated): Destination IP addresses for network communications from suspicious processes can help in identifying known bad IPs or domains.
