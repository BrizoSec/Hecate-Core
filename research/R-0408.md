## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries use the technique T1003.008 to dump the contents of /etc/passwd and /etc/shadow files on Linux systems, facilitating offline password cracking and potentially granting unauthorized access to user accounts.

### Key Findings
- Adversaries commonly use command-line utilities like 'cat', 'less', or 'grep' to read /etc/shadow without altering file permissions.
- The technique often involves privilege escalation to gain the necessary permissions for accessing /etc/shadow.
- Detection of this activity can be enhanced by monitoring unusual access patterns and failed login attempts associated with compromised credentials.
- Organizations should implement strong password policies and regular audits to mitigate risks related to offline password cracking.
