## 1. System Research: How It Works

### Summary
The system involves a Rust-based backdoor (RUSTYSHADE) that utilizes private GitHub repositories as an encrypted Command-and-Control channel using AES-256-GCM, alongside tools like RUSTYMOVE for USB propagation and PSNATCH/BASHNATCH for file exfiltration to the same GitHub infrastructure. Normal behavior is characterized by network traffic to GitHub REST APIs containing encrypted data blobs and scheduled task execution of renamed legitimate-looking binaries.

### Key Findings
- RUSTYSHADE communicates via the GitHub REST API using a hardcoded Personal Access Token (PAT) in the Authorization header, sending requests with an Accept header of 'application/vnd.github.v3+json' to read/write specific filenames like command.txt and results.txt.
- C2 payloads are encrypted using AES-256-GCM with a nonce generated by BCryptGenRandom, formatted as HCENC1:[base64(nonce || ciphertext || tag)] before being written to or read from the private repository files.
- RUSTYMOVE operates as a lightweight USB propagation tool that enters an infinite loop every 2 seconds to detect removable media and copy pre-staged files (DriverInstaller.zip and a PDF.LNK) to the root directory of any detected external drive.
- Persistence for the USB tool RUSTYMOVE is established via a scheduled task named 'StandAloneOneDriveUpdater-2626' that executes a binary from C:\Users\Public\AccountPictures upon user logon, designed to mimic legitimate services.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
APT36 (Operation C-Major/Transparent Tribe) launched Operation RapidRust in August/September 2026 to target Indian and Afghan government and defense organizations, utilizing a suite of custom Rust-based malware including the RUSTYSHADE backdoor and PSNATCH/BASHNATCH stealers. The adversary abuses private GitHub repositories as encrypted command-and-control infrastructure and leverages typosquatted domains impersonating Indian news outlets for initial access.

### Key Findings
- RUSTYSHADE is a 64-bit Windows backdoor written in Rust that uses hardcoded GitHub Personal Access Tokens to communicate with attacker-controlled private repositories via the REST API, employing AES-256-GCM encryption for all C2 traffic.
- The campaign utilizes typosquatted domains impersonating Indian news organizations to stage malicious PowerShell scripts, which download next-stage payloads like RUSTYMOVE from Backblaze B2 storage.
- RUSTYMOVE is a USB propagation tool that monitors for removable media and copies pre-staged malicious files (such as DriverInstaller.zip) to external drives to facilitate lateral movement in air-gapped networks.
- PSNATCH (Windows) and BASHNATCH (Linux) are file-stealing tools designed to exfiltrate data from specific directories (Desktop, Documents, OneDrive, etc.) to private GitHub repositories, tracked via local JSON files.
- Adversaries maintain strict operational security by conducting operations exclusively on weekdays between 4:00-11:00 UTC and using scheduled tasks disguised as legitimate services (e.g., 'StandAloneOneDriveUpdater-2626') for persistence.

## 5. Research Synthesis

### Executive Summary
APT36 (Operation C-Major) leverages a Rust-based malware suite, primarily RUSTYSHADE and RUSTYMOVE, to compromise government and defense infrastructure in India and Afghanistan via typosquatted domains. Post-exploitation involves encrypted Command-and-Control over GitHub REST APIs and lateral propagation through removable media, indicating sophisticated operational security and air-gapped network targeting.

### Recommended Hypothesis
> Adversaries use hardcoded GitHub Personal Access Tokens and AES-256-GCM encryption via the GitHub REST API to establish encrypted Command-and-Control channels for RUSTYSHADE while employing RUSTYMOVE USB propagation tools to lateral move across air-gapped segments.

### Gaps Identified
- Current network telemetry may fail to detect C2 activity due to legitimate-looking HTTPS traffic to api.github.com, while the absence of file integrity monitoring allows undetected persistence via scheduled tasks mimicking legitimate services like 'StandAloneOneDriveUpdater'.
- Endpoint Detection and Response (EDR) solutions may miss RUSTYMOVE's USB enumeration and file copying behaviors if they do not specifically monitor for CreateProcessW calls spawning PowerShell scripts that interact with removable drive volumes.

### Key Findings
- Hypothesis: Adversaries use hardcoded GitHub Personal Access Tokens and AES-256-GCM encryption via the GitHub REST API to establish encrypted Command-and-Control channels for RUSTYSHADE while employing RUSTYMOVE USB propagation tools to lateral move across air-gapped segments.
- Gap: Current network telemetry may fail to detect C2 activity due to legitimate-looking HTTPS traffic to api.github.com, while the absence of file integrity monitoring allows undetected persistence via scheduled tasks mimicking legitimate services like 'StandAloneOneDriveUpdater'.
- Gap: Endpoint Detection and Response (EDR) solutions may miss RUSTYMOVE's USB enumeration and file copying behaviors if they do not specifically monitor for CreateProcessW calls spawning PowerShell scripts that interact with removable drive volumes.
- Focus: Hunt for anomalous GitHub REST API requests containing base64-encoded blobs prefixed with 'HCENC1' or utilizing specific hardcoded PATs, which deviate from standard GitHub usage patterns.
- Focus: Investigate scheduled tasks with benign-sounding names (e.g., 'StandAloneOneDriveUpdater') executing binaries from C:\Users\Public\AccountPictures, and monitor for the creation of 'DriverInstaller.zip' or similar staged payloads in public directories.
