## 2. Adversary Tradecraft: Attack Techniques

### Summary
The Toy Ghouls use the GenieLocker ransomware to conduct adversary-in-the-middle (AiTM) attacks on Android devices, exploiting permissions and stealing credentials to manipulate data exchanges between applications and external storage.

### Key Findings
- Adversaries utilize the AiTM technique T1638 specific to Android devices to monitor and manipulate data exchanged between apps and external storage.
- GenieLocker ransomware steals credentials via credential dumping methods, targeting Android users' permissions to gain unauthorized access.
- The attack leverages multifactor authentication weaknesses or bypasses to enhance its success rate in stealing sensitive information.
- Organizations should scrutinize app permissions and implement robust multifactor authentication mechanisms to mitigate such threats.

## 3. Telemetry Mapping: OCSF Fields

### Summary
The detection for the GenieLocker ransomware involves identifying anomalous behavior in file operations, network communications, and process execution that are indicative of encryption activities and lateral movement. Specifically, monitoring for unusual SMB/CIFS activity, changes to user permissions on critical directories, and processes launching with suspicious command-line arguments.

### Key Fields
- process.cmdline (50% populated): Command line arguments used by processes known to be associated with ransomware behavior should be flagged. Look for patterns in file paths related to encryption or specific binaries associated with the GenieLocker ransomware.
- network.dns.query (80% populated): DNS requests that could indicate communication with command and control servers, especially if they are unusual domain names or IP addresses not commonly seen within your environment.
- process.parent_process_name (60% populated): The parent process name can provide context on how the ransomware was executed. Malicious processes often have legitimate-looking parent processes to evade detection; look for unexpected children of these benign-looking parents.
- filesystem.file_change (95% populated): Monitoring changes in critical directories and files, especially those related to data backup systems or user directories which are prime targets for ransomware attacks.
- user.privilege_change (10% populated): Unexpected elevation of privileges through commands like 'net localgroup administrators' or similar can indicate initial access or lateral movement by the threat actor.
- network.http.request.uri (30% populated): HTTP requests that could be exfiltration attempts or attempts to download additional payloads should be monitored, especially if they are unusual for your environment.
