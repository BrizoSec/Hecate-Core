## 2. Adversary Tradecraft: Attack Techniques

### Summary
Kimsuky employed the Gomir family of malware to infiltrate a South Korean groupware vendor, utilizing custom data encryption and service discovery techniques for lateral movement within the network. The attack leveraged MITRE ATT&CK tactics such as File and Directory Discovery, Query Registry, System Service Discovery, and Acquire Infrastructure: Web Services.

### Key Findings
- Kimsuky used a new Gomir family malware variant to conduct targeted attacks against South Korean groupware vendor infrastructure.
- The attack involved custom data encryption methods for exfiltrating collected information from the target network.
- Adversaries conducted extensive service and file discovery activities using various techniques like Query Registry (T1012) and System Service Discovery (T1007).
- Kimsuky employed web services to establish a covert channel, likely for command and control communications or data exfiltration purposes.
- The use of custom encryption indicates an attempt to evade detection by security tools that rely on known patterns for identifying malicious traffic.
- There is evidence of Adversary-in-the-Middle (AiTM) techniques being used to manipulate network traffic within the victim's infrastructure.
