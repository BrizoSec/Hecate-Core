## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries may abuse AI-driven techniques by leveraging prompt injection to manipulate or deceive AI systems, such as chatbots and other conversational interfaces, into performing unintended actions. CrowdStrike's Prompt Injection Taxonomy helps security teams understand how these attacks work and how they can be detected.

### Key Findings
- Adversaries are increasingly using prompt injection techniques to exploit AI-driven systems for malicious purposes.
- Prompt injection allows attackers to manipulate the input given to AI models, causing them to generate responses or take actions that were not intended by the developers.
- CrowdStrike's taxonomy provides a comprehensive framework for understanding and classifying different types of prompt injection attacks.
- Detection of prompt injection requires monitoring for unusual patterns in user interactions with AI systems and analyzing deviations from expected behavior.
- Security teams need to implement stricter input validation mechanisms and continuous learning models to mitigate the risks associated with prompt injection.
