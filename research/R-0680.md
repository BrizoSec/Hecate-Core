## 1. System Research: How It Works

### Summary
The RedFlick technique observed in Star Blizzard campaigns utilizes password-protected archives containing LNK files that trigger hidden command-line execution to download decoy PDFs and subsequently invoke SSH.exe with PermitLocalCommand enabled. This chain facilitates the remote download and installation of an MSI installer, which establishes persistence via scheduled tasks that use control.exe to execute a downloader masquerading as a Control Panel applet.

### Key Findings
- The RedFlick malware delivery technique relies on LNK files that launch conhost.exe in a hidden window to spawn cmd.exe and execute embedded BAT scripts, rather than standard GUI interactions.
- Attackers abuse SSH.exe with PermitLocalCommand enabled within the initial payload to download and execute a remotely hosted MSI installer, indicating a specific abuse of legitimate Windows subsystems for malware transport.
- The resulting MSI installer creates scheduled tasks masquerading as legitimate system functions (e.g., 'Internet Quality Test Connection', 'Network Configuration Manager') that utilize control.exe and Control_RunDLL to execute the CosmicPulse downloader.
- The downloader, also known as NOROBOT or BAITSWITCH, installs a Python backdoor called CosmicPulse (also referred to as YESROBOT) by decoding it with an AES key retrieved from the HKEY_CURRENT_USER\Software\Classes\.mollis registry key.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
Russian state threat actor Star Blizzard employs the 'RedFlick' technique to deliver the CosmicPulse Python backdoor via a streamlined infection chain requiring only single user interaction, significantly enhancing detection evasion capabilities. This evolution involves using compromised websites, large-scale phishing campaigns with password-protected archives, and scheduled tasks masquerading as legitimate system utilities to maintain persistence.

### Key Findings
- The RedFlick technique utilizes scheduled tasks named 'Internet Quality Test Connection', 'Network Configuration Manager', and 'System Health Monitor' to download and execute the CosmicPulse downloader, which masquerades as a Control Panel applet (CPL).
- Malware delivery relies on decoy documents such as password-protected ZIPs (.rar files like Chatham_London_Conference_2026_Invitation.rar) and virtual disk images (.vhdx), with the initial stage often executing via 'conhost.exe' and 'cmd.exe' to run embedded BAT scripts.
- The infection chain leverages 'SSH.exe' with PermitLocalCommand enabled and 'curl' to download payloads from actor-controlled servers, while persistence is maintained through registry keys (e.g., HKEY_CURRENT_USER\Software\Classes\.mollis) storing encrypted AES keys.
- The final payload, identified as YESROBOT or NOROBOT/BAITSWITCH, is a malicious Python backdoor decoded using an embedded key in AES-ECB mode recovered from the registry, allowing for remote code execution via 'Control_RunDLL'.
- Star Blizzard has observed evolving tactics since January 2026, including the use of compromised website accounts and the deployment of MSI installers that create scheduled tasks to access hardcoded C2 servers.

## 3. Telemetry Mapping: OCSF Fields

### Summary
The RedFlick technique involves a multi-stage delivery chain starting with LNK files that spawn hidden conhost.exe and cmd.exe processes to execute BAT scripts. These scripts utilize SSH.exe (with PermitLocalCommand) or curl.exe to download decoy PDFs or payloads, which subsequently trigger the creation of malicious scheduled tasks masquerading as legitimate system functions (e.g., 'Internet Quality Test Connection'). Persistence is maintained via these scheduled tasks that invoke control.exe or PowerShell to execute remote DLLs/MSI installers (CosmicPulse/NOROBOT/BAITSWITCH), often involving registry modifications for decryption keys.

### Key Fields

OCSF path → the event field `knowledge/environment.md` documents for it.

- `process.name` → `process_name` (Endpoint) (written as `process_activity.process.name`): Detect conhost.exe, cmd.exe, ssh.exe, curl.exe, and control.exe executions, particularly when spawned from unusual parents or in hidden windows.
- `process.cmd_line` → `command_line` (Endpoint) (written as `process_activity.process.cmd_line`): Identify SSH commands with 'PermitLocalCommand' enabled, curl downloads of PDFs/MSIs, and schtasks.exe invocations creating tasks with benign names like 'Internet Quality Test Connection'.
- `file.path` → unmapped: the environment profile documents no field (written as `file_activity.file.path`): Monitor for creation of files in C:\Windows\System32\Tasks\ corresponding to suspicious scheduled tasks and the presence of .mollis registry-linked files.
- `process.file.hashes` → unmapped: the environment profile documents no field (written as `process_activity.process.file.hashes`): Match artifacts associated with CosmicPulse/NOROBOT/BAITSWITCH downloaders and YESROBOT backdoors (e.g., SHA256 hashes provided in intelligence).
- `network_endpoint.hostname` → unmapped: the environment profile documents no field: Observe connections to actor-controlled servers for hosting decoy PDFs, MSI installers, and C2 infrastructure via WebDAV or HTTP/S.

## 5. Research Synthesis

### Executive Summary
Star Blizzard's RedFlick technique leverages LNK files to spawn hidden conhost.exe instances that execute BAT scripts abusing SSH.exe with PermitLocalCommand and curl.exe for payload delivery. This chain installs MSI-based persistence via scheduled tasks masquerading as system utilities, which invoke control.exe and Control_RunDLL to deploy the CosmicPulse Python backdoor using AES-encrypted keys stored in HKCU registry keys.

### Recommended Hypothesis
> Adversaries use hidden conhost.exe execution with SSH PermitLocalCommand abuse and scheduled task persistence masquerading as system utilities to deliver and execute the CosmicPulse Python backdoor on targeted Windows endpoints.

### Gaps Identified
- Standard EDR telemetry often fails to capture the specific 'PermitLocalCommand' parameter in SSH command lines or distinguishes legitimate control.exe invocations from malicious DLL loading via Control_RunDLL without behavioral context.

### Key Findings
- Hypothesis: Adversaries use hidden conhost.exe execution with SSH PermitLocalCommand abuse and scheduled task persistence masquerading as system utilities to deliver and execute the CosmicPulse Python backdoor on targeted Windows endpoints.
- Gap: Standard EDR telemetry often fails to capture the specific 'PermitLocalCommand' parameter in SSH command lines or distinguishes legitimate control.exe invocations from malicious DLL loading via Control_RunDLL without behavioral context.
- Focus: Hunt for scheduled tasks with benign names (e.g., 'Internet Quality Test Connection', 'Network Configuration Manager') that trigger control.exe or schtasks.exe, and monitor HKCU registry writes to .mollis extensions containing encrypted AES keys.
