## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries like UAT-11795 are employing the Adversary-in-the-Middle (AiTM) technique to intercept and manipulate network traffic, often through ARP poisoning or proxy use, allowing them to modify system processes and permissions on both Linux/Mac and Windows systems in real time.

### Key Findings
- Adversaries with privileged access can execute AiTM attacks by manipulating network packets directly.
- ARP poisoning is a common method used to redirect traffic through the attacker's machine.
- Proxy use allows adversaries to control and modify network communications passing through it.
- Attackers target Linux and Mac file/directory permissions, as well as Windows system processes.
- Network intrusion detection systems (NIDS) can help detect and mitigate AiTM attacks.
- Mitigation strategies include implementing strong encryption protocols and monitoring for unusual network behavior.
