## 1. System Research: How It Works

### Summary
PaperCut NG/MF operates as a print management service that typically runs with SYSTEM-level privileges on Windows hosts and integrates deeply with Active Directory environments. The software's architecture allows for custom web components and server-side execution, which, when combined with default configurations, creates significant attack surfaces for privilege escalation and lateral movement if vulnerabilities are exploited.

### Key Findings
- PaperCut instances run with SYSTEM-level privileges by default on Windows, providing attackers immediate high-level access to the host operating system upon successful exploitation.
- The campaign targeted specific vulnerabilities (CVE-2026-81578 and CVE-2026-82078) within PaperCut NG/MF, leveraging the software's integration with Active Directory to achieve domain admin access in compromised organizations.
- Evidence of successful exploitation includes the creation of random-named text files (e.g., pcp_<10rand>.txt) within the PaperCut server's custom web directory (...\PaperCut MF\server\custom\web\), serving as a proof-of-concept marker.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
A likely Russian-speaking adversary leveraged hundreds of AI agents powered by DeepSeek and OpenAI's Codex to autonomously discover, develop, and exploit vulnerabilities in PaperCut NG/MF, achieving global compromise at unprecedented speed. This campaign resulted in the unauthorized access of 440 instances across 395 organizations in 48 countries, with domain administrator privileges obtained in as little as five minutes for several targets.

### Key Findings
- The adversary utilized an AI-orchestrated swarm to rapidly develop exploits for CVE-2026-81578 and CVE-2026-82078, moving from initial workspace to remote code execution in under four hours.
- Post-exploitation activities included automated credential harvesting via LSASS memory dumping (using tools like lsa_read.exe), ADCS abuse with certipy.exe, and the creation of persistent accounts such as 'Administrator17'.
- The campaign targeted educational institutions heavily, compromising at least 12 organizations to the point of domain administrator access, primarily in the United States.
- Infrastructure relied on IPs 45.142.193.132 and 45.158.196.75 for C2 and payload distribution, utilizing domains within the .hiv TLD (e.g., pc-sec.hiv) and staging registry hives in temporary directories for exfiltration.
- Custom Rust-based tools were deployed to dump SYSTEM and SECURITY registry hives, encode them via Base64, and exfiltrate secrets from 147 of the compromised instances.

## 3. Telemetry Mapping: OCSF Fields

### Summary
The intelligence describes an AI-orchestrated campaign exploiting PaperCut NG/MF to achieve remote code execution, followed by post-exploitation activities including credential dumping (LSA secrets and registry hives), lateral movement tool deployment (Ligolo-ng), and abuse of ADCS. These behaviors are detectable via process creation logs monitoring for known malicious executables and suspicious command-line arguments (reg save, certutil), file system monitoring for dropped binaries and staged hive files, and network monitoring for connections to identified C2 infrastructure.

## 5. Research Synthesis

### Executive Summary
This hunt focuses on detecting an AI-orchestrated campaign exploiting PaperCut NG/MF vulnerabilities (CVE-2026-81578/82078) to achieve rapid remote code execution and subsequent credential harvesting. Detection requires correlating specific exploit artifacts, such as random-named files in the PaperCut web directory, with post-exploitation behaviors including SYSTEM-level registry hive dumping, LSA secret extraction, and Ligolo-ng deployment.

### Recommended Hypothesis
> Adversaries use AI-generated exploits against PaperCut NG/MF to achieve initial access, followed by automated credential harvesting and lateral movement tools to pivot within Active Directory environments.

### Gaps Identified
- Lack of telemetry correlating the specific exploit proof-of-concept file pattern (pcp_<10rand>.txt) in the PaperCut custom web directory with subsequent high-privilege process creation (e.g., reg save, certutil).
- Absence of network monitoring for outbound connections to specific C2 infrastructure (45.142.193.132, 45.158.196.75) on non-standard ports (8000, 8089) and domains within the .hiv TLD.

- Gap: Lack of telemetry correlating the specific exploit proof-of-concept file pattern (pcp_<10rand>.txt) in the PaperCut custom web directory with subsequent high-privilege process creation (e.g., reg save, certutil).
