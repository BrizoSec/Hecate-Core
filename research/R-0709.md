## 1. System Research: How It Works

### Summary
PIVOTPIPE is a .NET-based unofficial beacon payload that mimics Cobalt Strike functionality while employing advanced evasion techniques such as AMSI bypass, indirect syscalls, and sleep masking to evade EDR detection. It operates via a loader that extracts and decrypts a RAT module into memory, supporting both TCP and SMB peer-to-peer communication channels for C2 interactions.

### Key Findings
- The malware utilizes a two-component architecture where the loader extracts configuration (agent.json), public keys (pk.der), and a compressed/encrypted RAT payload (core.pak) into a temporary folder prefixed with 'nb_' before executing the RAT in memory.
- PIVOTPIPE implements specific EDR evasion mechanisms including AMSI bypass via a small shellcode stub ('MOV EAX,80070057; RET;'), indirect syscall initialization, and sleep masking to avoid behavioral detection.
- Debug artifacts indicate active development, with the malware writing detailed debug logs (e.g., nb_drip_dbg.txt, nb_hook_dbg.txt) to C:\WINDOWS\Temp\ and referencing hardcoded development paths like 'C:\Users\admin\Desktop\cscs\4.5\payloads\dotnet-4.x'.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
PIVOTPIPE is a .NET-based, unofficial Cobalt Strike-like beacon payload discovered by IIJ in July 2026 that mimics official Beacon functionality while employing unique evasion techniques such as AMSI bypass and indirect syscalls. The tool utilizes a loader to unpack a compressed RAT payload into memory, supporting both TCP and SMB C2 channels with P2P pivoting capabilities.

### Key Findings
- PIVOTPIPE consists of two components: a loader that implements EDR evasion (AMSI bypass, indirect syscalls, sleep masking) and a Remote Access Trojan (RAT) module that executes in memory.
- The malware supports C2 communication via TCP Beacon and SMB Beacon, allowing for peer-to-peer pivoting through compromised hosts when the 'pivot_mode' configuration is set to true.
- Debug artifacts in the C:\WINDOWS\Temp directory (e.g., nb_fatal.txt, nb_hook_dbg.txt) and hardcoded development paths suggest the tool was under active development at the time of discovery, indicating potential for future enhancements.
- The loader extracts configuration files (agent.json), public keys (pk.der), and the XOR/GZIP compressed RAT payload (core.pak) into a temporary directory starting with 'nb_' before executing the RAT in memory.
- Three specific SHA256 hashes have been identified as indicators of compromise: AD9A03F3..., FEEB5CAE..., and 715558E0... associated with filenames netbeacon_pivot.exe, pivot_hop2_kasp.exe, and x64beacon.exe.
