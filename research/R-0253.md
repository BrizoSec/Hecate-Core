## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries abuse the pass-the-hash technique by leveraging stolen cryptographic hashes of user accounts to gain unauthorized access and maintain persistence within a network, bypassing traditional authentication mechanisms. This method allows attackers to authenticate to services without needing actual passwords.

### Key Findings
- The attack involves stealing NTLM or Kerberos ticket-granting service (TGS) tickets which contain hash values of user credentials.
- Adversaries may use tools like Mimikatz to extract these hashes from memory and then utilize them for authentication across the network.
- Indicators include anomalous authentication attempts, particularly those originating from unusual sources or times within a network.
- The event was reported with a medium threat level, indicating that while significant security measures are in place, there is still potential risk of compromise.
