## 1. System Research: How It Works

### Summary
NetScaler ADC and Gateway systems are network appliances that typically handle secure traffic management and user authentication, but in this context, they are being targeted by unauthenticated attackers exploiting zero-day flaws to inject commands and upload malicious files. The exploitation involves poisoning log files for remote code execution via CVE-2026-88771 and leveraging a DTLS memory overflow via CVE-2026-88772 to establish persistence through webshells.

### Key Findings
- CVE-2026-88771 enables unauthenticated remote code execution through a three-stage command injection chain that specifically involves poisoning log files to execute arbitrary commands on the system.
- CVE-2026-88772 is a DTLS memory overflow vulnerability that allows attackers to achieve remote code execution or cause denial of service, with exploitation methods including the deployment of .deb webshell files.
- Threat actors are using PHP webshells encrypted with RC4 for command and control communications, which they deploy into custom directories within NetScaler Gateway interfaces to maintain persistent access.

- The use of RC4 encryption for C2 communications blinds network security controls from inspecting the payload content, requiring reliance on behavioral anomalies in command execution rather than signature-based detection.
