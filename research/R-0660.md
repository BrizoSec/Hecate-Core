## 1. System Research: How It Works

### Summary
SocGholish operates as a malware loader that utilizes social engineering, such as fake software updates, to execute malicious JavaScript code which profiles the victim's system and connects to command-and-control infrastructure. Once the environment is profiled, it downloads and executes secondary payloads, including backdoors and ransomware, often distributing them through drive-by downloads or compromised websites.

### Key Findings
- The SocGholish loader executes arbitrary tasks via malicious JavaScript code that communicates with a command-and-control server to retrieve further payloads like stealer routines or ransomware components.
- The malware employs obfuscation techniques and utilizes TDS (Threat Detection Service) methods for redirection during the infection process, which began in April 2018.
- SocGholish infrastructure supports domain shadowing and domain rotation to maintain access, with observed associations to threat groups including Evil Corp, TA569, Gold Drake, and UNC2165.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries are executing a targeted phishing campaign against Washington State election infrastructure using electorally themed emails to deliver the SocGholish malware framework, which profiles victims and downloads secondary payloads via obfuscated JavaScript. The campaign aims to establish initial access to voter registration databases and conduct reconnaissance for potential DDoS attacks to undermine public confidence in the upcoming November elections.

### Key Findings
- The attack leverages socio-political engineering with fake browser updates and look-alike domains impersonating the Washington Secretary of State's office, such as wa-elections-support.com and secure-voter-wa.org.
- SocGholish malware is delivered via malicious zip attachments or HTML smuggling, utilizing JavaScript embedded in compromised sites to profile the victim's system before executing obfuscated WScript commands.
- The malware achieves persistence by creating scheduled tasks named 'UpdateCheck' (executed every 15 minutes) and modifying registry run keys.
- Threat actors are conducting reconnaissance for DDoS attacks against election websites, aiming to overwhelm them on election day to erode public trust in the electoral process.
- C2 traffic was observed connecting to IPs 198.51.100.45 and 203.0.113.88, though external enrichment sources returned errors or null results for these indicators.
- While SocGholish is a known threat used by groups like Evil Corp to target business relationships, this specific context highlights its deployment against political organizations and election officials in Washington State.

## 5. Research Synthesis

### Executive Summary
Adversaries are executing a targeted SocGholish campaign against Washington State election infrastructure via electorally-themed phishing, leveraging obfuscated WScript and HTML smuggling to deploy a JavaScript-based loader that profiles systems and establishes persistence through 'UpdateCheck' scheduled tasks. The immediate technical objective is initial access to voter data networks, followed by reconnaissance for potential DDoS operations to undermine electoral integrity.

### Recommended Hypothesis
> Adversaries use obfuscated WScript execution and fake software update social engineering to deliver SocGholish payloads for system profiling and persistence on election infrastructure endpoints.

### Gaps Identified
- Current telemetry lacks specific correlation between 'UpdateCheck' scheduled task creation events and parent process ancestry (e.g., wscript.exe or explorer.exe) originating from temporary directories like %APPDATA%\Local\Temp.
