## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries are exploiting the wp2shell vulnerability in WordPress plugins to upload malicious files and gain unauthorized access to web servers. The exact attribution of these attacks is currently unknown, but they pose a significant risk due to their widespread impact.

### Key Findings
- Exploitation targets the wp2shell vulnerability which allows for plugin file uploads with elevated privileges
- Malicious actors are using this method to deploy backdoors or other malware on compromised servers
- Indicators of compromise (IOCs) include unexpected files uploaded via a WordPress plugin's upload feature and unusual network traffic patterns
- The lack of specific adversary attribution highlights the need for continuous monitoring and threat intelligence sharing

## 3. Telemetry Mapping: OCSF Fields

### Summary
To detect wp2shell exploitation activities, telemetry should capture file creation/modification events in the WordPress plugin directory, HTTP requests involving file uploads to known vulnerable plugins, and network communications indicative of command-and-control (C2) activity. This includes monitoring for suspicious PHP files being uploaded or modified that could indicate shell access.

### Key Fields
- file.create.modify: Tracks changes to files within the wp-content/plugins directory where malicious scripts might be dropped by exploiting plugin vulnerabilities
- http.request.method: POST requests to URLs containing 'wp-admin' or 'wp-login', which may include file upload attempts targeting known vulnerable plugins
- network.dns.query: Queries for unusual domain names that could signify C2 communication from uploaded shells
- process.create.execve: Processes spawning PHP scripts in the wp-content/uploads directory, indicating shell execution via plugin vulnerabilities
