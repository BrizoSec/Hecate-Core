## 1. System Research: How It Works

### Summary
Kunai malware exploits the DNS protocol for data exfiltration by encoding sensitive information into DNS queries, leveraging open recursive DNS servers to bypass network security measures and avoid detection.

### Key Findings

- Malware uses legitimate DNS infrastructure, including public DNS resolvers, to evade traditional network monitoring techniques.
- The use of DNS for command-and-control (C&C) and exfiltration purposes highlights the need for enhanced detection mechanisms specifically targeting anomalous DNS activity.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries using Kunai malware abuse open recursive DNS servers to exfiltrate data covertly through DNS tunneling, making it difficult for traditional network monitoring tools to detect the malicious activity due to its use of standard DNS protocols.

### Key Findings
- Kunai leverages DNS tunneling to transmit stolen data in a manner that mimics legitimate DNS traffic, thereby evading detection.
- The malware targets open recursive DNS servers which are publicly accessible and allow queries from any IP address, providing a convenient channel for exfiltration.
- Attackers use standard DNS query protocols to encode and send sensitive information, exploiting the high volume of normal DNS requests to blend in with legitimate traffic.
- Detection challenges arise due to the low network visibility into DNS request payloads, allowing adversaries to continuously refine their techniques to avoid alerting security systems.
