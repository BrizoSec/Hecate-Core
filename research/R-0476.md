## 1. System Research: How It Works

### Summary
TrueConf is a video conferencing solution that allows for real-time collaboration and communication. It typically requires users to connect via authorized means, but attackers have exploited unpatched vulnerabilities in the server software to gain unauthorized access.

### Key Findings
- Unpatched TrueConf servers are vulnerable to exploitation through port 43.
- Attackers use these vulnerabilities to execute scripts and establish command-and-control channels.
- The backdoors PhantomCore and PhantomGraph enable lateral movement within networks and facilitate data exfiltration.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
The Head Mare hacktivist group exploited unpatched vulnerabilities (KLCERT-26-057 and KLCERT-26-058) in TrueConf video conferencing servers to deliver PhantomCore and PhantomGraph backdoors via trojanized client installers. These backdoors allowed for reconnaissance, credential theft, remote access, and command-and-control activities.

### Key Findings
- Head Mare exploited unpatched vulnerabilities in TrueConf servers to deploy trojanized client installers containing PhantomCore and PhantomGraph backdoors.
- PhantomCore provides capabilities such as reconnaissance, credential theft, and command-and-control functionalities.
- The attack involved replacing legitimate TrueConf client software with compromised versions that infiltrate the victim's network.
- Kaspersky researchers observed these attacks in July 2026, highlighting the critical nature of keeping systems up-to-date with security patches.

## 5. Research Synthesis

### Executive Summary
Attackers have exploited unpatched vulnerabilities in TrueConf video conferencing servers to deploy PhantomCore and PhantomGraph backdoors, enabling reconnaissance, credential theft, and lateral movement within networks. The attack highlights the critical importance of maintaining up-to-date security patches for software.

### Recommended Hypothesis
> Adversaries use exploitation of unpatched TrueConf vulnerabilities to deliver trojanized client installers containing PhantomCore and PhantomGraph backdoors in order to establish command-and-control channels and facilitate data exfiltration from targeted networks.

### Gaps Identified
- Current coverage lacks comprehensive monitoring for file integrity on endpoints, which could help detect the installation of compromised TrueConf clients or modifications made by backdoor executables.
- There is insufficient visibility into the specific techniques used by Head Mare to initially breach TrueConf servers and distribute trojanized client installers across networks.

### Key Findings
- Hypothesis: Adversaries use exploitation of unpatched TrueConf vulnerabilities to deliver trojanized client installers containing PhantomCore and PhantomGraph backdoors in order to establish command-and-control channels and facilitate data exfiltration from targeted networks.
- Gap: Current coverage lacks comprehensive monitoring for file integrity on endpoints, which could help detect the installation of compromised TrueConf clients or modifications made by backdoor executables.
- Focus: Enhance network traffic analysis by implementing real-time detection for unusual outbound connections from internal TrueConf servers to suspicious IP addresses or domains. Additionally, prioritize process and file monitoring to identify unexpected processes or files associated with known malware signatures.
- Gap: There is insufficient visibility into the specific techniques used by Head Mare to initially breach TrueConf servers and distribute trojanized client installers across networks.
- Focus: Investigate the initial infection vector of unpatched vulnerabilities in TrueConf servers, such as KLCERT-26-057 and KLCERT-26-058, to develop targeted detection rules for preventing or early identification of similar attacks.
