## 1. System Research: How It Works

### Summary
MATCHBOIL is a custom C# downloader used by the Russia-aligned APT group UAC-0099 that establishes persistence via scheduled tasks and registry keys while retrieving payloads from command-and-control servers. It operates through spearphishing campaigns targeting Ukrainian organizations, utilizing deceptive graphical interfaces and evolving obfuscation techniques to deliver the MATCHWOK backdoor.

### Key Findings
- MATCHBOIL establishes persistence by creating scheduled tasks (e.g., 'Updates\CheckTask' or 'UpdateCheckers\DailyPlanner') and registry values under HKCU\Software\Microsoft\Windows\CurrentVersion\Run, evolving from early registry-only methods to more robust task-based execution.
- The malware gathers system information via WMI queries using the ManagementObjectSearcher class to retrieve CPUID and BIOS serial numbers, aiding in victim profiling or sandbox evasion.
- MATCHBOIL employs deceptive file naming conventions for its payloads and configuration files, such as 'WallpappersSet.jpg' in user Pictures folders, 'config.library-ms' in Public Libraries, and 'MeowMeowProgramm.exe' to blend in with legitimate system artifacts.
- The group utilizes specific C# obfuscation tools over time, transitioning from Unicode symbol obfuscation to the Eziriz .NET Reactor, and relies on HTML-based extraction patterns like <script>(.*?)</script> to parse downloaded content.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
UAC-0099 utilizes the MATCHBOIL C# downloader, distributed via spearphishing emails with malicious links to VBScript files, to establish persistence and deploy the MATCHWOK backdoor against Ukrainian organizations in critical sectors. The malware evolves continuously, employing increasingly sophisticated evasion techniques such as .NET Reactor obfuscation, sandbox detection, and deceptive graphical interfaces mimicking legitimate utilities.

### Key Findings
- MATCHBOIL targets Ukrainian infrastructure across transportation, manufacturing, and energy sectors, primarily delivering the MATCHWOK C# backdoor as its final payload.
- The malware employs dynamic persistence mechanisms, transitioning from registry keys (HKCU\...\Run) in early versions to scheduled tasks (e.g., Updates\CheckTask, UpdateCheckers\DailyPlanner) in later iterations.
- Obfuscation techniques have evolved over time, moving from Unicode symbol obfuscation and custom string encryption to the use of the Eziriz .NET Reactor obfuscator.
- MATCHBOIL utilizes WMI queries via the ManagementObjectSearcher class to gather system information such as CPUID and BIOS serial numbers for victim profiling.
- The group also deploys LONEPAGE, a PowerShell downloader characterized by 'page' in its C&C URLs, alongside MATCHBOIL to facilitate initial access.
