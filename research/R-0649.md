## 1. System Research: How It Works

### Summary
PaperCut NG/MF is a print management system that utilizes a bundled Apache Derby database and an HTTP-based configuration editor to manage external user lookups. Normal operation involves standard database interactions and web service communications for printing tasks, without the use of automated AI agents or registry hive dumping utilities.

### Key Findings
- Normal PaperCut NG/MF behavior does not involve HTTP POST requests to the configuration editor endpoint for the purpose of injecting malicious SQL payloads or modifying external user-lookup settings via Apache Derby drivers.
- Standard print management operations do not generate artifacts such as base64-encoded SYSTEM or SECURITY registry hives (e.g., pc-system.b64) in C:\Windows\Temp, nor do they invoke certutil for encoding local system files.
- The deployment of legitimate software names like Ligolo-ng (legit-svc.exe) in ProgramData or the creation of hidden accounts like Administrator17 are not part of the normal PaperCut NG/MF operational profile.
- PaperCut NG/MF does natively utilize AI agents powered by DeepSeek or OpenAI models to orchestrate exploitation, develop exploits for CVE-2026-81578/CVE-2026-82078, or coordinate global intrusion campaigns.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
A likely Russian-speaking adversary orchestrated a global campaign against PaperCut NG/MF by deploying hundreds of AI agents powered by DeepSeek and OpenAI Codex to independently develop, test, and exploit vulnerabilities CVE-2026-81578 and CVE-2026-82078. This automated approach allowed the threat actor to achieve remote code execution across 440 instances in 395 organizations within hours, significantly accelerating the attack lifecycle from initial compromise to domain administration.

### Key Findings
- The adversary utilized an agentic workflow where AI agents developed and tested exploits in a self-hosted lab before launching coordinated attacks, reducing the time from workspace creation to remote code execution to under four hours.
- At least 440 PaperCut instances across 395 organizations in 48 countries were compromised, with approximately half of the victims belonging to the education sector.
- The campaign leveraged CVE-2026-81578 and CVE-2026-82078 for initial exploitation, while also referencing related vulnerabilities such as CVE-2021-42278, CVE-2021-42287, CVE-2023-27532, and CVE-2026-0400.
- Post-exploitation activities included credential harvesting from 280 instances, secret extraction from 147 instances, and the use of custom Rust-based tools (e.g., lsa_read.exe, save_hives.exe) to dump SYSTEM and SECURITY registry hives via base64 encoding for exfiltration.
- The infrastructure originated from IP 45.142.193.132, tracked since July 2026 for attacks against various technologies, with additional C2 activity linked to IP 45.158.196.75 and domains ending in .hiv (e.g., pc-sec.hiv).
- The adversary achieved domain administrator access in 12 organizations, primarily affecting US educational institutions, using tools like certipy for ADCS abuse and Ligolo-ng for lateral movement.

## 5. Research Synthesis

### Executive Summary
Adversaries are leveraging AI-orchestrated agents to exploit CVE-2026-81578/82078 in PaperCut NG/MF, achieving rapid lateral movement and credential harvesting via custom Rust-based LSA dumping tools (e.g., lsa_collect.exe) and Ligolo-ng for C2 proxying. Detection requires correlating anomalous PaperCut web access with suspicious registry hive staging, base64 encoding via certutil, and the execution of specific malicious artifacts like legit-svc.exe.

### Recommended Hypothesis
> Adversaries use AI-generated exploits against PaperCut NG/MF vulnerabilities to deploy custom LSA credential harvesters and Ligolo-ng proxies for rapid domain admin access on educational institutions.

### Gaps Identified
- Lack of visibility into HTTP POST payloads targeting the PaperCut configuration editor endpoint, which obscures the initial exploitation phase (CVE-2026-81578/82078) before malicious binaries are downloaded.
- Missing file creation monitoring for specific staging artifacts (e.g., pc-*.hiv, pc-*.b64 in C:\Windows\Temp) and the deployment of Ligolo-ng under disguised paths (C:\ProgramData\LegitSvc\), allowing credential dumping to occur undetected.

### Key Findings
- Hypothesis: Adversaries use AI-generated exploits against PaperCut NG/MF vulnerabilities to deploy custom LSA credential harvesters and Ligolo-ng proxies for rapid domain admin access on educational institutions.
- Gap: Lack of visibility into HTTP POST payloads targeting the PaperCut configuration editor endpoint, which obscures the initial exploitation phase (CVE-2026-81578/82078) before malicious binaries are downloaded.
- Gap: Missing file creation monitoring for specific staging artifacts (e.g., pc-*.hiv, pc-*.b64 in C:\Windows\Temp) and the deployment of Ligolo-ng under disguised paths (C:\ProgramData\LegitSvc\), allowing credential dumping to occur undetected.
- Focus: Monitor for command lines invoking 'reg save' on HKLM\SYSTEM/SECURITY followed by 'certutil -encode', and correlate with the download/execution of lsa_collect.exe or legit-svc.exe from IP 45.142.193.132.
