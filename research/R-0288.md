## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries are leveraging advanced AI technologies to rapidly identify and exploit vulnerabilities, thereby collapsing the traditional 'window of opportunity' available for defenders to patch or mitigate threats. This necessitates the adoption of sophisticated AI-driven defensive measures to stay ahead in the cyber arms race.

### Key Findings
- AI is being used by attackers to automate and accelerate vulnerability discovery, reducing the time between a flaw's identification and its exploitation.
- Defenders must implement advanced analytics and machine learning models to detect anomalous behaviors indicative of AI-driven attacks at an early stage.
- Collaboration with leading AI research institutions like OpenAI helps in understanding emerging threats and developing countermeasures.
- DNS poisoning remains a critical vector for both traditional and AI-enhanced cyberattacks, requiring robust monitoring and response capabilities.

## 3. Telemetry Mapping: OCSF Fields

### Summary
The telemetry should capture detailed information about process creation, network communications, file system changes, and credential usage across endpoints and servers to identify suspicious activities indicative of advanced attacker behaviors.

### Key Fields
- process.name (75% populated): Tracks the names of processes created on endpoints for identifying misuse of common utilities.
- network.http.request.uri (60% populated): Captures URLs accessed by HTTP(S) requests from endpoints to detect data exfiltration and command-and-control communications.
- file.path (85% populated): Tracks file paths of created or modified files, useful in identifying unauthorized changes to system configurations or malicious file drops.
- process.parent.name (70% populated): Indicates the parent process that spawned a child process for detecting suspicious process chains used by attackers.
- credential.username (45% populated): Logs usernames associated with credential events such as logon attempts or password changes, indicating brute force attacks or privilege escalation activities.
- network.tcp.stream.dst_port (60% populated): Tracks destination ports for TCP connections to identify communications with known malicious IP addresses on unusual ports.
