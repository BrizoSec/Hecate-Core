## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries are employing GitHub to redirect traffic to their command and control (C2) servers, thereby obfuscating the true location of C2 infrastructure and evading detection by security tools. This technique falls under the 'Hide Infrastructure' tactic in MITRE ATT&CK framework, leveraging network manipulation for evasion.

### Key Findings
- Adversaries use GitHub redirects to proxy malicious traffic, masking their C2 servers behind legitimate services.
- Detection involves monitoring for anomalies in DNS requests and network traffic directed towards known redirection points like GitHub.
- The technique is part of the broader strategy to evade defensive tools by manipulating network protocols and infrastructure acquisition methods.
- Cobalt Strike is noted for its ability to mimic HTTP protocol, blending malicious C2 communication with legitimate web traffic.
