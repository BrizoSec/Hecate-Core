## 1. System Research: How It Works

### Summary
SANDWORM_MODE is a sophisticated supply chain attack that targets widely used tools like Trivy and Bitwarden to compromise software development processes. It employs obfuscation techniques to hide malicious payloads, making detection challenging but possible through monitoring for unusual API calls and package installations.

### Key Findings
- Monitoring for unauthorized access patterns such as unexpected API calls or package installations is crucial in detecting supply chain compromises like SANDWORM_MODE.
- Tools used for managing secrets (e.g., GCP Secret Manager, Azure Key Vault) are targeted by attackers to gain unauthorized access and should be closely monitored.
- Using default credentials or overly permissive OAuth scopes can expose systems to risks such as project enumeration and secret theft.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries exploit supply chain vulnerabilities in AI frameworks by injecting malicious code through MCP servers to steal credentials and compromise AI development environments, leading to broader attacks orchestrated with autonomous agents.

### Key Findings
- SANDWORM_MODE leverages MCP server injection to penetrate AI development environments and steal credentials from AI providers.
- Adversaries use backdoors in AI Integrated Development Environments (IDEs) to maintain persistence and control over compromised systems.
- Zero-width Unicode poisoning is employed as a sophisticated method of data exfiltration, targeting specific files like .cursorrules and CLAUDE.md.
- AI supply chain attacks are characterized by multi-vector campaigns that involve coordinated use of autonomous agents for broader operational scope.
