## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries exploit DNS tunneling to covertly exfiltrate data by encoding information within DNS queries and responses, leveraging the trust enterprises place in DNS traffic which often bypasses firewall inspections. This technique is frequently employed in advanced persistent threat campaigns and malware incidents to avoid detection due to insufficient monitoring of DNS traffic.

### Key Findings
- Attackers encode arbitrary data within standard DNS query structures to facilitate covert communication channels that appear as legitimate name resolution requests.
- The abuse relies on the architectural flow where endpoints send queries to internal resolvers, which then communicate with authoritative name servers controlled or compromised by the attacker.
- Data exfiltration is achieved by logging and reconstructing the encoded data from DNS responses at the attacker's authoritative DNS server infrastructure.
- This technique remains effective in mature security environments because it exploits the minimal inspection applied to DNS traffic, often going unnoticed due to a lack of specialized expertise in analyzing such logs.

## 5. Research Synthesis

### Executive Summary
Adversaries are leveraging open recursive DNS infrastructure to covertly exfiltrate data by encoding information within standard DNS queries, bypassing traditional firewall inspections due to the inherent trust placed in DNS traffic. This technique exploits the lack of specialized monitoring for anomalous DNS record types and high-volume query patterns, allowing threat actors to reconstruct encoded payloads at their authoritative servers while evading detection in mature security environments.

### Recommended Hypothesis
> Adversaries use DNS tunneling via open recursive resolvers to exfiltrate sensitive data covertly on enterprise endpoints by encoding information within legitimate-looking DNS queries and responses.

### Gaps Identified
- Lack of correlation between low-throughput, high-entropy TXT/CNAME record queries and specific malware process ancestry chains (e.g., tracing back from zsh/bash to systemd) limits the ability to distinguish malicious exfiltration from legitimate resolver activity.

### Key Findings
- Hypothesis: Adversaries use DNS tunneling via open recursive resolvers to exfiltrate sensitive data covertly on enterprise endpoints by encoding information within legitimate-looking DNS queries and responses.
- Gap: Lack of correlation between low-throughput, high-entropy TXT/CNAME record queries and specific malware process ancestry chains (e.g., tracing back from zsh/bash to systemd) limits the ability to distinguish malicious exfiltration from legitimate resolver activity.
- Focus: Implement eBPF-based telemetry mapping to correlate `process_name` and parent-process hierarchies with `dest_ip` attributes of DNS queries to identify non-standard recursive resolvers and abnormal query volumes associated with specific executables.
