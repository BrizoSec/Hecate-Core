## 2. Adversary Tradecraft: Attack Techniques

### Summary
CrowdStrike has joined the Open Secure AI Alliance to combat emerging threats from AI, particularly focusing on adversary techniques such as prompt injection and agent manipulation. These tactics involve adversaries exploiting vulnerabilities in AI systems to inject malicious instructions or manipulate agents to perform unauthorized actions.

### Key Findings
- Adversaries are increasingly using advanced AI-driven tools to conduct sophisticated attacks that bypass traditional security measures.
- Prompt injection involves attackers inserting harmful code into input prompts, thereby manipulating the output of AI models to carry out malicious activities.
- Agent manipulation tactics involve adversaries tricking AI systems into performing unauthorized actions by exploiting weaknesses in their decision-making processes.
- CrowdStrike tracks over 180 adversary techniques and continuously updates its security services like Falcon AI Detection and Response to counter these threats.
