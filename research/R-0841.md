## 1. System Research: How It Works

### Summary
Warden Stealer is a Rust-based infostealer that operates by injecting shellcode into legitimate system processes, such as explorer.exe via the Shell_TrayWnd window, to evade detection. It employs sophisticated anti-analysis techniques, including VM checks via registry enumeration and Application-Bound Encryption bypasses, to systematically exfiltrate sensitive data including cryptocurrency wallet credentials and AI agent prompt histories.

### Key Findings
- The malware utilizes process injection by locating the Shell_TrayWnd window (typically owned by explorer.exe) using FindWindowA and GetWindowThreadProcessId to determine the target PID for execution.
- Warden Stealer specifically targets AI assistant and agentic coding tool data, collecting tokens, credentials, and prompt histories from applications such as Claude, Codex, Grok, and Cursor, which distinguishes it from traditional stealers.
- The loader binaries are deliberately inflated with massive PE overlays to bypass detection, a technique also associated with GoFlateLoader, and older builds leveraged TLS callbacks for code execution.
