## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries are exploiting the Indian tax season to launch spearphishing campaigns aimed at taxpayers, using malicious links and mobile exfiltration techniques such as Drinik malware to steal sensitive information. These attacks employ sophisticated tactics like obfuscating files and leveraging application layer protocols for data extraction.

### Key Findings
- Spearphishing links are being used extensively during tax season to trick Indian taxpayers into clicking on malicious URLs that download malware onto their devices.
- Drinik malware is targeting Android users, using advanced capabilities such as exfiltrating call logs and other protected user data over C2 channels.
- Attackers are employing obfuscation techniques to hide the true nature of files and communications from detection, making it harder for security tools to identify malicious activities.
- The use of application layer protocols is observed in malware tactics aimed at extracting data directly from mobile devices without raising suspicion.

## 5. Research Synthesis

### Executive Summary
During tax season, adversaries exploit Indian taxpayers by deploying phishing and malware campaigns that utilize sophisticated techniques such as brand abuse, malicious links, and mobile exfiltration via Drinik malware. These activities peak around the tax filing period and are characterized by unusual network communications and file modifications.

### Recommended Hypothesis
> Adversaries use spearphishing emails containing tax-themed lures to deploy Drinik malware on Android devices, aiming to steal sensitive information from Indian taxpayers during tax season.

### Gaps Identified
- Current coverage lacks detailed telemetry for mobile device monitoring and analysis of application layer protocols used in data exfiltration by malware like Drinik.

### Key Findings
- Hypothesis: Adversaries use spearphishing emails containing tax-themed lures to deploy Drinik malware on Android devices, aiming to steal sensitive information from Indian taxpayers during tax season.
- Gap: Current coverage lacks detailed telemetry for mobile device monitoring and analysis of application layer protocols used in data exfiltration by malware like Drinik.
- Focus: Enhance detection mechanisms for spearphishing emails with tax-themed lures, monitor unexpected network traffic patterns indicative of C2 communications, and improve visibility into file creation timestamps and process activity associated with known malicious payloads.
