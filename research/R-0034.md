## 3. Telemetry Mapping: OCSF Fields

### Summary
To detect the deployment of Starland RAT and WLDR C2 implant, which are typically used in financially motivated attacks, we need to monitor for indicators such as unexpected outbound connections, unusual process behaviors, and specific network protocols being abused or newly introduced. Key telemetry would include Windows Security Event Logs (e.g., logon events, process creation), DNS queries, HTTP/HTTPS traffic analysis, and potentially unknown file hashes.

### Key Fields
- process_creation: The Starland RAT may create suspicious processes that can be flagged by monitoring for unusual executable paths or command-line arguments. Populated in SIEM with a rate of 50%+ depending on endpoint coverage.
- network_connections: Look for unexpected outbound connections, particularly to known malicious IP addresses or domains. This field is typically populated around 10-20% when using comprehensive network monitoring tools.
- dns_queries: Monitor for DNS queries that resolve to known bad actors or newly registered domains used in C2 communications. Population rate can be up to 95% if all endpoints have DNS logging enabled.
- file_hashes: New files executed by the Starland RAT will generate unique hashes. This field is populated with a high frequency, around 80-100%, when using endpoint detection and response (EDR) tools.
- http_requests: Analyze HTTP/HTTPS traffic for anomalies such as unexpected user-agents or unusual request patterns indicative of C2 activity. Population rate may vary but can be up to 90% with proper web proxy logging in place.
