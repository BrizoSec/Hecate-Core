## 3. Telemetry Mapping: OCSF Fields

### Summary
To detect behavior indicative of the SANDWORM_MODE attack vector, particularly focusing on AI-driven malware leveraging supply chain attacks, we need detailed telemetry from endpoint processes, network traffic, and file modifications. Key areas include tracking command line arguments that invoke suspicious scripts or executables, monitoring outbound connections to known malicious domains or IP addresses, and observing unusual file creations or deletions.

### Key Fields
- process_name (65% populated): Identifies the executable running on endpoints which can be indicative of malware activities. Suspicious process names include those related to AI toolchains or scripts with obfuscated parameters.
- command_line (40% populated): Captures the full command line arguments used when executing processes, crucial for identifying malicious activity such as invoking compromised binaries with specific flags or parameters that signify a supply chain attack.
- network_dst_ip (80% populated): Tracks outbound IP addresses associated with network traffic. Detection of connections to newly observed or suspicious IPs can indicate an attempt at exfiltration or command and control communication.
- file_name (75% populated): Monitors file names created, modified, or deleted on endpoints. Suspicious filenames might include indicators like unusual extensions (.vbs, .js) or obfuscated strings that hint at malicious scripts.
- network_protocol (90% populated): Identifies the protocols used in network communications. Unusual use of HTTPS or DNS for data exfiltration can be a red flag, especially when combined with other suspicious activities.
- process_parent_name (55% populated): Tracks parent processes responsible for spawning child processes that could indicate lateral movement or privilege escalation tactics.
