**Topic:** ClickFix Mac Malware

## 1. System Research: How It Works

### Summary
ClickFix is a social-engineering technique that tricks users into executing malicious shell commands in Terminal by masking them as legitimate system prompts, such as fake CAPTCHAs. This method allows attackers to bypass traditional application download mechanisms and macOS security controls like Gatekeeper and notarization by delivering payloads directly through command-line execution.

### Key Findings
- The attack vector relies on clipboard hijacking, where a malicious command is automatically copied to the user's clipboard while they view a fake CAPTCHA or error page, requiring them to manually paste and run it in Terminal.
- Execution typically involves downloading obfuscated payloads via curl and piping them directly into shell interpreters (bash/zsh), which minimizes disk footprint and evades detection by avoiding recognizable installer artifacts.
- The technique effectively circumvents standard macOS security mechanisms, including quarantine handling and application notarization, because the malicious code is executed as a command-line instruction rather than a downloaded application file.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries utilize the ClickFix social engineering technique to trick macOS users into manually executing malicious Bash commands in Terminal via fake CAPTCHA prompts or error messages. This method allows the malware to bypass traditional file-based defenses and download architecture-specific Go-based Mach-O payloads that steal credentials and gradually drain cryptocurrency wallets.

### Key Findings
- The attack leverages ClickFix social engineering, where victims are deceived into pasting attacker-supplied commands into Terminal to execute a Bash script that downloads and runs the malware from malicious infrastructure.
- The deployed stealer targets browser passwords, Apple Keychain credentials, and cryptocurrency wallets (Bitcoin, Litecoin, Dogecoin, Monero, Ethereum, XRP) using a 'DRAIN' function that siphons funds by redirecting portions to attacker-controlled accounts.
- Persistence is established via macOS Background Task Management by deploying payloads disguised as software updates at /Users/<redacted>/Library/Caches/com.apple.softwareupdate/SoftwareUpdate and registering LaunchAgents such as com.apple.softwareupdated.plist.
- Infrastructure is hosted through Aeza Group (a sanctioned Russian bulletproof hosting provider), utilizing IPs 193.29.224.151 and 77.221.152.34 for payload delivery, with Command and Control communication occurring to 138.124.118.69 over port 8133/tcp.
- The malware employs evasion techniques including Gatekeeper bypass, ad-hoc signing, and credential harvesting via fake system prompts using osascript, while hiding artifacts in directories mimicking legitimate processes like com.apple.trustd.

## 5. Research Synthesis

### Executive Summary
This hunt focuses on detecting the ClickFix social engineering chain targeting macOS, characterized by fake CAPTCHA prompts that trick users into executing malicious bash commands in Terminal. The malware establishes persistence via Background Task Management (BTM) using ad-hoc signed LaunchAgents mimicking system processes and communicates with C2 infrastructure over non-standard ports (8133/tcp). Detection requires correlating suspicious terminal activity, specific file drops in disguised cache directories, and network connections to known Aeza Group hosting infrastructure.

### Recommended Hypothesis
> Adversaries use fake CAPTCHA social engineering to trick users into executing malicious bash commands that deploy Go-based Mach-O stealers via Background Task Management, aiming to steal cryptocurrency and credentials from macOS endpoints.

### Gaps Identified
- Standard endpoint telemetry often fails to capture the initial ClickFix vector (clipboard hijacking) or the specific 'osascript' privilege escalation prompts, while network monitoring may miss exfiltration traffic if it blends with legitimate HTTP flows on non-standard ports without SSL inspection.

### Key Findings
- Hypothesis: Adversaries use fake CAPTCHA social engineering to trick users into executing malicious bash commands that deploy Go-based Mach-O stealers via Background Task Management, aiming to steal cryptocurrency and credentials from macOS endpoints.
- Gap: Standard endpoint telemetry often fails to capture the initial ClickFix vector (clipboard hijacking) or the specific 'osascript' privilege escalation prompts, while network monitoring may miss exfiltration traffic if it blends with legitimate HTTP flows on non-standard ports without SSL inspection.
- Focus: Monitor for anomalous terminal command lines involving 'curl' piped to 'bash' in /tmp, specifically looking for the creation of LaunchAgents named com.apple.softwareupdated.plist and payloads dropped in $HOME/Library/Caches/com.apple.trustd/.
