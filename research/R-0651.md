## 2. Adversary Tradecraft: Attack Techniques

### Summary
In the first half of 2026, ransomware incidents in Japan increased by 4.7%, with The Gentlemen emerging as the most active group and Qilin utilizing AI-generated scripts for deployment. These attacks predominantly targeted small and medium-sized enterprises (SMEs) with capital under JPY 1 billion, which accounted for 80% of victims.

### Key Findings
- The Gentlemen was the most active ransomware group in Japan during this period, conducting 14 incidents and more than doubling their leak-site listings from 48 in January to 105 in July.
- Qilin ranked as the second most active group and showed evidence of using AI, specifically generating code for scripts such as 'deploy_locker.py' via LLMs.
- The Gentlemen utilized a diverse toolkit including RustHound for Active Directory data collection, AdaptixC2 for command-and-control, Ligolo-ng and Chisel for tunneling, and impacket-partial-mic for NTLM relay attacks.
- SMEs with capital under JPY 1 billion represented approximately 80% of the victims, indicating a strong focus on smaller organizations by these threat actors.
- Adversaries employed scripts to destroy backups before encryption, including 'veeam_kill.py' to disable Veeam backups and a Python script named 'deadman.py', while also using Responder for adversary-in-the-middle attacks.

## 5. Research Synthesis

### Executive Summary
The Gentlemen leveraged RustHound for Active Directory mapping and impacket-partial-mic for NTLM relay attacks to exfiltrate credential material (ntds.dit/SAM), while Qilin demonstrated the operationalization of LLM-generated code in deployment scripts like deploy_locker.py. Detection requires correlating specific tool execution, such as AdaptixC2 and Ligolo-ng, with anomalous credential dumping and backup destruction activities targeting SME infrastructure.

### Recommended Hypothesis
> Adversaries use LLM-assisted script generation and Rust-based AD enumeration tools to automate attack path analysis and ransomware deployment against under-resourced SME networks

### Gaps Identified
- Lack of telemetry for /mnt/vhdx directory creation and specific Python script file paths (veeam_kill.py, deploy_locker.py) prevents direct detection of backup destruction and payload staging phases
- Inability to detect content generated by LLMs in deploy_locker.py or deadman.py due to the absence of code integrity checks or behavioral baselining for non-standard Python script execution patterns
