## 1. System Research: How It Works

### Summary
TACACS+ is a 33-year-old authentication protocol operating on port 49 that validates user credentials and logs actions for networking devices such as routers and switches. It is widely embedded in modern enterprise, ISP, and cloud infrastructure to manage access control and accounting.

### Key Findings
- The protocol relies on weak encryption that can be cracked offline, allowing attackers to exploit a pre-authentication remote code execution vulnerability using only two packets.
- Two major versions of the protocol exist: one maintained by Shrubbery Networks (for which patches are now available) and an archived fork previously maintained by Facebook.
- Chinese cyber-espionage groups Salt Typhoon and Fire Ant have actively exploited TACACS+ vulnerabilities over the past two years to establish persistence and facilitate lateral movement within telecommunications networks.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries exploit a critical pre-authentication remote code execution vulnerability in the TACACS+ protocol to execute malicious code on authentication servers without valid credentials, leveraging weak encryption and requiring only two packets. This technique enables Chinese cyber-espionage groups to establish persistence and perform lateral movement within targeted telecommunications and enterprise networks.

### Key Findings
- The vulnerability allows unauthenticated remote code execution (RCE) by exploiting weak encryption in the 33-year-old TACACS+ protocol, which handles authentication for networking equipment like routers and switches.
- Chinese threat actors Salt Typhoon and Fire Ant have exploited this flaw over the past two years to target telecommunications companies globally for persistence and lateral movement.
- The attack is highly efficient, requiring only two packets to exploit, and can be conducted offline without needing valid user credentials first.
- The vulnerability affects both the version maintained by Shrubbery Networks (for which patches are available) and an archived fork maintained by Facebook; no CVE has been assigned yet.
- While the attack works over the internet or local networks with direct server access, exploiting it via intermediary devices is less reliable due to inconsistent protocol support across different vendor models.

## 5. Research Synthesis

### Executive Summary
Adversaries, specifically Salt Typhoon and Fire Ant, are exploiting a critical pre-authentication remote code execution (RCE) vulnerability in the legacy TACACS+ protocol by leveraging weak encryption to execute malicious code on authentication servers with only two packets. This technique enables persistent access and lateral movement within telecommunications and enterprise networks without valid credentials, targeting central infrastructure managed by Shrubbery Networks or archived forks.

### Recommended Hypothesis
> Adversaries use pre-authentication RCE via weak TACACS+ encryption to execute arbitrary code on port 49 for persistence and lateral movement on telecom and enterprise networking infrastructure
