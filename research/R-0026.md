## 1. System Research: How It Works

### Summary
UTA0565 is a cyber-espionage group that leverages zero-day exploits to deploy CLEANGULP malware onto government entities' systems. This malware communicates over HTTP with encrypted data and uses typosquatted domains for command and control, silently executing malicious payloads without triggering Windows security warnings.

### Key Findings
- The malware downloads a replacement executable from the web that has had its Windows internet warning marker stripped to avoid detection by users.
- CLEANGULP supports core commands such as file transfers and process listing over HTTP with encrypted data using AES-256-GCM, connecting to typosquatted domains.
- The exploit chain involves cloning legitimate websites to silently trigger Chrome and Windows zero-day exploits before executing the final malicious payload.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
UTA0565 leverages zero-day vulnerabilities in Google Chrome and Microsoft Windows through phishing emails to breach target networks. Once inside, the threat actor uses DLL Hijacking and Mimikatz for credential extraction before deploying CLEANGULP malware.

### Key Findings
- Uses zero-day exploits in Chrome (CVE-2026-85046 and CVE-2026-87491) and a Windows Advanced Local Procedure Call flaw to gain initial access
- Deploys phishing emails to deliver the exploit chain and breach networks
- Employs DLL Hijacking and Mimikatz for credential extraction after gaining initial foothold
- Deploys CLEANGULP malware within compromised environments

## 3. Telemetry Mapping: OCSF Fields

### Summary
Telemetry captures the creation and execution of processes initiated by PsExec for lateral movement within a network. The OCSF fields include details about the process name, command line arguments, destination IP address, parent process, file path, and timestamp.

### Key Fields
- process.name: Indicates the name of the process being created (e.g., psexec.exe)
- process.cmd_line: Contains the full command line used to execute the process
- network_activity.dst_endpoint.ip [NOT AN OCSF FIELD; did you mean device.ip?]: The destination IP address where PsExec is attempting execution
- process.parent_process.name: Identifies the parent process that initiated psexec.exe
- file.path: Path of the file being executed by PsExec, if any specific file is mentioned in command line arguments
- process.created_time: Timestamp when the process was created

## 5. Research Synthesis

### Executive Summary
UTA0565 utilizes zero-day vulnerabilities in Google Chrome and Microsoft Windows to breach target networks, employing phishing emails and DLL Hijacking for initial access and credential theft. They deploy CLEANGULP malware which communicates over HTTP with AES-256-GCM encryption to exfiltrate data.

### Recommended Hypothesis
> Adversaries use zero-day exploits in Chrome and Windows along with phishing emails and DLL Hijacking to gain initial access and credential theft, deploying CLEANGULP malware for lateral movement and data exfiltration on government entities' systems.

### Gaps Identified
- The encryption used by CLEANGULP (AES-256-GCM) blinds the payload content during communication, making it challenging to detect malicious traffic without decrypting the data. Additionally, there is a lack of telemetry capturing typosquatted domains and their associated IP addresses for better detection of command-and-control servers.
- Current monitoring lacks specific alerts or detections for modified executables that have had their Windows internet warning markers removed, which allows adversaries to avoid user detection during payload delivery.
