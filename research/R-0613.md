## 1. System Research: How It Works

### Summary
RevStealer is a stealthy Windows infostealer that gathers credentials, browser data, and cryptocurrency wallet information. It exfiltrates this stolen data in encrypted form and can disable Windows Update and Defender to run additional malicious activities like crypto mining.

### Key Findings
- RevStealer uses multi-layer validation to target specific victims rather than indiscriminate distribution.
- It spreads through fake downloads on GitHub repositories and game cheat websites, such as the Claude Opus 5 download.
- The malware exfiltrates various types of sensitive data including browser passwords, cookies, cryptocurrency wallets, gaming accounts, messaging data, and files before self-deleting to leave no trace.
