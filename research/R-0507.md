## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries often leverage compromised systems or phishing campaigns to gain initial access, subsequently using fileless techniques or living off the land binaries (LOLBIN) for lateral movement and persistence. They may also employ domain fronting or encrypted channels to obfuscate command and control communications.

### Key Findings
- Initial access vectors include spear-phishing emails with malicious attachments or links that exploit vulnerabilities in outdated software.
- [UNCERTAIN] Adversaries are increasingly using fileless malware techniques, such as PowerShell scripts, to execute commands directly in memory without touching the disk.
- Commonly observed tools for lateral movement and persistence include Windows Management Instrumentation (WMI) event subscriptions and scheduled tasks created with built-in system utilities like schtasks.exe or At.exe.
- Encryption is heavily used by adversaries to secure command and control traffic, making it harder to detect and analyze without decryption keys.
- [UNCERTAIN] Domain fronting techniques are employed by threat actors to hide their true IP addresses and evade network-based detection mechanisms.

## 3. Telemetry Mapping: OCSF Fields

### Summary
Telemetry shows a spike in PowerShell command execution events with suspicious argument patterns, which may indicate reconnaissance or credential dumping activities.

### Key Fields
- event_id: Security event ID related to the PowerShell activity (e.g., 4688 for process creation).
- user_name: The username associated with the PowerShell session. Typically 100% populated if user authentication is required.
- process_path: Path to the executable file that initiated the PowerShell command, which might be unusual or located in a temporary directory (populated at least 75%).
- command_line: Command line arguments used by the PowerShell process, showing potential signs of credential dumping or reconnaissance commands (populated around 90% when using monitored tools like Sysmon).
- process_parent_path: Path to the parent process that spawned the PowerShell instance, which could indicate lateral movement if unusual services are initiating such processes.
- network_connections: Network connections established by the PowerShell process, potentially showing outbound communication patterns indicative of data exfiltration or C2 (Command and Control) activity.
