## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries abuse the Create Account (T1136) technique to maintain persistent access to victim systems by establishing secondary credentialed entry points, thereby avoiding the need for deploying traditional remote access tools. This method is applied across local, domain, and cloud environments to ensure continued system control.

### Key Findings
- The T1136 technique falls under the Persistence tactic and is utilized to establish secondary credentialed access without requiring persistent remote access tools on the system.
- Accounts can be created in various environments including local systems, domains, and cloud tenants, with cloud accounts potentially having limited service access to reduce detection risks.
- On Linux systems, specific commands such as useradd and adduser are identified as methods for creating these accounts.
- Detection strategies include monitoring for command execution logs, user account creation events, and process creation activities associated with the technique.
- The Symantec WastedLocker campaign (June 2020) is cited as a specific example of adversaries using this technique to maintain access.
