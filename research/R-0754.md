## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries are abusing private, fraudulent Home Trading System (HTS) software to distribute ransomware, specifically KRSID, alongside traditional investment scams. Victims are lured via social media into installing these counterfeit applications, which then execute malicious updates that encrypt files and demand payment while simultaneously stealing initial investment funds.

### Key Findings
- Threat actors impersonate legitimate Swiss financial institution Union Bancaire Privee (UBP) using a fraudulent HTS named 'UBP Asset' to lure victims through Telegram and KakaoTalk group chats.
- The primary distribution mechanism involves the 'UBPPatch.Psh' executable, which connects to an update server to download a configuration file ('Update.Lst') that triggers the installation of ransomware ('HTSPnew.Exe').
- The deployed ransomware, identified as KRSID, is written in Rust and utilizes AES-256 and RSA-2048 encryption algorithms to lock victim files with the '.Krsid' extension.
- KRSID ransomware includes specific command-line arguments (such as --Path and --Dry-run) that allow for targeted encryption of file paths or logging of targets without execution, and notably lacks volume shadow copy deletion capabilities.
- Previous campaigns using similar private HTS platforms (e.g., 'HPlus') distributed Quasar RAT for remote control and data theft, indicating an evolution in threat actor tactics from pure financial fraud to dual-purpose malware distribution.

## 5. Research Synthesis

### Executive Summary
Threat actors are leveraging fraudulent Home Trading System (HTS) applications, specifically impersonating 'UBP Asset', to distribute the Rust-based KRSID ransomware. The attack chain relies on the malicious updater component 'UBPPatch.Psh' downloading configuration from unauthorized servers to trigger the execution of 'HTSPnew.Exe', which encrypts files using AES-256/RSA-2048 without deleting shadow copies.

### Recommended Hypothesis
> Adversaries use fraudulent HTS update mechanisms (UBPPatch.Psh) to deliver and execute KRSID ransomware (HTSPnew.Exe) on Windows endpoints for financial extortion and data encryption.

### Gaps Identified
- Lack of visibility into the 'UBPUpdater.Exe' execution chain and 'UBPPatch.Psh' network communications, as standard endpoint telemetry may not capture the specific FTP/HTTP connections to unauthorized update servers hosting 'Update.Lst'.
- Inability to detect the Rust-based KRSID payload via traditional signature matching due to its custom compilation and lack of known IoCs in static analysis, requiring behavioral detection of AES-256/RSA-2048 encryption patterns on specific file extensions.

### Key Findings
- Hypothesis: Adversaries use fraudulent HTS update mechanisms (UBPPatch.Psh) to deliver and execute KRSID ransomware (HTSPnew.Exe) on Windows endpoints for financial extortion and data encryption.
- Gap: Lack of visibility into the 'UBPUpdater.Exe' execution chain and 'UBPPatch.Psh' network communications, as standard endpoint telemetry may not capture the specific FTP/HTTP connections to unauthorized update servers hosting 'Update.Lst'.
- Gap: Inability to detect the Rust-based KRSID payload via traditional signature matching due to its custom compilation and lack of known IoCs in static analysis, requiring behavioral detection of AES-256/RSA-2048 encryption patterns on specific file extensions.
- Focus: Monitor for the execution of suspicious updater binaries (UBPUpdater.Exe, UBPPatch.Psh) and subsequent network connections to non-whitelisted domains or FTP endpoints associated with HTS updates.
