## 1. System Research: How It Works

### Summary
Falcon Onum is a tool designed to optimize and enrich telemetry data in real-time, reducing noise and enhancing the quality of data for faster threat detection. It works seamlessly with CrowdStrike's SIEM and MDR solutions to enhance data control and routing, thereby improving overall security posture.

### Key Findings
- Falcon Onum reduces noise by filtering out irrelevant data while amplifying context in telemetry data.
- It enables the creation of sophisticated pipelines like Impossible Traveler that parse and enrich user activity data (such as VPN login events) to detect unusual activities quickly.
- By integrating with external services like GeoIP through HTTP requests, Falcon Onum enhances its threat detection capabilities by adding geographical context to IP addresses.

## 3. Telemetry Mapping: OCSF Fields

### Summary
Telemetry for detecting malicious PowerShell command execution should capture detailed logs of PowerShell activity, including process creation events (Event ID 4688) and their associated command-line arguments. This data helps identify suspicious patterns or known indicators of compromise.

### Key Fields
- EventID (95% populated): Indicates the creation of a new process on Windows systems, which is crucial for monitoring PowerShell activity.
- CommandLine (70-100% populated): Provides the command-line arguments used to start the PowerShell process, critical for identifying malicious commands.
- ImageFileName (90-100% populated): Specifies the full path of the executable file that was created as a child process, often revealing if PowerShell is involved.
- ParentProcessId and ParentImageFileName (85-92% populated): Provide information about the parent process creating the PowerShell instance, aiding in understanding the context of process creation.

## 5. Research Synthesis

### Executive Summary
Falcon Onum is a powerful tool for enhancing real-time telemetry data, reducing noise, and improving threat detection capabilities by integrating with external services like GeoIP. It captures detailed logs of PowerShell activities to identify malicious patterns but faces challenges in detecting certain types of obfuscated malware and lateral movement.

### Recommended Hypothesis
> Adversaries use polymorphic malware and obfuscated shell commands to evade Falcon Onum's AI-driven detection mechanisms on Windows systems, aiming to mask their lateral movement activities.

### Gaps Identified
- Current coverage lacks the ability to fully detect or mitigate advanced evasion techniques used by adversaries, such as polymorphism and obfuscation of shell commands.
- There is insufficient real-time monitoring and detection of lateral movement activities beyond basic process creation events, which may allow adversaries to go undetected.

### Key Findings
- Hypothesis: Adversaries use polymorphic malware and obfuscated shell commands to evade Falcon Onum's AI-driven detection mechanisms on Windows systems, aiming to mask their lateral movement activities.
- Gap: Current coverage lacks the ability to fully detect or mitigate advanced evasion techniques used by adversaries, such as polymorphism and obfuscation of shell commands.
- Focus: Enhance Falcon Onum's capabilities for detecting polymorphic malware and obfuscated shell commands through more sophisticated pattern recognition and behavioral analysis.
- Gap: There is insufficient real-time monitoring and detection of lateral movement activities beyond basic process creation events, which may allow adversaries to go undetected.
- Focus: Develop advanced threat hunting pipelines like Impossible Traveler that integrate with GeoIP services to detect unusual geographical patterns in user activity data, enhancing the identification of lateral movements.
