## 1. System Research: How It Works

### Summary
IPIDEA, a large residential proxy network, was disrupted by Google in 2026. The network covertly enrolled consumer devices as exit nodes using SDKs embedded in apps, allowing threat actors to mask their malicious activities with legitimate IP addresses.

### Key Findings
- Residential proxy networks require control over millions of residential IP addresses for sale to customers.
- IPIDEA used software development kits (SDKs) within applications to covertly enroll consumer devices as proxy exit nodes without the users' knowledge.
- The compromised apps continued to function normally while secretly participating in the proxy network.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries abuse the T1021 Remote Services technique to gain unauthorized access and move laterally within networks by exploiting remote services such as RDP, SSH, and VNC. Google successfully disrupted a major residential proxy network in 2026 that was leveraging this method for malicious activities.

### Key Findings
- Adversaries use T1021 Remote Services to exploit legitimate remote access tools like RDP, SSH, and VNC for unauthorized access and lateral movement within networks.
- Google's disruption of the NetNut residential proxy network in 2026 highlights the threat posed by large-scale abuse of T1021 techniques.
- The use of residential proxies in conjunction with remote services exploitation enables attackers to mask their activities and evade detection.
- Valid accounts are frequently used by adversaries to log into remote services, allowing them to perform actions as authorized users.

## 3. Telemetry Mapping: OCSF Fields

### Summary
Adversaries may use Remote Services such as Telnet, SSH, or VNC with valid accounts to log into the system and perform actions. Detection focuses on identifying these remote access methods and associated authentication events.

### Key Fields
- network.telnet: Indicates the usage of the Telnet protocol which can be used for remote shell services by adversaries
- network.ssh: Identifies SSH connections, a commonly exploited method by attackers to gain unauthorized access
- network.rdp: Represents Remote Desktop Protocol (RDP) activity, another target for adversary exploitation through valid accounts
- event.authorization: Describes authentication events such as logins and logouts which are critical in identifying when an attacker is using a compromised account
- process.creation: Captures the creation of new processes initiated by remote access tools or scripts that adversaries might use post-compromise
- network.http: Tracks HTTP requests, useful for detecting if any web-based RDP clients or other remote management interfaces are being used
