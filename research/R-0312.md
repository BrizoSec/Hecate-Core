## 1. System Research: How It Works

### Summary
AS-REP Roasting is a Kerberos pre-authentication method used to protect against Pass-the-Hash attacks. It involves the client sending a request with a hash of its own password, which the server validates without revealing the actual password.

### Key Findings
- Normal behavior includes the client and server communicating encrypted messages for mutual authentication using Ticket Granting Tickets (TGT) and Service Tickets (ST)
- The AS-REP Roasting process involves a client sending an Authenticator with a hash of its own password, which the Key Distribution Center (KDC) verifies to authenticate the user
- The KDC sends a fresh Service Ticket if the authentication is successful, enabling the client to access services without re-entering credentials
- Disabled AS-REP Roasting accounts are unable to participate in this pre-authentication process and may be more vulnerable to Pass-the-Hash attacks
- It's important to note that, while AS-REP Roasting is a defensive measure against certain types of attacks (like Pass-the-Hash), it doesn't guarantee complete immunity and should be used in combination with other security measures.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries exploit the AS-REP Roasting technique (T1558.004) to abuse Kerberos pre-authentication disabled accounts. This method allows them to extract hashed passwords, enabling potential account takeover and unauthorized access.

### Key Findings
- Attackers leverage AS-REP Roasting to request TGS-REQ/TGS-REP messages without a valid TGT, exploiting the Kerberos protocol's weak pre-authentication process
- Common tools used in these attacks include Mimikatz, CrackMapExec, and Metasploit, which help in password hashing, cracking, and post-exploitation activities
- One of the key indicators is an unusual number of failed Kerberos authentication attempts, especially from internal IP addresses or unknown sources
- [UNCERTAIN] Some attacks might involve abnormal Kerberos ticket lifetimes or excessive ticket renewal requests
- Anomalous account lockouts or multiple login failures within a short time span can also be an indicator of AS-REP Roasting attempts
