## 1. System Research: How It Works

### Summary
Supply chain attacks often involve malicious actors creating or compromising legitimate software packages to distribute malware. In this case, researchers found that typosquatted NPM packages appeared normal but contained hidden malicious code upon closer inspection.

### Key Findings
- Typosquatting is a common technique used in supply chain attacks where attackers create package names similar to well-known ones to trick users into installing them.
- The obfuscated nature of the malicious code within these packages makes initial detection difficult, as it appears normal until de-obfuscation reveals its true purpose.
- Continuous polling behavior after initial beaconing is indicative of a sophisticated implant attempting to maintain persistence and communication with command-and-control servers.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries are leveraging the QuickFox supply chain attack to deploy FDMTP, a sophisticated backdoor that uses DLL sideloading and DMTP for encoding and encryption. This technique is employed by APT groups such as Earth Preta and Twill Typhoon, allowing them to evade detection while delivering secondary control tools like PTSOCKET for exfiltration.

### Key Findings
- FDMTP utilizes complex evasion techniques including DLL sideloading and DMTP encoding/encryption.
- The malware is delivered through a compromised supply chain, targeting entities with updated attack methods from Earth Preta and Twill Typhoon APT groups.
- Secondary tools such as PTSOCKET are deployed after the initial FDMTP infection to facilitate further malicious activities like data exfiltration.
- Adversaries implement fallback mechanisms for ensuring that even if primary payloads fail, secondary operations can still execute.

## 5. Research Synthesis

### Executive Summary
Adversaries are exploiting the QuickFox supply chain to deploy FDMTP, a sophisticated backdoor that uses evasion techniques such as DLL sideloading and DMTP encoding/encryption. This attack leverages typosquatted NPM packages to distribute malware, making initial detection challenging due to obfuscated code.

### Recommended Hypothesis
> Adversaries use supply chain injection of typosquatted npm packages to deploy FDMTP backdoor for persistence and data exfiltration on targeted entities

### Gaps Identified
- Current coverage lacks robust mechanisms to detect the initial stages of obfuscated malware within compromised NPM packages without manual analysis.
- There is a lack of real-time monitoring solutions that can effectively identify fallback mechanisms implemented by adversaries post-initial infection to ensure secondary payloads execute even if primary attacks fail.

### Key Findings
- Hypothesis: Adversaries use supply chain injection of typosquatted npm packages to deploy FDMTP backdoor for persistence and data exfiltration on targeted entities
- Gap: Current coverage lacks robust mechanisms to detect the initial stages of obfuscated malware within compromised NPM packages without manual analysis.
- Gap: There is a lack of real-time monitoring solutions that can effectively identify fallback mechanisms implemented by adversaries post-initial infection to ensure secondary payloads execute even if primary attacks fail.
- Focus: Develop advanced heuristic and behavioral detection methods for identifying anomalous process execution and file creation patterns associated with FDMTP implants.
- Focus: Enhance network traffic analysis capabilities to detect and block communication between compromised hosts and C2 servers used by adversaries.
