## 1. System Research: How It Works

### Summary
This dual-payload malware toolkit executes via a ClickFix social engineering chain, deploying RemotePanel for persistent remote access and BoundSiphon for in-memory credential theft. RemotePanel establishes control by masquerading as the Windows Time service and utilizing BNB Smart Chain contracts for dynamic C2 resolution, while BoundSiphon leverages process injection into legitimate Chromium processes to bypass App-Bound Encryption protections.

### Key Findings
- RemotePanel persists on the system by impersonating the Windows Time service, providing operators with PowerShell control, file/process management, screen access, and modular HVNC capabilities.
- The malware utilizes a BNB Smart Chain smart contract to dynamically resolve its active Command and Control (C2) server address, enabling infrastructure rotation without rebuilding the implant.
- BoundSiphon operates primarily in memory without establishing persistence, targeting browser credentials, cryptocurrency wallets, and password manager data by moving decryption logic into legitimate Chromium processes to extract App-Bound Encrypted secrets.
- The initial infection vector involves a ClickFix attack where 'finger.exe' is abused to retrieve subsequent commands from attacker infrastructure, followed by privilege escalation via the CMSTPLUA COM component in 'dead.fik'.
- Strong code overlap exists between BoundSiphon and a .NET stealer previously documented by Socket, particularly regarding browser decryption components, injection frameworks, and unusual build metadata.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries utilize a ClickFix delivery chain to deploy a dual-payload .NET toolkit consisting of RemotePanel for persistent remote access and BoundSiphon for data theft. This architecture separates operational roles, allowing RemotePanel to establish a durable foothold via masquerading while BoundSiphon operates in memory to exfiltrate high-value credentials and cryptocurrency assets.

### Key Findings
- The infection chain begins with ClickFix social engineering that uses 'finger.exe' with obfuscated characters to retrieve initial commands, followed by privilege escalation via the Windows COM component CMSTPLUA to launch a hidden elevated PowerShell process.
- RemotePanel masquerades as the Windows Time service (W32Time) to maintain persistence and provides operators with modular capabilities including PowerShell control, HVNC, file/process management, and fleet management.
- RemotePanel employs a BNB Smart Chain contract to dynamically resolve its Command and Control server address, enabling infrastructure rotation without requiring updates to the implant code.
- BoundSiphon targets browser credentials, sessions, cryptocurrency wallets, and password manager data, including secrets protected by Chromium App-Bound Encryption by injecting decryption logic into legitimate Chromium processes.
- Strong code overlap exists between BoundSiphon and a .NET stealer previously documented by Socket, indicating they share the same builder lineage or codebase despite differences in infrastructure and configuration.

RemotePanel establishes persistent remote access by masquerading as the Windows Time service and dynamically resolving Command and Control infrastructure via BNB Smart Chain smart contracts, while BoundSiphon executes in-memory to extract high-value data from Chromium browsers. The threat actor leverages a ClickFix delivery chain abusing 'finger.exe' for command retrieval and CMSTPLUA COM objects for privilege escalation, creating a specialized dual-payload architecture that separates persistent control from rapid credential theft.

### Recommended Hypothesis
