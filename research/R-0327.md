## 3. Telemetry Mapping: OCSF Fields

### Summary
Telemetry capturing the execution context and communication patterns of suspicious processes, particularly those involving unusual network activity or attempts at lateral movement within the infrastructure, are crucial for identifying potential AI-driven malware like SANDWORM_MODE. This includes tracking file modifications in critical directories, monitoring process creations with elevated privileges, and recording network communications that deviate from baseline behavior.

### Key Fields
- process_creation (90% populated): Tracks the creation of new processes on endpoints, which is essential for detecting anomalous or unauthorized process executions. This helps identify if scripts or executables are being run unexpectedly, possibly as part of a supply chain attack.
- file_modification (85% populated): Monitors changes to critical files and directories that can indicate tampering with system binaries or configuration files, often used by attackers to maintain persistence or exfiltrate data.
- network_connection (70% populated): Captures network traffic details such as destination IP addresses, port numbers, protocols, and payloads. This is vital for identifying malicious outbound communications that could be associated with command-and-control activities or data exfiltration.
- user_activity (50% populated): Tracks user-related events like logons, logoffs, and changes in permissions. Monitoring these can help identify unauthorized access attempts or privilege escalations.
- registry_change (60% populated): Detects modifications to the Windows Registry that could indicate persistence mechanisms or configuration changes made by malicious actors.
- process_child_creation (80% populated): Monitors the creation of child processes from parent processes, which is critical for identifying command execution patterns and lateral movement techniques.
