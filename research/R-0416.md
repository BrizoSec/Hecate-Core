## 3. Telemetry Mapping: OCSF Fields

### Summary
Telemetry capturing PowerShell usage is crucial for detecting malicious activity. This includes process creation events (Event ID 4688) that contain the command line used by PowerShell.

### Key Fields
- "process_name": "powershell.exe" (Highly populated): Identifies instances of PowerShell being executed, a common vector for malicious activities.
- "command_line": string (Moderately populated): Reveals the arguments passed to PowerShell which can indicate obfuscation or remote command execution.
- "parent_process_name": string (Highly populated): Helps in identifying if PowerShell was launched by another suspicious process, indicating possible lateral movement.
- "event_id": integer (4688 for Windows Security Event Logs) (Highly populated): Identifies the specific event related to a new process creation involving PowerShell.
