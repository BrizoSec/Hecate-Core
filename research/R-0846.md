The Kimsuky threat group is executing Operation GitPower, a spear-phishing campaign targeting Ukrainian diplomatic and security experts via fraudulent conference invitations that deploy malicious LNK files and fake Zoom installers. The adversary leverages legitimate GitHub repositories for both malware distribution and data exfiltration, utilizing PowerShell abuse to execute payloads and establish command-and-control channels through specific dynamic DNS hosts and IP infrastructure.

### Recommended Hypothesis
> Adversaries use spear-phished LNK files and fake Zoom installers to deploy PowerShell-based malware that abuses GitHub for distribution and exfiltration, targeting Ukrainian policy experts to monitor South Korea-Ukraine cooperation.

### Gaps Identified
- Lack of telemetry correlating outbound HTTPS traffic to specific GitHub user content URLs (raw.githubusercontent.com) with local PowerShell execution events, allowing exfiltration to blend into legitimate development tooling traffic.
- Insufficient detection for malicious LNK file properties pointing to non-standard or temporary directories combined with immediate PowerShell child processes, as standard EDR rules may whitelist common LNK targets in temp folders.
