## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries abuse Windows Kernel Driver Rootkits to hide their presence on a system by intercepting and manipulating kernel-level operations, allowing them to evade detection and maintain long-term persistence while conducting malicious activities.

### Key Findings
- Adversaries leverage advanced debugging techniques and tools like WinDbg for reversing rootkits.
- Rootkits are used to intercept system calls and manipulate kernel data structures to hide files, processes, and network connections from users and security software.
- Detection of such rootkits often requires deep analysis using specialized forensic and reverse engineering tools.
- Indicators include unusual system behavior, unexpected driver installations, or discrepancies between system queries and actual conditions.

### Key Fields
