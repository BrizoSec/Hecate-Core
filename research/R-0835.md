## 1. System Research: How It Works

### Summary
Threat actors deploy malware families EtherRAT and TONResolver via phishing emails disguised as guest complaints, utilizing LNK shortcuts to execute payloads. These malicious binaries evade traditional detection by resolving Command and Control (C2) infrastructure dynamically through public blockchain APIs (Ethereum and TON) rather than hardcoded domains.

### Key Findings
- The attack chain initiates with social engineering emails targeting the accommodation industry, featuring fake guest complaints, reviews, or inquiries to lure victims into executing malicious LNK shortcut files disguised as images.
- C2 infrastructure is managed via blockchain abuse: EtherRAT queries Ethereum APIs and TONResolver queries TON blockchain APIs to retrieve active C2 addresses, allowing operators to rotate infrastructure cheaply through small transactions.
- This blockchain-based resolution technique renders traditional domain takedown efforts ineffective, as the underlying C2 endpoints can be changed rapidly without updating the malware's core logic or relying on static DNS records.
- Adversaries likely employ generative AI to create unique email variants for each campaign, significantly complicating detection efforts by avoiding signature-based matching of standard phishing templates.
