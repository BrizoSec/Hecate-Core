## 1. System Research: How It Works

### Summary
DarkMe RAT is a Visual Basic 6-based malware that typically spreads through phishing emails containing links to malicious PIF files. Once executed, it can download additional payloads from a command and control (C2) server and uses obfuscation techniques to avoid detection by security software.

### Key Findings
- DarkMe RAT is delivered via phishing campaigns using disguised image links in emails.
- It employs process hollowing into legitimate signed Microsoft binaries for persistence.
- The malware performs an inverted sandbox check against 329 applications to identify genuine user environments.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
DarkMe RAT is a Visual Basic 6-based malware that has shifted from using sophisticated zero-day exploits to employing basic phishing tactics for initial infection. Once installed, it uses process hollowing and custom protocol handlers to steal financial information such as cryptocurrency wallets and passwords.

### Key Findings
- DarkMe RAT leverages phishing emails with disguised image links to deliver PIF executables as part of its attack chain.
- The malware employs Visual Basic 6 loaders and process hollowing techniques into legitimate signed Microsoft binaries for persistence and execution.
- DarkMe uses an inverted sandbox detection mechanism that identifies genuine user environments by checking against a list of 329 applications, ensuring it does not run in analysis systems.
- Indicators include specific file hashes (MD5, SHA1, SHA256), URLs related to phishing campaigns, and domains used for malicious activity.
