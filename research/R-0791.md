## 1. System Research: How It Works

### Summary
The PureRAT and PureLogs campaign leverages multilingual phishing emails disguised as product damage complaints to distribute ZIP archives containing customized loaders. These loaders utilize advanced evasion techniques, including process hollowing, Donut loading, and Bring Your Own Vulnerable Driver (BYOVD) via Lenovo drivers, to inject and execute the final payload on the target system.

### Key Findings
- Phishing infrastructure relies on PHP Swift Mailer, evidenced by Content-Type boundaries formatted as '_=_swift_<UNIXTIME>_<HEX>_=_ ', and utilizes mismatched Reply-To addresses pointing to Outlook/Hotmail accounts.
- Loader implementations vary per sample but consistently employ process hollowing, AMSI/ETW bypasses, and BYOVD attacks using the vulnerable Lenovo driver BootRepair.sys to evade detection.
- The campaign targets East and Southeast Asia with Japanese and Korean language emails, directing victims to fake document-sharing sites that adapt display languages based on IP and browser settings.
- Final payloads are consistently PureRAT (remote access) or PureLogs (credential theft), delivered via executables with double extensions and DLLs containing custom Donut loaders or Python interpreters.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries conducted a sophisticated phishing campaign targeting Japanese and Korean organizations in July and August 2026 by sending deceptive emails disguised as product damage complaints. These emails directed victims to fake document-sharing websites that delivered ZIP archives containing customized loaders for PureRAT or PureLogs malware, utilizing advanced evasion techniques like process hollowing and BYOVD attacks.

### Key Findings
- The campaign utilized Japanese and Korean-language phishing emails with subject lines mimicking product damage complaints or refund requests to lure victims.
- Victims were directed to impersonated document-sharing or video-viewing websites that determined the display language based on visitor location and device type, hiding download buttons on mobile devices.
- Downloaded ZIP archives contained executable files with double extensions and DLLs implementing varied loader techniques, including customized Donut loaders, Python interpreters, AMSI/ETW bypasses, process hollowing, and BYOVD attacks using vulnerable Lenovo drivers (BootRepair.sys).
- Despite varying loader implementations across samples, the final payloads consistently delivered PureRAT or PureLogs malware families to steal sensitive data.
- Email header analysis revealed commonalities in sending infrastructure, specifically shared Feedback-ID values and Content-Type boundaries characteristic of the PHP Swift Mailer library.

## 5. Research Synthesis

### Executive Summary
This campaign utilizes sophisticated loader evasion techniques, including process hollowing, BYOVD via BootRepair.sys, and customized Donut loaders within PHP Swift Mailer-delivered ZIP archives to deploy PureRAT or PureLogs payloads. Detection requires correlating specific driver loads with anomalous process injection behaviors rather than relying on static file hashes due to the campaign's polymorphic loader architecture.

### Recommended Hypothesis
> Adversaries use BYOVD via vulnerable Lenovo drivers and process hollowing to inject PureRAT/PureLogs payloads into legitimate system processes, bypassing AMSI/ETW monitoring on Japanese and Korean enterprise endpoints.

### Gaps Identified
- Lack of telemetry correlating the specific 'BootRepair.sys' driver load with immediate process creation or memory injection events, allowing the BYOVD stage to remain undetected if the driver itself is not flagged as malicious.
- Insufficient visibility into the execution context of 'python.exe' when invoked without clear command-line arguments, as the campaign repurposes the Python interpreter as a dynamic loader for obfuscated code segments.

### Key Findings
- Hypothesis: Adversaries use BYOVD via vulnerable Lenovo drivers and process hollowing to inject PureRAT/PureLogs payloads into legitimate system processes, bypassing AMSI/ETW monitoring on Japanese and Korean enterprise endpoints.
- Gap: Lack of telemetry correlating the specific 'BootRepair.sys' driver load with immediate process creation or memory injection events, allowing the BYOVD stage to remain undetected if the driver itself is not flagged as malicious.
- Gap: Insufficient visibility into the execution context of 'python.exe' when invoked without clear command-line arguments, as the campaign repurposes the Python interpreter as a dynamic loader for obfuscated code segments.
- Focus: Implement detection logic for process hollowing indicators (e.g., NtCreateProcessEx with specific flags) paired with the loading of known-vulnerable Lenovo drivers or unsigned DLLs into system processes.
- Focus: Monitor for the execution of EXE files with double extensions or unusual file associations derived from ZIP archive extractions, specifically tracking their parent process to identify loader stages initiated by archiving tools.
