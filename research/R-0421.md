## 3. Telemetry Mapping: OCSF Fields

### Summary
Telemetry capturing this behavior would include detailed logs of authentication events (e.g., failed login attempts), process creation events, network connections, and file access requests on Windows endpoints. These logs are crucial for identifying unauthorized access patterns that deviate from baseline activity.

### Key Fields
- windows.security.event_id: The Event ID field captures specific security-related activities, such as failed logon attempts (4625) or process creations (4688). This is typically highly populated in environments where detailed logging is enabled. For example, Event ID 4625 for a failed login attempt.
- windows.security.user_id: The User SID or username involved in the security event can help identify if an unauthorized user is attempting to gain access. This field would be populated whenever there's a user-related activity tracked by the system.
- process.creation_time: Captures the timestamp of when processes are created, which is essential for identifying unusual patterns such as rapid succession of process creations or unexpected times of day where these events occur.
- network.connection_details: Provides details about network connections initiated from endpoints, helping to identify potential exfiltration attempts or inbound attacks. This field could include IP addresses and ports involved in the connection.
- file.system.access_time: Records timestamps when files are accessed (read/write operations), which can be used to correlate with other events such as process creation times to infer malicious activity.
