## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries may attempt to exploit the telemetry data pipeline of Falcon Onum by injecting malicious traffic that mimics legitimate patterns, thereby evading detection and allowing them to engage in credential theft, exfiltrate sensitive data, or conduct lateral movement within an environment. They could also target the integration points with SIEM tools to inject false alerts or manipulate telemetry.

### Key Findings
- Adversaries leverage sophisticated obfuscation techniques for shell commands on VMware ESX to evade detection and persist in cloud environments.
- Credential theft remains a prevalent tactic, often achieved through phishing emails or exploiting vulnerabilities in web applications.
- Data exfiltration occurs via encrypted channels such as HTTPS or DNS tunneling, making it challenging to detect without advanced analytics like those provided by Falcon Onum.
- Streamlined SIEM integration can be exploited if not properly secured, allowing adversaries to inject false telemetry that disrupts threat detection efforts.
- Suspicious travel patterns of users or processes across network segments can indicate lateral movement and should be monitored closely for signs of compromise.
- The use of third-party EDR tools alongside Falcon Onum requires robust configuration management to ensure consistent security posture and alerting.

## 3. Telemetry Mapping: OCSF Fields

### Summary

### Key Fields
- process_name (95% populated): Name of the process accessing sensitive files, which can help in identifying potential malicious software or unauthorized user activities.
- file_path (80% populated): Path to the file being accessed, indicating the location and type of data targeted by suspicious processes.
- user_sid (70% populated): Security Identifier (SID) of the user account associated with the process accessing sensitive files, aiding in identifying whether the access is legitimate or unauthorized.
- parent_process_id (65% populated): Process ID of the parent process that spawned the current process, useful for tracing process lineage and detecting command-and-control activities.
- event_id (100% populated): Event ID from Windows Security Event Logs indicating specific actions such as file access, which can be filtered to focus on critical events like 4656 (File System Access), etc.

Falcon Onum enhances real-time threat detection by enriching telemetry data in CrowdStrike's Falcon platform, but adversaries can exploit its capabilities through sophisticated evasion techniques like obfuscated commands and false alerts. The system effectively detects unauthorized access to sensitive files via unexpected processes but requires further scrutiny against cloud-based threats and SIEM integration vulnerabilities.
