### Summary

This includes monitoring for valid account logins via services like SSH, RDP, or VNC, which can indicate adversary presence before ransomware execution.

### Key Fields
- user.login (85% populated): Records the user accounts that successfully authenticate to remote services such as SSH, RDP, or other network-accessible applications. This field will help identify if known bad actors are logging into systems.
- network.connection (90% populated): Logs network connections initiated from external IP addresses to internal services on specific ports associated with remote access protocols (e.g., 22 for SSH, 3389 for RDP).
- process.create (75% populated): Tracks the creation of new processes related to remote service applications or other command-line utilities that may be used by adversaries after gaining a foothold. This can indicate if ransomware is being deployed.
- file.modify (60% populated): Monitors changes in file permissions, attributes, or content which could signal ransomware activity such as encrypting files.
