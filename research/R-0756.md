## 1. System Research: How It Works

### Summary
ChainScript is a Node.js Remote Access Trojan that disguises itself as legitimate software installers (e.g., Spotify, Zoom) to deploy a malicious agent into user-specific Microsoft-themed directories. It utilizes a Polygon blockchain smart contract to dynamically resolve its active WebSocket command-and-control endpoint at runtime, allowing operators to rotate infrastructure without redistributing the malware.

### Key Findings
- The malware installer (MSI) distributes components across multiple legitimate-looking paths within the user profile, such as %LOCALAPPDATA%\Microsoft\Windows\Libraries\QuickSystemSearch for the Node.js runtime and %APPDATA%\Microsoft\Windows\Themes\SettingsHostStandard58 for the application core.
- Command and Control discovery is achieved via a specific Polygon smart contract (Chain ID 137, Contract 0xf9099d0d747368cce8C10226CC9AF2bFD4DDbCF4), which acts as a DNS-like resolver to provide the active WebSocket server address to the infected endpoint.
- The infection chain relies on hidden PowerShell and VBScript execution (specifically _scatter.ps1 and _agent.vbs) to launch the bundled node.exe runtime without displaying a console window, establishing persistence through scheduled tasks or Registry Run keys.
- The agent provides extensive remote access capabilities including interactive CMD/PowerShell shells, file management, screenshot capture via .NET utilities, cryptocurrency wallet theft, and remote JavaScript execution.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries deploy ChainScript, a Node.js Remote Access Trojan (RAT), through malicious Windows Installer packages disguised as legitimate software like Spotify and Zoom via ClickFix lures. The malware leverages a Polygon blockchain smart contract to dynamically resolve its Command and Control (C2) WebSocket infrastructure at runtime, allowing operators to rotate backend services without rebuilding the agent.

### Key Findings
- ChainScript is delivered via malicious MSI files masquerading as legitimate software (e.g., Spotify, Zoom Workplace, Microsoft Teams) distributed through ClickFix campaigns.
- The malware utilizes an 'EtherHiding-style' technique to discover C2 endpoints by querying a Polygon smart contract (contract 0xf9099d0d747368cce8C10226CC9AF2bFD4DDbCF4 on chain ID 137) via eth_call.
- The agent is built on Node.js, with the installer bundling a custom runtime and decomposing files into disguised Microsoft-themed user profile paths (e.g., %LOCALAPPDATA%\Microsoft\Windows\Themes) to evade detection.
- Execution involves hidden PowerShell and VBScript stages that launch the bundled node.exe to run the primary agent from app\src\index.js without displaying a console window.
- ChainScript provides extensive remote access capabilities including interactive shells, file operations, screenshots, payload deployment, cryptocurrency wallet theft, and remote JavaScript execution.

## 5. Research Synthesis

### Executive Summary
ChainScript is a Node.js-based RAT that leverages malicious MSI installers disguised as legitimate software to deploy a JavaScript agent into user-profile directories, utilizing a Polygon smart contract to dynamically resolve WebSocket C2 endpoints at runtime. The adversary employs 'EtherHiding' techniques to rotate infrastructure without redistributing agents, while maintaining persistence through hidden PowerShell and VBScript execution chains that evade standard console logging.

### Recommended Hypothesis
> Adversaries use Polygon blockchain smart contracts to dynamically resolve WebSocket C2 endpoints and Node.js runtimes disguised as legitimate software installers to deploy persistent remote access capabilities on endpoint hosts.

### Gaps Identified
- Standard EDR telemetry often misses the initial configuration retrieval from api-configuard[.]com due to lack of specific DNS logging for this domain, and internal file system scattering into Microsoft-themed user paths (e.g., %LOCALAPPDATA%\Microsoft\Windows\Libraries) blends with legitimate activity.
- The use of bundled node.exe and hidden wscript.exe execution chains obscures the primary process tree, making it difficult to correlate the malicious JavaScript agent with standard PowerShell or CMD command-line telemetry without specific process creation rule tuning.

### Key Findings
- Hypothesis: Adversaries use Polygon blockchain smart contracts to dynamically resolve WebSocket C2 endpoints and Node.js runtimes disguised as legitimate software installers to deploy persistent remote access capabilities on endpoint hosts.
- Gap: Standard EDR telemetry often misses the initial configuration retrieval from api-configuard[.]com due to lack of specific DNS logging for this domain, and internal file system scattering into Microsoft-themed user paths (e.g., %LOCALAPPDATA%\Microsoft\Windows\Libraries) blends with legitimate activity.
- Gap: The use of bundled node.exe and hidden wscript.exe execution chains obscures the primary process tree, making it difficult to correlate the malicious JavaScript agent with standard PowerShell or CMD command-line telemetry without specific process creation rule tuning.
