## 1. System Research: How It Works

### Summary
FortiMail is an email security appliance that utilizes an Internet Encryption (IBE) feature, which contains a critical path traversal vulnerability allowing unauthenticated attackers to write arbitrary files and modify system binaries. The exploit leverages improper NULL byte neutralization in HTTP/HTTPS requests to compromise the underlying operating system, leading to active exploitation in the wild.

### Key Findings
- The vulnerability (CVE-2026-104286) affects FortiMail versions 7.2 through 8.0 and allows unauthenticated code execution by bypassing input validation via NULL byte manipulation.
- Indicators of compromise include modified system binaries, added malicious libraries, and suspicious archive configurations communicating with external Command & Control infrastructure.
- A verified C2 indicator is the IPv4 address 79.141.169.187, associated with Tele Asia Limited (ASN: 133398), which has been flagged as malicious in threat intelligence feeds.
- The attack payload involves executing shell commands via '/bin/sh -c', specifically referencing a path starting with '/migadmin' to escalate privileges or deploy malware.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries exploit CVE-2026-104286, a critical path traversal vulnerability in FortiMail versions 7.2 through 8.0, to write arbitrary files unauthenticatedly by leveraging improper NULL byte neutralization. This exploitation allows attackers to compromise the underlying system and establish persistence through modified binaries and malicious libraries.

### Key Findings
- The primary attack vector is CVE-2026-104286, a path traversal vulnerability affecting FortiMail versions 7.2.0-7.2.9, 7.4.0-7.4.8, 7.6.0-7.6.6, and 8.0.0-8.0.1.
- The vulnerability enables unauthenticated attackers to write arbitrary files on the system via crafted HTTP/HTTPS requests, specifically targeting the IBE (Internet-Based Encryption) feature.
- Indicators of Compromise include seven specific MD5 hashes and seven SHA256 hashes associated with modified system binaries or malicious libraries, alongside an active C2 IP address (79.141.169.187).
- Post-exploitation activities involve executing commands such as '/bin/sh -c 'O=/migadmin ...'', indicating potential command execution and system manipulation.
- Mitigation strategies include immediately disabling the IBE feature or restricting management interface access until patches are released.
