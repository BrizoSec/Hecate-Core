## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries use the Adversary-in-the-Middle (AiTM) technique to intercept and manipulate network traffic, enabling them to block, log, modify, or inject data into communications. This allows attackers to gain control over network communications and potentially compromise sensitive information.

### Key Findings
- Attackers leverage privileged network access for real-time modification of network traffic using AiTM attacks.
- Indicators of Compromise (IoCs) include unusual DNS requests or HTTPS traffic patterns that deviate from normal communication flows.
- Tools such as SSLStrip, Ettercap, and Wireshark can be used by attackers to intercept and manipulate encrypted web communications.
- Attackers often use phishing emails to initially gain access to a network before deploying AiTM techniques.
