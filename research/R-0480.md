## 3. Telemetry Mapping: OCSF Fields

### Summary
Telemetry capturing user logon events across multiple systems (e.g., Event ID 4624) and process creation activities on endpoints (e.g., Event ID 4688) would be crucial for detecting lateral movement. Additionally, network logs showing unusual outbound connections to suspicious IP addresses or domains are also vital.

### Key Fields
- ocsf:log:event_id (95% populated): Identifies specific Windows Security Event IDs like 4624 and 4776 that indicate logon events and privilege elevation, respectively. These can help detect initial access and lateral movement.
- ocsf:network:dest_ip (80% populated): Tracks destination IP addresses of network connections, which is useful for identifying communication with known malicious IPs or unusual outbound traffic patterns indicative of data exfiltration attempts.
- ocsf:endpoint:process_name (92% populated): Captures the names and paths of processes created on endpoints. This field helps identify suspicious binaries or scripts that are typically used in lateral movement attacks.
- ocsf:user:username (100% populated): Logs user account names involved in logon events, process creations, and network activities. Correlating these with baseline activity can highlight anomalies associated with compromised accounts.
