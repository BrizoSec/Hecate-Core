## 1. System Research: How It Works

### Summary
The native integration between Sublime Security and Elastic Security automatically routes email detections from Sublime into the Elastic platform, enabling a unified view of phishing incidents. This setup allows security teams to correlate quarantined emails with subsequent endpoint activity and track the threat's propagation across all affected mailboxes.

### Key Findings
- Sublime Security natively sends email detection data directly into Elastic Security, eliminating manual ingestion steps for initial triage.
- The system enables the correlation of a specific quarantined email with subsequent actions or telemetry observed on the endpoint after the phishing attempt.
- Elastic Security is utilized to aggregate and pull threat intelligence from every mailbox the malicious email reached, providing comprehensive scope analysis.
- The integration supports agentic SOC workflows, specifically targeting alert triage in under three minutes by automating the connection between email detection and endpoint context.
