## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries may exploit the Falcon AIDR system by deploying malware that mimics legitimate behavior or by leveraging AI toolchain supply chain attacks to inject malicious code into Copilot Studio agents and Claude Code, thereby evading detection mechanisms. CrowdStrike's approach is robust but requires continuous updates to counter new evasion techniques.

### Key Findings
- Adversaries are increasingly using AI-based tools in their attack chains, such as the SANDWORM_MODE technique, to bypass traditional security measures like AIDR.
- Supply chain attacks targeting AI toolchains pose a significant risk, with attackers potentially injecting malicious code during the development phase of software used by organizations.
- CrowdStrike's AIDR technology protects against sophisticated threats by employing an adversary-based detection and response methodology that focuses on identifying unusual patterns indicative of malicious activity.
- The integration of community tools like ShellShock Scanner enhances threat intelligence sharing, aiding in proactive defense strategies.
