## 1. System Research: How It Works

### Summary
Kimsuky is an advanced persistent threat (APT) group that targets South Korean entities using various tactics such as dynamic DNS resolution and spear-phishing campaigns through compromised servers.

### Key Findings
- Kimsuky leverages Dynamic Domain Name System (DDNS) services to maintain command and control infrastructure within the target's region, enhancing operational security and camouflage.
- APT group activities include using domain fronting or similar techniques to avoid detection by network monitoring tools.
- The use of South Korean-based DDNS servers allows Kimsuky to blend in with legitimate traffic patterns and evade regional cybersecurity measures.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries like Kimsuky abuse the 'Data from Local System' technique (T1005) to gather sensitive data and files of interest from compromised systems before exfiltration. This involves searching local system sources such as file systems, configuration files, databases, or even process memory using command-line interpreters and scripts.

### Key Findings
- Kimsuky uses compromised blogs and infrastructure to deliver malware to high-profile targets in South Korea.
- Adversaries employ various encryption methods like RC4 for data exfiltration from compromised systems.
- Techniques include system service discovery (T1007) to identify running services on the victim's machine.
- Custom methods are used by Kimsuky to archive and encrypt collected data before exfiltration, making detection challenging.
- The use of command-line interpreters like cmd.exe aids in executing scripts for file manipulation and data collection.

## 3. Telemetry Mapping: OCSF Fields

### Summary
Telemetry for detecting T1005 'Data from Local System' should focus on monitoring command-line activities and file access patterns that may indicate an adversary is searching the local system for sensitive data. This includes tracking commands executed by users or services, changes to files of interest, and unusual activity in directories known to contain sensitive information.

### Key Fields
- process_event.command (60% populated): Tracks the specific command-line arguments used by processes that may be indicative of file searching behavior on the system. For example, cmd.exe commands such as 'dir' or 'findstr'.
- file_event.path (85% populated): Monitors access to files and directories known to contain sensitive data. This includes paths to configuration files, databases, and other repositories where attackers might look for valuable information.
- network_event.destination.port (40% populated): Although T1005 is about local system searches, this field can help identify if any exfiltration attempts follow the initial data gathering.
- process_event.parent_process_guid: Helps establish process lineage to determine if a suspicious command-line activity was spawned by another malicious process.
- event_time: Correlates timestamps of file access and command executions to identify patterns in how an attacker might be searching for specific types of files over time.
- user_account.name (95% populated): Identifies the user account associated with unusual file accesses or command-line activities, which is crucial for attributing potentially malicious behavior.
