## 1. System Research: How It Works

### Summary
Casbaneiro is a banking trojan targeting Latin American users via phishing emails and PDFs, utilizing HTA downloaders and AutoIt loaders to establish persistence and steal financial data. It employs sophisticated evasion techniques including geofencing based on IP location, distributed data-receiving servers that split stolen information, and malformed HTTP packets to complicate analysis.

### Key Findings
- The malware implements strict geofencing filters to target specific Latin American countries (Argentina, Peru, Colombia, Mexico) while actively avoiding victims in Germany, France, and English-speaking regions.
- It uses a multi-stage infection chain involving HTA downloaders and AutoIt loaders, dropping components such as an AutoIt interpreter and compressed files into a randomly named directory under C:\.
- Stolen data is exfiltrated across multiple distributed servers using malformed HTTP packets, with the infrastructure deliberately returning HTTP 403 responses to hinder detection and analysis efforts.
- The trojan exhibits active persistence and collection behaviors including clipboard injection (specifically targeting Bitcoin wallets), fake window creation for fraud, and storage of system information markers in %APPDATA% and HKCU\SOFTWARE.

The Casbaneiro banking trojan employs a multi-stage infection chain involving geofencing, HTA downloaders, AutoIt loaders, and distributed data exfiltration. Detection requires monitoring for the creation of specific mutexes to prevent concurrent execution, file system artifacts in temporary directories, registry modifications, and network connections to known malicious IPs/domains associated with its distributed server infrastructure.

- process_activity:process.parent_process.name: Investigate parent-child process anomalies where a browser or document viewer (e.g., chrome.exe, acroread.exe) spawns an AutoIt interpreter or PowerShell instance.

## 5. Research Synthesis

### Executive Summary
Casbaneiro employs a multi-stage infection chain using HTA downloaders and AutoIt loaders to deploy banking trojans with strict geographic geofencing targeting Latin America. The malware utilizes sophisticated evasion techniques including distributed data exfiltration across multiple servers, malformed HTTP packets, and deliberate HTTP 403 responses to complicate forensic analysis.

### Recommended Hypothesis
> Adversaries use distributed data-receiving servers and malformed HTTP packets to exfiltrate stolen financial data while evading detection on specific Latin American targets via IP-based geofencing.

### Gaps Identified
- Standard network monitoring may miss the threat due to deliberate HTTP 403 responses and malformed packet structures designed to bypass traditional signature-based DLP or IDS rules, requiring deep packet inspection or behavioral analysis of AutoIt script execution.
