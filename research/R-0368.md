## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries may exploit the traditional CVSS-based patching approach by focusing on vulnerabilities that are highly rated but not necessarily the most critical in a given context, thereby delaying or diverting attention from more targeted and impactful risks. CrowdStrike's Falcon Platform mitigates this risk by employing a dynamic, risk-based patching strategy that evaluates technical impact based on real-time adversary intelligence and asset context.

### Key Findings
- Adversaries often prioritize vulnerabilities based on CVSS scores to maximize disruption while remaining under the radar of standard patch management practices.
- The Falcon Platform uses attack path analysis and exploit likelihood validation to identify risks that are most relevant to an organization's specific assets and threat landscape, not just the highest CVSS-rated ones.
- Real-time adversary intelligence and context-aware risk assessment tools help in identifying emerging threats before they can be exploited by adversaries.
- Integration of Falcon Platform IOAs (Indicator of Attack) into Next-Gen SIEM enables proactive detection and response to new threats, enhancing overall security posture.

## 3. Telemetry Mapping: OCSF Fields

### Summary
To meet the requirements of CISA Binding Operational Directive (BOD) 26-04, which mandates continuous monitoring and logging of security events in government networks, telemetry must capture detailed endpoint activity. This includes process creation, modification of system settings, network connections initiated by processes, and user authentication activities that can indicate malicious or suspicious behavior.

### Key Fields
- event_id (100% populated): Unique identifiers for specific Windows Security Events such as logon events (4624), logoff events (4634), process creation (4688), and service-related operations (7045). These IDs help in tracking user activity, system modifications, and potential security breaches.
- process_name (90% populated): The name of the process that was created or modified. This is crucial for identifying potentially malicious software or unexpected program execution.
- network_connections: Information about network connections initiated by processes, including destination IP addresses and port numbers. This helps in detecting unusual outbound communications indicative of data exfiltration or command-and-control (C2) activities.
- user_identity (85% populated): User account details involved in security events like logon/logoff actions and process execution. Essential for tracking user activity across the network and identifying potential insider threats.
- timestamp: Precise time when an event occurred, critical for correlating related incidents and establishing timelines of attack sequences.
