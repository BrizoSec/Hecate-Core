## 1. System Research: How It Works

### Summary
The August 2, 2026 security update includes several hardening changes aimed at enhancing system security by enforcing TDI transport registration requirements. This change can potentially disrupt third-party applications that use unregistered TDI transports over sockets.

### Key Findings
- The SSU (Servicing Stack Update) only runs when a servicing task is being executed, meaning it does not operate independently of actual system updates or modifications.
- Applications using unregistered third-party TDI transports may face disruptions due to the new security hardening requirements introduced in the update.
- Official documentation for this specific security update (KB5011352) is missing, which could pose challenges for IT administrators trying to understand and mitigate potential issues.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries are increasingly exploiting vulnerabilities in public-facing applications to gain initial access, using sophisticated techniques such as trust abuse and AI supply chain compromises for stealth. This includes weaponizing trusted environments to conduct targeted attacks on cryptocurrency systems.

### Key Findings
- Adversaries exploit public-facing applications to compromise systems through known vulnerabilities.
- Sophisticated adversaries use trust abuse in software supply chains, particularly targeting AI environments, to execute stealthy operations.
- The DPRK-associated adversary FAMOUS CHOLLIMA has been exploiting trusted AI-centric environments to conduct cyber attacks.
- Attackers leverage downgrade techniques to weaken security measures and gain unauthorized access to systems.
- CrowdStrike reports an uptick in threat actors using advanced exploitation methods that include supply chain attacks on software updates.
- Indicators of compromise include unusual traffic patterns, unexpected software updates from untrusted sources, and anomalies in AI system behavior.
