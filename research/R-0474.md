## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries use the Adversary-in-the-Middle (AiTM) technique to intercept and manipulate network traffic, enabling them to conduct a range of malicious activities such as data exfiltration or system manipulation. This method is particularly concerning in ICS environments where it can target critical control systems like PLCs and routers.

### Key Findings
- Adversaries employ ARP poisoning to establish an AiTM position within networks, allowing them to intercept traffic between devices.
- Security software discovery is a common precursor to AiTM attacks as adversaries seek to bypass or disable security measures before establishing their presence in the network.
- AiTM tactics can be employed against various critical infrastructure components such as control servers and routers, posing significant risks to operational integrity.
- The Triton Safety Instrumented System Attack illustrates how sophisticated actors leverage AiTM techniques to target specific systems within ICS environments for malicious purposes.

## 3. Telemetry Mapping: OCSF Fields

### Summary
Telemetry capturing malicious PowerShell execution involves tracking process creations for PowerShell scripts (powershell.exe) that are launched from suspicious locations or connected to known malicious endpoints. Relevant data includes command-line arguments, source/destination IPs and URLs, and file system modifications.

### Key Fields
- process_creation.executable_name (80% populated): Identifies the name of the executable being run, such as powershell.exe.
- process_creation.command_line (65% populated): Contains the full command line arguments passed to PowerShell, which can reveal malicious commands or paths.
- network_traffic.destination_ip_address (72% populated): Indicates connections made by PowerShell scripts to external IPs, potentially for C2 communications.
- file_system.file_path (90% populated): Tracks file system operations related to temporary directories where suspicious files may be dropped before execution.
