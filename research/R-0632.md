## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries abuse T1055 (Process Injection) to execute arbitrary code within the address space of legitimate, live processes, thereby evading process-based defenses and potentially escalating privileges. This technique masks malicious activity under trusted system binaries, allowing attackers to access memory, network resources, and elevated rights while bypassing standard detection mechanisms.

### Key Findings
- Process injection is a primary method for executing arbitrary code in the context of another process, enabling access to that process's memory and system/network resources.
- The technique is specifically utilized to evade process-based defenses by masking execution under a legitimate process, which helps avoid detection from security products.
- Adversaries may employ multiple process injections within sophisticated samples to segment modules further enhancing evasion capabilities.
- Injection implementations often abuse legitimate functionalities and can utilize Inter-Process Communication (IPC) mechanisms, such as named pipes, for communication channels.
- T1055 is a prevalent technique frequently observed in conjunction with the Defense Evasion and Persistence tactics across various operating systems.
