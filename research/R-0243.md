## 2. Adversary Tradecraft: Attack Techniques

### Summary
MoustachedBouncer is a cyberespionage group that targets foreign diplomats in Belarus, employing file transfer protocols and remote data staging techniques to steal sensitive information. This group has been active since at least 2014.

### Key Findings
- Utilizes file transfer protocols (T1071.002) for exfiltrating stolen data from compromised systems.
- Employs application layer protocol abuse to evade detection and maintain operational security during espionage activities.
- Uses remote data staging techniques (T1074.002) to temporarily store stolen data on external servers before final extraction or analysis.
- Targets high-value assets like foreign diplomats in Belarus, indicating a focus on state-level intelligence gathering.
