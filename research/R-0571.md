## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries are exploiting legitimate Chrome and Edge extensions to deliver malicious payloads that can steal credentials or drain cryptocurrency wallets. This abuse typically involves the use of compromised or newly created extensions to bypass browser security mechanisms, targeting unsuspecting users who trust well-known platforms.

### Key Findings
- Adversaries are leveraging trusted third-party extension repositories like the Chrome Web Store and Microsoft Edge Add-ons to distribute malware.
- [UNCERTAIN] Malicious payloads may be delivered through seemingly benign updates or new installations of extensions that have been compromised or created for malicious purposes.
- The attack vectors often include social engineering tactics, such as promoting fake security tools or productivity enhancers on forums and social media platforms.
- Once installed, the malicious extension can execute arbitrary code, steal user credentials stored in browsers' password managers, or monitor cryptocurrency transactions to siphon funds from wallets.
- Indicators of compromise might include unusual activity within browser extensions, such as unexpected requests for permissions unrelated to the extension's functionality.
- Adversaries are likely using obfuscation techniques and living-off-the-land binaries (LOLBins) to evade detection by security solutions.
