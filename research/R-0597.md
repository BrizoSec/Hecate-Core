### Summary

This includes process creation events, network connections, file modifications, and external device usage details.

### Key Fields
- process_creation (90% populated): Tracks the creation of new processes on endpoints, which is crucial for identifying malicious activities like AI-driven malware execution or automated attack scripts.

- external_device_usage (65% populated): Tracks usage of external devices such as USB drives and mobile phones, which can be used by attackers for data exfiltration or lateral movement within a network.
