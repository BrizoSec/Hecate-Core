## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries use System Network Configuration Discovery (T1016) to gather network configuration details such as IP and MAC addresses, which helps them understand the network environment and plan subsequent attack actions. This technique aids in identifying accessible systems and determining if they can communicate with command-and-control servers.

### Key Findings
- Adversaries leverage tools like `ipconfig`, `route`, and `nbtstat` to discover system network configurations.
- Technique T1016 includes sub-techniques such as Internet Connection Discovery (T1016.001) and Wi-Fi Discovery (T1016.002).
- Network Device CLI commands are used on network devices to gather information about IP addresses of configured interfaces and routes.
- Frankenstein group has been observed using T1016 to enumerate hosts for public IP address discovery.
- APT29 uses this technique to ensure web servers in a victim environment are Internet-accessible before deploying additional tools or malware.

## 5. Research Synthesis

### Executive Summary
Global webmail espionage involves sophisticated phishing attacks where APT groups, like Chinese APT32, use AI-driven lures and social engineering to harvest credentials. Adversaries also employ System Network Configuration Discovery (T1016) to gather network configuration details for planning subsequent attack actions.

### Recommended Hypothesis
> Adversaries use sophisticated phishing techniques leveraging AI and social engineering to harvest webmail credentials, while simultaneously using T1016 behavior to map out the target's network environment.

### Gaps Identified
- Current telemetry coverage lacks comprehensive monitoring of command-line parameters passed to system utilities like ipconfig or netsh on Windows systems for detailed analysis.
- There is insufficient tracking and correlation between DNS queries made during reconnaissance activities and subsequent network connection attempts that may indicate malicious intent.

### Key Findings
- Hypothesis: Adversaries use sophisticated phishing techniques leveraging AI and social engineering to harvest webmail credentials, while simultaneously using T1016 behavior to map out the target's network environment.
- Gap: Current telemetry coverage lacks comprehensive monitoring of command-line parameters passed to system utilities like ipconfig or netsh on Windows systems for detailed analysis.
- Gap: There is insufficient tracking and correlation between DNS queries made during reconnaissance activities and subsequent network connection attempts that may indicate malicious intent.
- Focus: Enhance real-time detection capabilities by expanding telemetry to capture full command lines with parameters for system utilities such as ipconfig, arp, and netsh.
- Focus: Improve the ability to correlate DNS queries with network connections to better identify and respond to reconnaissance activities indicative of webmail espionage.
