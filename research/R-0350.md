## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries with privileged network access exploit the Adversary-in-the-Middle (AiTM) technique to intercept and manipulate real-time network traffic, enabling them to alter data in transit or inject malicious content without detection. This method is particularly concerning for industrial control systems (ICS), where such interference can have severe operational impacts.

### Key Findings
- Adversaries use AiTM attacks to modify network protocols in real time, often targeting specific communication channels between devices and servers.
- Attackers leverage deep packet inspection techniques to identify and manipulate sensitive information within the intercepted traffic.
- Common tools include Man-in-the-Middle (MitM) software that can be deployed on compromised systems or devices to facilitate AiTM attacks.
- Indicators of Compromise (IoCs) may include unusual network latency, unexpected data corruption or anomalies in protocol behavior during communications.

## 3. Telemetry Mapping: OCSF Fields

### Summary
Telemetry capturing PowerShell command execution, particularly those involving downloading content from external sources via HTTP/HTTPS requests, is critical for identifying malicious activities. This includes process creation events where PowerShell.exe is launched with parameters indicating remote script downloads.

### Key Fields
- process_creation (90% populated): Monitors the creation of new processes on endpoints, specifically tracking when PowerShell.exe is executed with suspicious arguments or URLs.
- network_connection (85% populated): Tracks network connections initiated by endpoint processes. This includes HTTP/HTTPS requests made from PowerShell scripts to external IP addresses or domains, which can indicate attempts to download malicious payloads.
- dns_requests (75% populated): Captures DNS query activity related to the resolution of domain names accessed via PowerShell commands for downloading content.
- file_operation (60% populated): Identifies file creation and modification activities that follow script execution, such as writing files to disk from downloaded content.
