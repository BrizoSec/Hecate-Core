## 3. Telemetry Mapping: OCSF Fields

### Summary
The exploitation window for threats is shrinking due to accelerated AI adoption. This trend necessitates continuous monitoring of critical events in Windows Security logs and endpoint telemetry to detect anomalous behavior indicative of threat activity.

### Key Fields
- event_id (100% populated): Captures specific event IDs from the Windows Security Event Logs, such as 4624 for account logon, 4625 for account logoff, and other relevant IDs like 4768 for user rights management changes.
- process_name (95% populated): Tracks executable file names which are crucial for identifying malicious processes or unusual executables running on endpoints.
- process_path (90% populated): Provides the full path of the process being executed, critical for detecting suspicious locations like temporary directories or system folders.
- user_id (100% populated): Identifies the user account associated with an event. Essential for tracking and correlating activities to specific users, especially in scenarios involving privilege escalation or lateral movement.
- source_ip (85% populated): Indicates the source IP address of incoming network traffic relevant for detecting external threats that may leverage known vulnerabilities.
