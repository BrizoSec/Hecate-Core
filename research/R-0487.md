## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries may abuse the Falcon Onum system by exploiting its features to hide malicious activities, such as using obfuscated shell commands or conducting fileless attacks that evade traditional detection mechanisms. They can also leverage legitimate tools and techniques to blend in with normal network behavior and avoid triggering alerts.

### Key Findings
- Adversaries use obfuscated shell commands on VMware ESX environments to bypass detection by Falcon Onum.
- Fileless script-based attacks are prevalent, where adversaries execute malicious scripts directly in memory without writing files to the disk.
- Data exfiltration techniques involve using legitimate channels like web services or email to transfer sensitive data out of an organization's network.
- The system can detect suspicious user behavior patterns such as impossible travel scenarios (users logging into systems from geographically distant locations simultaneously).
- Leveraging Redis and other caching mechanisms to store and manipulate user credentials or session tokens for lateral movement within a network.
- Adversaries often employ advanced persistence techniques that utilize built-in system tools and services to maintain access without relying on external malware.

## 3. Telemetry Mapping: OCSF Fields

### Summary
Detecting unauthorized access involves monitoring for anomalous login activities, process creation events that indicate privilege escalation or malware execution, and unusual outbound network connections.

### Key Fields
- user_id (75% populated): Unique identifier for a user account involved in the logged activity.
- process_name (90% populated): Name of the process being created or executed.
- event_id (100% populated): A unique identifier for an event type, such as login attempts or network connections.
- ip_address (85% populated): Source IP address from which a connection originates or to which data is sent.
- process_path (65% populated): Full path of the process being executed, useful for identifying malware or unauthorized software installation.
- logon_type (40% populated): Indicates the type of logon event, such as interactive, network, service, etc., aiding in distinguishing between normal and suspicious activities.

Telemetry mapping highlights the need for monitoring anomalous login activities, process creations, and network connections to detect unauthorized access.

### Recommended Hypothesis

### Key Findings
