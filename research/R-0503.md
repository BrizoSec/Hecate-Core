## 1. System Research: How It Works

### Summary
Fake app stores and apps trick users into downloading malware by mimicking legitimate software, often through deceptive web traffic or search engine optimization techniques. Once installed, these fake apps can steal personal information and compromise device security.

### Key Findings
- Cybercriminals use third-party and fake app stores to distribute malicious apps that mimic popular applications.
- Users are typically tricked into downloading malware through deceptive tactics such as SEO manipulation and official-looking webpages.
- Once installed, these fake apps often steal personal information and can compromise device security.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries exploit the trust users have in well-known websites by creating fake versions that deliver malicious software, often using social engineering tactics such as phishing and misleading error messages to trick victims into executing harmful commands or downloading malware.

### Key Findings
- Adversaries use SEO poisoning techniques to rank their malicious sites highly in search engine results, making them appear legitimate.
- Fake websites are designed to mimic popular services, offering free apps that actually install malware on users' systems when downloaded and executed.
- Social engineering tactics include presenting fake error messages or CAPTCHA prompts that instruct users to execute commands via the terminal or Run dialog box.
- Malicious copy-and-paste campaigns can target multiple operating systems, not just Windows.
- Adversaries compromise third-party web services or register custom URIs to intercept sensitive data and deliver malware.
- Phishing through SMS messages is used to distribute malicious APK files targeting mobile devices.

## 3. Telemetry Mapping: OCSF Fields

### Summary
To detect fake popular sites offering free apps that take over PCs, telemetry should focus on identifying unusual file download patterns, execution of suspicious binaries, and network anomalies indicative of lateral movement or data exfiltration.

### Key Fields
- file.created (50% populated): Tracks creation of new files, which is often the first sign of a malicious app installation. Look for executables with unknown origins.
- process.executed (75% populated): Records the execution of processes, especially those that are unusual or unauthorized on user machines. This can help identify when a fake app starts running.
- network.http.request (90% populated): Captures HTTP requests made by binaries to suspicious domains, which is often an early sign of lateral movement or communication with command and control servers.
- file.modified.permissions (30% populated): Monitors changes in file permissions that could indicate malicious software attempting to gain elevated privileges.
- network.http.response (85% populated): Tracks responses from HTTP requests which can reveal data exfiltration attempts by fake apps.
- endpoint.event.logon (40% populated): Logs successful and failed logon events, useful for detecting account compromise or lateral movement.

## 5. Research Synthesis

### Executive Summary
Adversaries exploit user trust in popular websites and applications by creating fake sites offering free apps, which actually deliver malware that steals personal information and compromises device security. These attacks often involve social engineering tactics such as misleading error messages and SEO poisoning to trick users into downloading malicious software.

### Recommended Hypothesis
> Adversaries use deceptive web traffic and social engineering tactics to distribute fake apps through third-party app stores, with the goal of stealing personal information and compromising device security on user PCs.

### Gaps Identified
- Current telemetry coverage does not sufficiently monitor changes in file permissions or unauthorized process executions that could indicate early-stage malicious activity.

### Key Findings
- Hypothesis: Adversaries use deceptive web traffic and social engineering tactics to distribute fake apps through third-party app stores, with the goal of stealing personal information and compromising device security on user PCs.
- Gap: Current telemetry coverage does not sufficiently monitor changes in file permissions or unauthorized process executions that could indicate early-stage malicious activity.
- Focus: Enhance detection of unusual file download patterns and HTTP requests made to suspicious domains. Additionally, increase monitoring for social engineering tactics such as fake error messages and misleading webpages designed to trick users into executing harmful commands.
