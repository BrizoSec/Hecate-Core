## 1. System Research: How It Works

### Summary
Chinese threat actor UTA0565 exploited unpatched zero-day vulnerabilities in Google Chrome and Microsoft Windows by launching sophisticated phishing campaigns with fake websites impersonating legitimate organizations. The attacks involved a chain of exploits targeting CVE-2026-85046, CVE-2026-87491, and CVE-2026-85880 to deliver the CLEANGULP malware.

### Key Findings
- UTA0565 used fake domains and phishing emails to target Asian government entities with an exploit chain leveraging multiple zero-day vulnerabilities in Chrome and Windows.
- The attacks delivered a new backdoor malware called CLEANGULP, which can execute commands and perform file operations on compromised systems.
- Multiple Chinese APT groups demonstrated coordinated access to the same exploit kit during the vulnerability window.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
Chinese APT group UTA0565 exploited unpatched zero-day vulnerabilities in Google Chrome and Microsoft Windows through sophisticated phishing campaigns, using fake websites that mimic legitimate organizations to trick victims into downloading a custom backdoor payload called CLEANGULP.

### Key Findings
- UTA0565 registered multiple domains mimicking reputable organizations like China Digital Times and the Center for American Progress to conduct targeted phishing attacks.
- The attack chain leveraged three zero-day vulnerabilities: CVE-2026-85046, CVE-2026-87491, and CVE-2026-85880 in Chrome and Windows.
- CLEANGULP is a previously undocumented malware with backdoor capabilities such as command execution, file operations, and beacon object file execution.
- The malware communicated with C2 servers via encrypted HTTP traffic using custom encoding.
