## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries can exploit vulnerabilities in AI systems through advanced techniques like prompt injection, where they manipulate input to alter or control system outputs. By understanding these methods better, defenders can develop more robust safeguards against such manipulations.

### Key Findings
- Prompt injection attacks are a significant threat as they allow attackers to manipulate AI-based security tools and systems.
- Adversaries use sophisticated techniques to hide prompt injection attacks within normal traffic or queries, making detection challenging.
- CrowdStrike's new taxonomy for prompt injection provides detailed insights into how these attacks work and how they can be mitigated.
- The Open Secure AI Alliance leverages open models and shared tools to collaboratively test and improve the resilience of AI systems against adversarial threats.
- Third-party environments are increasingly becoming targets, as seen with Falcon Exposure Management now being available for such settings.
