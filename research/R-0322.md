## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries use Adversary-in-the-Middle (AiTM) techniques to intercept and manipulate network traffic, allowing them to block, log, modify, or inject malicious content into the communication between parties. Common methods include ARP poisoning and setting up rogue proxies.

### Key Findings
- Adversaries employ ARP spoofing to perform AiTM attacks by sending fake ARP messages onto a local area network (LAN), creating confusion about which MAC address corresponds to which IP address.
- Attackers may use proxy servers or man-in-the-middle tools like SSLstrip, to intercept and modify HTTP traffic on unsecured networks.
- Tools such as Ettercap can be used for both sniffing and poisoning ARP tables to facilitate AiTM attacks in LAN environments.
- Indicators of Compromise (IoCs) include unusual network traffic patterns, unexpected DNS requests or responses, and discrepancies between IP addresses and MAC addresses.
