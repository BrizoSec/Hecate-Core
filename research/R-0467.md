## 1. System Research: How It Works

### Summary
npm (Node Package Manager) is a widely used package manager for JavaScript and Node.js applications, facilitating the installation of pre-written code packages to accelerate development. Developers rely on npm to install, manage, and share modules that are hosted in the npm registry.

### Key Findings
- npm packages serve as building blocks for software projects, allowing developers to reuse code without reinventing the wheel.
- The npm ecosystem's popularity makes it a prime target for supply chain attacks like ChainDrop, which can propagate through trusted channels and infect multiple dependencies.
- ChainDrop leverages the trust within the npm community by inserting malicious code into legitimate packages, highlighting the critical need for robust security measures in package management.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
The ChainDrop worm infected over 400 npm packages by stealing developer credentials and using compromised publishing tokens to propagate itself, affecting millions of users through the npm ecosystem. This attack highlights the risk of supply chain breaches that can spread rapidly across widely used software libraries.

### Key Findings
- Adversaries targeted npm packages with high download counts to maximize impact.
- The worm stole developer and cloud credentials to gain access to package publishing tokens, allowing for further propagation.
- Infected packages executed malicious code during installation that steals information and spreads the infection.
- ChainDrop shares similarities with previous Mini Shai-Hulud attacks in its self-propagating nature and targeting of software supply chains.
