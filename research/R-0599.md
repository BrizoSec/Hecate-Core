## 3. Telemetry Mapping: OCSF Fields

### Summary
To detect a financially motivated threat actor targeting Brazil, we need to focus on Windows Security Event Logs, system/application logs, and endpoint telemetry. This includes monitoring for unusual process creation events (e.g., rundll32.exe or powershell.exe with suspicious command-line arguments), network connections to known malicious IPs, unexpected user authentication patterns, and file/directory changes indicative of data exfiltration.

### Key Fields
- event_id (4688 - Process Creation): Indicates creation of processes which could be used for lateral movement or executing malware. Typically highly populated in a Windows environment, around 90-100%.
- destination_ip: Logs network connections to external IPs, useful for identifying data exfiltration attempts. Populated when outbound traffic is monitored, typically 80-95%.
- event_id (4768 - Account Management): Tracks changes in user account permissions and password resets which could indicate credential theft or misuse. Populated around 10-20%.
- file_path: Monitors file access and modifications that can reveal data exfiltration activities like copying files to network shares or USB drives. Typically populated based on organization’s monitoring policies, around 50%.
- process_id (PID): Tracks process IDs which are essential for linking related events together during an investigation. Populated when process creation events are logged, typically 90-100%.
