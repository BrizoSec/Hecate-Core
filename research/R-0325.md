## 3. Telemetry Mapping: OCSF Fields

### Summary
Telemetry should capture network traffic data including TCP/UDP port scans, DNS queries to potentially malicious or unusual domains, and HTTP(S) requests that target known bad IPs. Event logs from endpoints and perimeter security devices are also crucial for identifying failed login attempts, unexpected service communications, and anomalies in user behavior.

### Key Fields
- event.category (50% populated): Identifies the category of events like authentication, network connection, etc., which can help in detecting unusual patterns such as excessive failed login attempts or unexpected access to sensitive systems.
- dns.query (30% populated): Tracks DNS requests and responses that could indicate reconnaissance activities, including queries to known malicious domains or DGA-generated domains.
- network.http.request (25% populated): Captures HTTP(S) traffic which can be used for identifying connections to suspicious or blacklisted IP addresses.
- process.opened_file.path (40% populated): Monitors file access patterns that could suggest reconnaissance activities, such as reading network configuration files or scanning tools being run.
- network.tcp.stream (60% populated): Provides detailed information about TCP streams which can help in identifying port scans and unusual traffic volumes directed at a single host or range of hosts.
- event.action (75% populated): Describes the specific action taken, such as 'login failed', 'process created', 'file written', etc., crucial for pinpointing malicious activities.
