### Key Findings
- CVE-2026-20131 is a critical remote code execution vulnerability (CVSS 10) that allows unauthenticated attackers to execute arbitrary Java code with root privileges by sending specially crafted web requests containing serialized Java code to the web-based management interface.
- CVE-2026-20079 is an authentication bypass vulnerability enabling unauthenticated, remote attackers to obtain root access on the Cisco FMC software.
- CVE-2026-20316 is a static credential vulnerability that allows a remote attacker to log in using a low-privileged account, distinct from the critical RCE and authentication bypass flaws.
- The vulnerabilities are not dependent on one another for exploitation, meaning an attacker can exploit CVE-2026-20079 or CVE-2026-20316 independently of the other.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries are actively exploiting two critical vulnerabilities in Cisco Secure Firewall Management Center (CVE-2026-20079 and CVE-2026-20316) to bypass authentication or log in using static credentials. These exploits enable remote attackers to execute scripts, gain root access, and deploy various post-compromise tools including web shells, reverse shells, and ransomware.

### Key Findings
- Three distinct threat clusters are actively exploiting CVE-2026-20079 (authentication bypass) and CVE-2026-20316 (static credential vulnerability) in Cisco Secure Firewall Management Center.
- One cluster deploys web shells and performs credential exfiltration after gaining initial access.
- A second cluster utilizes Netcat-based reverse shells to deploy Cyclops Blink malware on compromised systems.
- A third cluster, attributed to a ransomware operator, uses static credentials for reconnaissance and deploys tunneling tools to harvest credentials before ransomware deployment.
