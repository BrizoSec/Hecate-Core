## 1. System Research: How It Works

### Summary
Intercom-client@7.0.4 is a tool or library that interacts with the Intercom API for customer communication management. However, version 7.0.4 has been exploited to harvest GitHub credentials by scanning repositories for exposed secrets and using them for unauthorized access.

### Key Findings
- Exploitation involves scanning public and private GitHub repositories for exposed credentials
- Developers need robust tools to prevent accidental exposure of sensitive information in their code repositories
- The incident underscores the importance of secure credential management practices

## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries often target popular npm packages such as Intercom-client to deploy malicious versions that harvest GitHub credentials from unsuspecting users when they install or use these compromised packages. This technique allows adversaries to gain access to repositories and further propagate their attacks within the ecosystem.

### Key Findings
- Adversaries create rogue npm package versions with slight modifications in version numbers to mimic legitimate updates, tricking developers into installing them.
- The malicious code inside these packages typically includes scripts or libraries that capture environment variables containing API keys, tokens, and other sensitive information during installation or runtime.
- Attackers may leverage the compromised GitHub credentials to push more malware into various repositories, escalating their control over multiple development environments.
- Signatures of such attacks can be identified through unusual traffic patterns when packages are installed or updated, as well as by monitoring for unexpected code changes in legitimate repositories.
