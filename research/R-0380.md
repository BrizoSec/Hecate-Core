## 1. System Research: How It Works

### Summary
GitHub Actions is a continuous integration and delivery (CI/CD) platform that automates software development workflows. When triggered by events such as code pushes, it executes predefined actions using GitHub-hosted runners or self-hosted runners, which can be used to automate tasks like testing, building, and deploying applications.

### Key Findings
- GitHub Actions enables developers to automate various tasks in their repositories without the need for local infrastructure.
- The platform's flexibility allows threat actors to leverage it for malicious purposes by hosting executable payloads on external servers and using GitHub workflows to execute them.
- Vulnerabilities like CVE-2026-41940 can be exploited via automated attack chains set up through GitHub Actions, leading to credential harvesting and secret exfiltration from targeted systems.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries are abusing GitHub Actions to exploit cPanel and WHM servers by launching scans from compromised repositories hosted on GitHub, using the platform's resources to execute payloads and steal credentials without relying on package users' systems. This method allows threat actors to leverage GitHub-hosted runners for scanning vulnerable servers and exfiltrating data.

### Key Findings
- Threat actors use compromised GitHub repositories to launch malicious workflows targeting cPanel and WHM servers, exploiting vulnerabilities such as CVE-2026-41940.
- The attack relies on GitHub Actions' hosted runners for executing payloads remotely, enabling the harvesting of cloud credentials and API keys from targeted servers.
- Compromised repositories deliver payloads to Command and Scripting Interpreters like cmd.exe on target systems via C2 servers at IP 43.228.157.68, facilitating data exfiltration.
- Adversaries can dynamically update or expand the payload hosted externally from GitHub, enhancing their capability for continuous exploitation without repository modifications.

### Executive Summary
Adversaries are exploiting GitHub Actions to automate the scanning and exploitation of cPanel and WHM servers, using compromised repositories to execute payloads remotely and exfiltrate sensitive data. This method leverages vulnerabilities such as CVE-2026-41940 and involves the use of Command and Scripting Interpreters like cmd.exe on target systems.

### Recommended Hypothesis

### Gaps Identified
- The current coverage lacks detection for the dynamic update mechanisms of external payloads hosted outside GitHub repositories, which enhances continuous exploitation capabilities without repository modifications.
