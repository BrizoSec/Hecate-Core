## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries often abuse legitimate system tools and administrative protocols to gain unauthorized access, maintain persistence, and exfiltrate data without detection. They may leverage social engineering tactics or exploit vulnerabilities in software to deploy malware that enables command and control communications.

### Key Findings
- Adversaries commonly use living off the land (LotL) techniques, exploiting built-in system tools like PowerShell for lateral movement and credential dumping.
- [UNCERTAIN] Malware may be delivered via spear-phishing emails containing malicious attachments or links to compromised websites hosting exploit kits.
- Commonly observed is the use of fileless malware which resides solely in memory, making it harder to detect using traditional signature-based methods.
- Persistence mechanisms such as adding registry keys or scheduled tasks are frequently employed by adversaries to ensure continued access after system reboots.
- Data exfiltration often occurs through encrypted channels, utilizing tools like WinSCP for transferring files securely over SFTP/SSH.
- Remote Desktop Protocol (RDP) brute-forcing remains a prevalent technique for initial compromise and lateral movement within networks.

### Summary
The telemetry captures behaviors indicative of an advanced persistent threat (APT) attempting to move laterally within the network by leveraging stolen credentials. This involves unusual access attempts and file copy actions across hosts.

### Key Fields
- event_id: Event IDs such as 4624, 4625 from Windows Security Logs indicate user logon/logoff activities which can be crucial for detecting unauthorized access patterns.
- process_name (80% populated): Monitors the creation of processes that are commonly abused by attackers, like 'PsExec.exe', 'WMIEXEC.exe' or other remote management tools used to execute commands on a target system.
- user_id: Identifies the user accounts involved in suspicious activities. This can help trace whether known admin or service accounts are being compromised for lateral movement.
- file_path (70% populated): Tracks the file paths and names of files being copied between systems, which may indicate data exfiltration attempts or malware distribution.
- destination_ip: Monitors connections to external IPs that do not typically communicate with internal resources, signaling potential data leakage.
