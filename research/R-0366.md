## 1. System Research: How It Works

### Summary
The Zoom macOS installer typically requires special user permissions to install or uninstall the application, and it is designed securely by the official developer. However, attackers exploit this setup by distributing fake Zoom update installers that trick users into granting root access, allowing them to inject malware like Overlord RAT for persistent remote control.

### Key Findings
- Fake Zoom installer attacks target macOS users by masquerading as legitimate updates and exploiting user permissions to gain root access.
- Once installed, the Overlord RAT sets up persistence mechanisms on infected systems to continuously run and maintain a connection with command-and-control servers for remote operation.
- These malware campaigns often involve sophisticated social engineering tactics and are associated with advanced threat actors such as North Korean hackers.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries are using a fake Zoom installer on macOS to deliver the Overlord Remote Access Tool (RAT), exploiting users' trust in well-known applications to secretly install and execute malicious software that can provide remote access to their systems.

### Key Findings
- The use of legitimate-looking installation packages for popular software like Zoom is a common tactic by adversaries to trick users into downloading malware.
- Overlord RAT, once installed, provides the attacker with extensive control over the infected system, including keylogging and screen capture capabilities.
- Indicators include unexpected processes related to Overlord RAT running on the system, network connections to known malicious IP addresses or domains, and unusual changes in file permissions or hidden files.
- Adversaries often bundle malware within seemingly legitimate software updates or installations, making it crucial for users and security teams to verify the authenticity of downloads.

## 3. Telemetry Mapping: OCSF Fields

### Summary
The behavior involves an attacker distributing a malicious package masquerading as a legitimate Zoom application installer which installs Overlord RAT on macOS systems. Relevant telemetry includes process creation events, network connections made by the malicious payload, file system modifications related to the installation of the RAT, and any suspicious use of built-in tools for persistence or lateral movement.

### Key Fields
- process.name (highly populated): Monitors the names of processes launched on macOS systems. Look for unusual executables that might be associated with the fake installer, such as 'ZoomInstaller.app' or other malicious binaries.
- network.http.request.uri (moderately populated): Tracks HTTP requests made by any process. This can help in identifying if the RAT is communicating with command and control servers via HTTP/HTTPS protocols.
- file.system.file_change (highly populated): Logs modifications to files on the file system, including creation or modification of executable files that could be used by Overlord RAT for persistence or payload delivery.
- process.parent.name (moderately populated): Helps in identifying the parent process responsible for launching suspicious child processes. This can help trace back to the fake installer if it spawns malicious processes.
- file.system.directory_change (highly populated): Monitors changes in directories, which could indicate that files have been moved or placed into system directories by the RAT for persistence.
- process.command_line (moderately populated): Captures command-line arguments used when launching processes. This can be useful to identify if any suspicious commands were used during installation or execution of the fake Zoom installer.
