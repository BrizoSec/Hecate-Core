## 1. System Research: How It Works

### Summary
WebDAV (Web Distributed Authoring and Versioning) is a protocol that enables users to edit and manage files on remote web servers, often over HTTPS port 443 to avoid detection. Rundll32.exe is a Windows utility used to execute functions exported from DLLs by ordinal number, which can be used for legitimate system tasks but also abused for hiding malicious intent.

### Key Findings
- WebDAV traffic on port 443 blends in with normal HTTPS traffic and can be used for covert data exfiltration or command execution without raising alarms.
- Rundll32.exe can invoke functions within DLLs via ordinal numbers, making it difficult to detect malicious activities based solely on file names or process names.
- The absence of dropped files on the disk makes ClickFix harder to identify using traditional signature-based detection methods.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries are employing the ClickFix technique to exploit users through social engineering, often using encoded PowerShell commands or rundll32 with WebDAV to execute payloads. This method obfuscates files and information to evade detection and is becoming increasingly sophisticated as threat actors refine their approach.

### Key Findings
- Adversaries are leveraging WebDAV and rundll32.exe for ordinal execution of obfuscated commands to bypass security measures.
- Encoded PowerShell commands or scripts delivered via ClickFix can be used to download and execute malware, making detection challenging due to the use of legitimate system binaries.
- The technique involves sophisticated social engineering tactics that encourage users to copy and paste suspicious content from web pages into their systems, often masquerading as helpful solutions to common issues.
- Detection requires monitoring process creation events for obfuscated or encoded commands executed via rundll32.exe or similar tools, along with checking RunMRU entries for signs of LOLBins usage.
