## 1. System Research: How It Works

### Summary
The Frame Buffer (FB) device in Linux is responsible for handling graphics hardware interfaces by providing an abstraction layer between the application and the hardware. It supports various visual modes including pseudo color where each pixel value goes through a programmable lookup table to determine its final color representation.

### Key Findings
- Frame Buffer devices support multiple visual modes, such as pseudo color, true color, etc., which define how pixels are represented on screen.
- In pseudo color mode, the entire pixel value is processed through a configurable lookup table that maps it to a specific RGB color before display.
- The Frame Buffer device allows for dynamic configuration of graphics hardware settings and supports different types of video memory mappings.

### Key Fields
