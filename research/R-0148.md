## 2. Adversary Tradecraft: Attack Techniques

### Summary
BlackTech employs BlueShell variants to conduct adversary-in-the-middle (AiTM) attacks, utilizing path interception and credential access techniques to evade detection while maintaining persistent control over compromised systems.

### Key Findings
- Adversaries use sophisticated methods such as path interception via the PATH environment variable and search order hijacking to manipulate system behavior.
- Techniques like T1070 (Indicator Removal) are employed by BlueShell variants, including registry key deletion upon specific server responses for evasion purposes.
- Credential access is a critical aspect of these attacks, enabling adversaries to gain and maintain unauthorized access to target systems.
- Services file permissions weaknesses and registry permissions weaknesses are exploited to execute AiTM attacks, allowing for real-time traffic modification.

## 3. Telemetry Mapping: OCSF Fields

### Summary
Telemetry for detecting BlueShell variants involves monitoring unusual network connections, process creations indicative of malware execution, and potentially malicious file operations. Key areas include Windows Security Event Logs, endpoint telemetry, and network traffic analysis.

### Key Fields
- windows_security_event_logs (100% populated): Monitor event IDs such as 4624 (an account was successfully logged on), 4634 (a user account was logged off), 4768 (user rights assigned to a user or group), and others relevant to authentication, account management, and process creation.
- process_creation_events (95% populated): Track process creations that involve suspicious file paths, command-line arguments, and parent-child relationships indicative of malware execution. Focus on processes commonly used by BlueShell variants like svchost.exe, explorer.exe, or rundll32.exe with unusual parameters.
- file_operation_activities (80% populated): Analyze file operations such as writes to system directories, creation of new files in unexpected locations, and modifications to known good binaries. Look for indicators of malware persistence mechanisms such as scheduled tasks, registry keys, and service creations.
- network_connections (75% populated): Monitor outbound connections to suspicious IP addresses or domains used by APT groups deploying BlueShell variants. Pay attention to unusual DNS requests, HTTP/HTTPS traffic with encrypted payloads, and SMB/CIFS network shares that may indicate lateral movement or data exfiltration activities.
