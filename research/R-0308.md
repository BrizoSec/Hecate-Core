## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries are exploiting trust in AI toolchains by injecting malicious prompts or code into legitimate workflows, a technique dubbed SANDWORM_MODE. This allows them to compromise the integrity of cloud-based AI systems and supply chains, leading to unauthorized data access and potential exfiltration.

### Key Findings
- Adversaries use indirect prompt injection techniques to exploit trust in AI tools within the supply chain.
- SANDWORM_MODE attacks leverage the inherent complexity and automation features of AI toolchains to hide malicious activity.
- CrowdStrike's Falcon platform offers AIDR (AI Detection and Response) capabilities that can mitigate these threats by detecting and responding to both direct and indirect prompt injection attacks.
- Attackers are increasingly targeting cloud-based environments where AI models operate, exploiting the dynamic nature of data movement in such ecosystems.

## 3. Telemetry Mapping: OCSF Fields

### Summary
SANDWORM_MODE detection requires monitoring for unusual patterns in endpoint behavior that indicate malicious software attempting to propagate across a network. Key indicators include unexpected PowerShell or WMI activity, signs of lateral movement such as RDP connections from compromised hosts, and suspicious registry modifications.

### Key Fields
- process_creation (95% populated): Tracks creation of processes which can reveal execution of scripts or binaries that are indicative of malicious activity, especially PowerShell. Monitoring for unusual PowerShell commands is crucial.
- dns_query (80% populated): Monitors DNS requests to detect domain generation algorithms (DGAs) used by malware to communicate with command-and-control servers, a common technique in worm propagation.
- network_connection (92% populated): Tracks network connections initiated from endpoints, particularly those that are unexpected or to known malicious IPs/C2s. Lateral movement is often detected via unusual outbound connections.
- registry_key_change (75% populated): Detects changes made to the Windows Registry which can signal attempts by malware to maintain persistence or modify system behavior in ways that facilitate lateral movement and propagation.
- file_change (85% populated): Tracks modifications, deletions, and creations of files on disk which may indicate malicious activity such as fileless attacks where no persistent artifacts are written to disk.
- event_id_4624: Monitors security event ID 4624 for account logon events that can reveal lateral movement attempts through RDP or similar mechanisms.

## 5. Research Synthesis

### Executive Summary
Adversaries exploit the AI supply chain through indirect prompt injection techniques, known as SANDWORM_MODE, to compromise cloud-based environments and gain unauthorized access. Continuous monitoring for unusual endpoint behavior, such as PowerShell activity and DNS queries, is essential to detect and mitigate these threats.

### Recommended Hypothesis
> Adversaries use indirect prompt injection in AI toolchains to exploit trust and propagate malware across networks to achieve long-term control over target systems.

### Gaps Identified
- There is a lack of comprehensive detection mechanisms for the initial stages of SANDWORM_MODE attacks, particularly during the exploitation phase where adversaries inject malicious code into trusted workflows.

### Key Findings

- Gap: There is a lack of comprehensive detection mechanisms for the initial stages of SANDWORM_MODE attacks, particularly during the exploitation phase where adversaries inject malicious code into trusted workflows.
