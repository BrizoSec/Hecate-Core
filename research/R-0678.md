## 1. System Research: How It Works

### Summary
Kubernetes operators function as automated site reliability engineers designed to reduce operational toil, but they inherently rely on highly privileged service accounts to manage system states. These operators often exhibit excessive Role-Based Access Control (RBAC) permissions that diverge from their documented functionality, creating significant security risks for non-human identities.

### Key Findings
- OperTraitor is an open-source analysis engine introduced to audit Kubernetes operator privileges and identify discrepancies between documented functionality and actual RBAC permissions.
- Excessive RBAC permissions granted to operators create single points of failure; for example, the Prometurbo operator possessed cluster-wide read access to all secrets.
- The research highlights that operators can betray security posture by maintaining non-human identities with excessive privileges that allow attackers to exploit their automated capabilities.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries exploit Kubernetes operators by leveraging excessive Role-Based Access Control (RBAC) permissions, which function as silent backdoors due to overly permissive service account configurations. This abuse allows unauthorized access to sensitive data and systems across all namespaces, effectively betraying the organization's security posture through trusted non-human identities.

### Key Findings
- Palo Alto Networks Unit 42 identified that over 5% of operators in the OperatorHub registry contain excessive RBAC permissions, creating significant security risks.
- CVE-2026-6389 is a high-severity vulnerability in IBM's Turbonomic Prometurbo operator that granted cluster-wide access to secrets across all namespaces.
- The OperTraitor tool was introduced by Unit 42 to audit privileges of Kubernetes operators, identify excessive RBAC risks, and secure non-human identities.
- Kubernetes operators with overly permissive service account configurations act as silent backdoors, enabling unauthorized access to sensitive data and systems.
- Healthcare organizations face specific HIPAA violation risks due to operator misconfigurations that enable unauthorized access to patient data and medical systems.
