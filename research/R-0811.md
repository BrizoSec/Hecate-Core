## 1. System Research: How It Works

### Summary
This analysis details a PamStealer variant targeting macOS via a fake Wavel cryptocurrency wallet, utilizing a sophisticated server-side decryption chain with ECIES key exchange to prevent offline payload analysis. The malware employs a second stage rewritten in Swift for PAM-based credential validation and targets a wide array of browsers, Keychain credentials, and user files while maintaining persistence through multiple redundant mechanisms.

### Key Findings
- The malware distribution relies on a fake Wavel application distributed via DMG files hosted on y32me8.com and wavel.apple03cloudstore.com, with secondary payloads encrypted using ECIES keys exchanged live with the C2 infrastructure to ensure offline decryption is impossible.
- Infostealer capabilities include harvesting credentials from seventeen browsers (including Arc, Zen, Waterfox, and LibreWolf), extracting macOS Keychain entries, collecting system fingerprints, and harvesting user files such as shell history and account photos via Open Directory.
- Persistence is established through four redundant repair mechanisms: LaunchAgent installation, shell hooks, Git hooks, and a local backup tarball, alongside notification suppression achieved by killing background task management processes.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries are distributing a new variant of the PamStealer infostealer disguised as a legitimate Wavel cryptocurrency wallet application for macOS. The malware employs a complex server-side decryption mechanism using ECIES key exchange to prevent offline analysis, followed by credential harvesting and robust persistence mechanisms across the infected system.

### Key Findings
- The threat is distributed via a fake Wavel crypto wallet (Wavel.dmg) that downloads a second-stage payload encrypted with CoreUpdate.pkg.enc from the domain wavel.apple03cloudstore.com, requiring live server-side interaction for decryption.
- The malware utilizes a purpose-built utility named pkgunpack to perform ECIES key exchanges with C2 infrastructure, ensuring that payloads cannot be decrypted offline, while the second stage has been rewritten in Swift to maintain PAM-based credential validation.
- PamStealer targets 17 browsers including Arc, Zen, Waterfox, and LibreWolf, extracting browser credentials alongside macOS Keychain entries, system fingerprints, shell history, and user photos from Open Directory.
- Persistence is enforced through four redundant mechanisms: LaunchAgent installation, shell hooks, Git hooks, and a local backup tarball, while the malware suppresses notifications by killing background task management processes.
- Three primary SHA-256 hashes (4841..., be7a..., ed98...) are associated with this variant, with VirusTotal identifying them as trojan.agentosx/appl or trojan.macsync/multiverze, and Abuse.ch logs showing HTTP 401 errors for related infrastructure.
- The attack chain relies on the domain y32me8.com for initial distribution URLs and wavel.apple03cloudstore.com for hosting the malicious DMG, encrypted payloads, and decryption utilities.

## 5. Research Synthesis

### Executive Summary
A new PamStealer variant compromises macOS systems via a fake Wavel cryptocurrency wallet, utilizing a live ECIES key exchange with 'pkgunpack' to prevent offline analysis and rewriting its second stage in Swift for credential harvesting. The threat actor establishes robust persistence through redundant mechanisms including LaunchAgents, shell/Git hooks, and local tarballs, while actively suppressing notifications by terminating background task management processes. Detection efforts must prioritize monitoring for the specific ECIES decryption workflow, Swift-based process execution patterns, and lateral credential extraction from Keychain and seventeen distinct browser profiles.

### Recommended Hypothesis
> Adversaries use a fake Wavel cryptocurrency wallet installer with live server-side ECIES decryption via pkgunpack to deliver a Swift-based infostealer targeting macOS Keychain, extensive browser credentials, and user files on affected endpoints.

### Gaps Identified
- Current telemetry lacks visibility into the specific memory-reserved ECIES key exchange handshake performed by the 'pkgunpack' utility, which blinds static analysis of the second-stage payload and obscures the initial C2 communication channel before decryption occurs.
- Detection capabilities are limited regarding the suppression mechanism that terminates background task management processes to silence notifications, as well as the specific file system writes to ~/Library/LaunchAgents/ and ~/.gitconfig that persist the Swift-based infostealer without standard macOS quarantine flags.
