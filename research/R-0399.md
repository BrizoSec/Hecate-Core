## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries can potentially abuse Falcon Onum by leveraging its real-time telemetry enrichment capabilities to mask their activities or to conduct reconnaissance more efficiently. By understanding the system's capabilities, attackers may also find ways to evade detection mechanisms that rely on impossible travel patterns and other anomaly-based detections.

### Key Findings
- Adversaries can exploit Impossible Traveler pipelines by using compromised credentials with legitimate IP addresses through GeoIP services, thereby evading location-based fraud alerts.
- Attackers might use Falcon Onum’s integration with security workflows to conduct stealthy reconnaissance on the network without triggering alerts designed for suspicious activity detection.
- The system's real-time telemetry enrichment feature can be targeted by attackers to inject false data or manipulate legitimate traffic patterns to obscure malicious activities.
- Falcon Onum’s reliance on Redis and other caching technologies could be a target for Distributed Denial of Service (DDoS) attacks, disrupting the service and potentially enabling further exploitation.

### Summary
This use case involves detecting suspicious SMB traffic that could indicate lateral movement in the network, such as credential dumping or file transfer activities. Telemetry should capture endpoint behavior related to SMB protocol usage.

### Key Fields
- network.protocol (95% populated): Identifies the communication protocols used by endpoints, focusing on SMB for this scenario.
- event.category (85% populated): Classifies the event type, which could include network traffic analysis or process execution that involves SMB-related activity.
- process.name (90% populated): Captures the name of the processes involved in network communications, particularly those initiating or responding to SMB requests.
- network.destination.ip: Provides IP addresses of remote systems accessed via SMB, critical for identifying potential compromised endpoints or servers within the network.
- user.id (75% populated): Identifies user accounts associated with suspicious activities, helping track if specific credentials are being abused across multiple machines.
