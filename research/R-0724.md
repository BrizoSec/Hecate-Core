## 1. System Research: How It Works

### Summary
Noodle RAT is a cross-platform remote access trojan with distinct Windows and Linux variants that utilize in-memory execution and modular backdoor capabilities to maintain persistent access. The malware establishes command-and-control channels using sophisticated encryption, including RC4/XOR on Windows and AES/HMAC-SHA1 on Linux, while leveraging loaders like MULTIDROP and MICROLOAD for initial deployment.

### Key Findings
- Windows variant (Win.NOODLERAT) operates as an in-memory modular backdoor loaded via shellcode from loaders such as MULTIDROP and MICROLOAD, supporting TCP proxying and self-deletion.
- Linux variant provides reverse shell capabilities, SOCKS tunneling, and task scheduling, typically installed post-exploit or via webshell deployment against exposed servers.
- C2 traffic is heavily obfuscated using RC4, XOR, and custom algorithms on Windows, whereas the Linux variant relies on HMAC-SHA1 and AES-128-CBC for communication security.
- Persistence mechanisms include Registry Run Keys and Scheduled Tasks (T1547.001, T1053.005) on Windows, and RC Scripts on Linux.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries utilize MITRE T1560 to compress or encrypt collected data prior to exfiltration, employing algorithms like RC4 for configuration decryption and AES-128-CBC for communication to obfuscate traffic and minimize network footprint. This technique is actively observed in campaigns by Chinese-speaking threat actors using tools such as Noodle RAT, which leverages these methods across Windows and Linux platforms to evade detection during data theft.

### Key Findings
- Noodle RAT (also known as ANGRYREBEL) is a modular remote access trojan actively used by Chinese-speaking threat actors since at least mid-2016, with dual variants for Windows and Linux.
- The malware employs sophisticated encryption techniques including RC4, XOR, custom algorithms, HMAC-SHA1, and AES-128-CBC to obfuscate C2 traffic and decrypt configurations, aligning with T1560 and T1071 behaviors.
- Threat groups identified as utilizing Noodle RAT include Iron Tiger, Calypso APT, Rocke, and Cloud Snooper, targeting entities in the Asia-Pacific region such as Thailand, India, Japan, Malaysia, and Taiwan.
- Noodle RAT shares code segments with known families like Gh0st RAT (Windows) and Rekoobe/Tiny SHell (Linux), though it is now recognized as a distinct backdoor family potentially distributed via commercial malware kits.

## 5. Research Synthesis

### Executive Summary
Noodle RAT utilizes T1560 to archive and encrypt collected data prior to exfiltration, employing platform-specific ciphers (RC4/XOR for Windows, AES-128-CBC/HMAC-SHA1 for Linux) to obscure traffic from defenders. This technique is executed within in-memory backdoors loaded via MULTIDROP/MICROLOAD, creating a high-risk scenario where data archival and exfiltration occur without writing large temporary files to disk.

### Recommended Hypothesis
> Adversaries use Noodle RAT's modular file management and encryption capabilities (T1560) to archive sensitive assets in memory or via lightweight processes, then obfuscate the resulting data stream using RC4/XOR or AES-128-CBC before exfiltrating it over C2 channels.

### Gaps Identified
- Standard endpoint telemetry often fails to capture the 'Archive Collected Data' phase because Noodle RAT performs compression/encryption in-memory or via transient shellcode loaders (MULTIDROP/MICROLOAD), evading file creation alerts and leaving no persistent artifacts for `file.path` mapping.
- Existing detection models may lack baseline profiles for the specific combination of TCP proxying (T1059/T1106) and lightweight archive utilities (e.g., 7zip/zip invoked via Native API) commonly used by this family, leading to false negatives in network-based anomaly detection.
