## 1. System Research: How It Works

### Summary
ValleyRAT is a sophisticated trojan that spreads through phishing emails and masquerades as legitimate software to evade detection. It establishes persistence on infected systems by creating unique mutexes, copying itself, and renaming its executables to mimic genuine processes.

### Key Findings
- ValleyRAT disguises itself as adware to trick users into downloading it.
- The malware creates a unique mutex to ensure only one instance runs at any given time on an infected system.
- It copies itself and renames the copied file to mimic legitimate processes, thereby evading detection.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
ValleyRAT is a sophisticated backdoor malware that spreads disguised as adware, targeting organizations globally for espionage and financial gain. It employs process hollowing to maintain persistence on compromised systems and collects sensitive data.

### Key Findings
- ValleyRAT uses adware distribution channels to infect victims, masquerading as legitimate software to evade detection.
- The malware relies on process hollowing techniques to inject malicious code into legitimate processes, ensuring stealth and persistence.
- Sensitive data collection is a primary objective of ValleyRAT, indicating its use in espionage operations against high-value targets.
- Detection involves monitoring for unusual DLLs and registry changes associated with the malware's activities.
