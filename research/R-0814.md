## 1. System Research: How It Works

### Summary
The Psychedelic Stealer operates by exploiting compromised legitimate websites to serve a fake Cloudflare verification page, which tricks users into executing signed Microsoft binaries via the 'ClickFix' method rather than using encoded PowerShell. This technique establishes persistence and credential theft capabilities by installing browser extensions with native-messaging bridges and polling a REST API for arbitrary executable tasking.

### Key Findings
- The attacker utilizes a 'ClickFix' social engineering chain where victims are coerced into manually running msiexec.exe commands via the Windows Run dialog, achieving a high completion rate of 14% by leveraging signed Microsoft binaries to evade detection.
- The malware, identified as 'Psychedelic' (psychedeliclove.exe), specifically targets cryptocurrency holdings by stealing browser credentials, session tokens, and wallet data from major clients including MetaMask, Trust Wallet, Exodus, and Atomic Wallet.
- The threat actor predominantly targets small-business websites in Ukraine, compromising at least six sites between September 9 and 14, 2026, to distribute the payload via domains such as uasputnik.com and fsputnik.com.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries compromise legitimate Ukrainian small-business websites to deliver a fake Cloudflare CAPTCHA page that tricks users into manually executing MSI installer commands via the Windows Run dialog. This 'ClickFix' technique achieves a high infection rate by leveraging signed Microsoft binaries to bypass detection, ultimately installing the 'Psychedelic Stealer' to exfiltrate cryptocurrency credentials and establish persistent control.

### Key Findings
- The attack utilizes a 'ClickFix' chain where victims are convinced to run 'msiexec.exe' commands manually via the Windows Run dialog after encountering a fake CAPTCHA, achieving a 14% completion rate (79 infections from 426 clicks).
- The payload, internally named 'Psychedelic', combines credential theft with persistent agent capabilities by installing browser extensions with native-messaging bridges and establishing scheduled tasks.
- Targeting is heavily focused on Ukraine with clear financial motivation, collecting browser credentials, session tokens, and data from wallets including MetaMask, Trust Wallet, Exodus, and Atomic Wallet.
- The adversary deliberately avoids encoded PowerShell, instead using signed Microsoft binaries to bypass common ClickFix detections and reduce the likelihood of detection by security tools.
- Indicators include specific file hashes for 'psychedeliclove.exe' and 'elita.msi', domains uasputnik.com and fsputnik.com, and C2 infrastructure hosted on IPs 193.178.159.128 and 176.53.159.40.

## 5. Research Synthesis

### Executive Summary
The Psychedelic Stealer campaign leverages compromised Ukrainian SMB websites to deploy a fake Cloudflare CAPTCHA, coercing users into manually executing signed msiexec.exe commands via the ClickFix technique to bypass detection. This chain installs a persistent agent that establishes native-messaging bridges in browsers to exfiltrate cryptocurrency wallet credentials and session tokens while polling a REST API for further tasking.

### Recommended Hypothesis
> Adversaries use signed msiexec.exe execution via fake CAPTCHA prompts to install Psychedelic Stealer, aiming to persist via native-messaging bridges and exfiltrate cryptocurrency wallet data from Ukrainian targets.

### Gaps Identified
- Current telemetry likely misses the initial social engineering context, as detection relies on endpoint process creation logs for msiexec.exe rather than network indicators of the fake CAPTCHA delivery or the subsequent REST API polling for tasking.
- The use of signed Microsoft binaries (msiexec.exe) and MSI installers masks the malicious intent, meaning standard heuristic alerts for encoded PowerShell or unsigned scripts will not trigger, requiring specific focus on command-line anomalies and file creation events in transient directories.
