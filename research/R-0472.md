## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries may use advanced evasion tactics and shell command obfuscation to circumvent Falcon Onum's real-time threat detection mechanisms, thereby enabling them to perform malicious activities without triggering alerts.

### Key Findings
- Use of complex obfuscated scripts or commands to evade signature-based detections
- Leveraging legitimate system tools in a manner that does not generate suspicious telemetry
- Abusing API calls and web services like GeoIP for hiding geolocation data from security teams
- Employing multi-stage attack chains that distribute indicators across multiple hosts, diluting the signal-to-noise ratio
- Manipulating timestamps or session metadata to mask anomalous activities
- Exploiting third-party integrations with Falcon Onum for lateral movement and exfiltration

## 3. Telemetry Mapping: OCSF Fields

### Summary
Telemetry captures unauthorized access attempts through authentication events and failed login attempts across systems. This includes monitoring Windows Security Event Logs (Event IDs such as 4625, 4771) for suspicious activity.

### Key Fields
- event_id (90% populated): Identifies specific event log entries that indicate unauthorized access or authentication failures.
- user_name: Indicates the user attempting to gain unauthorized access.
- process_path: Path of the process initiating the failed login attempt, useful for identifying potential malware or scripts.
- outcome: Indicates whether the event was successful or unsuccessful (e.g., 'failure' for a failed login).
- logon_type: Specifies the type of logon action (e.g., network logon, interactive logon) which can help differentiate normal from abnormal access patterns.
