## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries in South Korea during June 2026 employed obfuscation techniques such as phishing with disguised files, particularly LNK files, to deliver malware and establish persistence through DLL side-loading. This method targeted specific individuals via spear-phishing campaigns.

### Key Findings
- APT groups used phishing emails containing obfuscated LNK files to deploy malware in a covert manner.
- DLL side-loading was observed as a common technique for establishing persistent access on compromised systems.
- The use of encrypted and compressed payloads within the LNK files helped evade detection by security solutions.
- Spear-phishing campaigns were tailored to specific individuals, indicating high-level reconnaissance and social engineering skills.

## 3. Telemetry Mapping: OCSF Fields

### Summary
Telemetry capturing file obfuscation activities involves monitoring for signs of file encryption, compression, encoding, and anomalies in file modification times and permissions. This includes logging of suspicious processes, network traffic related to file transfers (encrypted or compressed), and changes in system entropy levels.

### Key Fields
- file_name: Obfuscated file names can be indicative of T1027 activities if the name does not match typical conventions for files of that type.
- process_command_line: Command-line arguments used by processes, especially those involving encryption or compression tools (e.g., zip, gzip, openssl), are critical indicators.
- file_modification_time: Unusual changes in file modification times without corresponding changes in content can suggest obfuscation activities.
- network_traffic_http_request_headers: Headers indicating encrypted data transfer over HTTP/HTTPS can be a sign of obfuscated files being transmitted.
- process_creation: Creation of processes associated with encryption or compression tools is relevant, especially if these processes are run unexpectedly by non-administrator accounts.
- file_entropy: High entropy values in file contents can suggest encryption or encoding.

## 5. Research Synthesis

### Executive Summary
In June 2026, North Korean-linked APT groups in South Korea predominantly used obfuscated LNK files for spear-phishing campaigns to deploy malware and establish backdoors. These campaigns leveraged DLL side-loading techniques and encrypted payloads to evade detection by security solutions.

### Recommended Hypothesis
> Adversaries use obfuscation of malicious payloads within disguised LNK files to covertly install malware and establish persistent access on targeted systems in South Korea.

### Gaps Identified
- The current coverage lacks deep insights into the specific encryption methods and protocols used by APT groups for file obfuscation, hindering the ability to detect such activities proactively.
- There is insufficient knowledge regarding the reconnaissance techniques employed by attackers before launching spear-phishing campaigns to tailor their attacks effectively.

### Key Findings
- Hypothesis: Adversaries use obfuscation of malicious payloads within disguised LNK files to covertly install malware and establish persistent access on targeted systems in South Korea.
- Gap: The current coverage lacks deep insights into the specific encryption methods and protocols used by APT groups for file obfuscation, hindering the ability to detect such activities proactively.
- Gap: There is insufficient knowledge regarding the reconnaissance techniques employed by attackers before launching spear-phishing campaigns to tailor their attacks effectively.
- Focus: Strengthening detection capabilities for encrypted or compressed payloads within LNK files and monitoring unusual DLL side-loading activities on endpoints.
- Focus: Enhancing threat intelligence sharing and analysis of reconnaissance tactics used in spear-phishing campaigns targeting specific individuals.
