## 1. System Research: How It Works

### Summary
The FakeAgent malvertising campaign leveraged the Fallout Exploit Kit to deliver GandCrab ransomware via compromised ads on search engines and social media, exploiting vulnerabilities in browsers and operating systems. The attackers used VBScript code encoded in Base64 within landing pages to execute malicious scripts that installed the malware on victims' machines.

### Key Findings
- The campaign utilized malvertising to distribute GandCrab ransomware through compromised online advertising.
- Fallout Exploit Kit was employed as a delivery mechanism, exploiting vulnerabilities in web browsers and operating systems.
- Base64 encoded VBScript code within landing pages facilitated the execution of malicious scripts that installed the payload on victim machines.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries orchestrated the FakeAgent malvertising campaign using AI-generated content and compromised ad networks to distribute malware, targeting 29 organizations. The attackers employed sophisticated techniques including data extraction from internal databases, use of Claude Code for malicious activities, and evasion tactics that bypass ad-blockers.

### Key Findings
- Adversaries used AI to generate convincing content and compromised ad networks to deliver the FakeAgent malware.
- The campaign leveraged Claude Code to query internal databases and systems for data extraction purposes.
- Sophisticated evasion methods were employed to bypass ad-blocking software, making detection challenging.
- Automated collection techniques were utilized once initial footholds were established within targeted organizations.
