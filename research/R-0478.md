## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries can potentially abuse Falcon Onum by leveraging its real-time telemetry enrichment capabilities to mask their movements or exfiltrate data more efficiently. By understanding the system's mechanisms for reducing data volume and accelerating SIEM migrations, attackers might exploit these features to evade detection while conducting malicious activities.

### Key Findings
- Adversaries may use Falcon Onum’s real-time telemetry enrichment feature to disguise malicious traffic as normal network activity, thereby evading detection.
- Attackers could abuse the system's data reduction capabilities to exfiltrate large volumes of sensitive information without raising alarms due to reduced data volume.
- The Impossible Traveler pipeline in Falcon Onum might be exploited by attackers who conduct rapid and geographically dispersed activities to appear legitimate through IP address manipulation.
- Insider threats may use Falcon Onum’s intelligent control over data movement to access, modify, or exfiltrate sensitive information from within the network environment.

## 3. Telemetry Mapping: OCSF Fields

### Summary
WMI-based lateral movement detection: This involves monitoring for suspicious WMI activity indicative of attackers using WMI to communicate between hosts and perform actions like creating remote WMI jobs.

### Key Fields
- event_id (10% populated): Event ID corresponding to the creation or modification of a WMI job. Common IDs include 4657, 4698, etc., which are related to security policy changes and might be indicative of malicious activity.
- process_name: The process responsible for creating/modifying the WMI object, typically indicating a potential attack vector if unusual processes execute such actions.
- parent_process_name (20% populated): Identifies parent processes that spawn suspicious WMI activities. This can help determine if an attacker is using legitimate tools or scripts to hide their activity.
- user_id: The user account performing the action, which can be critical in identifying whether the operation was performed by a compromised user or an attacker with credentials.
- ip_address (30% populated): Source and destination IP addresses involved in WMI communications. This field helps trace back the origin of malicious activity within the network.
- wmi_query: The actual WMI query used, which can be evaluated for known patterns associated with lateral movement or reconnaissance activities.
