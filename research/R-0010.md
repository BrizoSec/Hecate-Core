## 3. Telemetry Mapping: OCSF Fields

### Summary
Telemetry capturing user and system activities across network boundaries is essential for identifying lateral movement attacks. This includes monitoring for unusual access patterns, unexpected service communications between hosts, and process execution paths indicative of compromised credentials or malware spreading.

### Key Fields
- user.login (90% populated): Tracks successful logins by users and provides critical information about user activity timing and location.
- network.connection (85% populated): Records network connections initiated from endpoints to other hosts within the network, which is crucial for identifying lateral movement patterns.
- process.execution (75% populated): Captures details of process executions on endpoints, including parent-child relationships, which are vital in tracing the spread of malicious activities through processes.
- file.creation/modification (60% populated): Monitors file creation and modification events to detect signs of malware deployment or configuration changes indicative of lateral movement.
- registry.key_modification (50% populated): Tracks modifications to system registry keys, which can indicate credential dumping or service manipulation for gaining unauthorized access.
