## 1. System Research: How It Works

### Summary
Redis is an open-source, in-memory data structure store that functions as a database, cache, and message broker. It allows for high-speed access to key-value pairs stored in memory on Linux systems. Cron jobs are scripts scheduled by the cron utility to execute at specified intervals.

### Key Findings
- Cron jobs are commonly used for automating repetitive tasks in Unix-like operating systems such as Linux.
- [UNCERTAIN] A Redis server can potentially be exploited if it is not properly secured, allowing attackers to inject malicious cron jobs that persist across reboots.
- [UNCERTAIN] XMRig is a cryptocurrency mining software often deployed by botnets to mine Monero coins on compromised systems.


---

## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries abuse Redis to inject cron jobs that persist the XMRig cryptominer on Linux systems, enabling long-term unauthorized cryptocurrency mining. The botnet also replicates itself across other machines using these compromised systems as a base.

### Key Findings
- Cron injection is used for persistence by adversaries to ensure the miner runs continually despite system restarts or attempts to remove it.
- The XMRig miner is deployed on Linux systems, targeting CPU and potentially GPU resources for mining Monero cryptocurrency.
- [UNCERTAIN] Adversaries may leverage Redis vulnerabilities such as weak configurations or unsecured connections to initially deploy the attack payload.
- The botnet's replication mechanism likely involves exploiting other machines from an already infected one, possibly using common network scanning techniques.
- Indicators of compromise include unexpected cron jobs running XMRig or similar mining executables and unusual cryptocurrency wallet activity.
