## 1. System Research: How It Works

### Summary
DNS exfiltration is a technique used by malware to covertly transfer data out of a network by encoding sensitive information into DNS queries, often in base64 or hex format, and splitting it into chunks that are sent as subdomain labels or TXT records.

### Key Findings
- Malware encodes stolen data using character sets valid for DNS names, such as base64 or hexadecimal.
- Encoded data is split into chunks of up to 250 bytes per DNS query for exfiltration.
- DNS queries are directed to controlled domains to avoid detection and use the trusted nature of DNS traffic.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
Kunai is a malware sample that exploits open recursive DNS servers to exfiltrate data, disguising the malicious traffic as normal DNS queries. This technique aligns with MITRE ATT&CK T1438 and enables stealthy data movement by leveraging DNS for covert communication.

### Key Findings
- Kunai employs DNS tunneling (T1438) to exfiltrate data, using open recursive DNS servers to disguise malicious traffic as legitimate DNS queries.
- The malware's method allows for the covert transfer of information from infected systems without triggering typical network security alerts.
- While the specific details about Kunai's operational mechanisms are limited in the provided context, it is clear that DNS exfiltration serves as a key tactic enabling stealthy data movement and communication between compromised hosts and attackers.
- The use of open recursive DNS servers highlights a common vulnerability in DNS infrastructure which can be exploited for malicious purposes.
