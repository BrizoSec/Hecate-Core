## 1. System Research: How It Works

### Summary
The system utilizes unsupervised machine learning algorithms, specifically UMAP and HDBSCAN, to analyze cloud audit logs and map identity roles based on observed behavioral patterns rather than static permissions. This approach enables the automated detection of anomalies, such as compromised accounts or masquerading identities, by continuously evaluating cluster membership for specific groups like DevOps users or security tools via standard SQL queries.

### Key Findings
- Behavioral clustering models group cloud identities into distinct categories based on their observed actions in audit logs, allowing for the inference of roles and detection of deviations from established behavioral norms.
- The methodology supports scaling to ingest new identities and automatically determine cluster membership for specific groups, such as DevOps users or security tools, enabling continuous threat detection.
- The implementation relies on standard SQL queries to evaluate cluster membership, providing a mechanism for accurate role inference at scale that complements traditional static IAM permission audits.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries exploit cloud identities by using masquerading techniques to blend in with legitimate users, making detection difficult without behavioral analysis. The provided research context focuses on defensive methodologies, specifically using unsupervised machine learning (UMAP and HDBSCAN) to map over 40,000 identities into functional roles for automated threat detection.

### Key Findings
- The study analyzed behavior of over 40,000 identities across 125 cloud environments over a two-month period to create a behavioral clustering model.
- Unsupervised machine learning algorithms Uniform Manifold Approximation and Projection (UMAP) and Hierarchical Density-Based Spatial Clustering of Applications with Noise (HDBSCAN) are used to categorize cloud identities.
- This approach enables continuous threat detection by mapping identities to functional roles, allowing for the identification of anomalies in operating patterns.
- The methodology helps identify masquerading techniques used by attackers to disguise their activities as legitimate user behavior.
- Detection capabilities are enhanced by enabling the use of standard SQL queries on mapped identity roles rather than relying solely on traditional logging.

## 5. Research Synthesis

### Executive Summary
This research establishes a behavioral clustering methodology using UMAP and HDBSCAN to map AWS CloudTrail identities into functional roles, enabling the detection of masquerading techniques by identifying deviations from established behavioral norms rather than relying on static IAM permissions. By leveraging standard SQL queries to evaluate cluster membership for over 40,000 identities, this approach provides a scalable mechanism for continuous threat detection of compromised accounts and identity-based anomalies.

### Recommended Hypothesis
> Adversaries use masquerading techniques to blend in with legitimate user behavior and evade detection on cloud environments where static IAM audits are insufficient.

### Gaps Identified
