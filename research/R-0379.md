## 2. Adversary Tradecraft: Attack Techniques

### Summary
The Chaos ransomware group employs msaRAT, a sophisticated Rust-based remote access trojan (RAT) that exploits the Chrome DevTools Protocol to establish covert command and control (C2) communications. This malware leverages WebRTC over TURN to mask attacker IPs, enabling stealthy and persistent control over compromised systems without direct network communication.

### Key Findings
- msaRAT uses the Chrome DevTools Protocol for C2 communications, hijacking browser functionalities to execute remote commands.
- WebRTC via TURN is employed by msaRAT to anonymize attacker IP addresses, enhancing operational security and evading traditional network monitoring techniques.
- The malware enables persistent access through living off the land (LotL) tactics, utilizing legitimate browser processes for C2 communications.
- msaRAT is Rust-based, indicating advanced programming skills among Chaos ransomware developers, which may reflect a shift towards more robust coding languages in malware development.
