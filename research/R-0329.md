## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries with privileged network access may perform real-time modification of network traffic using adversary-in-the-middle (AiTM) attacks, allowing them to manipulate or intercept data for malicious purposes such as eavesdropping, injecting malware, and altering command-and-control communications.

### Key Findings
- Real-time network traffic manipulation is a sophisticated technique used by adversaries with insider access.
- Adversaries leverage AiTM attacks to inject malware into legitimate network sessions, compromising the integrity of data in transit.
- AI/ML tools are increasingly being employed to automate and enhance the effectiveness of AiTM attacks.
- IOCs such as IP addresses, domain names, and file hashes associated with botnet command-and-control (C2) servers are critical for detection and mitigation.

## 3. Telemetry Mapping: OCSF Fields

### Summary
The telemetry captures the execution of malicious payloads delivered via phishing emails, followed by lateral movement activities within the corporate network. This includes initial compromise through a known malware strain (e.g., TrickBot), and subsequent actions such as credential dumping and use of PsExec for spreading across internal systems.

### Key Fields
- windows.event_id (100% populated): The SIEM platform aggregates Windows Security Event IDs, particularly those indicating process creation (4688) and service management activities (7036), which are critical in detecting lateral movement. These events include actions like PsExec usage.
- process.name (95% populated): Identifies the names of processes that are flagged as suspicious or known malware strains such as 'svchost.exe' when used abnormally for lateral movement.
- user.account_name (80% populated): Tracks user accounts involved in abnormal activities, especially during credential dumping and other privilege escalation attempts. This helps identify if a compromised account is being reused across multiple systems.
- network.destination_ip (75% populated): Monitors outbound connections from internal IPs to external IP addresses that are known indicators of command-and-control activity or lateral movement within the network.
- file.path (85% populated): Reveals file paths where malicious binaries or scripts are stored, aiding in identifying the initial infection vector and subsequent spread mechanisms such as copying files across systems.
