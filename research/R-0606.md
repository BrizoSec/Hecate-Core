## 1. System Research: How It Works

### Summary
JWR is a sophisticated phishing framework that targets payment gateways by mimicking their login and checkout pages to steal payment card data, credentials, and PII in real time. It uses an AES-CTR encrypted WebSocket for command execution and keystroke streaming.

### Key Findings
- The JWR framework executes its client-side engine upon loading a phishing webpage, which sets the global flag `window.__HOST_MODE` to control session operations.
- A Host Bridge module within JWR relays commands through an inline frame, while a Vue.js application manages victim interactions and renders 44 distinct frames for various user interfaces.
- The framework employs AES-CTR encryption over WebSocket for secure real-time communication between the client and server.
