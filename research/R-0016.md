## 3. Telemetry Mapping: OCSF Fields

### Summary
The telemetry captures file-related events that indicate potential malicious activity by tracking the creation, modification, deletion, and execution of files on endpoints. This includes monitoring for unusual patterns such as unexpected file modifications, execution of suspicious binaries or scripts, and anomalous file access times.

### Key Fields
- file.path (95% populated): The full path to a file where an event occurred. Monitoring changes in critical directories like C:\Windows can help detect potential malware installations or privilege escalation attempts.
- process.name (80% populated): The name of the process that initiated the file activity, which is essential for identifying anomalous behavior such as legitimate processes executing unexpected commands or files from unusual locations.
- file.mtime (75% populated): Modification time of a file. Sudden changes to system binaries without corresponding software updates can indicate tampering and should be investigated further.
- process.cmdline (85% populated): Command line arguments used when launching a process, which is crucial for detecting unusual execution patterns or attempts at obfuscation by attackers.
- network.destination (60% populated): IP addresses or domain names contacted by processes. This helps in identifying if files are communicating with known malicious domains or IP ranges.
- file.sha256 (90% populated): SHA-256 hash of a file, which allows for quick comparison against known good and bad hashes to determine the integrity and reputation of files.
