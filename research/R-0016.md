## 1. System Research: How It Works

### Summary
VeloCloud Orchestrator (VCO) is a centralized management platform used to configure, provision, and manage VeloCloud Edge devices. It includes on-premises deployments that were found to have a critical vulnerability allowing unauthenticated remote attackers to access privileged internal functionality.

### Key Findings
- A critical zero-day vulnerability (CVE-2026-93952) exists in VCO versions prior to 5.2.3.16, 6.4.2.8, and other specified lower versions, enabling remote attackers to exploit without needing credentials.
- The flaw allows attackers to compromise the confidentiality, integrity, and availability of the orchestrator and managed data through network access to the VCO web interface and knowledge of public portions of VeloCloud Edge authentication certificates.
- Hosted VCO versions were reportedly already patched against this vulnerability.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries are exploiting a critical vulnerability (CVE-2026-93952) in Arista VeloCloud Orchestrator, which allows remote attackers to access privileged internal functionality and compromise the orchestrator. This flaw is actively being used to install backdoors, exfiltrate sensitive data, disrupt operations, and pivot within the network.

### Key Findings
- Adversaries can gain full system compromise through command injection in VeloCloud Orchestrator versions below specified thresholds.
- Exploitation requires access to the public portion of VeloCloud Edge authentication certificates and involves executing arbitrary commands remotely.
- Indicators of compromise include suspicious HTTP headers, connections from known malicious IP addresses, and presence of specific files (MD5 hash: dc78e206eaeadec59fc5801fe4556bd0).
- Attackers leverage this vulnerability to install persistent backdoors or web shells for long-term access.
- Sensitive SD-WAN configuration data can be exfiltrated from compromised VeloCloud Orchestrators.

## 5. Research Synthesis

### Executive Summary
A critical zero-day vulnerability (CVE-2026-93952) in VeloCloud Orchestrator versions prior to specified thresholds allows remote attackers to compromise the orchestrator and managed data without credentials, leading to a high risk of data exfiltration and operational disruption. Adversaries are actively exploiting this flaw by leveraging command injection and installing persistent backdoors.

### Recommended Hypothesis
> Adversaries use remote exploitation via CVE-2026-93952 to gain full system compromise on VeloCloud Orchestrator deployments for long-term access and data exfiltration

- There is a lack of comprehensive threat intelligence on how adversaries are leveraging the certificate authentication bypass mechanism in VCO versions below specified thresholds.
