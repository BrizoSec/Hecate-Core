## 1. System Research: How It Works

### Summary
The 'Psychedelic Stealer' campaign compromises legitimate Ukrainian business websites to inject iframes displaying a fake Cloudflare verification page. When users interact with the lure, they are tricked into pasting a Windows Installer command from their clipboard into the Windows Run dialog, which downloads an MSI package that delivers the infostealer.

### Key Findings
- The attack utilizes a 'ClickFix' social engineering technique where a fake CAPTCHA page copies a Windows Installer command to the user's clipboard and instructs them to paste it into the Windows Run dialog.
- The malware payload is delivered via an MSI package named 'elita.msi' which retrieves and decrypts the stealer executable from http://107.175.82[.]242:9000/wilow/psychedeliclove.exe.
- The infostealer, identified by the embedded tag 'Psychedelic' (also referred to as LunexStealer), extracts browser passwords, session cookies, and cryptocurrency wallet data.
- The stealer employs a vulnerable AMD driver to disable security monitoring tools before deploying its payload.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries compromise legitimate Ukrainian business websites to inject iframes displaying a fake Cloudflare CAPTCHA verification page. This social engineering lure tricks victims into copying a Windows Installer command to their clipboard and pasting it into the Windows Run dialog, which silently downloads and executes an MSI package containing the 'Psychedelic' infostealer.

### Key Findings
- The attack leverages compromised infrastructure (T1584.004), specifically at least six legitimate Ukrainian small-business websites, to distribute the malicious payload via injected iframes.
- The initial access vector relies on a 'ClickFix' style technique where a fake Cloudflare CAPTCHA instructs users to manually execute a command in the Windows Run dialog (Win+R).
- The delivered malware is an infostealer identified by the embedded tag 'Psychedelic,' which targets sensitive data including browser passwords, account tokens, and cryptocurrency wallet information.
- The geographic scope of the campaign spans 32 countries across Europe, the Americas, and Asia-Pacific, indicating a broad international targeting effort.
- The payload delivery mechanism utilizes an MSI package retrieved via the user-executed command, allowing the adversary to bypass typical browser-based execution restrictions.

## 5. Research Synthesis

### Executive Summary
Adversaries compromise Ukrainian business websites to inject iframes that deploy a 'ClickFix' social engineering lure, tricking users into executing a malicious msiexec command via the Windows Run dialog. This technique facilitates the silent download and execution of an MSI package delivering the 'Psychedelic' infostealer, which utilizes a vulnerable AMD driver to disable security monitoring tools before exfiltrating browser credentials and cryptocurrency wallet data.

### Recommended Hypothesis
> Adversaries use injected iframes on legitimate websites to trigger clipboard-based ClickFix attacks, forcing users to manually execute msiexec commands via the Windows Run dialog to deploy the Psychedelic infostealer.

### Gaps Identified
- Lack of visibility into the specific clipboard content being copied by malicious iframes, preventing detection of the pre-execution social engineering phase where the attacker copies the command string.
- Standard endpoint telemetry often misses the initial injection vector (the iframe) and the parent-child process relationship between the browser/explorer.exe and the subsequent msiexec execution unless specific command-line auditing is enabled.

### Key Findings
- Hypothesis: Adversaries use injected iframes on legitimate websites to trigger clipboard-based ClickFix attacks, forcing users to manually execute msiexec commands via the Windows Run dialog to deploy the Psychedelic infostealer.
