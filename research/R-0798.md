## 1. System Research: How It Works

### Summary
Citrix NetScaler ADC and Gateway function as high-performance application delivery controllers and secure gateways, typically managing SSL offloading, load balancing, and authentication for web applications. In the context of CVE-2026-88771, pre-authentication command injection allows attackers to bypass these security controls, executing arbitrary system commands on the underlying operating system without valid credentials.

### Key Findings
- The exploitation leverages a pre-authentication command injection vulnerability (CVE-2026-88771) where attackers use malicious authentication events with attacker-controlled usernames containing 'pitboss' and 'NSPPE' strings to execute commands.
- Post-exploitation activities include the deployment of two specific payloads: main.py (SHA256: e9fe43968c6c0955300e3bc4d7fb0b05a18570b4733aaf4f5c6f7f09be5a242c) which establishes reverse shells to C2 infrastructure, and update_c08937.pl (SHA256: 974b69782fdf5d67b97cfd508465939e44ee10798dbcc1e82b92d78776bad938) which creates privileged 'sec_monitor' superuser accounts and deploys PHP web shells.
- Attackers stage NetScaler configuration data for exfiltration by archiving the /flash/nsconfig directory into /tmp/update_result_3567cs.tgz or copying ns.conf to /var/netscaler/logon/insight-new.js, then upload these artifacts to C2 servers like 64.94.85.67:443.
- Network indicators reveal active Command and Control (C2) and payload hosting infrastructure at IPs including 45.141.21.130 (C2), 64.94.85.67 (C2/exfiltration), and 31.56.197.72, with the custom binary 'customsnmpd' creating TCP connections to 45.141.21.130:443.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries are actively exploiting CVE-2026-88771, a critical pre-authentication command-injection vulnerability in Citrix NetScaler ADC and Gateway, to deploy malicious payloads via curl and wget. The exploitation chain involves staging second-stage scripts that establish reverse shells, create privileged persistence accounts, install PHP web shells, and exfiltrate configuration data.

### Key Findings
- The attack utilizes two distinct second-stage payloads: 'main.py' (SHA256: e9fe43968c6c0955300e3bc4d7fb0b05a18570b4733aaf4f5c6f7f09be5a242c) which establishes reverse shells to C2 infrastructure, and 'update_c08937.pl' (SHA256: 974b69782fdf5d67b97cfd508465939e44ee10798dbcc1e82b92d78776bad938) which creates privileged accounts and deploys web shells.
- Indicators of Compromise include the creation of a 'sec_monitor' superuser account, modification of system binaries (specifically a custom 'snmpd'), and the deployment of a PHP web shell at /var/netscaler/logon/LogonPoint/.local_journal for persistent access.
- Configuration exfiltration is attempted by archiving the /flash/nsconfig directory to /tmp/update_result_3567cs.tgz or copying ns.conf to the web directory, with data sent to C2 endpoints such as http://64.94.85.67:443/update_result_3567cs.tgz.
- Network indicators reveal a distributed infrastructure where 64.94.85.67 serves as primary exploit/C2/hosting infrastructure, while other IPs like 45.141.21.130 and 31.56.197.72 are used for payload delivery and C2 communication over ports 443 and 9090.
- Attacks are pre-authentication in nature, identified by authentication events containing attacker-controlled usernames with 'pitboss' and 'NSPPE' strings, correlating with the VT threat label 'trojan.pitbossshell/yjmboj126'.

## 5. Research Synthesis

### Executive Summary
Adversaries are actively exploiting CVE-2026-88771 via pre-authentication command injection to deploy two distinct second-stage payloads, 'main.py' and 'update_c08937.pl', for reverse shell C2 establishment, privileged account persistence ('sec_monitor'), and NetScaler configuration exfiltration. Detection requires correlating specific malicious HTTP authentication strings ('pitboss', 'NSPPE') with outbound network connections to known C2 infrastructure (e.g., 45.141.21.130, 64.94.85.67) and file system artifacts in web-accessible directories.

### Recommended Hypothesis
> Adversaries use pre-authentication command injection via malicious username fields containing 'pitboss' or 'NSPPE' to execute arbitrary payloads, establishing reverse shells via main.py and deploying PHP web shells for persistent access on Citrix NetScaler ADC/Gateway devices.

### Gaps Identified
- Standard network monitoring often fails to detect payload downloads if they occur over encrypted HTTPS (port 443) without SSL inspection, while endpoint detection may miss the initial injection if it bypasses WAF rules by targeting specific authentication endpoints.

- Gap: Standard network monitoring often fails to detect payload downloads if they occur over encrypted HTTPS (port 443) without SSL inspection, while endpoint detection may miss the initial injection if it bypasses WAF rules by targeting specific authentication endpoints.
