## 1. System Research: How It Works

### Summary
RSS (Real-time Security System) monitors and logs administrative activities in a network to ensure compliance with security policies. Normal admin activity adheres to predefined protocols, is well-documented, and includes routine maintenance tasks such as system updates, user management, and troubleshooting.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries often exploit Windows Admin Shares to gain unauthorized access and control over networked systems, mimicking legitimate administrative activities. They may also use various techniques such as token impersonation, process injection, and DHCP spoofing to evade detection and maintain persistence.

### Key Findings
- Monitoring for unusual SMB/Windows Admin Share activity can help identify potential LoTL abuse.
- Token manipulation and access token theft are common methods used by adversaries to escalate privileges.
- Process hollowing, Doppelgänging, and other memory injection techniques enable stealthy execution of malicious code.
- DHCP spoofing allows attackers to intercept network traffic and manipulate configurations for reconnaissance or redirection purposes.
- Elevated execution mechanisms like Setuid/Setgid can be abused to run commands with higher privileges without user interaction.
- Unexpected creation of scheduled tasks or jobs through tools like 'cron' or 'launchd' scripts might indicate automated adversary activities.

## 3. Telemetry Mapping: OCSF Fields

### Summary
To detect LoT abuse vs. normal admin activity, focus on process monitoring and user behavior analysis. Key indicators include command-line arguments for common system binaries used in suspicious ways (e.g., unusual network connections, file operations outside of typical usage patterns).

### Key Fields
- process.name (100% populated): Identifies the binary or application being executed.
- process.cmdline: Reveals the exact command-line arguments passed to a process, critical for spotting misuse of tools like PowerShell or CMD.
- user.name: Specifies who initiated the suspicious activity.
- network.dns.query: Detects unusual DNS requests that could indicate data exfiltration via DNS tunneling.
- process.parent.name (80% populated): Helps trace malicious processes back to their parent process for context.
- event.time_generated: Provides timestamps for events, crucial for temporal analysis and correlation.

## 5. Research Synthesis

### Executive Summary
Adversaries exploit legitimate administrative tools and techniques, such as Windows Admin Shares and process injection methods, to mimic normal admin activities for unauthorized access or lateral movement. Detecting these abuses requires monitoring unusual patterns in system behaviors, command-line arguments, network traffic, and user actions.

### Recommended Hypothesis
> Adversaries use living-off-the-land (LoTL) tactics to escalate privileges and maintain stealthy persistence within a network by mimicking legitimate admin activities.

### Gaps Identified
- Current coverage lacks comprehensive detection for advanced memory injection techniques like Doppelgänging, which can evade traditional monitoring tools.

### Key Findings
- Hypothesis: Adversaries use living-off-the-land (LoTL) tactics to escalate privileges and maintain stealthy persistence within a network by mimicking legitimate admin activities.
- Gap: Current coverage lacks comprehensive detection for advanced memory injection techniques like Doppelgänging, which can evade traditional monitoring tools.
- Focus: Enhance process and user behavior analysis to identify suspicious patterns in the use of common system binaries (e.g., PowerShell) that deviate from normal baseline behaviors.
