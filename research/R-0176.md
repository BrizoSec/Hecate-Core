## 1. System Research: How It Works

### Summary
WebAuthn allows for secure, passwordless authentication through digital signatures and integrates with browser-based Remote Desktop Protocol (RDP) clients via JavaScript API calls. When used in conjunction with RDP, parameters like 'redirectwebauthn' can be utilized to redirect WebAuthn requests from a remote session back to the local device for user verification.

### Key Findings
- WebAuthn authentication is initiated by the relying party through JavaScript API calls to the browser client.
- RDP clients can use specific parameters such as 'redirectwebauthn' to enable seamless redirection of WebAuthn requests from a remote session to the local device.
- Local devices can support various methods for user verification including FIDO2 security keys, passkeys, and platform authenticators like Windows Hello.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries may exploit vulnerabilities or misconfigurations in the implementation of WebAuthn within browser-based RDP clients to gain unauthorized access. They might leverage phishing attacks or man-in-the-middle (MITM) tactics, exploiting user trust in modern authentication methods.

### Key Findings
- Phishing campaigns aimed at stealing WebAuthn credentials
- Man-in-the-Middle (MITM) attacks intercepting WebAuthn communication
- Exploitation of RDP client vulnerabilities for initial access
- Credential stuffing attacks targeting weak or stolen WebAuthn credentials
