## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries in the ClickFix campaign abuse DLL hijacking by sideloading a malicious mscoree.dll and shipping a driver to terminate Elastic Endpoint, enabling them to evade detection. This technique involves placing a compromised DLL in a directory that is searched before legitimate system directories, allowing it to be loaded instead of the genuine DLL.

### Key Findings
- Adversaries use DLL hijacking to inject malicious code into trusted processes by exploiting the Windows DLL search order.
- A driver is employed to terminate Elastic Endpoint security solutions to prevent detection of malicious activities.
- The ClickFix campaign demonstrates the use of a NativeAOT library as part of the attack vector, highlighting advanced obfuscation techniques.
- Elastic Defend 9.5.0 effectively detects unauthorized DLL loading and process injection through behavior-based rules.

## 5. Research Synthesis

### Executive Summary
Elastic Defend 9.5.0 simplifies the detection of DLL hijacking by reducing complex rule configurations to a single field, making it easier to identify 'DLL Hijack: Masquerading'. The ClickFix campaign demonstrates advanced evasion techniques such as sideloading malicious mscoree.dll and using a driver to terminate Elastic Endpoint security solutions.

### Recommended Hypothesis
> Adversaries use DLL hijacking to masquerade as legitimate processes in order to evade detection on targeted systems

### Gaps Identified
- Current coverage lacks detailed telemetry for detecting drivers that terminate endpoint protection software, which is crucial for identifying evasion techniques used by sophisticated adversaries.
- There's a need for more research into the obfuscation techniques used in NativeAOT libraries as part of DLL hijacking campaigns, given their effectiveness in evading detection.

### Key Findings
- Hypothesis: Adversaries use DLL hijacking to masquerade as legitimate processes in order to evade detection on targeted systems
- Gap: Current coverage lacks detailed telemetry for detecting drivers that terminate endpoint protection software, which is crucial for identifying evasion techniques used by sophisticated adversaries.
- Focus: Enhance monitoring of process injection and driver-level activities to detect advanced evasion tactics employed by attackers.
- Gap: There's a need for more research into the obfuscation techniques used in NativeAOT libraries as part of DLL hijacking campaigns, given their effectiveness in evading detection.
- Focus: Develop more comprehensive behavior-based rules that can identify and flag malicious NativeAOT libraries alongside traditional DLLs.
