## 1. System Research: How It Works

### Summary
Shai-Hulud is a sophisticated npm-based worm that spreads through compromised packages, steals credentials and secrets by leveraging CI/CD environments, and employs advanced obfuscation techniques to avoid detection.

### Key Findings
- The worm uses multiple channels for exfiltrating stolen data, including GitHub repositories.
- It performs triple deobfuscation in npm's internal cache directory using the Bun runtime environment.
- Shai-Hulud leverages CI/CD environments and dependency confusion attacks to propagate itself.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries are exploiting the npm package ecosystem by deploying self-propagating malware called ChainDrop, which uses Ethereum smart contracts for command and control. The worm targets npm packages to steal credentials and propagate within the supply chain without needing updates once deployed.

### Key Findings
- ChainDrop utilizes Ethereum smart contracts for dynamic C2 infrastructure reconfiguration.
- The worm steals credentials from compromised npm packages and encrypts them with AES-256-GCM before RSA encryption using a hardcoded public key.
- ChainDrop demonstrates sophisticated supply chain attack techniques, leveraging npm's package registry to propagate and infect other systems.
- There is evidence of similarities between ChainDrop and the Shai-Hulud toolchain in terms of targeting npm packages but no confirmation that they are from the same actors.

## 5. Research Synthesis

### Executive Summary
Shai-Hulud is a sophisticated npm-based worm that propagates through compromised packages, leveraging CI/CD environments and Ethereum smart contracts for command and control. It steals credentials using advanced obfuscation techniques and exfiltrates data via multiple channels, including GitHub.

### Recommended Hypothesis
> Adversaries use npm package dependencies to deploy Shai-Hulud worms that exploit system owner/user credentials and CI/CD environments to propagate within the supply chain and steal sensitive information.

### Gaps Identified
- The current telemetry lacks comprehensive monitoring of Ethereum smart contract interactions related to command-and-control infrastructure reconfiguration, which could provide deeper insights into the worm's operational dynamics.
- There is insufficient visibility into npm package installation patterns in CI/CD pipelines, which limits our ability to detect ChainDrop propagation and credential theft.

### Key Findings
- Hypothesis: Adversaries use npm package dependencies to deploy Shai-Hulud worms that exploit system owner/user credentials and CI/CD environments to propagate within the supply chain and steal sensitive information.
- Gap: The current telemetry lacks comprehensive monitoring of Ethereum smart contract interactions related to command-and-control infrastructure reconfiguration, which could provide deeper insights into the worm's operational dynamics.
- Gap: There is insufficient visibility into npm package installation patterns in CI/CD pipelines, which limits our ability to detect ChainDrop propagation and credential theft.
- Focus: Enhancing monitoring of Ethereum smart contract interactions to identify dynamic C2 infrastructure reconfiguration by Shai-Hulud.
- Focus: Improving detection mechanisms for unexpected npm package installations and updates within CI/CD environments to prevent supply chain attacks.
