## 1. System Research: How It Works

### Summary
Falcon Onum is a data pipeline solution by CrowdStrike that transforms and routes telemetry data in real-time, enabling organizations to filter out noise and enrich data for better security insights. It acts as an intermediary layer between data sources and destinations, ensuring efficient data management and reducing costs.

### Key Findings
- Falcon Onum enables real-time transformation of raw telemetry into actionable intelligence by filtering out irrelevant data.
- It helps in decoupling data producers from consumers, enhancing flexibility in how security solutions are deployed and managed.
- The system ensures data integrity while allowing custom routing and reshaping for different downstream tools and platforms.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries can abuse Falcon Onum by using it to mask their activities, such as employing legitimate tools and commands in a way that blends with normal network behavior, making detection challenging. They may also leverage the system's data processing capabilities to exfiltrate sensitive information without triggering alerts.

### Key Findings
- Adversaries use shell command obfuscation techniques on VMware ESX to evade detection by Falcon Onum and similar systems.
- Legitimate tools like PowerShell, WMI, or Netsh can be abused for lateral movement and data exfiltration while remaining undetected by standard monitoring.
- Public IP addresses from suspicious VPN login events are flagged via GeoIP services in the Impossible Traveler pipeline to identify potential breaches.
- Falcon Onum's real-time telemetry enrichment feature can inadvertently assist attackers by normalizing their activities, reducing noise and making malicious patterns harder to detect.
- Adversaries may exploit the system’s reliance on Redis for data retrieval to manipulate or poison cache entries, leading to false negatives in threat detection.
