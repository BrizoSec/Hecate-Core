## 1. System Research: How It Works

### Summary
EtherRAT is a sophisticated malware that leverages Ethereum smart contracts for command and control (C2) communications, enabling it to hide its C2 infrastructure by decentralizing control. It typically disguises itself as legitimate software or game mods to gain initial footholds on Windows systems before deploying further malicious activities.

### Key Findings
- EtherRAT uses Ethereum blockchain technology for decentralized C2 communication.
- It often masquerades as legitimate software such as administrative tools or system utilities like RAMMap to evade detection.
- The malware employs a log writing routine that appears to be incomplete or obfuscated, likely to confuse analysis efforts.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
The Gentlemen Affiliate uses EtherRAT to deploy ransomware across Windows networks, leveraging Ethereum smart contracts for command and control (C2) communications. Initial access is gained through a malicious MSI installer, followed by data exfiltration via cloud storage services.

### Key Findings
- Adversaries use Ethereum blockchain for C2 communication in EtherRAT to avoid traditional detection methods.
- Initial infection vector involves a malicious MSI installer that grants adversaries initial foothold within the network.
- Data is exfiltrated using legitimate cloud storage platforms like Wasabi, with specific commands to exclude sensitive directories like 'AppData/' from being copied.
- Adversaries conduct extensive reconnaissance of the target environment before deploying ransomware, utilizing tools such as Advanced IP Scanner and Nmap.

The initial infection vector involves malicious MSI installers and subsequent data exfiltration via cloud storage services like Wasabi.
