## 1. System Research: How It Works

### Summary
Falcon Onum is a sophisticated cybersecurity solution that employs machine learning algorithms to detect and prevent threats in real-time. It continuously monitors system behavior, network traffic, and user activities to identify potential malicious actions before they can cause damage.

### Key Findings
- Falcon Onum excels at identifying advanced persistent threats (APTs) through behavioral analysis rather than just relying on signature-based detection methods.
- The system leverages machine learning models trained on vast datasets of normal and anomalous network behavior to provide predictive threat intelligence.
- It offers a centralized dashboard for security operations teams to monitor alerts, manage configurations, and conduct forensic investigations efficiently.

## 3. Telemetry Mapping: OCSF Fields

### Summary
Telemetry should include Windows Event Logs and process data related to RDP sessions. Specifically, event IDs like 4625 (logon events), 4778 (account used for remote access), and 1149 (failed logon attempts). Process execution details of tools commonly used in reconnaissance activities after a successful login should also be recorded.

### Key Fields
- event_id:4625 (90% populated): This event ID captures user account logons, which can indicate an RDP session initiated from a remote IP address. Analyzing this data for unusual patterns or access attempts from suspicious IPs is crucial.
- event_id:1149 (85% populated): This event indicates failed logon attempts, which could be indicative of brute-force attacks targeting RDP sessions. Monitoring these events can help detect early signs of lateral movement.
- process_name: netsh.exe (70% populated): Netsh is commonly used for network configuration and troubleshooting but also by attackers to perform port scanning or enumerate network services post-compromise.
- source_ip: (85% populated): The IP address from which an RDP session originated. Identifying unusual source IPs that attempt or succeed in connecting can help detect lateral movement.
- target_user: (90% populated): The user account targeted by the logon attempts or successful sessions, helping to track potential misuse of accounts across different endpoints.
