## 1. System Research: How It Works

### Summary
Automated threat hunting is a proactive cybersecurity strategy that uses advanced analytics and machine learning to detect hidden threats in an organization's network, complementing traditional reactive security measures. It leverages expert knowledge and intelligence from various sources to identify potential attack vectors before they cause harm.

### Key Findings
- Threat hunting enhances the detection of sophisticated attacks by identifying patterns that may indicate malicious activities beyond what standard security tools can find.
- The process involves using automated tools alongside manual analysis to reduce dwell time and limit the impact of breaches.
- Integrating threat intelligence and machine learning algorithms improves the efficiency and effectiveness of cybersecurity teams in dealing with advanced persistent threats.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries are increasingly leveraging AI to evade detection and using trusted identities and legitimate tools to carry out attacks, making traditional alert-driven approaches inadequate. CrowdStrike's reports highlight the need for continuous threat hunting to identify and mitigate sophisticated threats effectively.

### Key Findings
- 82% of detections in 2025 were malware-free, indicating a shift towards stealthier attack methods.
- Adversaries are using AI technologies to enhance their evasion capabilities, making it harder to detect them with conventional security measures.
- Trusted identities and legitimate tools are being exploited by attackers to accelerate attacks and avoid raising suspicion.
- Continuous threat hunting and automation are essential for closing detection gaps created by sophisticated adversaries.

## 3. Telemetry Mapping: OCSF Fields

### Summary
The telemetry would capture behaviors indicative of unauthorized account usage, such as abnormal logon activities, unusual process creations involving unauthorized software, and network connections to suspicious IP addresses. This includes Windows Security Event Logs detailing user account changes (Event IDs 4720-4739) and logons/logoffs (Event IDs 4624, 4625), as well as endpoint telemetry that records process execution with command-line arguments.

### Key Fields
- event_id: Describes the type of security-related event. Populated for all Windows Security events captured in SIEM/Log Aggregation Platform (e.g., Event ID 4720 indicates a user account was created).
- process_name: Indicates the name of the process that performed an action, like executing a malicious tool or modifying system settings.
- command_line: Specifies the command line arguments used when invoking a process. This is crucial for identifying suspicious activities such as running scripts with administrative privileges.
- source_ip: The IP address from which network connections were initiated, useful in detecting unusual external access patterns.
- user_id: Identifies the user account associated with an event (e.g., logon/logoff), allowing tracking of specific users' behavior over time.
- network_protocol: Describes the protocol used for communication, such as TCP or UDP, aiding in identifying potentially malicious network traffic.

## 5. Research Synthesis

### Executive Summary
Automated threat hunting is essential for detecting sophisticated attacks that evade traditional security measures. With the increasing sophistication of adversaries, leveraging machine learning and continuous threat intelligence is crucial to identify and mitigate stealthy threats effectively.

### Recommended Hypothesis
> Adversaries use AI-driven evasion techniques to hide malware-free attacks on trusted identities within organizations

### Gaps Identified
- Current security measures may not adequately detect stealthy attack methods that do not rely on traditional signatures or alerts, such as living-off-the-land behaviors and credential abuse.

### Key Findings
- Hypothesis: Adversaries use AI-driven evasion techniques to hide malware-free attacks on trusted identities within organizations
- Gap: Current security measures may not adequately detect stealthy attack methods that do not rely on traditional signatures or alerts, such as living-off-the-land behaviors and credential abuse.
