## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries often employ execution guardrails like mutual exclusion via mutexes to control malware instances, ensuring that only one copy of the malicious code runs at a time. This technique minimizes system impact and avoids detection by preventing multiple infections or executions.

### Key Findings
- Mutex-based mutual exclusion is commonly used in ransomware variants such as BlackByte and LockBit 2.0 to prevent concurrent execution.
- Adversaries use mutexes to signal the presence of an active malware instance, ensuring that further attempts to launch the same malicious code are suppressed.
- Techniques like this are part of a broader strategy to maintain stealth and control over infected systems, reducing the risk of detection by security mechanisms.
- Mutex names used in mutual exclusion can serve as valuable indicators for threat hunting and incident response activities.
