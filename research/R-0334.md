## 1. System Research: How It Works

### Summary
The npm (Node Package Manager) ecosystem is a platform for sharing and installing JavaScript packages. Developers use it to publish their code, which other developers can then install into their projects via the command line or package.json files.

### Key Findings
- npm packages are often used as dependencies in larger applications, making them potential targets for supply chain attacks where malicious actors inject harmful scripts.
- The ChainDrop worm leverages compromised developer accounts to inject malicious code into npm packages and propagate across multiple repositories.
- Once installed, the malware steals credentials and uses them to further spread within the npm ecosystem.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
The CHAINDROP worm compromised over 400 npm packages by stealing developer credentials and using Ethereum blockchain for command-and-control, demonstrating a sophisticated supply chain attack that self-deletes after 24 hours to evade detection.

### Key Findings
- CHAINDROP utilizes stolen credentials from developers to propagate itself across multiple npm packages.
- The worm employs the Ethereum blockchain for issuing commands and controlling its propagation, indicating advanced operational security measures.
- Infected packages execute malicious code upon installation, designed to steal additional credentials and facilitate further infection of other packages.
- Detection is complicated by the self-deleting nature of CHAINDROP, which removes itself after 24 hours to avoid being identified.
- The attack targets widely-used npm packages with millions of weekly downloads, maximizing its reach and potential impact on software supply chains.
