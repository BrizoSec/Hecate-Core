## 1. System Research: How It Works

### Summary
MacSync is a macOS information stealer distributed via SEO poisoning and ClickFix social engineering, where victims are tricked into pasting malicious Terminal commands that download and execute a Mach-O binary stager. The malware employs process daemonization, AppleScript execution, and single-byte XOR obfuscation to bypass security controls like Gatekeeper and EDR while exfiltrating credentials and cryptocurrency wallets via chunked uploads to C2 infrastructure.

### Key Findings
- The attack chain relies on ClickFix social engineering delivered through SEO poisoning, leading victims to execute malicious code in Terminal that triggers a wrapper script decompressing a native Mach-O binary stager (e.g., com.utils.Launcher).
- MacSync utilizes sophisticated evasion techniques including renaming its persistence mechanism as legitimate Apple or Google plist files (com.google.keystone.plist or com.apple.sync.plist) in ~/Library/LaunchAgents/ and spoofing User-Agent strings to mimic standard macOS network traffic.
- The malware exfiltrates high-value data such as keychain entries, SSH keys, browser cookies, and cryptocurrency wallets by staging them in /tmp/osalogging.zip and performing fault-tolerant 10MB chunked uploads to C2 domains like drivinguber.com and newsinweb.com.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries deploy MacSync Stealer, a macOS information stealer sold via malware-as-a-service, utilizing ClickFix social engineering and fake CAPTCHA lures to trick users into executing malicious Terminal commands. This technique enables the automatic download and execution of payloads that evade standard detection mechanisms while exfiltrating high-value credentials and cryptocurrency wallet data.

### Key Findings
- The attack chain leverages 'ClickFix' social engineering, often impersonating legitimate services like Google Meet or Docker, to force victims to paste malicious commands into the Terminal, which then fetches and executes encoded scripts without further user interaction.
- MacSync employs sophisticated evasion techniques including process daemonization, single-byte XOR obfuscation, in-memory AppleScript execution via `osascript`, and code-signing/notarization to bypass Gatekeeper, XProtect, and EDR solutions.
- The malware targets high-value assets by stealing keychain data, browser session cookies, SSH keys, Telegram sessions, and cryptocurrency wallets, exfiltrating the data through fault-tolerant 10MB chunked uploads to command-and-control infrastructure.
- Persistence is achieved by renaming the Mach-O binary stager as `com.google.keystone.plist` or `com.apple.sync.plist` within the `~/Library/LaunchAgents/` directory, mimicking legitimate Apple and Google system processes.
- Threat intelligence identifies the 'Pulsar MacSync cluster' as the adversary group orchestrating these campaigns, which utilize domains like `drivinguber.com` and `newsinweb.com` for C2 communications and distribute payloads with hashes such as SHA-256 `9ff32f7c0108e9d27a3b491edf04827b6ca025f44db68aeadc44eeb97c9aab11`.

## 5. Research Synthesis

### Executive Summary
MacSync is an evasive macOS stealer leveraging ClickFix social engineering to trick users into executing Terminal commands that deploy a Mach-O stager (com.utils.Launcher) which persists via spoofed LaunchAgents like com.google.keystone.plist. The malware employs single-byte XOR obfuscation, in-memory AppleScript execution via osascript, and fault-tolerant 10MB chunked uploads to C2 domains drivinguber.com and newsinweb.com to exfiltrate credentials and cryptocurrency wallets while bypassing Gatekeeper and EDR controls.

### Recommended Hypothesis
> Adversaries use ClickFix social engineering to force terminal command execution, enabling the deployment of a Mach-O stager that persists via spoofed LaunchAgents and exfiltrates high-value data through XOR-obfuscated, chunked HTTP uploads to C2 infrastructure.

### Gaps Identified
- Lack of telemetry capturing the specific curl-to-osascript pipe command line or the creation of /tmp/osalogging.zip, which allows the initial payload delivery and staging phases to remain invisible.

### Key Findings
- Hypothesis: Adversaries use ClickFix social engineering to force terminal command execution, enabling the deployment of a Mach-O stager that persists via spoofed LaunchAgents and exfiltrates high-value data through XOR-obfuscated, chunked HTTP uploads to C2 infrastructure.
- Gap: Lack of telemetry capturing the specific curl-to-osascript pipe command line or the creation of /tmp/osalogging.zip, which allows the initial payload delivery and staging phases to remain invisible.
