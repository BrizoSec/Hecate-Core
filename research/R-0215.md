## 1. System Research: How It Works

### Summary
System hardening is the process of securing a computer system by reducing its surface of attack: closing unused ports, removing unnecessary software, disabling unnecessary services, applying security patches regularly, configuring firewalls effectively, and implementing strong authentication mechanisms.

### Key Findings
- Disabling or uninstalling unnecessary services can significantly reduce potential entry points for attackers.
- Regularly updating the system with the latest security patches helps protect against known vulnerabilities.
- Proper firewall configuration is crucial to control inbound and outbound traffic effectively, preventing unauthorized access.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries exploit the system hardening weaknesses by leveraging adversary-in-the-middle (AiTM) attacks to intercept and manipulate network traffic, enabling them to eavesdrop on or modify sensitive data. This technique often requires privileged access but can also be executed through specific vulnerabilities like unquoted paths in services, allowing for manipulation of environment variables or search orders.

### Key Findings
- Adversaries may exploit weaknesses in the PATH environment variable or unquoted service paths to hijack and manipulate network traffic.
- Services file permissions and registry settings can be manipulated by adversaries with privileged access to intercept network communications.
- AiTM attacks on Android devices involve monitoring data exchanged between applications and external storage, requiring specific tools like packet sniffers for interception.
- Attack detection involves monitoring unusual network activity, unauthorized changes in system configurations, and signs of compromised credentials or permissions.
