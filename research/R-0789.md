## 1. System Research: How It Works

### Summary
Tailscale is a networking technology that utilizes its data plane, including WireGuard encryption and DERP relays, to facilitate secure peer-to-peer connections without requiring traditional IP addresses or administrative accounts in its 'tailcat' variant. From a sensor perspective, this manifests as encrypted traffic routed through Tailscale's infrastructure, allowing legitimate utility tools to establish persistent, low-profile command-and-control channels that bypass conventional network inspection.

### Key Findings
- Tailcat operates by leveraging Tailscale's data plane (WireGuard, NAT traversal, and DERP) while deliberately omitting the control plane, resulting in a system with no IP addresses, user accounts, admins, or governance structures, which facilitates anonymous short-lived connections.
- Access to tailcat is determined solely by the possession of a specific tailcat address and the public keys used to identify connecting devices, rather than traditional authentication methods.
- The tool functions as a standard CLI application running in userspace without requiring privileged access to the machine, enabling it to forward requests from local TCP ports (e.g., 127.0.0.1:18080) to an operator's node port (e.g., 4444).
- Unlike standard Tailscale VPN, tailcat does not require device registration or account creation, making it designed specifically for transient connections where traditional network monitoring signatures would fail.
- The underlying infrastructure relies on hosted relays which, while lacking governance controls, may still retain metadata logs of the communications passing through them.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
The Kothamine remote-access Trojan abuses Tailscale's open-source tool, tailcat, to establish encrypted command-and-control communications that evade conventional network detection by eliminating the need for traditional C2 domains or accounts. The malware is distributed via malicious npm packages and leverages this technique alongside Windows Defender exclusion persistence to maintain access to infected Windows systems.

### Key Findings
- Kothamine utilizes 'tailcat,' an open-source Tailscale tool that uses the data plane (WireGuard, NAT traversal, DERP) without a control plane, allowing for encrypted C2 traffic without requiring user accounts, IP addresses, or admin governance.
- The malware is distributed through malicious npm packages, specifically linked to a package named 'dotnet-runtime-base' which downloads an executable ('npm-sc-legit.exe') containing the Kothamine agent.
- To evade detection, the malware adds its components (MicrosoftEdgeUpdateCore.exe and .dll) and processes to Windows Defender exclusions using PowerShell commands upon execution.
- Persistence is achieved by creating a scheduled task named 'MicrosoftEdgeUpdateTask' that executes the legitimate-looking binary at user logon, while also dropping files into %ROAMING% directories.
- C2 communication is established by injecting tailcat as a forwarder; the agent connects to a local port (e.g., 127.0.0.1:18080) which tailcat then tunnels via WireGuard to the attacker's node on port 4444.
- The Kothamine Agent supports over 30 commands, including file manipulation, browser data theft, and camera/microphone recording, with capabilities extended by loading additional DLLs.

## 5. Research Synthesis

### Executive Summary
The Kothamine Agent malware utilizes the open-source tool 'tailcat' to establish encrypted, account-less Command-and-Control (C2) channels that bypass conventional network inspection by leveraging Tailscale’s data plane. The threat actor distributes this payload via malicious npm packages, employing process injection into explorer.exe and Windows Defender exclusion policies to maintain persistence and evade endpoint detection.

### Recommended Hypothesis
> Adversaries use Tailscale's tailcat utility for encrypted C2 communication and malicious npm packages for initial access to control infected Windows systems while evading network and endpoint defenses.

### Gaps Identified
- Lack of visibility into userspace WireGuard/DERP traffic flows allows tailcat-based C2 to blend with legitimate Tailscale infrastructure traffic, masking the encrypted payload.
- Standard EDTR telemetry often misses the specific 'Add-MpPreference' PowerShell evasion techniques or the file system artifacts related to %APPDATA%\TailscalePortable extraction before process injection occurs.

### Key Findings
- Hypothesis: Adversaries use Tailscale's tailcat utility for encrypted C2 communication and malicious npm packages for initial access to control infected Windows systems while evading network and endpoint defenses.
- Gap: Lack of visibility into userspace WireGuard/DERP traffic flows allows tailcat-based C2 to blend with legitimate Tailscale infrastructure traffic, masking the encrypted payload.
- Gap: Standard EDTR telemetry often misses the specific 'Add-MpPreference' PowerShell evasion techniques or the file system artifacts related to %APPDATA%\TailscalePortable extraction before process injection occurs.
- Focus: Monitor for unauthorized execution of tailcat.exe with 'forward' arguments and unexpected WireGuard protocol signatures originating from non-standard user processes.
