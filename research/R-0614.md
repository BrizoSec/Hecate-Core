## 2. Adversary Tradecraft: Attack Techniques

### Summary
BengalSEO employs black hat SEO tactics such as DOM injection, DOM shuffling, backlink spamming, and keyword stuffing to manipulate search engine rankings for malicious websites. These techniques aim to deceive users into visiting fraudulent pages.

### Key Findings
- Adversaries use DOM injection and DOM shuffling to modify web page content dynamically, making it difficult for search engines to detect the true nature of the page.
- Backlink spamming is employed to artificially inflate link popularity metrics, which can boost a site's rankings in search results.
- Keyword stuffing is used to increase the frequency of specific keywords on pages, aiming to improve visibility and relevance in searches.
- Malicious lure pages are created to mimic legitimate websites, tricking users into visiting them.
