## 1. System Research: How It Works

### Summary
Elastic InfoSec manages Linux endpoint configurations without MDM by using a scheduled Elastic Workflow that executes every six hours to deploy and enforce settings for tools like Cursor and Codex. This workflow utilizes a script from the Elastic Security library to apply changes while ensuring offline hosts do not accumulate duplicate actions.

### Key Findings
- The system relies on a 68-line YAML workflow that checks Linux endpoints every six hours to maintain configuration currency without requiring traditional Mobile Device Management (MDM).
- Managed configurations are written to specific legacy and constraint files, including /etc/codex/managed_config.toml for OpenTelemetry defaults and /etc/codex/requirements.toml for enforced approval policies.
- Enterprise hook configurations take precedence over local settings via /etc/cursor/hooks.json, which works in conjunction with the /usr/local/share/ai-hooks directory to enforce system-wide behavior.
