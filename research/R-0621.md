## 1. System Research: How It Works

### Summary
This system leverages the Google Visualization API to retrieve obfuscated JavaScript from a publicly accessible Google Sheets document, which is then executed in the victim's browser session—either directly via the Chrome address bar using the 'javascript:' protocol or through the Tampermonkey browser extension. The malicious script dynamically injects itself into cryptocurrency trading websites like SimpleSwap.io, exfiltrating sensitive data over HTTPS to a C2 server whose address is stored in an Ethereum smart contract.

### Key Findings
- The C2 infrastructure is hosted on Google Docs via the Google Visualization API, with the malicious payload retrieved from a publicly published Google Sheets document, appearing as legitimate web traffic.
- The initial delivery mechanism involves social engineering where users are tricked into pasting a JavaScript URL (from paste.sh) into the Chrome address bar prefixed with 'javascript:', resulting in direct script execution in the current page context.
- A secondary delivery method uses the Tampermonkey browser extension, where the malicious script is installed as a user script and activated automatically when visiting targeted cryptocurrency sites like SimpleSwap.io.
- The C2 server address is dynamically resolved from an Ethereum smart contract, allowing operators to update the command and control endpoint via a single blockchain transaction, enabling rapid botnet relocation.
- The malicious script performs DOM analysis to detect and inject into browser extension-related script elements, facilitating the theft of cryptocurrency session data and credentials during active user sessions.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries abuse the Google Visualization API and publicly accessible Google Sheets to host and retrieve obfuscated JavaScript payloads for cryptocurrency theft, leveraging trusted services to evade detection. The attack chain begins with social engineering lures that instruct victims to execute malicious scripts via the Chrome browser's navigation bar using the 'javascript:' protocol, or to install the script via the Tampermonkey browser extension for automatic execution on specific cryptocurrency trading sites.

### Key Findings
- The campaign uses Google Sheets, accessible via docs.google.com, as a command and control (C2) channel to deliver obfuscated JavaScript payloads through the Google Visualization API.
- Victims are lured through deceptive instructions to execute scripts directly in the browser's navigation bar by prefixing a paste.sh URL with 'javascript:', enabling immediate execution in the current context.
- A new variant of the attack targets users of cryptocurrency trading platforms like SimpleSwap.io, with the malicious script activated automatically when the user visits the site if installed via Tampermonkey.
- The attack leverages trusted infrastructure (Google services) and common browser behaviors (JavaScript execution in navigation bar, browser extensions) to bypass traditional security controls.
- The use of paste.sh as a script delivery mechanism suggests a focus on ease of distribution and user interaction, with the payload hosted in a publicly accessible URL that can be dynamically updated.
- The technique demonstrates a shift from requiring manual script execution to automated execution via browser extensions, increasing the attack's persistence and reach [UNCERTAIN: exact timing of transition not specified].

## 5. Research Synthesis

### Executive Summary
Adversaries leverage the Google Visualization API to dynamically retrieve obfuscated JavaScript payloads from publicly accessible Google Sheets, executing them in the browser via the 'javascript:' protocol or Tampermonkey extension to steal cryptocurrency credentials on targeted trading platforms like SimpleSwap.io. The C2 infrastructure is ephemeral and relocatable via Ethereum smart contract updates, enabling rapid evasion and persistence through trusted cloud services and browser extension automation.

### Recommended Hypothesis
> Adversaries use the Google Visualization API to retrieve obfuscated JavaScript from publicly accessible Google Sheets and execute it via the 'javascript:' protocol or Tampermonkey extension to exfiltrate cryptocurrency data from targeted trading sites such as SimpleSwap.io.

### Gaps Identified
- Lack of telemetry mapping for 'javascript:' protocol usage in browser navigation bars, especially when targeting specific domains like SimpleSwap.io, limits detection of initial script execution.
- Absence of behavioral detection for dynamic payload injection via Google Visualization API calls to docs.google.com with non-standard query parameters (e.g., 'tq' or 'gid') prevents identification of C2 beaconing patterns.

### Key Findings
- Hypothesis: Adversaries use the Google Visualization API to retrieve obfuscated JavaScript from publicly accessible Google Sheets and execute it via the 'javascript:' protocol or Tampermonkey extension to exfiltrate cryptocurrency data from targeted trading sites such as SimpleSwap.io.
- Gap: Lack of telemetry mapping for 'javascript:' protocol usage in browser navigation bars, especially when targeting specific domains like SimpleSwap.io, limits detection of initial script execution.
- Gap: Absence of behavioral detection for dynamic payload injection via Google Visualization API calls to docs.google.com with non-standard query parameters (e.g., 'tq' or 'gid') prevents identification of C2 beaconing patterns.
- Focus: Develop signature-based detection for Google Sheets API requests with obfuscated query parameters (e.g., 'tq=select%20A%2C%20B%20from%201234567890') used to retrieve malicious payloads.
- Focus: Implement browser process monitoring for Tampermonkey script activation triggered on visits to high-risk domains (e.g., cryptocurrency exchanges), including inspection of injected script content via sandboxed execution.
- Focus: Correlate DNS and HTTP telemetry from Chrome processes to detect outbound connections to docs.google.com with high-frequency, low-volume requests to Google Sheets documents containing non-standard or obfuscated payload identifiers.
