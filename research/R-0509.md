## 1. System Research: How It Works

### Summary
Google Apps Script (GAS) allows developers to automate tasks within Google Workspace products such as Gmail and Drive. Typically, scripts are written in JavaScript and can interact with various APIs provided by Google services. If Project CAV3RN utilizes GAS for a Command and Control infrastructure in Israel, it likely leverages the platform's capabilities to remain undetected while communicating between malware components or servers.

### Key Findings
- GAS scripts can be embedded within legitimate-looking Google Workspace files like spreadsheets or documents, making them harder to detect as malicious activity.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries may abuse Google Apps Script to establish a Command and Control (C2) infrastructure that is stealthy due to its reliance on legitimate cloud services. This method allows attackers to communicate with compromised systems or deploy additional malware while evading traditional network security measures.

### Key Findings
- Google Apps Script can be utilized as a proxy for exfiltrating data from targeted networks, leveraging the trust associated with Google services to avoid detection by firewall rules and intrusion detection systems.
- [UNCERTAIN] Attackers might use OAuth tokens or API keys compromised through phishing or other means to gain unauthorized access to Google Apps Script environments and initiate C2 communications.
- The use of webhooks in Google Sheets or Forms can serve as a trigger mechanism for initiating malicious activities, such as downloading additional payloads or executing scripts on infected machines.
- Adversaries could exploit Google Apps Script's ability to send emails from any domain hosted by Google Workspace (formerly G Suite) without raising immediate suspicion about suspicious network traffic patterns.
- [UNCERTAIN] By embedding malicious scripts within seemingly benign Google Docs or Sheets, adversaries can create a persistent and hard-to-detect C2 channel that operates under the guise of legitimate user activity.
- Google Apps Script's ability to interact with other Google services (such as Drive) provides attackers with an additional layer of obfuscation for data exfiltration and lateral movement within a network.
