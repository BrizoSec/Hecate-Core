## 1. System Research: How It Works

### Summary
Terraform is an infrastructure-as-code tool that normally manages cloud resources through declarative configuration files and official, signed provider plugins. In this incident, a legitimate-looking provider was trojanized to silently download and execute cross-platform malware payloads disguised as system utilities or browser updaters.

### Key Findings
- The malicious campaign utilizes a lookalike domain (hashicorp-terraform.io) to distribute a fake Terraform provider plugin, which serves as the initial delivery mechanism for subsequent stages.
- A Bash loader script, named 'safari_updater', is dropped into the temporary directory to orchestrate payload deployment, using 'xattr -d com.apple.quarantine' on macOS to bypass security controls before execution.
- The malware employs platform-specific persistence by installing itself as a service with names mimicking legitimate system processes: 'snap-imagent' on Linux, 'imagent' in Library/Services on macOS, and 'powershell-config-service' on Windows.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
The TraderTraitor group exploits trust in infrastructure-as-code tools by distributing a trojanized Terraform provider that downloads a Bash loader from a HashiCorp-themed lookalike domain. This loader dynamically selects and deploys cross-platform malware, including the FLATROOF backdoor and Python-based information stealers, tailored to the victim's operating system.

### Key Findings
- The initial compromise vector involves a malicious Terraform provider that retrieves a Bash payload from 'hashicorp-terraform.io', a domain impersonating the legitimate HashiCorp infrastructure.
- The campaign employs platform-specific persistence mechanisms: installing 'snap-imagent' as a service on Linux, 'imagent' in Library/Services on macOS, and 'powershell-config-service' in AppData on Windows.
- Encrypted executables are concealed within fake font files and extracted using marker-based techniques with AES-256-CBC decryption to evade static analysis.
- Command and Control (C2) operations utilize multiple resilient channels, including the Telegram Bot API, GitHub, and cryptographically signed Pastebin dead drops for ROOFDECK backdoor discovery.
- Python-based information stealers are deployed to exfiltrate browser credentials, cookies, cryptocurrency wallet extensions, and system information from targeted Web3 developers.

## 5. Research Synthesis

### Executive Summary
The TraderTraitor group leverages a trojanized Terraform provider to deploy cross-platform malware (FLATROOF, ROOFDECK) by downloading Bash loaders from the lookalike domain 'hashicorp-terraform.io', which then installs platform-specific persistence services like 'imagent' or 'powershell-config-service'. Detection relies on identifying unusual file system activity in temporary directories (e.g., 'safari_updater') and outbound network connections to C2 infrastructure such as 'arusupport-region1-webhook.online' and Pastebin dead drops.

### Recommended Hypothesis
> Adversaries use trojanized Terraform providers and lookalike HashiCorp domains to deliver platform-specific persistent backdoors (FLATROOF/ROOFDECK) targeting Web3 developers across macOS, Linux, and Windows.
