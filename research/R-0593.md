### Summary
Telemetry should capture process creation events, network connections, and file integrity monitoring to detect AI-driven attacks. This involves identifying anomalous behavior such as rapid lateral movement, unexpected outbound connections, and unauthorized changes in system files.

### Key Fields
- process_creation (95% populated): Monitors the creation of processes on endpoints which is crucial for detecting malicious activities like DLL injections or fileless malware execution.
