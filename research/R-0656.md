## 1. System Research: How It Works

### Summary
The exploit chain leverages a type-confusion bug in Chrome's V8 engine (CVE-2026-85046) and a WebAssembly sandbox escape defect (CVE-2026-87491), followed by a heap-based buffer overflow in the Windows ALPC subsystem (CVE-2026-85880). This sequence allows an attacker to execute arbitrary code within the browser context and subsequently escalate privileges or establish persistence via kernel-level exploitation.

### Key Findings
- The exploit relies on a 'patch-gap' window where vulnerabilities were patched in Chromium source code but not yet deployed to stable Chrome releases, allowing attackers to exploit unpatched systems between August 7 and September 3, 2026.
- Payload delivery involves a loader that dynamically assembles an exploit URL at runtime by appending a 'mode=payload' flag to a base configuration URL (e.g., cloud.shinewrist.net), which is then injected into a hidden iframe invisible to the user.
- The attack chain results in the deployment of distinct post-exploitation tools tailored to specific actors: UTA0560 utilizes the GRIMWEDGE JScript backdoor for reconnaissance, while JungleBamboo deploys the SUPERSTOMP loader and LONGTALE Chrome extension for credential theft and surveillance.
- Both threat actors utilized byte-for-byte identical shellcode, indicating a shared exploit supply chain despite their differing operational objectives and phishing lure strategies (financial vs. generic themes).

## 2. Adversary Tradecraft: Attack Techniques

### Summary
Chinese threat actors UTA0560 and JungleBamboo exploited a 'patch gap' in September 2026 by chaining Chrome zero-day vulnerabilities (CVE-2026-85046, CVE-2026-87491) with a Windows kernel vulnerability (CVE-2026-85880) that was fixed in the Chromium source but not yet released to end-users. They delivered these exploits via spear-phishing campaigns, resulting in the deployment of distinct post-exploitation tools like the GRIMWEDGE backdoor and LONGTALE extension despite sharing identical exploit shellcode.

### Key Findings
- The attackers leveraged a 'patch gap' by exploiting vulnerabilities in Chrome and Windows that had been patched in the open-source Chromium repository but not yet distributed to the general public, allowing them to study the fix and reverse-engineer the vulnerability.
- Two distinct Chinese threat groups, UTA0560 and JungleBamboo, operated concurrently using byte-for-byte identical shellcode, suggesting a shared exploit supply chain or cooperation, while deploying different malware payloads based on their specific operational goals.
- UTA0560 targeted NGOs with financial-themed spear-phishing emails to deliver the GRIMWEDGE JScript backdoor for reconnaissance and command execution.
- JungleBamboo used generic phishing themes to deploy the SUPERSTOMP loader, which installed the LONGTALE Chrome extension designed for credential theft, keylogging, and surveillance.
- The exploitation chain relied on CVE-2026-85046 and CVE-2026-87491 in Google Chrome combined with the Windows kernel vulnerability CVE-2026-85880 to achieve remote code execution and persistence.
- Infrastructure indicators include domains such as msbenefit.com and gitprogram.com, hosting URLs like https://photos.msbenefit.com/fa/t3, and an IP address at 206.166.251.164 associated with BL Networks.

This chain enabled the deployment of distinct post-exploitation tools, including the GRIMWEDGE JScript backdoor and LONGTALE Chrome extension, while sharing identical exploit shellcode indicative of a common supply chain.

### Recommended Hypothesis
> Adversaries use chained zero-day exploits in Chrome and Windows kernel to execute arbitrary code and establish persistent surveillance via malicious browser extensions and JScript backdoors on targeted organizational endpoints
