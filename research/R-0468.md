## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries use Adversary-in-the-Middle (AiTM) techniques to intercept and manipulate network traffic, which allows them to block, log, modify, or inject data into the communication stream between two parties. Common targets include industrial control systems and network devices, where such interference can cause significant operational disruptions.

### Key Findings
- Adversaries often leverage AiTM attacks in targeted campaigns against ICS networks to disrupt critical infrastructure operations.
- Tools like ARP poisoning are commonly used to establish a man-in-the-middle position within the network.
- Indicators of AiTM activities include unusual patterns of DNS requests or HTTP traffic, unexpected SSL/TLS certificate errors, and anomalous network latency.
- AiTM attacks can be extended beyond traditional networks to mobile environments as well, exploiting vulnerabilities specific to these platforms.

## 3. Telemetry Mapping: OCSF Fields

### Summary
Telemetry capturing process creation events, network traffic logs, and specific Windows Security Event IDs will help in detecting lateral movement and C2 communication attempts.

### Key Fields
- process_name (100% populated): Indicates the name of the executable or script used for lateral movement or malicious activities.
- process_path (95% populated): Provides the full path where the process was executed, which can help in identifying if it is a legitimate system file being abused.
- network_protocol (85% populated): Identifies the protocol used by the network traffic, such as HTTP or DNS, which might be indicative of C2 communication.
- event_id (90% populated): Specific Windows Security Event IDs like 4688 and 4776 that are crucial for identifying account creations and process creation activities.
