## 2. Adversary Tradecraft: Attack Techniques

### Summary
UAT-7810 employs adversary-in-the-middle (AiTM) techniques to build ORB networks by hijacking threads and intercepting network traffic, enabling credential theft and data manipulation. The malware frequently evolves its tactics to evade detection.

### Key Findings
- Adversaries use AiTM techniques to position themselves between two or more devices in the network for further attacks such as Network Sniffing and Data Manipulation.
- Thread hijacking and network traffic interception are primary methods used by UAT-7810 for credential theft and data manipulation within ORB networks.
- The malware changes tactics frequently, including altering C2 signatures over time to avoid detection by common defensive tools.
- Adversaries leverage privileged network access to modify real-time network traffic using AiTM attacks on ICS systems.
