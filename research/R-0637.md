## 1. System Research: How It Works

### Summary
MacSync is a macOS information stealer that exploits the ClickFix social engineering technique, tricking victims into executing malicious terminal commands that bypass Gatekeeper and code-signing validations. It delivers a Mach-O stager which daemonizes itself, executes in-memory AppleScript to exfiltrate credentials and crypto wallets, and communicates with C2 infrastructure using chunked uploads.

### Key Findings
- The malware utilizes the ClickFix delivery chain, where victims are manipulated into pasting malicious commands into Terminal, allowing the attacker to bypass macOS security controls like Gatekeeper that validate software packages rather than individual shell commands.
- Technical artifacts include a native Mach-O stager binary (SHA256: 9ff32f7c0108e9d27a3b491edf04827b6ca025f44db68aeadc44eeb97c9aab11) and a wrapper script that decompresses a payload executing via /usr/bin/osascript, with persistence established by renaming itself to com.google.keystone.plist or com.apple.sync.plist in ~/Library/LaunchAgents/.
- Data exfiltration involves dumping keychains, session cookies, SSH keys, and cryptocurrency wallets into /tmp/osalogging.zip before deleting the archive and a local status file (/tmp/.httpcode) to cover tracks, followed by fault-tolerant 10MB chunked uploads to C2 domains like drivinguber.com and newsinweb.com.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries abuse the ClickFix technique by manipulating macOS users into executing malicious terminal commands disguised as legitimate software installation or update prompts, thereby bypassing standard security warnings. This delivery method facilitates the execution of MacSync Stealer, an evasive information stealer that exfiltrates sensitive data such as credentials and cryptocurrency wallets while employing sophisticated evasion tactics to avoid detection.

### Key Findings
- The primary delivery mechanism is ClickFix social engineering, where victims are tricked into copying and pasting malicious commands into the Terminal under the guise of legitimate actions like installing AI software or Docker updates.
- MacSync Stealer employs advanced evasion techniques including process daemonization, single-byte XOR obfuscation, in-memory AppleScript execution, and increasingly, code-signing and notarization to bypass Gatekeeper and EDR solutions.
- The malware targets high-value data including keychain credentials, browser session cookies, SSH keys, Telegram sessions, and cryptocurrency wallets, exfiltrating this information via fault-tolerant 10MB chunked uploads to C2 infrastructure.
- Indicators of Compromise include specific C2 domains such as drivinguber.com and newsinweb.com (with subdomains like asia.newsinweb.com and usa.newsinweb.com), alongside malicious file hashes like MD5 9678f71ea4cccbc3d511dc8d7f24b113.
- Post-exploitation persistence is achieved by renaming the payload to mimic legitimate system files, such as com.google.keystone.plist or com.apple.sync.plist, within the ~/Library/LaunchAgents/ directory.

## 5. Research Synthesis

### Executive Summary
MacSync Stealer exploits ClickFix social engineering to bypass Gatekeeper by tricking users into executing malicious terminal commands, resulting in the deployment of a Mach-O stager that daemonizes via LaunchAgents and executes in-memory AppleScript. The malware employs single-byte XOR obfuscation and fault-tolerant chunked uploads to exfiltrate high-value data including keychain credentials, SSH keys, and cryptocurrency wallets to C2 infrastructure.

### Recommended Hypothesis
> Adversaries use ClickFix social engineering to trick macOS users into executing malicious terminal commands, bypassing Gatekeeper to deploy a daemonized Mach-O stager that exfiltrates sensitive data via in-memory AppleScript execution.

### Gaps Identified
- Standard endpoint telemetry often fails to capture the full context of ad-hoc signed binaries (e.g., com.utils.Launcher) and short-lived /tmp artifacts due to lack of file integrity monitoring or process lineage correlation, while network sensors may miss fault-tolerant chunked uploads if not explicitly correlated with C2 domains.
- The use of in-memory AppleScript execution via piped curl output obscures traditional static analysis indicators, requiring dynamic behavioral detection rather than signature-based matching for the initial stage.

### Key Findings
- Hypothesis: Adversaries use ClickFix social engineering to trick macOS users into executing malicious terminal commands, bypassing Gatekeeper to deploy a daemonized Mach-O stager that exfiltrates sensitive data via in-memory AppleScript execution.
- Gap: Standard endpoint telemetry often fails to capture the full context of ad-hoc signed binaries (e.g., com.utils.Launcher) and short-lived /tmp artifacts due to lack of file integrity monitoring or process lineage correlation, while network sensors may miss fault-tolerant chunked uploads if not explicitly correlated with C2 domains.
- Gap: The use of in-memory AppleScript execution via piped curl output obscures traditional static analysis indicators, requiring dynamic behavioral detection rather than signature-based matching for the initial stage.
- Focus: Implement detection for suspicious process chains involving /usr/bin/curl piping directly into /usr/bin/osascript and subsequent creation of LaunchAgents with spoofed identifiers like com.apple.sync.plist in ~/Library/LaunchAgents/.
- Focus: Monitor for outbound network connections to identified C2 domains (drivinguber.com, newsinweb.com) and detect the specific HTTP User-Agent string 'Mozilla/5.0 (Macintosh; Intel Mac OS X 10_15_7) CFNetwork/Darwin 26.0.0' associated with the stager.
