## 1. System Research: How It Works

### Summary
Endpoint and network sensors detect ongoing AI-augmented intrusion campaigns (CL-CRI-1131 and CL-CRI-1163) targeting Latin American organizations, where attackers leverage AI tools like NextChat and custom scripts to automate malicious workflows. These systems communicate via dynamically generated DNS names (e.g., m-doxa-*.duckdns.org) and use known infrastructure (e.g., 178.128.87.160) to host AI-driven command-and-control operations and download malware such as SockTz versions.

### Key Findings
- The process 'NextChat' is actively hosted on TCP port 3000 at IP 178.128.87.160, indicating AI-assisted C2 communication for CL-CRI-1131 operations.
- Dynamic DNS subdomains (e.g., m-doxa-apodo.duckdns.org, m-doxa-intel.duckdns.org) are used to host C2 infrastructure, suggesting automated domain generation with operational intent tied to Mexican government and transportation sectors.
- Multiple AI-generated scripts (exploit_creative.py, exploit_careful.py, rce_focused.py) are observed in attack workflows, indicating the use of LLMs to create targeted exploitation code.
- The SockTz proxy tool (versions v8 and v9) is downloaded from a known malicious IP (167.148.195.53) via HTTP on port 8888, indicating a persistent malware delivery chain.
- Active Let's Encrypt TLS certificates are associated with duckdns.org subdomains, confirming that attackers use legitimate encryption to obfuscate C2 traffic while maintaining domain persistence.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries are leveraging agentic AI tools, including ChatGPT and Claude, to enhance their intrusion campaigns targeting organizations in Latin America, particularly in the Mexican transportation and government sectors (CL-CRI-1131) and the Brazilian financial sector (CL-CRI-1163). These campaigns involve AI-assisted development of custom scripts and exploitation techniques, combined with established malware and tunneling tools like SockTz and NextChat for persistence and data exfiltration.

### Key Findings
- Attackers use AI models such as ChatGPT and Claude to generate and refine malicious scripts, including exploit_creative.py, exploit_careful.py, and rce_focused.py, to improve attack efficiency.
- The campaigns leverage the open-source tool NextChat, hosted on IP 178.128.87.160 at port 3000, as a command-and-control (C2) mechanism, indicating integration of AI-driven tools into C2 infrastructure.
- Dynamic DNS domains like m-doxa-apodo.duckdns.org, m-doxa-geo.duckdns.org, m-doxa-intel.duckdns.org, and m-doxa-vacunas.duckdns.org are used for C2 communications, with subdomain naming suggesting targeting of Mexican federal government entities.
- Attackers employ the SockTz tool (versions 8 and 9) for tunneling and remote access, with download URLs such as http://167.148.195.53:8888/socktz_v9.exe, indicating persistent use of known malicious infrastructure.
- The use of Let's Encrypt TLS certificates on attacker-controlled domains reflects an operational tactic to blend in with legitimate encrypted traffic, increasing stealth.
- The attackers demonstrate improved technical capabilities through AI-augmented workflows, including automated exploitation and code generation, suggesting a shift toward more autonomous and adaptive attack behaviors [UNCERTAIN: extent of 'agentic' autonomy beyond script generation]

## 5. Research Synthesis

### Executive Summary
Adversaries are leveraging agentic AI tools such as ChatGPT and Claude to generate custom Python exploitation scripts (e.g., exploit_creative.py, exploit_careful.py) and operate AI-driven C2 infrastructure via NextChat on port 3000, while using dynamic DNS domains (e.g., m-doxa-*.duckdns.org) for resilient command-and-control communications. These campaigns exhibit persistent use of known malicious infrastructure (e.g., 178.128.87.160, 167.148.195.53) to deliver SockTz proxy tools and exfiltrate data, with observable telemetry including process execution, network connections to C2 IPs, and file drops of AI-generated payloads.

### Recommended Hypothesis
> Adversaries use AI-generated Python scripts and dynamic DNS-based C2 infrastructure to automate exploitation and maintain persistence in targeted Latin American organizations, particularly in the Mexican federal government and Brazilian financial sectors.

### Gaps Identified
- Lack of telemetry mapping for DNS resolution to duckdns.org subdomains with operational naming patterns (e.g., m-doxa-geo.duckdns.org) limits detection of AI-driven C2 infrastructure pivoting.
- Absence of process-level correlation between AI-assisted script execution (e.g., exploit_creative.py) and outbound network activity to known C2 IPs (e.g., 178.128.87.160) prevents detection of AI-augmented data exfiltration workflows.

### Key Findings
- Hypothesis: Adversaries use AI-generated Python scripts and dynamic DNS-based C2 infrastructure to automate exploitation and maintain persistence in targeted Latin American organizations, particularly in the Mexican federal government and Brazilian financial sectors.
- Gap: Lack of telemetry mapping for DNS resolution to duckdns.org subdomains with operational naming patterns (e.g., m-doxa-geo.duckdns.org) limits detection of AI-driven C2 infrastructure pivoting.
- Gap: Absence of process-level correlation between AI-assisted script execution (e.g., exploit_creative.py) and outbound network activity to known C2 IPs (e.g., 178.128.87.160) prevents detection of AI-augmented data exfiltration workflows.
- Focus: Implement network and endpoint correlation to detect execution of AI-generated scripts (e.g., exploit_*.py) followed by connections to known C2 IPs or dynamic DNS domains with structured naming patterns.
- Focus: Develop YARA or Sigma rules targeting the specific file paths (e.g., socktz_v9.exe) and process names (NextChat, SockTz) associated with SockTz proxy delivery and AI-enhanced C2 operations.
- Focus: Monitor for the presence of open-source AI tools like NextChat running on TCP port 3000 at known malicious IPs, especially in environments with restricted outbound access to non-standard ports.
