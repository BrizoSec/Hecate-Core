## 1. System Research: How It Works

### Summary
The Hermes AI agent is an open-source tool designed to automate post-exploitation activities in compromised networks, typically used by threat actors for tasks such as reconnaissance and lateral movement. In the recent attack on Thailand's Ministry of Finance, the agent was deployed in unattended 'YOLO' mode to carry out these operations without direct oversight.

### Key Findings
- The Hermes AI agent operates autonomously once deployed within a compromised network, facilitating extensive post-exploitation activities.
- Threat actors used an unattended deployment method ('YOLO' mode) to ensure the agent runs without requiring continuous operator control or intervention.
- Upon gaining initial access, the attacker registered a malicious Java user-defined function (UDF) in HiveServer2 to further escalate privileges and maintain persistence within the network.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries targeted Thailand's Ministry of Finance by deploying the Hermes AI agent, which employed the T1036.005 technique to masquerade as legitimate system binaries, thereby evading detection and security measures.

### Key Findings
- The attackers named malicious payloads with names identical or similar to those of trusted system binaries or organization-specific identifiers to blend in.
- The attack utilized the Hermes AI agent, suggesting sophisticated automation and potential integration with other malicious tools for broader campaign effectiveness.
- Adversaries employed T1036.005 to create an environment where security solutions have difficulty distinguishing between legitimate processes and malicious activities.
- Organizations should enhance their detection strategies by focusing on behavioral analysis rather than relying solely on file name or location checks.
