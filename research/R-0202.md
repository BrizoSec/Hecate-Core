## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries exploit the pass-the-hash (PtH) technique to gain unauthorized access and maintain persistence within a network by using stolen hash values of user accounts, thereby bypassing traditional password-based authentication methods. This method allows attackers to escalate privileges and move laterally across the network without needing actual passwords.

### Key Findings
- The attack leverages pass-the-hash (PtH) techniques to authenticate as high-privileged users without requiring plaintext passwords.
- Attackers may have exploited vulnerabilities similar to ProxyShell, indicating a focus on unpatched or misconfigured systems for initial foothold.
- Indicators of Compromise (IOCs) include unusual network traffic patterns and unexpected authentication events using hash values instead of credentials.
- The use of friction-inducing security measures such as out-of-band Multi-Factor Authentication challenges can mitigate PtH attacks by introducing operational hurdles.
