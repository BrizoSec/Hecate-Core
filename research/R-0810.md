## 1. System Research: How It Works

### Summary
The system involves a recreation management platform where legitimate member file upload functions are abused to deploy malicious webshells, bypassing initial exploitation failures. The compromised servers serve as infrastructure for credential harvesting and payment card theft via trojanized components and external communication channels.

### Key Findings
- Webshells are deployed by registering legitimate accounts and abusing the member file upload function after initial direct exploitation attempts fail, indicating a shift to identity-based access.
- The attacker establishes persistent credential harvesting capabilities by injecting a trojanized jQuery file into authentication pages when servers return to production prematurely.
- Data exfiltration and command-and-control operations utilize WebRTC and WebSocket channels routed through Cloudflare Workers infrastructure rather than traditional direct connections.
- Defense evasion is achieved through timestomping (modifying file timestamps) and file masquerading techniques to blend malicious artifacts with legitimate system files.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
A determined threat actor exploited a file upload vulnerability (CVE-2025-26399) in recreation management platforms to deploy webshells, initially attempting brute force before resorting to legitimate account abuse. The adversary demonstrated high adaptability by modifying tactics across compromised servers, utilizing timestomping, AI-generated scripts, and trojanized frontend libraries to establish persistent access via WebRTC and WebSocket channels for credential harvesting.

### Key Findings
- The attacker leveraged CVE-2025-26399 to exploit file upload vulnerabilities in municipal recreation management software, successfully compromising three web servers after initial brute-force attempts failed.
- Defense evasion techniques included timestomping and file masquerading, alongside the use of suspected AI-generated scripts to obfuscate malicious code and avoid detection.
- The adversary established sophisticated persistence mechanisms by injecting a trojanized jQuery file into authentication pages when one server was prematurely returned to production, enabling credential harvesting via WebRTC and WebSocket channels supported by Cloudflare Workers.
- Targeted objectives included database credential extraction and payment card data theft, specifically harvested from Fortis webhook logs on the compromised infrastructure.
- Indicators of compromise include six specific SHA-256 file hashes and user-agent strings indicating a Chinese origin, though external threat intelligence feeds (VirusTotal, Abuse.ch) currently show no detections for these specific artifacts.

Threat actors are exploiting CVE-2025-26399 in recreation management platforms to deploy webshells via legitimate user file uploads, utilizing timestomping and masquerading for defense evasion. The adversary establishes persistent credential harvesting infrastructure by injecting trojanized jQuery libraries into authentication flows, leveraging WebRTC and WebSocket channels routed through Cloudflare Workers for data exfiltration.

### Recommended Hypothesis
> Adversaries abuse member file upload functions following CVE-2025-26399 exploitation to deploy webshells and inject trojanized frontend libraries, establishing persistent credential harvesting via WebRTC/WebSocket channels proxied through Cloudflare Workers on municipal recreation management platforms.
