## 1. System Research: How It Works

### Summary
The Claude Desktop malvertising campaign exploited legitimate search results to redirect users to a spoofed website hosting SectopRAT malware, masquerading as an official download of the Claude application. This campaign targeted AI developers and organizations, leveraging deceptive advertising practices.

### Key Findings
- Attackers used Bing ads to direct victims to a fake Claude Desktop download page hosted on a subdomain of claude.ai.
- The malicious artifact created a mutex with a Windows Update SID mimicry to ensure single-instance execution and included a WMI-based hardware fingerprinting technique similar to ACRStealer.
- SectopRAT malware was distributed via an MSI installer that mimicked legitimate Anthropic installation paths, misleading victims into believing they were downloading official software.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries in the FakeAgent campaign leverage T1005, Data from Local System, to search local system sources such as file systems and configuration files for sensitive data before exfiltrating it. This technique is often executed through a Command and Scripting Interpreter like cmd.exe.

### Key Findings
- Adversaries use cmd.exe to execute commands that gather information from the local system's file system, which includes identifying sensitive data such as credentials or configuration files.
- The FakeAgent campaign targets multiple organizations by deploying malicious advertisements on desktops (malvertising) and then using T1005 to extract sensitive data once access is gained.
- Indicators of this activity include unusual network connections made from systems that are typically isolated, indicating potential exfiltration attempts after local data gathering.
- Tools such as PowerShell might also be used alongside cmd.exe for more sophisticated data retrieval and preparation for exfiltration.

The Claude Desktop malvertising campaign exploited legitimate search results to redirect users to a spoofed website hosting SectopRAT malware, masquerading as an official download of the Claude application. Adversaries leveraged T1005 (Data from Local System) using cmd.exe and PowerShell to gather sensitive data for exfiltration.
