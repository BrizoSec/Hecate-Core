## 2. Adversary Tradecraft: Attack Techniques

### Summary
The SANDWORM_MODE attack leverages self-replicating worms to compromise npm software supply chains, employing AI-generated reconnaissance and credential harvesting techniques for automated dissemination. This threat targets the OpenClaw skill marketplace and wider AI toolchain ecosystems.

### Key Findings
- Adversaries use AI-generated content for reconnaissance in the SANDWORM_MODE attack, enabling more sophisticated and adaptive tactics.
- Credential harvesting is a key component of this supply chain attack, facilitating automated worm propagation within npm ecosystems.
- The 'Shai-Hulud' worm exploits vulnerabilities in OpenClaw's skill marketplace to spread malicious packages across the npm ecosystem.
- Indicators of compromise include unusual package downloads or updates from suspicious sources within the npm registry.
- Automated tools and scripts are used by attackers to monitor and manipulate software supply chains, enhancing their ability to evade detection.

## 5. Research Synthesis

### Executive Summary
The research highlights a new class of supply chain attacks leveraging AI-generated reconnaissance and credential harvesting to propagate self-replicating malware through npm registries, specifically targeting the OpenClaw skill marketplace. Effective detection requires monitoring API calls for secret enumeration and using tools like Trivy for dependency scanning alongside comprehensive network and endpoint telemetry.

### Recommended Hypothesis
> Adversaries use AI-generated reconnaissance and credential harvesting to propagate self-replicating malware through npm registries, targeting the OpenClaw skill marketplace to gain persistent access and control over supply chains.

### Gaps Identified
- There is a lack of visibility into API calls related to secret management services like GCP Secret Manager and Azure Key Vault for suspicious activities, which are crucial in identifying initial compromise vectors.
- Current detection mechanisms may not adequately account for the adaptive nature of AI-driven reconnaissance techniques, making it challenging to identify and respond to evolving threats.

### Key Findings
- Hypothesis: Adversaries use AI-generated reconnaissance and credential harvesting to propagate self-replicating malware through npm registries, targeting the OpenClaw skill marketplace to gain persistent access and control over supply chains.
- Gap: There is a lack of visibility into API calls related to secret management services like GCP Secret Manager and Azure Key Vault for suspicious activities, which are crucial in identifying initial compromise vectors.
- Gap: Current detection mechanisms may not adequately account for the adaptive nature of AI-driven reconnaissance techniques, making it challenging to identify and respond to evolving threats.
- Focus: Enhance monitoring of API calls related to secret management services and file system changes on endpoints to detect potential credential harvesting activities early in an attack lifecycle.
- Focus: Develop anomaly detection mechanisms that can differentiate between normal AI toolchain usage and suspicious behaviors indicative of supply chain compromise.
