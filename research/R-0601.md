## 1. System Research: How It Works

### Summary
Malicious Packagist themes exploit unpatched iPhones by injecting JavaScript to steal cryptocurrency wallet seeds and mnemonics from wallets such as Bitget, Phantom, and Trust Wallet. The spyware searches the iPhone's keychain for sensitive information used to recover or access crypto funds.

### Key Findings
- The malicious themes are distributed through Packagist and target iOS devices with unpatched vulnerabilities.
- The spyware targets specific cryptocurrency wallets like Bitget, Phantom, and Trust Wallet by searching the iPhone's keychain for seed phrases and mnemonics.
- These packages inject JavaScript to execute a sophisticated exploit chain that steals sensitive data from affected iPhones.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries are exploiting vulnerabilities in older versions of iOS through malicious Packagist themes, deploying sophisticated spyware that steals crypto wallet seeds and other sensitive information from iPhones. This attack leverages a WebKit-to-kernel exploit chain to install the malware, which is capable of harvesting data from multiple crypto wallets.

### Key Findings
- The attackers use a PHP package repository like Packagist to distribute malicious themes that target unpatched iOS versions with an exploit chain, leading to the installation of spyware on iPhones.
- Once deployed, the spyware specifically targets and steals seed phrases and mnemonics from various crypto wallets including Bitget, Trust Wallet, Phantom, and others by accessing data stored in the keychain.
- The stolen information is encrypted using AES before being exfiltrated to command-and-control servers via HTTPS POST requests to maintain operational security.
- Malicious themes also inject JavaScript that redirects users to gambling sites or phishing pages requesting seed phrases and mnemonics directly, adding another layer of attack vector.
