## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries with privileged network access can perform an adversary-in-the-middle (AiTM) attack to intercept and modify real-time network traffic. This technique involves methods such as ARP poisoning or DHCP spoofing, which redirect traffic to systems controlled by the attacker, enabling them to conduct activities like sniffing data or injecting malicious content.

### Key Findings
- Adversaries use AiTM attacks to manipulate network traffic in real time for various purposes including data exfiltration and communication interception.
- Common sub-techniques include ARP poisoning and DHCP spoofing, which are used to redirect victim traffic through attacker-controlled systems.
- Network intrusion detection systems (NIDS) can detect anomalies indicative of an AiTM attack by monitoring unusual patterns in network traffic.
- Organizations should implement robust network segmentation and strong authentication mechanisms for critical services to mitigate the risk of AiTM attacks.
