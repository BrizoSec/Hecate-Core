## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries are leveraging AI capabilities to move faster than traditional security operations can detect or respond, often remaining undetected until significant damage occurs. This necessitates the transition to agentic AI-driven Security Operations Centers (SOCS) capable of real-time threat detection and response.

### Key Findings
- The increasing sophistication of adversaries is driving the need for autonomous SOCs that can operate at machine speed to detect threats in real time.
- Traditional SOC models often fail to provide immediate responses, allowing stealthy attacks like ransomware deployment to go unnoticed until severe damage is done.
- Partnerships between security vendors such as CrowdStrike and IBM are expanding to support the transformation towards agentic SOCs that can better manage AI-enabled threats.
- Agentic SOCs aim to establish a new standard for autonomous defense, requiring organizations to adopt scalable and coordinated threat detection mechanisms.

## 3. Telemetry Mapping: OCSF Fields

### Summary
Telemetry to detect unauthorized privilege escalation should capture process creation events involving administrative tools or scripts. Network communication patterns indicating lateral movement post-escalation are also crucial.

### Key Fields
- process.name (90% populated): Indicates the name of a process that was launched, which could be an indicator of administrative tool usage such as 'netsh', 'mimikatz', or PowerShell scripts with elevated privileges.
- network.protocol (85% populated): Describes the network protocol used in communication after gaining elevated access. Commonly, protocols like SMB/CIFS might show abnormal use patterns post-escalation.
- process.parent.name (70% populated): The name of the parent process that spawned a potentially malicious child process, useful for understanding how an attacker reached elevated privileges.
- network.destination.port (85% populated): Identifies destination ports used in network communications which might indicate lateral movement or data exfiltration using common service ports like 445/SMB.
- process.command_line (60% populated): Provides the full command line of a process that was executed, which can be crucial for detecting administrative actions taken via scripts or tools.
- network.destination.ip_address (75% populated): Lists IP addresses involved in network communication post-escalation, often showing lateral movement to other hosts within an environment.
