## 3. Telemetry Mapping: OCSF Fields

### Summary
Telemetry for detecting NadMesh botnet activities would focus on identifying anomalous network communications, unusual process behaviors indicative of malicious software execution, and deviations from baseline system activity that may suggest command-and-control (C2) server interactions or data exfiltration attempts.

### Key Fields
- network.http.request.method: Identifies HTTP request methods used by potential C2 servers. This field is typically populated in environments where network traffic analysis is enabled, with an estimated population rate of around 80%.
- process.executable.path: Captures the path of executables launched on endpoints which could indicate malicious binary execution or lateral movement activities. Populated at a rate of approximately 95% in most SIEM configurations focusing on endpoint telemetry.
- network.tcp.destination.ip_address: Tracks IP addresses connected to from within the network, useful for identifying C2 server connections. This field is populated based on outbound traffic monitoring and can have varying population rates but averages around 70-80% depending on network segmentation policies.
- process.create.parent_process_name: Monitors parent processes responsible for launching suspicious executables or scripts which may be indicative of malware activities. Populated when process creation events are captured, typically at a rate above 90% in comprehensive monitoring setups.
