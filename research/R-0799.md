## 2. Adversary Tradecraft: Attack Techniques

### Summary
A malicious actor exploited a Citrix NetScaler Gateway zero-day vulnerability three days prior to public disclosure to attempt root access and establish persistence. The attack chain involved setting setuid/setgid bits on /bin/sh and installing a password-protected PHP webshell disguised as a CSS file using server aliases.

### Key Findings
- The adversary exploited pre-disclosure zero-day vulnerabilities, specifically CVE-2025-5777 and CVE-2026-88771, against Citrix NetScaler Gateway on September 24, 2026.
- Detection was achieved through behavioral analysis rather than CVE-specific signatures, identifying the attacker's IP address 149.104.78.141 (ASN: 154177, LIGHT NODE LIMITED) which had prior malicious history on VirusTotal.
- The post-exploitation playbook aimed to escalate privileges by attempting to set both Set User ID (setuid) and Set Group ID (setgid) bits on /bin/sh to obtain a root shell.
- Persistence mechanisms included a password-protected webshell located at /var/netscaler/logon/LogonPoint/custom/.ctxs.receiver, controlled via a specific cookie value.
- The attacker utilized web server configuration manipulation to evade detection by creating an Alias for receiver.min.css and an AliasMatch pattern (receiver\.min\.[0-9a-f]+\.css) to route requests to the hidden webshell.

## 5. Research Synthesis

### Executive Summary
Adversaries are executing pre-disclosure zero-day exploitation against Citrix NetScaler Gateway (CVE-2025-5777, CVE-2026-88771) to establish persistence via a password-protected PHP webshell disguised as 'receiver.min.css' and attempting privilege escalation through setuid/setgid manipulation on /bin/sh. Detection relies on behavioral anomalies in file system modifications and web server configuration injection rather than static signatures, requiring monitoring for specific alias routing rules and suspicious cookie-based authentication patterns.

### Recommended Hypothesis
> Adversaries use Apache Alias and AliasMatch configuration injections to route CSS traffic to hidden PHP webshells and attempt setuid/setgid bit manipulation on /bin/sh to gain root persistence on Citrix NetScaler Gateway.

### Gaps Identified
- Lack of file integrity monitoring or audit logs for the /var/netscaler/logon/LogonPoint/custom/ directory prevents detection of the malicious .ctxs_receiver file creation and subsequent configuration file modifications (httpd.conf/nginx.conf) prior to compromise.
- Standard network security controls often fail to detect this threat because the webshell is disguised as a legitimate CSS resource, bypassing content inspection that expects standard CSS syntax, while cookie-based authentication evades standard HTTP request logging if not explicitly parsed for anomalous custom headers.

### Key Findings
- Hypothesis: Adversaries use Apache Alias and AliasMatch configuration injections to route CSS traffic to hidden PHP webshells and attempt setuid/setgid bit manipulation on /bin/sh to gain root persistence on Citrix NetScaler Gateway.
