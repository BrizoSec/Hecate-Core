## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries are increasingly utilizing AI to optimize their techniques, including the use of T1005 'Data from Local System' to gather sensitive data and files from compromised hosts. This technique is employed by threat actors such as Latrodectus and Lazarus Group for lateral movement and exfiltration.

### Key Findings
- AI technology is being used to accelerate techniques like T1005, enabling faster data collection and exfiltration.
- Stealer modules within malware, such as those used by the Latrodectus threat group, are actively collecting data from compromised systems.
- The Lazarus Group has been observed using T1005 to gather files and data from various networked environments.
- Adversaries are now moving laterally through networks in under 30 minutes on average, a significant decrease compared to previous years.
- Command and Scripting Interpreters like cmd.exe are commonly used alongside other tools to execute T1005.

## 3. Telemetry Mapping: OCSF Fields

### Summary
To detect T1005 - Data from Local System, telemetry should capture actions where adversaries access local system sources like file systems, configuration files, or process memory to search for sensitive data. This involves monitoring command and script executions that interact with the filesystem and registry.

### Key Fields
- file.read (unknown): Represents attempts by processes to read from disk files which could include scripts or commands used by adversaries to gather information about the local system.
- process.create (unknown): Tracks the creation of new processes, particularly those associated with command interpreters like cmd.exe that might be used to run scripts for data collection.
- registry.query (unknown): Monitors registry access queries which can indicate an adversary searching through the system configuration for sensitive information or credentials.
- file.write (unknown): Detects writes to files which could signify changes made by malicious actors to hide their tracks or modify local configurations.
- network.connect: While not directly related to T1005, network connections should be monitored in case data exfiltration occurs as a subsequent step after data collection.

## 5. Research Synthesis

### Executive Summary
Adversaries are leveraging AI to enhance their data gathering techniques, such as T1005 (Data from Local System), which involves collecting sensitive information and files from compromised hosts. This activity is often facilitated by malware like the ACR Stealer used in recent intrusions, where telemetry indicates attempts at file reading, process creation, registry querying, and file writing to gather data efficiently.

### Recommended Hypothesis
> Adversaries use AI-enhanced T1005 techniques to accelerate exfiltration of sensitive data on compromised hosts.

### Gaps Identified
- The current coverage lacks real-time detection capabilities for AI-driven lateral movement within the network, especially in under 30 minutes.
- There is insufficient knowledge about how adversaries are modifying traditional malware behaviors (e.g., file writing) with AI to evade modern security measures.

### Key Findings
- Hypothesis: Adversaries use AI-enhanced T1005 techniques to accelerate exfiltration of sensitive data on compromised hosts.
- Gap: The current coverage lacks real-time detection capabilities for AI-driven lateral movement within the network, especially in under 30 minutes.
- Gap: There is insufficient knowledge about how adversaries are modifying traditional malware behaviors (e.g., file writing) with AI to evade modern security measures.
- Focus: Enhance monitoring and alerting for command and scripting interpreter activities that interact with local system sources to detect potential data exfiltration attempts early.
- Focus: Investigate the integration of machine learning models in threat intelligence platforms like MISP to better predict and prevent AI-assisted T1005 attacks.
