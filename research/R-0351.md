## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries may attempt to exploit vulnerabilities before they are prioritized for patching under the CrowdStrike Falcon Platform's dynamic risk-based approach. They could also try to bypass or evade detection by leveraging sophisticated techniques that are not yet covered in the platform’s threat intelligence.

### Key Findings
- Adversaries prioritize vulnerabilities with high business impact and exploit them before they receive critical security updates, challenging the risk-based patching strategy.
- Sophisticated attackers use evasion tactics to circumvent detection by Next-Gen SIEM systems like Falcon, such as deploying custom malware or using living-off-the-land (LotL) binaries that mimic legitimate processes.
- CrowdStrike's dynamic threat intelligence and IOAs (Indicator of Attack) may lead adversaries to shift their focus towards new vectors not yet covered in the platform’s database, seeking out zero-day exploits or lesser-known vulnerabilities.
- Attackers might attempt to disrupt or manipulate patch management systems, delaying timely application of critical security updates that could mitigate known risks identified by CISA BOD-26-04.

This includes event IDs from Windows Security Event Logs that indicate account logon/logoff activities, process creation, and registry changes.

### Key Fields
- process_events (95% populated): Tracks all process creations on endpoints, which is crucial for detecting abnormal or malicious activity such as unauthorized software installation or lateral movement techniques.

- user_activity (75% populated): Logs user actions that affect system state, including logon/logoff events, which are critical for understanding the context of other activities and identifying compromised accounts.
- registry_changes (60% populated): Tracks modifications to the Windows Registry, important for detecting changes made by malware or administrators attempting to modify security settings.
- file_events (85% populated): Documents file operations such as creation, modification, deletion, and renaming, which can indicate exfiltration attempts or installation of malicious software.

The platform's telemetry captures critical process activity, network communications, user behavior, and registry changes essential for detecting malicious activities.
