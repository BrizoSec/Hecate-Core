## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries employ the pass-the-hash attack technique to leverage stolen hashed credentials, enabling them to create new sessions on compromised systems without requiring the original password. This method allows attackers to maintain persistence and escalate privileges within a network.

### Key Findings
- Pass-the-Hash (PtH) attacks enable adversaries to authenticate using NTLM or Kerberos hashes instead of passwords.
- Attackers can use stolen credentials from one machine to gain unauthorized access to other systems within the same domain.
- The technique is commonly used in conjunction with lateral movement and credential dumping activities.
- Indicators include anomalous authentication attempts, failed logon events, and unusual network connections between compromised hosts.
