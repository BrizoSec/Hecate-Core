## 2. Adversary Tradecraft: Attack Techniques

### Summary
Process Injection (T1055) is a technique where adversaries execute arbitrary code within the address space of a separate, legitimate live process to evade process-based defenses and potentially elevate privileges. This method allows attackers to access the target process's memory, system resources, and network capabilities while masking the origin of the malicious execution.

### Key Findings
- Adversaries utilize process injection to separate the identity of the executing process from the origin of the code, making detection difficult unless memory contents and thread origins are specifically inspected.
- The primary objectives of this abuse are to evade process-based security defenses and to gain access to elevated privileges or sensitive system/network resources available to the host process.
- Common technical implementations of this technique include DLL injection, process hollowing, thread hijacking, and shellcode injection via CreateRemoteThread.
- The technique allows malware to run under the guise of a trusted process, thereby masking its presence from standard visibility tools that rely on process names or origins.
