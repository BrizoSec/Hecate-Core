## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries abuse the modular cyber espionage framework by employing techniques such as adversary-in-the-middle (AiTM) to intercept network traffic, allowing them to capture credentials and session data. They exploit public-facing applications to gain initial access and use automated collection methods to gather valuable information from compromised systems.

### Key Findings
- Adversaries leverage tools like evilginx2 and PHProxy for AiTM attacks to steal user credentials and session tokens.
- Exploitation of Apache/Nginx or other web servers through suspicious requests in access logs can indicate initial compromise attempts.
- Automated collection techniques are used by threat groups to compile archives of specific file types from victim directories.
- Native APIs on Windows systems, such as `GetComputerNameA` and `GetComputerNameExA`, are exploited for information gathering purposes.

## 3. Telemetry Mapping: OCSF Fields

### Summary
To detect behaviors associated with a modular cyber espionage framework, focus on telemetry that captures process creation events, network connections, and lateral movement indicators. This includes monitoring for anomalous binary behavior, unusual command-line arguments, and suspicious inter-process communications.

### Key Fields
- event_id (10% populated): Event IDs like 4688 in Windows Security logs indicate the creation of a process. Monitoring these can help detect when new modules are loaded or executed.
- process_creation (5% populated): Logs capturing details such as command-line arguments and parent-child relationships can reveal suspicious binary behaviors indicative of modular frameworks loading components.
- network_connection (20% populated): Tracking outbound connections, especially to known bad IPs or domains, helps in identifying data exfiltration attempts from compromised systems.
- file_change (5% populated): Monitoring for changes to files commonly used by espionage tools can alert on the presence of malicious binaries and scripts.
- user_account_activity (10% populated): Observing user account creation/modification events and unusual login patterns across different systems indicate potential lateral movement activities.
