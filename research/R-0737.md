## 1. System Research: How It Works

### Summary
HEAVYGRAM is a Windows-based surveillance backdoor attributed to the Iran-linked threat actor Handala Hack, which utilizes Telegram bots and groups for command-and-control operations and data exfiltration. Deployed since Fall 2023 via social-engineered files masquerading as legitimate applications, it enables remote command execution, screen capture, and persistence on targeted systems.

### Key Findings
- The malware employs a Telegram-based C2 protocol using specific message prefixes for distinct operations: '@@' executes arbitrary system commands via os.popen, double-backticks write data to 'C:\ProgramData\ur.txt', and other prefixes facilitate file transfers and exfiltration.
- It captures sensitive telemetry including screen shots, microphone input, running programs, web browser data, saved passwords, and specific data from Telegram Desktop and WhatsApp directories.
- The implant achieves persistence through registry modifications and DLL side-loading, supported by 29 identified samples linked to Vultr Object Storage infrastructure and Persian-language decoys.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
The Iran-linked threat actor Handala Hack, assessed as a front for the Ministry of Intelligence and Security (MOIS), deploys HEAVYGRAM, a multi-stage Windows surveillance backdoor targeting dissidents, journalists, and opposition figures. This malware utilizes social-engineered files masquerading as legitimate applications to establish persistence and executes commands via Telegram bot APIs for remote control, data exfiltration, and system reconnaissance.

### Key Findings
- HEAVYGRAM is a Windows-based surveillance backdoor deployed since Fall 2023, attributed to the Iran-linked group Handala Hack, which is assessed to be affiliated with Iran's Ministry of Intelligence and Security (MOIS).
- The malware abuses the Telegram bot API for command-and-control operations, enabling remote command execution, screen capture, and data exfiltration while blending in with legitimate messaging traffic.
- Initial access is achieved through social engineering, where victims receive malicious files disguised as legitimate applications such as Telegram, KeePass, or Pictory.
- The implant employs advanced evasion and persistence techniques including DLL side-loading, registry modification for startup persistence, and system reconnaissance capabilities.
- Infrastructure analysis identified 29 samples utilizing networks of Telegram bots and groups, supported by Vultr Object Storage and Persian-language decoys to target specific profiles like academics and media personnel.
