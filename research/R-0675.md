## 1. System Research: How It Works

### Summary
LegionLoader is distributed via ClickFix tactics using fake Cloudflare CAPTCHA pages to trick users into executing malicious PowerShell commands that download and execute the malware. The malware dynamically decrypts internal shellcode and PE files, evaluates the infection environment through display device checks and ASN verification, and executes a backdoor capable of running various payloads.

### Key Findings
- LegionLoader uses fake Cloudflare CAPTCHA pages to disguise ClickFix attacks, tricking users into executing PowerShell commands that download compressed files containing the malware.
- The malware dynamically identifies Crypto API and Thread Pool APIs to decrypt internally stored encrypted shellcode and PE files before execution.
- Infection environment evaluation includes checking for virtualized or remote conditions by comparing EnumDisplayDevicesA results against blacklisted display device names and performing ASN verification.
- Once executed, the backdoor can run various payloads including PE files, shellcode, PowerShell scripts, and MSI files, and steals Chrome browser credentials and profile information based on C2 server commands.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries are distributing LegionLoader malware using the ClickFix technique, which tricks users into executing malicious PowerShell commands via fake Cloudflare CAPTCHA pages. This method is primarily propagated through spear-phishing emails and compromised wiki pages, leading to the download and execution of LegionLoader.

### Key Findings
- The primary distribution vector involves fake Cloudflare CAPTCHA or Turnstile screens that coerce users into copying and pasting malicious PowerShell commands.
- Two main initial access methods have been identified: spear-phishing emails disguised as internal business system account issuance instructions, and malicious URLs on Korea's Namu Wiki page.
- LegionLoader decrypts encrypted shellcode and PE files, performs environment checks (display device and ASN), and executes backdoor payloads such as PowerShell scripts or MSI files.
- The malware includes credential theft capabilities, specifically targeting Chrome browser credentials and profile information based on C2 server commands.
- Intermediary infrastructure utilizes domains with TLDs like .Monster and .Cfd for redirects, alongside specific indicators of compromise including domains dallasbackstage.com and gemscocl.com.

## 3. Telemetry Mapping: OCSF Fields

### Summary
The LegionLoader distribution via ClickFix involves a user-initiated execution of a PowerShell script triggered by a fake CAPTCHA page. This results in the creation of a PowerShell process with specific command-line arguments, followed by network connections to C2 domains (dallasbackstage.com, gemscocl.com) and potentially DNS queries for these domains. The malware also drops encrypted shellcode/PE files to disk.

### Key Fields

OCSF path → the event field `knowledge/environment.md` documents for it.

- `process.cmd_line` → `command_line` (Endpoint) (written as `process_activity.process.cmd_line`): Captures the PowerShell command line used to download and execute the malicious payload, often containing encoded commands or URLs pointing to dallasbackstage.com/gemscocl.com.
- `dst_endpoint.hostname` → unmapped: the environment profile documents no field (written as `network_activity.dst_endpoint.hostname`): Identifies connections to known C2 domains (dallasbackstage.com, gemscocl.com) during the initial download or subsequent beaconing phases.
- `process.parent_process.name` → `parent_process` (Endpoint) (written as `process_activity.parent_process.name`): Identifies the parent process (e.g., svchost.exe, rundll32.exe, or cmd.exe) invoking PowerShell, which is often obfuscated or unusual in ClickFix attacks.
- `file.path` → unmapped: the environment profile documents no field (written as `file_activity.file.path`): Logs the creation of dropped files such as encrypted shellcode or PE loaders in temporary directories (e.g., %TEMP%) by the PowerShell process.
- `process.name` → `process_name` (Endpoint) (written as `process_activity.process.name`): Confirms the execution of 'powershell.exe' or 'pwsh.exe', which is the primary tooling for the ClickFix delivery mechanism.

## 5. Research Synthesis

### Executive Summary
LegionLoader is actively distributed via ClickFix campaigns utilizing fake Cloudflare CAPTCHA pages to coerce users into executing obfuscated PowerShell commands that download and decrypt a modular backdoor. The malware dynamically evaluates the infection environment through specific API hooking (EnumDisplayDevicesA) and ASN verification before executing payload binaries or stealing Chrome credentials via C2 channels.

### Recommended Hypothesis
> Adversaries use fake Cloudflare CAPTCHA pages to trick users into pasting malicious PowerShell commands to deploy LegionLoader backdoors for credential theft and further payload delivery

### Gaps Identified
- Lack of telemetry on specific API hooking sequences (EnumDisplayDevicesA, ASN resolution) used by LegionLoader for environment validation allows evasion of standard behavioral detection rules
- Inability to inspect encrypted shellcode payloads stored within the malware's memory or disk artifacts prevents identification of the final malicious actions until execution occurs

### Key Findings
- Hypothesis: Adversaries use fake Cloudflare CAPTCHA pages to trick users into pasting malicious PowerShell commands to deploy LegionLoader backdoors for credential theft and further payload delivery
- Gap: Lack of telemetry on specific API hooking sequences (EnumDisplayDevicesA, ASN resolution) used by LegionLoader for environment validation allows evasion of standard behavioral detection rules
- Gap: Inability to inspect encrypted shellcode payloads stored within the malware's memory or disk artifacts prevents identification of the final malicious actions until execution occurs
- Focus: Hunt for PowerShell processes spawned from unusual parents (e.g., svchost.exe, rundll32.exe) containing encoded command lines referencing dallasbackstage.com or gemscocl.com
- Focus: Monitor for network connections to identified C2 domains and DNS queries for these names, coupled with file creation events in %TEMP% directories containing encrypted binaries
