## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries continue to leverage sophisticated malware distribution tactics by embedding malicious payloads within legitimate software updates or using phishing campaigns that exploit social engineering. They increasingly use domain fronting and encrypted channels to evade detection and maintain persistent access.

### Key Findings
- Leveraging popular software update mechanisms, adversaries are distributing malware via compromised update servers or rogue update packages.
- Phishing emails remain a prevalent method for initial compromise, often featuring convincing social engineering techniques that target high-value employees within organizations.
- Adversaries are using domain fronting to disguise their command and control (C2) traffic as legitimate web requests over HTTPS, complicating detection efforts by network monitoring tools.
- Encrypted channels such as TLS/SSL are exploited for exfiltration of stolen data or lateral movement within a compromised network.
- Persistence mechanisms include the use of scheduled tasks and registry keys to ensure continued execution of malware despite system reboots.
