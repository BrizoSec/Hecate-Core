## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries are leveraging direct IP communications to evade traditional detection methods by avoiding the use of commonly monitored or blacklisted infrastructure such as C2 domains and email servers. This technique allows malware to maintain stealthy communication channels, making it harder for security systems to identify and block malicious activities.

### Key Findings
- Malware samples are increasingly employing direct IP communications to establish command-and-control (C2) links with unknown adversaries.
- The use of static IP addresses for C2 communications helps in maintaining long-term persistence while avoiding domain generation algorithms (DGAs).
- Indicators of Compromise (IOCs) include specific IP addresses, port numbers, and communication patterns that can be monitored to detect such activities.
- Direct IP communication bypasses DNS-based detection methods, making it a favored technique for sophisticated threat actors.

## 3. Telemetry Mapping: OCSF Fields

### Summary
The telemetry for capturing malware communication directly to IPs involves monitoring network traffic logs such as DNS queries, HTTP/HTTPS requests, and direct TCP/IP connections. Process creation events are also critical in identifying potential malicious activities.

### Key Fields
- network.process_connections (50%): Tracks process IDs making outgoing connections along with their destination IP addresses.
- network.http_requests (30%): Captures HTTP/HTTPS requests made by processes, including the URL, method, and headers, which can be indicative of command-and-control communications.
- network.dns_queries (45%): Logs DNS queries initiated from within the network, potentially revealing malicious domain names or IP addresses.
- process.start_create (80%): Monitors process creation events to identify suspicious binaries that may attempt to communicate with external IPs.
