## 1. System Research: How It Works

### Summary
The article describes the Microsoft Post-Quantum Cryptography (PQC) TLS Pilot Program, which enables eligible Certificate Authorities to issue quantum-resilient ML-DSA-87 certificates for interoperability testing in controlled, non-production environments. These pilot certificates are not publicly trusted and require specific Windows 11 updates to be evaluated within systems like Schannel to identify ecosystem readiness gaps before broad adoption.

### Key Findings
- The pilot utilizes the Module-Lattice-Based Digital Signature Algorithm (ML-DSA-87) as the quantum-resilient standard for issuing test certificates, which are restricted to closed environments and cannot be used for public-facing trust scenarios.
- Testing support is available on Windows 11 systems via specific updates: KB5101681 (OS Build 28000.2608) for version 26H1, and KB5101684 (OS Builds 26200.8973 and 26100.8973) for versions 25H2.
- The pilot roots are operated by seven specific Certificate Authorities: ComSign, DigiCert, HARICA, IdenTrust Services, Sectigo, Shanghai Electronic Certification Authority, and SSL.com.
- The program is designed to evaluate operational challenges such as certificate-size constraints, performance effects, and application incompatibilities within the PKI ecosystem rather than validating a predetermined cryptographic outcome.
