## 3. Telemetry Mapping: OCSF Fields

### Summary
Telemetry capturing specific event IDs within Windows Security Event Logs (e.g., 4624, 4625, 4648, 4768, 4769, 4771) and endpoint process activity is crucial for detecting lateral movement and privilege escalation attempts. This data should be ingested into the SIEM platform to identify suspicious patterns indicative of advanced threat actors.

### Key Fields
- event_id (50% populated): Specific Windows Security Event IDs such as 4624, 4768 are critical for detecting account logon/logoff activities and user or service authentication events. These can signal lateral movement tactics.
- process_name (30% populated): Endpoint telemetry regarding process names that execute at odd hours or in unexpected locations within the network can indicate suspicious activity related to privilege escalation techniques.
- destination_ip: Monitoring outbound connections from internal systems to unusual IP addresses is vital for identifying data exfiltration attempts during an attack.
- user_id (70% populated): User IDs involved in critical operations and their associated activities across different event logs are essential for tracking user behavior patterns and spotting anomalies.
