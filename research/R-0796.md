## 1. System Research: How It Works

### Summary
The attack chain initiates via a malicious Excel file exploiting CVE-2017-0199 to download an HTA file, which executes obfuscated PowerShell to retrieve a steganographic PNG containing a Base64-encoded .NET loader. This loader deploys the Remcos RAT, enabling persistent access through keylogging, screen capture, and data exfiltration to command and control infrastructure.

### Key Findings
- The initial exploit relies on CVE-2017-0199 (OLE2Link vulnerability in Microsoft Office) within an Excel file disguised as a project material purchase request form.
- The malware chain utilizes multi-stage obfuscation, including PowerShell script obfuscation and steganography where a PNG image contains the Base64-encoded .NET loader.
- Indicators of Compromise include specific malicious hashes for the initial dropper (e.g., MD5: db9ff235eae552276b12622ae9105f1c labeled as trojan.urcbadur/x97m) and the final Remcos payload (MD5: 5055c7b0ae1f6f77b16eb744a76cc453).
- Command and Control infrastructure involves HTTP requests to IP 172.245.209.133 (HostPapa) and the hostname blessedongrace.duckdns.org for HTA and PNG file downloads.
- Remcos RAT deployment enables advanced post-exploitation capabilities such as keylogging, screen capture, file manipulation, and system information exfiltration.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries are conducting a phishing campaign targeting South Korean organizations by sending emails disguised as project material purchase requests containing malicious Excel files. These files exploit CVE-2017-0199 to download and execute an HTA file, which ultimately deploys the Remcos RAT via a steganographic PNG loader for keylogging, screen capture, and data exfiltration.

### Key Findings
- The initial access vector involves malicious XLS files disguised as purchase order forms (e.g., 'PO0002938113_아부다비_가스 플랜트_주문서 - Copy.xls') that exploit the OLE2Link vulnerability CVE-2017-0199 in Microsoft Office to fetch remote HTA payloads.
- The malware delivery chain utilizes multiple obfuscation and encoding layers, including PowerShell obfuscation within the HTA file to download a Base64-encoded .NET loader hidden inside a steganographic PNG image (Img_201031.Png).
- The final payload is Remcos RAT, identified by VT labels such as 'trojan.remcos/rescoms', which provides adversaries with capabilities including keylogging, screen capture, file manipulation, and system information exfiltration.
- Infrastructure indicators include the hostname 'blessedongrace.duckdns.org' and the IP address 172.245.209.133 (owned by HostPapa), which serve as Command and Control endpoints for hosting malicious HTA and PNG files.
- Threat intelligence enrichment confirms high malignancy, with VT labels identifying the components as 'trojan.xworm/aevn', 'trojan.urcbadur/x97m', and 'trojan.remcos/rescoms', indicating a multi-stage trojanized delivery.

## 5. Research Synthesis

### Executive Summary
Adversaries deploy a multi-stage phishing campaign targeting South Korean entities using malicious Excel files that exploit CVE-2017-0199 to download an HTA payload, which subsequently executes obfuscated PowerShell to retrieve a steganographic PNG loader for the Remcos RAT. The attack chain relies on lateral encoding techniques and specific C2 infrastructure (HostPapa IP and DuckDNS hostname) to maintain persistence via keylogging and data exfiltration.

### Recommended Hypothesis
> Adversaries use CVE-2017-0199 exploitation in project purchase request Excel files to execute HTA-based PowerShell downloaders for steganographic Remcos RAT deployment on South Korean organizational endpoints.

### Gaps Identified
- Current telemetry mapping lacks robust logging of OLE object execution triggers within Office applications and does not explicitly correlate file content inspection (steganography) with network exfiltration events, leaving the initial delivery and loader extraction phases largely invisible to standard endpoint monitoring.

### Key Findings
- Hypothesis: Adversaries use CVE-2017-0199 exploitation in project purchase request Excel files to execute HTA-based PowerShell downloaders for steganographic Remcos RAT deployment on South Korean organizational endpoints.
- Gap: Current telemetry mapping lacks robust logging of OLE object execution triggers within Office applications and does not explicitly correlate file content inspection (steganography) with network exfiltration events, leaving the initial delivery and loader extraction phases largely invisible to standard endpoint monitoring.
- Focus: Investigate outbound HTTP/HTTPS traffic from non-browser processes (hta.exe, powershell.exe) connecting to dynamic DNS services or known hosting providers (e.g., HostPapa ASN 36352) for large binary payloads disguised as image files.
