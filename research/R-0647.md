## 1. System Research: How It Works

### Summary
AI-driven vulnerability discovery has created an environment where more than 99% of identified vulnerabilities remain unpatched, rendering traditional periodic patch management insufficient. To secure these unpatchable systems, security architectures must shift toward continuous remediation and runtime defense mechanisms that do not rely on vendor-provided fixes.

### Key Findings
- Traditional vulnerability disclosure is ineffective for AI/ML software because fixes often reduce performance or impose prohibitive costs, leading to a state where vulnerabilities are difficult or effectively impossible to patch.
- Compensatory controls such as network segmentation, rigorous visibility, and the deployment of NGFW/IPS combinations are required as a primary defense layer when runtime patches are unavailable.
- Vulnerability management must transition from periodic scanning to continuous remediation architecture, utilizing automated AI-assisted tools and SOAR integrations for immediate ticket routing and verification.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries exploit AI technology to identify vulnerabilities that are difficult or impossible to patch, utilizing the ability of AI-driven attacks to continuously adapt in real-time by learning from system responses. Because these threats may be effectively unpatchable, the focus shifts to securing the environment through network segmentation, rigorous visibility, and behavior-based detection.

### Key Findings
- AI-driven vulnerabilities are increasingly difficult or effectively impossible to patch, necessitating compensatory controls such as appropriate network segmentation and the deployment of Next-Generation Firewall (NGFW)/IPS combinations.
- Adversarial AI attacks differ from traditional cyberattacks by adapting in real-time; they learn from system responses and refine their approach continuously rather than relying on static methods.
- Mitigation strategies emphasize building visibility through network fingerprinting and applying micro-segmentation using VLANs and ACLs to restrict lateral movement.
- Behavior-based detection is highlighted as a highly effective, tool-agnostic method for identifying threats when traditional patching is insufficient.
- Adversaries aim to frustrate defenders by forcing them to find alternate accounts, tools, routes, or infrastructure, thereby increasing the cost and complexity of the defense.

## 5. Research Synthesis

### Executive Summary
As AI-driven vulnerability discovery renders traditional patching ineffective for over 99% of identified flaws, threat hunting must pivot from static patch verification to detecting the behavioral signatures of unpatchable exploits in real-time. Effective defense relies on enforcing strict network segmentation and leveraging NGFW/IPS combinations to intercept adaptive, runtime-exploiting adversaries before lateral movement occurs.

### Recommended Hypothesis
> Adversaries use AI-adaptive exploitation techniques to bypass static defenses and exploit unpatchable vulnerabilities for lateral movement across segmented networks.

### Gaps Identified
- Traditional periodic vulnerability scanning fails to detect active exploitation of runtime-only unpatchable flaws, lacking continuous telemetry correlation between network anomaly detection and endpoint behavior.
- Lack of granular micro-segmentation visibility allows AI-driven threats to refine payloads in real-time based on system responses, blinding static IPS signatures that do not account for adaptive behavioral shifts.

### Key Findings
- Hypothesis: Adversaries use AI-adaptive exploitation techniques to bypass static defenses and exploit unpatchable vulnerabilities for lateral movement across segmented networks.
- Gap: Traditional periodic vulnerability scanning fails to detect active exploitation of runtime-only unpatchable flaws, lacking continuous telemetry correlation between network anomaly detection and endpoint behavior.
- Gap: Lack of granular micro-segmentation visibility allows AI-driven threats to refine payloads in real-time based on system responses, blinding static IPS signatures that do not account for adaptive behavioral shifts.
- Focus: Implement continuous remediation architectures using automated SOAR integrations to correlate NGFW/IPS alerts with endpoint telemetry for immediate verification of unpatchable vulnerability exploitation attempts.
