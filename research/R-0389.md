## 1. System Research: How It Works

### Summary
Elastic InfoSec employs AI agents to triage security alerts, which initially required numerous Large Language Model (LLM) calls. Through a systematic optimization process, they reduced these LLM calls by 60%, enhancing operational efficiency and cost-effectiveness.

### Key Findings
- The initial AI alert-triage agents made up to 19 LLM calls per run before optimization.
- A five-step loop involving measurement, analysis, verification, and monitoring was crucial in reducing the number of LLM calls from 19 to a range of 7-9 per run.
- This reduction led to a significant cost savings and improved system performance.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries may exploit inefficiencies in AI-driven SOC tools by generating excessive false alerts or crafting sophisticated attacks that bypass initial triage mechanisms designed to reduce unnecessary large language model (LLM) calls. This can lead to a surge in LLM interactions, overwhelming the system and potentially revealing vulnerabilities.

### Key Findings
- Adversaries use advanced tactics to evade detection by AI-driven alert systems, focusing on attacks that mimic benign activity patterns or trigger false positives to overwhelm SOC resources.
- The optimization of LLM calls through specialized agents reduces costs but also narrows the attack surface that adversaries can exploit, as general-purpose agents are less likely to be targeted due to their reduced usage.
- Monitoring and analyzing token usage in LLM interactions can reveal anomalies indicative of adversarial activities aimed at probing system weaknesses or causing operational disruptions.
- Intrusion detection systems relying heavily on AI triage need continuous updates to signature-based detections to complement AI-driven methods, ensuring comprehensive coverage against both known and unknown threats.
