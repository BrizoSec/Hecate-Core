## 1. System Research: How It Works

### Summary
AsyncAPI is a specification that describes the APIs used for asynchronous events such as MQTT, AMQP, WebSockets, gRPC, etc. It extends the OpenAPI Specification to cater specifically to event-driven architectures and helps developers understand how services communicate asynchronously.

### Key Findings
- AsyncAPI documents are written in YAML or JSON format and describe not only API endpoints but also topics/subscriptions for message queues and event channels.
- [UNCERTAIN] The normal operation of an AsyncAPI involves secure, reliable communication between different components of a system through well-defined asynchronous protocols, which can be compromised if security measures like authentication and encryption are not properly implemented.
- Developers typically use AsyncAPI to design, document, and test the interactions within their systems that involve real-time or background processing.
