## 1. System Research: How It Works

### Summary
The Chrysalis backdoor, part of the Lotus Blossom toolkit, operates by deploying an installer that drops files into a hidden directory on a compromised Windows host. It then uses DLL side-loading to execute its code without triggering standard security measures once it gains SYSTEM privileges.

### Key Findings
- Chrysalis backdoor registers itself as a Windows service after gaining SYSTEM privileges.
- The payload replaces the original buffer and is treated as executable code upon decryption.
- Lotus Blossom constructs targeted DLL names using custom, position-dependent character obfuscation schemes.
