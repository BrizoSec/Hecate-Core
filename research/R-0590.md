## 1. System Research: How It Works

### Summary
EtherHiding is a technique where attackers leverage the Ethereum blockchain to store and update malicious scripts or codes remotely. By embedding references to these smart contracts within compromised websites, attackers can dynamically alter malware behavior without direct access to the host system.

### Key Findings
- Attackers use Ethereum transactions for data exfiltration and command updates.
- The technique allows remote control over malware by altering contract state rather than code.
- Blockchain's immutability is exploited in a way that new commands are appended as transaction data, making traditional monitoring tools ineffective.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries are leveraging the EtherHiding technique in Magecart campaigns to exfiltrate stolen credit card data through Ethereum blockchain endpoints, thereby concealing command and control communications. This method involves injecting malware into web pages during checkout processes to skim sensitive information from unsuspecting victims.

### Key Findings
- Magecart actors use EtherHiding to hide C2 traffic within the Ethereum network by leveraging blockchain transactions for data exfiltration.
- Attackers check if a victim has already been compromised through local storage variables to avoid repeated skimming and reduce detection risk.
- Injected malware is often disguised as legitimate scripts or images, such as Google Tag Manager or favicon files, making it harder to detect.
- Adversaries target widely-used websites across various industries, including food and cybersecurity sectors, expanding the attack surface.

## 5. Research Synthesis

Adversaries are utilizing the EtherHiding technique in Magecart campaigns to exfiltrate credit card data through Ethereum blockchain endpoints, hiding command and control communications within network traffic and making it difficult for traditional monitoring tools to detect.

### Recommended Hypothesis
