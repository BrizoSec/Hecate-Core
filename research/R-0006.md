## 1. System Research: How It Works

### Summary
TraderTraitor backdoors, specifically FLATROOF and ROOFDECK, target macOS systems through malicious Terraform projects, enabling reconnaissance, credential theft, and remote control via RSA-signed commands. SentinelOne identified a new victim with no cryptocurrency ties, indicating the malware may be expanding its scope beyond initial targets.

### Key Findings
- FLATROOF and ROOFDECK backdoors use RSA-2048 signatures to verify commands pulled from an HTTPS endpoint before decryption and execution, facilitating remote control and stealth.
- The malware bypasses macOS Gatekeeper via command-line execution, suggesting sophisticated evasion techniques.
- TraderTraitor attacks have expanded to include IT services firms with no direct ties to cryptocurrency, indicating a broader targeting strategy.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
TraderTraitor, a North Korean state-sponsored APT group, has targeted an IT services provider in India with the FLATROOF and ROOFDECK macOS backdoors. The attack was initiated through social engineering, involving a fake job interview where a malicious Terraform file was used to deploy the backdoor.

### Key Findings
- TraderTraitor uses social engineering techniques such as fake job interviews to deliver malware to victims' systems.
- The FLATROOF and ROOFDECK macOS backdoors are being deployed by TraderTraitor, which were previously seen in attacks on cryptocurrency-related targets.
- A malicious Terraform file was used as a delivery mechanism for the backdoor, targeting DevOps engineers who manage infrastructure with Terraform.
- The attack bypasses MacOS Gatekeeper defenses, and uses 'nohup' to execute commands outside of typical user sessions.

## 5. Research Synthesis

### Executive Summary
TraderTraitor, a North Korean state-sponsored APT group, has expanded its attack vector to target IT services firms with no direct ties to cryptocurrency. The group uses sophisticated social engineering tactics and malicious Terraform projects to deploy FLATROOF and ROOFDECK macOS backdoors, which can execute commands via RSA-signed HTTPS requests while evading macOS security measures.

### Recommended Hypothesis
> Adversaries use social engineering and malicious Terraform files to deploy backdoors that enable remote command execution on macOS systems with the goal of espionage or data exfiltration from IT services providers.

- Lack of coverage for identifying suspicious network activity related to API interactions without encryption, which is a key indicator of FLATROOF and ROOFDECK activities.
- Insufficient knowledge about the full extent of the command-and-control infrastructure used by TraderTraitor, including domain names or IP addresses involved in backdoor communication.
