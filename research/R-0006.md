## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries often exploit the limited timeframe within which a SOC must respond to an alert by employing advanced evasion techniques. This includes using polymorphic malware, living off the land (LOTL), and lateral movement tactics to stay under the radar before or during the critical 72-minute window.

### Key Findings
- Adversaries frequently use time-based triggers in their attack scripts to ensure actions occur within a narrow detection window of approximately 72 minutes, allowing them to evade initial security alerts.
- Common tools and techniques include leveraging PowerShell for executing malicious commands due to its prevalence on Windows systems and the challenges it poses for traditional antivirus solutions.
- Indicators of compromise (IoCs) often involve unusual network traffic patterns or unexpected execution of legitimate system binaries in a manner inconsistent with normal operational procedures.
- Lateral movement is another critical phase where adversaries may attempt to pivot across networks, using compromised machines as jump-off points within the 72-minute timeframe.

## 3. Telemetry Mapping: OCSF Fields

### Summary
Telemetry for detecting rapid lateral movement or privilege escalation should capture detailed user activity logs, process execution details, network communications, and integrity monitoring alerts. This helps identify anomalies within critical timeframes (e.g., 72-minute window) that could indicate malicious activities such as credential misuse, unauthorized access attempts, or data exfiltration.

### Key Fields
- user_login: Tracks user login times and locations for privilege escalation detection
- process_creation: Monitors creation of processes on endpoints to detect unusual binaries or scripts running with elevated privileges
- network_connections: Captures external network connections initiated from internal hosts, essential for identifying data exfiltration attempts
- file_change: Logs file modifications that could indicate tampering with system configurations or planting backdoors
- dns_requests: Monitors DNS query patterns to detect domain generation algorithms (DGAs) used in malware communications
