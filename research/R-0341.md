## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries may abuse the Maltrail system by leveraging its unauthenticated command injection vulnerability to execute arbitrary commands on the detection server, potentially allowing them to modify or disable monitoring and alerting mechanisms, thus evading detection while conducting AiTM attacks.

### Key Findings
- Adversary-in-the-Middle (AiTM) attacks can be facilitated through exploiting vulnerabilities in network traffic detection systems like Maltrail.
- Unauthenticated command injection vulnerabilities pose significant risks as they allow attackers to gain unauthorized access and control over the monitoring system.
- Maltrail's reliance on blacklists and heuristics for detecting malicious activities makes it a target for sophisticated adversaries who can bypass or manipulate these mechanisms.
- Network traffic manipulation by adversaries can be used to hide C2 (Command and Control) communications, data exfiltration, and other forms of malicious activity from detection systems.
- Real-time modification of network traffic can enable attackers to forge legitimate communication patterns, complicating forensic analysis and incident response efforts.
