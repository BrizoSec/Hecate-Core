## 1. System Research: How It Works

### Summary
The Contagious Interview malware campaign involves North Korean actors using fake developer job interviews to deliver malicious SVG files that exploit system vulnerabilities. The attackers lure victims with seemingly legitimate employment opportunities, and once the victim interacts with the embedded SVG file, the malware is delivered.

### Key Findings
- North Korean state-sponsored hackers use social engineering tactics in the form of fake job interviews to distribute malware
- The malware exploits vulnerabilities through malicious SVG images that appear benign but contain hidden payloads
- Attackers target developers and technical professionals, leveraging their skills and access to sensitive information

## 2. Adversary Tradecraft: Attack Techniques

### Summary
North Korean actors have been using the Contagious Interview campaign to target tech industry job seekers by luring them with fake recruitment opportunities. The malware, delivered via SVG images and updated through the Qt framework, includes new variants of BeaverTail and InvisibleFerret.

### Key Findings
- The attackers use SVG image files as a vector for delivering malicious payloads.
- New variants of BeaverTail and InvisibleFerret malware are being employed in this campaign.
- Job seekers are targeted through fake recruitment websites or emails, tricking them into downloading infected Qt applications.
- Malware is delivered using social engineering tactics to appear legitimate and trustworthy.
- The use of the Qt framework for updating malware suggests sophisticated development and evasion techniques.

## 3. Telemetry Mapping: OCSF Fields

### Summary
To detect malicious activities involving SVG image files, telemetry should focus on network traffic analysis for unexpected transfers of SVG files, endpoint activity related to file execution or modification, and any unusual behavior in processes handling these files. The key findings would be based on fields that track file operations, process events, network transfer details, and anomalies in user behavior.

- file.path (unknown): Tracks the path of accessed or modified SVG files which may indicate malicious activity if seen in unexpected locations or contexts.
