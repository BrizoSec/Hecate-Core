### Summary
The Flax Typhoon threat group leverages compromised infrastructure linked to Integrity Technology Group to deliver the FishHub malware and Microscan vulnerability scanning tools for targeting critical infrastructure globally. This campaign involves using a Mirai-based botnet to infect devices, conduct network scans, and exfiltrate sensitive data while obscuring the origin of Chinese state-sponsored actors.

### Key Findings

- Malicious activity included vulnerability scanning via the Microscan tool, cross-site scripting attacks, and password spraying against Microsoft Exchange servers.
- Six seized domains (98aicai.com, youtubecard.com, c0cc.cc, 98aicode.com, outlook3650.com, linkedinns.net) were actively used to deliver FishHub malware and access Microscan as of March 2024.

### Executive Summary
Flax Typhoon leverages Integrity Technology Group infrastructure to deploy FishHub malware and Microscan vulnerability scanners via seized domains (e.g., c0cc.cc, 98aicai.com), utilizing a Mirai-based botnet for network reconnaissance and lateral movement. Detection requires correlating DNS queries to these specific IOCs with outbound connections from IoT devices and Exchange server authentication anomalies.

### Recommended Hypothesis
> Adversaries use Microscan vulnerability scanning and FishHub malware delivery via compromised domains to enumerate networks and infect IoT devices for lateral movement on critical infrastructure targets.

### Gaps Identified
- Lack of DNS telemetry for recently seized domains (c0cc.cc, 98aicai.com, etc.) allows undetected C2 callbacks and tool downloads if historical logs are purged or not monitored in real-time.
- Absence of process command-line logging for Microscan execution prevents identification of active vulnerability scanning activities against internal networks, while standard EDR may miss Mirai-based botnet agents if they masquerade as legitimate IoT firmware updates.
