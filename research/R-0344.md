## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries with privileged network access employ Adversary-in-the-Middle (AiTM) attacks to intercept and manipulate network traffic in real-time, enabling them to block, log, modify, or inject malicious content into the communication.

### Key Findings
- Adversaries use AiTM techniques like ARP poisoning to redirect traffic through a malicious proxy server.
- Tools such as Ettercap and Cain & Abel are commonly employed for implementing AiTM attacks on local networks.
- Indicators of an AiTM attack include unusual DNS requests, unexpected network latency, or discrepancies in SSL/TLS certificates.

## 3. Telemetry Mapping: OCSF Fields

### Summary
The telemetry for the detection of malicious PowerShell activity would capture details about suspicious command-line activities, process creations involving powershell.exe, and any unexpected network communications initiated by such processes. This is critical for identifying potential threat actors leveraging PowerShell for lateral movement or data exfiltration.

### Key Fields
- process.entity.executable (100% populated): The field captures the executable name of the process that was launched; in this case, 'powershell.exe'.
- process.entity.command_line (65% populated): Provides the full command-line arguments passed to powershell.exe, which can include encoded commands or other suspicious parameters.
- network.connection.destination.ip_address (40% populated): Tracks any external IP addresses contacted by malicious PowerShell scripts for communication purposes.
- file.entity.full_name (30% populated): Identifies files potentially involved in the execution of malicious scripts, such as dropped payloads or script files.
- process.entity.parent.executable (75% populated): Reveals the parent process from which powershell.exe was spawned, aiding in understanding the context of the attack vector.
