## 1. System Research: How It Works

### Summary
ClickFix is a social engineering tactic used by attackers on macOS systems, where users are tricked into copying and running malicious commands in Terminal. This technique bypasses traditional security measures and delivers infostealers such as Atomic Stealer.

### Key Findings
- Users are misled into executing shell commands via social engineering.
- The attack leverages the Terminal to run malicious scripts that are not flagged by standard macOS security checks.
- ClickFix has evolved to include server-side checks, making detection more challenging.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries abuse the ClickFix social engineering technique on macOS by luring users into executing malware through deceptive prompts and fake download pages, often disguised as quick fixes for common computer issues. This campaign has evolved to include sophisticated methods such as clipboard injection via ClearFake infrastructure and deployment of information-stealing payloads following initial deception.

### Key Findings
- Adversaries use social engineering tactics to trick macOS users into downloading and executing malware through fake download pages, often disguised as quick fixes for common computer problems.
- The ClickFix campaign has expanded from Windows to macOS, leveraging AppleScript and Terminal phishing techniques to deploy information-stealing payloads after initial deception.
- Clipboard injection via ClearFake infrastructure is used to conceal the payload delivery process, making it harder to detect by security measures.
- Port 3333 on compromised systems often runs an HTTP service that acts as a hidden admin panel or command and control (C2) interface for communication with attackers.

## 3. Telemetry Mapping: OCSF Fields

### Summary
The ClickFix campaign on macOS employs stealthy tactics such as code injection into legitimate processes, leveraging system APIs for low-level operations, and creating cloaked gateways to exfiltrate data. Telemetry should focus on detecting anomalous process behavior, unexpected inter-process communication patterns, and unusual network activity indicative of covert command-and-control (C2) channels.

### Key Fields
- process.name: Tracks the names of processes involved in suspicious activities like code injection or API abuse.
- process.parent_name: Identifies parent-child relationships to detect process spoofing where malicious binaries mimic legitimate processes.
- network.http.user_agent: Monitors for unusual user-agent strings that may indicate cloaked gateways or C2 communications disguised as benign web traffic.
- file.path: Captures the file paths of suspicious files being executed, especially those found in unexpected locations or masquerading as system utilities like 'ClickFix'.
- process.args: Logs command-line arguments passed to processes which can reveal malicious intent such as injection flags or hidden parameters for cloaked gateways.
- network.dns.query: Tracks DNS requests that may be part of covert C2 communications, where attackers use domain generation algorithms (DGAs) to communicate with their infrastructure.
