## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries abuse SSH to gain initial access or lateral movement within a network by using compromised user credentials, often masquerading as legitimate processes like kernel threads. This technique is employed by APT groups such as MuddyWater and APT41 for deploying malware like BlueShell.

### Key Findings
- Adversaries use SSH to log in with valid accounts or stolen credentials from compromised systems.
- Malware such as the BlueShell RAT deploys via SSH, masquerading as legitimate processes (e.g., [kworker/12:12]) and establishing command-and-control (C2) communications.
- Suspicious file paths like `/tmp` can indicate malicious activity related to dropped malware or compromised system artifacts.
- Monitoring for abnormal SSH login times or locations helps detect unauthorized access attempts.
- Network traffic analysis should focus on identifying unusual outbound connections from infected hosts to C2 servers.
