## 1. System Research: How It Works

### Summary
Adversaries are increasingly using Large Language Models (LLMs) to automate and enhance attack operations, including the generation of deceptive documents and autonomous command execution. These LLMs can be integrated with databases for more sophisticated data manipulation and exfiltration.

### Key Findings
- Adversaries use AI-generated decoy documents to evade detection by security systems.
- LLMs are employed in attack orchestration, allowing for the automated generation of commands to copy sensitive files or perform other actions.
- Python scripts utilizing APIs from Hugging Face and local LLMs like Qwen2.5-Coder-32B-Instruct can be compiled with PyInstaller to facilitate stealthy data exfiltration.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries are leveraging AI, specifically large language models (LLMs), to generate sophisticated decoy documents and phishing content that can evade traditional detection methods. They use real-time intelligence and adaptive behavior to create highly tailored attacks against enterprises.

### Key Findings
- Adversaries utilize publicly available LLMs to automate the creation of convincing written materials, including phishing emails and fraudulent communications, which are harder to distinguish from legitimate content.
- Dynamic evasion techniques implemented through AI enable attackers to continuously adapt their strategies based on real-time feedback, making detection challenging.
- AI-generated attack vectors include the drafting of malicious scripts and content that can bypass traditional signature-based defenses by constantly mutating and evolving.
- MITRE ATT&CK framework sub-techniques such as T1588.007 (Utilizing AI) and T1683.001 (Generating Content) are increasingly relevant in describing how adversaries use AI to enhance their attack operations.

## 5. Research Synthesis

### Executive Summary
Adversaries are integrating AI, particularly Large Language Models (LLMs), into their attack operations to generate convincing decoy documents and phishing content, automate command execution, and dynamically evade detection. This involves the use of both public APIs and local LLMs for sophisticated data exfiltration and manipulation.

### Recommended Hypothesis
> Adversaries use AI-generated deceptive documents and autonomous commands to evade security systems on enterprise endpoints

### Gaps Identified
- Current monitoring lacks comprehensive coverage of real-time adaptive behavior by attackers using AI, including the mutation of attack vectors in response to detection mechanisms.
- There is insufficient understanding and detection capability for local LLMs used by attackers to generate sophisticated attacks, particularly in the context of dynamic evasion techniques.

### Key Findings
- Hypothesis: Adversaries use AI-generated deceptive documents and autonomous commands to evade security systems on enterprise endpoints
- Gap: Current monitoring lacks comprehensive coverage of real-time adaptive behavior by attackers using AI, including the mutation of attack vectors in response to detection mechanisms.
- Focus: Improve process monitoring for suspicious binaries that interact with AI tools or scripts; enhance file creation time analysis during off-hours or rapid succession to identify anomalies.
- Gap: There is insufficient understanding and detection capability for local LLMs used by attackers to generate sophisticated attacks, particularly in the context of dynamic evasion techniques.
- Focus: Strengthen network protocol monitoring to detect communication patterns indicative of data exfiltration or interaction with external AI services; enhance user account behavior analysis for signs of unauthorized software deployment.
