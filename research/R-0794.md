## 1. System Research: How It Works

### Summary
Custom GPTs are legitimate features on ChatGPT.com that allow users to create personalized AI assistants with specific instructions and tools. In this attack, threat actors abuse this feature to impersonate legitimate models and redirect victims to malicious Google Sites pages disguised as Cloudflare CAPTCHAs.

### Key Findings
- Attackers use sponsored Google search results to direct victims to fake Custom GPTs (e.g., 'Plus 5.6') that mimic official ChatGPT interfaces, leveraging the trusted chatgpt.com domain for initial lures.
- The attack chain utilizes ClickFix social engineering via Google Sites to trick users into executing PowerShell commands that bypass execution policies and download malicious MSI installers.
- Malicious payloads establish dual persistence mechanisms (User Run key and scheduled task) and evade detection by performing DLL sideloading through legitimately signed Canon and Stardock executables.
- The final payload is a Remote Access Trojan (RAT) with capabilities including remote desktop access, credential harvesting from 17 browsers, file management, and payload deployment.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries are abusing ChatGPT Custom GPTs to impersonate legitimate models and redirect victims via sponsored Google Ads to malicious Google Sites pages. These sites utilize ClickFix social engineering lures to trick users into executing PowerShell commands that initiate an eight-stage infection chain delivering a Remote Access Trojan (RAT).

### Key Findings
- Attackers use paid Google Ads to direct searchers for 'chatgpt' to malicious Custom GPTs hosted on the legitimate chatgpt.com domain, which impersonate official product offerings like 'Plus 5.6'.
- The Custom GPT delivers a fake 'Service Availability Notice' urging users to upgrade or switch to a 'backup domain,' which is actually a Google Sites page mimicking a CloudFlare CAPTCHA.
- Victims are tricked into running ClickFix PowerShell commands that download and execute an obfuscated script, leading to the installation of a malicious MSI (ISOSimple.msi).
- The malware employs DLL sideloading by abusing legitimately signed Canon executables (COTFileReadApp.exe) to load malicious code, evading detection.
- The payload establishes dual persistence mechanisms via a User Run key and a scheduled task, both named 'Canon Configuration Reader,' before deploying a full-featured RAT with capabilities including remote desktop access and credential harvesting from seventeen browsers.
- Huntress investigators have responded to at least 40 related incidents, confirming that two were directly driven by Custom GPT instances, indicating an active and persistent campaign.

## 5. Research Synthesis

### Executive Summary
Threat actors are abusing ChatGPT Custom GPTs and sponsored Google Ads to deliver ClickFix lures that initiate an eight-stage PowerShell execution chain, ultimately deploying a Remote Access Trojan via DLL sideloading using legitimately signed Canon or Stardock executables. The infection establishes resilient persistence through dual mechanisms (User Run key and scheduled tasks) while evading detection by leveraging trusted code signatures for malicious payload loading.

### Recommended Hypothesis
> Adversaries use abused ChatGPT Custom GPTs and ClickFix PowerShell lures to execute an eight-stage DLL sideloading chain via signed Canon/Stardock executables, delivering a RAT with dual persistence capabilities on Windows endpoints.

### Gaps Identified
- Standard endpoint detection may miss the initial social engineering vector as the attack originates from legitimate chatgpt.com domains and Google Sites, blinding traditional URL reputation checks against known-malicious infrastructure.
- DLL sideloading via legitimately signed Canon (`COTFileReadApp.exe`) or Stardock binaries evades signature-based alerts, requiring behavioral analysis of process creation arguments and module loading sequences rather than static file hashing.

### Key Findings
- Hypothesis: Adversaries use abused ChatGPT Custom GPTs and ClickFix PowerShell lures to execute an eight-stage DLL sideloading chain via signed Canon/Stardock executables, delivering a RAT with dual persistence capabilities on Windows endpoints.
- Gap: Standard endpoint detection may miss the initial social engineering vector as the attack originates from legitimate chatgpt.com domains and Google Sites, blinding traditional URL reputation checks against known-malicious infrastructure.
- Gap: DLL sideloading via legitimately signed Canon (`COTFileReadApp.exe`) or Stardock binaries evades signature-based alerts, requiring behavioral analysis of process creation arguments and module loading sequences rather than static file hashing.
- Focus: Monitor for anomalous PowerShell execution policies (specifically `-ExecutionPolicy Bypass`) combined with `irm` (Invoke-WebRequest) downloading scripts to `%TEMP%` directories, particularly those followed by MSI installation events.
