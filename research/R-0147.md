## 3. Telemetry Mapping: OCSF Fields

### Summary
To effectively capture behaviors indicative of potential security threats within a Microsoft 365 environment while applying Huntress Managed ISPM best practices, telemetry should focus on key event IDs from Windows Security Event Logs and endpoint activities. This includes monitoring for user account creations and logons (Event ID 4624), object access events (Event ID 4656), process creation and termination (Event IDs 4688 and 4697), PowerShell command execution, and other critical security-related operations.

### Key Fields
- event_id (10% populated): Specific Windows Security Event Log identifiers such as 4624 for account logon events and 4656 for object access are crucial for detecting unauthorized activities.
- user_name: Identifying the user associated with an event is essential, especially in conjunction with other indicators like process creation or file modifications.
- process_name (30% populated): Monitoring initiated processes can help detect malicious software execution or unusual activity patterns that may indicate a compromise.
- destination_ip_address: Tracking outbound connections from endpoints to suspicious IP addresses is vital for identifying potential data exfiltration attempts.
- file_path: Analyzing file paths related to events such as process creation, changes in registry keys, or modifications to critical files helps identify malicious scripts or malware locations.
- event_time (95% populated): Timestamps are crucial for correlating activities across different logs and identifying anomalous timing patterns that might suggest lateral movement or rapid succession of attacks.

## 5. Research Synthesis

### Executive Summary
Microsoft 365 hardening emphasizes multi-factor authentication and advanced threat detection through Huntress Managed EDR, while telemetry mapping highlights the importance of monitoring specific Windows Security Event Log IDs for detecting unauthorized activities. However, there are gaps in current coverage regarding detailed analysis of adversary tradecraft and continuous improvement areas.

### Recommended Hypothesis
> Adversaries use PowerShell command execution to establish persistence on Microsoft 365 environments by leveraging legitimate administrative tools and processes.

### Gaps Identified
- Limited telemetry data on event IDs related to user account management (Event ID 4720) and network connections (Event ID 4698) can hinder the detection of lateral movement within a compromised environment.
- The current approach lacks comprehensive testing and validation of Huntress Managed EDR's effectiveness against emerging threats like new malware variants or sophisticated evasion techniques.

### Key Findings
- Hypothesis: Adversaries use PowerShell command execution to establish persistence on Microsoft 365 environments by leveraging legitimate administrative tools and processes.
- Gap: Limited telemetry data on event IDs related to user account management (Event ID 4720) and network connections (Event ID 4698) can hinder the detection of lateral movement within a compromised environment.
- Focus: Enhancing monitoring capabilities for detecting unauthorized changes in security policies, such as modifications to Group Policy Objects (GPOs), to prevent adversaries from altering system configurations.
- Gap: The current approach lacks comprehensive testing and validation of Huntress Managed EDR's effectiveness against emerging threats like new malware variants or sophisticated evasion techniques.
- Focus: Investigating the abuse of legitimate Microsoft services, such as Teams Quick Assist feature, for unauthorized access and lateral movement within a network.
