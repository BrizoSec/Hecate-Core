## 3. Telemetry Mapping: OCSF Fields

### Summary
Telemetry capturing unusual user account activities such as logon events, failed login attempts, and process creation with elevated privileges would help detect potential attack behaviors.

### Key Fields
- event_id (100% populated): Identifies specific Windows Security Event IDs that are relevant to tracking user activity and privilege changes. Commonly monitored event IDs include 4624 for successful logon, 4625 for failed logon attempts, and 4768/4769 for account creation and management.
- event_data.user_id (100% populated): Represents the user ID of the entity performing actions. This field is critical for tracking which users are engaging in suspicious activities.
- event_data.process_name (85% populated): Indicates the name of the process that performed an action, such as a logon event or creating new processes with elevated privileges.
- event_data.target_user_id (70% populated): If applicable, this field captures the target user ID affected by certain actions like privilege escalation attempts.
- event_data.logon_type (95% populated): Specifies the type of logon being performed. Certain types are more indicative of suspicious activity, such as 3 for network logons or 7 for service logons.
