## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries can exploit the runtime security gap in HPC AI workloads by targeting cloud environments where traditional security measures fall short. With the rapid expansion of the attack surface due to increased use of AI and SaaS applications, adversaries may leverage vulnerabilities in these systems to breach defenses.

### Key Findings
- Adversaries are increasingly using sophisticated techniques to exploit the runtime security gaps in high-performance computing (HPC) environments that process artificial intelligence (AI) workloads.
- Organizations face a growing threat landscape as AI adoption accelerates, making it critical to integrate advanced cloud security solutions like CrowdStrike's Falcon platform into their infrastructure.
- The integration of AI-powered SaaS applications and AI workloads in the cloud expands the attack surface, providing adversaries with more entry points for launching sophisticated attacks.
- Adversaries may deploy tools that automate the discovery of vulnerabilities in AI workloads running on HPC systems to facilitate large-scale breaches.
- There is a need for continuous monitoring and adaptive security measures to counteract the dynamic nature of cloud environments and protect against emerging threats targeting AI workloads.

## 3. Telemetry Mapping: OCSF Fields

### Summary
To capture runtime security behavior for HPC AI workloads, telemetry should focus on process events (creation/execution), network connections, and file system activities. This ensures detection of anomalous patterns indicative of potential threats in real-time.

### Key Fields
- process_name (85% populated): Tracks the names of processes that are executed within HPC AI workloads to identify suspicious or unauthorized program executions.
- network_connections (70% populated): Logs information about network connections initiated by applications running on HPC nodes, crucial for detecting exfiltration attempts and unusual communication patterns.
- file_access_operations (65% populated): Records file read/write operations performed by processes in the HPC environment to identify unauthorized access or modification of sensitive AI models or data files.
- event_id (90% populated): Captures specific security event IDs relevant for Windows Security logs, including those related to process creation and user authentication, essential for correlating events across systems.
