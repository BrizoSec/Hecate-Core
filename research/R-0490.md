## 1. System Research: How It Works

### Summary
Falcon Onum is a real-time telemetry processing and enrichment tool that works with CrowdStrike's Falcon platform to enhance security operations by filtering out noise, enriching data, and routing it efficiently to various security tools. It supports high-fidelity data for faster threat detection while reducing storage costs.

### Key Findings
- Falcon Onum processes and enriches telemetry in real-time to reduce false positives and improve the signal-to-noise ratio.
- It integrates with CrowdStrike's Falcon platform to enhance threat hunting capabilities, such as identifying shell command obfuscation on VMware ESX environments.
- The system uses intelligent routing to ensure data integrity and can customize data for different tools while maintaining consistency in security operations.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
CrowdStrike's Falcon Onum enhances security through advanced telemetry processing but can be subverted by skilled attackers using evasion tactics and data manipulation.

### Key Findings
- Adversaries may use command obfuscation to evade detection mechanisms within Falcon Onum.
- Sophisticated threat actors can manipulate or inject false telemetry to mislead anomaly detection systems.
- Data exfiltration attempts might involve exploiting lesser-known protocols that are not yet flagged by Falcon Onum's filters.
- Insider threats may leverage legitimate access rights to bypass compliance monitoring controls.
- Adversaries continuously evolve their methods, requiring constant updates and refinements in Falcon Onum's threat intelligence.

## 3. Telemetry Mapping: OCSF Fields

### Summary
Unauthorized access attempts are identified through anomalous authentication patterns and network activity indicative of credential misuse.

### Key Fields
- EventID (100% populated): Specific event IDs like 4625 for failed logon events, 4769 for account lockout, and 4771 for password changes which can indicate unauthorized access attempts.
- SourceIP (85% populated): IP address from where the authentication request originated. Unusual IPs or patterns of requests from a new or suspicious IP might suggest an attack.
- UserName (100% populated): The username associated with each login attempt, helping to track whether known accounts are being targeted.
- ComputerName (95% populated): The hostname of the endpoint attempting access, useful for identifying if certain machines are compromised and used in attacks.
- LogonType (80% populated): Type of logon such as network or interactive sessions. Unusual logon types might indicate an attack vector like pass-the-hash.
- DestinationIP (50% populated): The IP address of the destination server being accessed. This can help trace if a particular service is under targeted attacks.

## 5. Research Synthesis

### Executive Summary
Falcon Onum enhances real-time threat detection and response by processing and enriching telemetry data, reducing false positives, and improving the signal-to-noise ratio. However, skilled adversaries can exploit command obfuscation, false telemetry injection, and lesser-known protocols to evade detection.

### Recommended Hypothesis
> Adversaries use polymorphic malware and obfuscated shell commands to evade Falcon Onum's AI-driven detection mechanisms while conducting malicious activities in VMware ESX environments.

### Gaps Identified
- There is limited coverage for detecting data exfiltration using less common protocols that are not yet flagged by Falcon Onum's filters.
- The system lacks robust measures against insider threats leveraging legitimate access rights to bypass compliance monitoring controls.

### Key Findings
- Hypothesis: Adversaries use polymorphic malware and obfuscated shell commands to evade Falcon Onum's AI-driven detection mechanisms while conducting malicious activities in VMware ESX environments.
- Gap: There is limited coverage for detecting data exfiltration using less common protocols that are not yet flagged by Falcon Onum's filters.
- Gap: The system lacks robust measures against insider threats leveraging legitimate access rights to bypass compliance monitoring controls.
- Focus: Enhance detection capabilities for obfuscated commands and polymorphic malware in VMware ESX environments.
