## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries abuse the Pass-the-Hash (PtH) technique by using stolen hashed credentials to establish sessions on compromised systems without needing the original password, often following an initial exploit like ProxyShell. This method allows attackers to maintain persistence and move laterally within a network.

### Key Findings
- Pass-the-Hash attacks enable adversaries to bypass traditional authentication mechanisms and gain unauthorized access to resources.
- The attack typically follows an initial compromise, such as through vulnerabilities like ProxyShell, which provide the foothold needed for credential harvesting.
- Indicators of PtH include anomalous use of credentials, unexpected inter-system communication patterns, and unusual network traffic involving known bad hashes or IP addresses.
- Adversaries may leverage PowerShell scripts or custom tools to execute Pass-the-Hash attacks, often employing encryption and obfuscation techniques to evade detection.

## 3. Telemetry Mapping: OCSF Fields

### Summary
Telemetry should focus on capturing network traffic details such as DNS queries and HTTP/S requests. Additionally, process-level telemetry providing information about suspicious processes executing network commands is essential for detecting malicious activity.

### Key Fields
- network.http.request.uri (50% populated): Records the full URI of HTTP requests made by endpoints, useful in identifying calls to C2 servers or exfiltration attempts.
- network.dns.query.name (80% populated): Tracks DNS queries issued by systems, allowing detection of connections to malicious domains.
- process.create.executable.path (65% populated): Logs the path of executables when a process is created, critical for identifying malware execution paths.
- file.network.connect.host (45% populated): Indicates hosts that files or processes attempt to connect to over the network, crucial for spotting data exfiltration attempts.
- network.tcp.stream.destination.ip (70% populated): Captures destination IP addresses of TCP streams, useful in identifying communication with external threat actors.
