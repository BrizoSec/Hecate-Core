## 1. System Research: How It Works

### Summary
Falcon Onum is a data processing and enrichment tool designed to enhance the functionality of CrowdStrike's Falcon Next-Gen SIEM. It optimizes telemetry by filtering out irrelevant noise, enriching data in transit, and ensuring that only valuable insights are sent for analysis, thereby improving detection speed and accuracy.

### Key Findings
- Falcon Onum filters and routes telemetry to reduce noise and optimize storage, enabling faster threat detection.
- It works alongside the Falcon Next-Gen SIEM platform to enrich data in motion with context from external services such as GeoIP lookups.
- The system supports intelligent routing of security data while ensuring integrity and reshaping data for different downstream tools.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries may attempt to exploit Falcon Onum's enriched telemetry data and integrated services such as GeoIP to evade detection or mask their activities. They can also leverage potential weaknesses in SIEM migrations or user behavior analytics.

### Key Findings
- Adversaries use credential theft and shell command obfuscation techniques to gain unauthorized access to systems.
- Falcon Onum's integration with third-party services like GeoIP may introduce new attack vectors for sophisticated adversaries.
- The 'Impossible Traveler' pipeline could be exploited by adversaries masquerading as legitimate users from unexpected geographic locations.
- SIEM migration processes can expose security gaps that adversarial actors might target to infiltrate or disrupt operations.

## 3. Telemetry Mapping: OCSF Fields

### Summary
Lateral Movement involves attackers moving from one system to another within a network often using compromised credentials or legitimate access methods such as RDP or SMB. To detect this behavior, we need to monitor for signs of unauthorized credential usage, unexpected process creations indicative of tool execution, and anomalous network activity.

### Key Fields
- process_creation (95% populated): Records the creation of new processes on endpoints, which can indicate the use of tools like PsExec or WMIC for remote command execution, common in lateral movement attempts.
- network_connection (80% populated): Logs connections made from one endpoint to another, especially over protocols such as SMB, RDP, and RPC, which are frequently used during lateral movement attacks.
- user_logon (75% populated): Tracks user logons across different systems and services, helping identify when an attacker is using compromised credentials or service accounts to gain access.
- file_change (40% populated): Monitors modifications made to files, especially those related to system binaries or configurations that could indicate the presence of malware used for lateral movement.
