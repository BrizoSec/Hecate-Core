## 1. System Research: How It Works

### Summary
The system involves Microsoft SharePoint serving as the initial access vector via exploited vulnerabilities, followed by the execution of malicious executables like doexe.exe and ssvagent.exe that leverage DLL sideloading to bypass security controls. The attacker then utilizes compromised signed drivers such as K7RKScan to disable endpoint protection before deploying Warlock ransomware through domain SYSVOL shares for rapid lateral propagation.

### Key Findings
- The attack chain relies on the 'ToolShell' exploit chain targeting SharePoint vulnerabilities (CVE-2025-49704, CVE-2025-49706) to gain initial access, specifically affecting water utilities and telecom operators in Portuguese and Spanish-speaking regions.
- Malicious binaries like doexe.exe and ssvagent.exe are deployed alongside legitimate-looking DLLs (doexeloc.dll, gsdll64.dll.tmp) in Windows system folders to establish covert remote access via Visual Studio Code tunneling using code-insiders.exe.
- The group abuses a vulnerable signed driver named K7RKScan to disable security software and pushes an AV/EDR-killing tool (a.exe) to multiple hosts, while using NetExec (nxc.exe) for lateral movement.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
The China-nexus threat group Longlegs targets critical infrastructure in Portuguese and Spanish-speaking regions by exploiting Microsoft SharePoint vulnerabilities (including the ToolShell chain) to gain initial access. They subsequently deploy Warlock ransomware at scale using DLL sideloading, vulnerable signed drivers to disable security controls, and domain SYSVOL shares for rapid distribution across compromised hosts.

### Key Findings
- Initial access is achieved by exploiting multiple Microsoft SharePoint vulnerabilities, specifically CVE-2025-49704, CVE-2025-49706, CVE-2025-53770, CVE-2025-53771, and CVE-2025-1055.
- The group disables security software by abusing a vulnerable signed driver named K7RKScan (associated with hash 80961850786d6531f075b8a6f9a756ad) and deploying AV/EDR-killing tools like a.exe.
- Warlock ransomware is distributed at scale by staging payloads in domain SYSVOL shares, allowing for rapid network-wide compromise of over 40 hosts in some incidents.
- Covert remote access is established using Visual Studio Code tunneling via the code-insiders.exe binary installed as a service, alongside open-source tools like NetExec (nxc.exe).
- The attack infrastructure relies on legitimate cloud storage services for payload delivery, specifically utilizing catbox.moe and wasabisys.com to host MSI installers such as vamd64.msi and xn8xyt.msi.
- Adversaries employ DLL sideloading techniques using artifacts like doexe.exe with doexeloc.dll and ssvagent.exe with logger.exe to execute malicious code within the context of legitimate processes.

## 5. Research Synthesis

### Executive Summary
The Longlegs threat group exploits the ToolShell chain (CVE-2025-49704/49706) in Microsoft SharePoint to execute DLL sideloading artifacts like doexe.exe and ssvagent.exe, subsequently abusing the signed driver K7RKScan to disable endpoint protection. Post-exploitation involves establishing covert C2 via Visual Studio Code tunneling (code-insiders.exe) and achieving rapid lateral movement of Warlock ransomware through domain SYSVOL share staging.

### Recommended Hypothesis
> Adversaries use SharePoint ToolShell exploitation and signed driver abuse to bypass security controls for rapid Warlock ransomware deployment via SYSVOL shares on critical infrastructure.

### Gaps Identified
- Lack of visibility into outbound tunneling connections on non-standard ports typically used by VS Code tunnels, as standard web proxy logs may not inspect encrypted C2 traffic effectively.
- Insufficient logging for file integrity changes in the SYSVOL directory structure to detect rapid staging of executable payloads across multiple domain controllers or file servers.

### Key Findings

- Gap: Lack of visibility into outbound tunneling connections on non-standard ports typically used by VS Code tunnels, as standard web proxy logs may not inspect encrypted C2 traffic effectively.
- Gap: Insufficient logging for file integrity changes in the SYSVOL directory structure to detect rapid staging of executable payloads across multiple domain controllers or file servers.
- Focus: Monitor for the specific execution of doexe.exe/ssvagent.exe with associated DLL sideloading artifacts (doexeloc.dll/gsdll64.dll.tmp) and alert on process creation of code-insiders.exe installed as a service.
