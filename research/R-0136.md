## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries exploit vulnerabilities in web applications such as wp2shell to perform unauthenticated remote code execution (RCE), gaining full control over the site. This technique often involves bypassing authentication mechanisms and executing arbitrary commands, thereby enabling further malicious activities like data exfiltration or establishing persistent access.

### Key Findings
- Adversaries leverage zero-day vulnerabilities in web applications for initial RCE to gain unauthorized access.
- Exploitation techniques frequently involve encoding shellcode as strings and using Python’s ctypes library to execute the code in memory without writing it to disk.
- Post-exploitation tools such as Evil-WinRM are utilized for maintaining remote control over compromised systems via Windows Remote Management (WinRM).
- Threat actors use specific user actions, like clicking malicious links or downloading files, to facilitate initial execution of their payloads.
