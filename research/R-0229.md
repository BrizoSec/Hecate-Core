## 3. Telemetry Mapping: OCSF Fields

### Summary

### Key Fields
- process_name (80% populated): The name of the executable or command being run, which is crucial for identifying potential malware processes.
- process_command_line (60% populated): Command line arguments used when launching a process; this helps in detecting unusual command usage patterns indicative of malicious activities.
- network_dst_ip (75% populated): Destination IP addresses involved in network connections from the endpoint. Monitoring these can help identify connections to known bad IPs or suspicious external destinations.
- process_parent_name (80% populated): The name of the parent process that spawned the current process, which is useful for identifying if a legitimate process was used as a launchpad for malicious activity.
- registry_key_modified (45% populated): Registry keys that were modified during an attack can provide insights into how adversaries are altering system configurations to maintain persistence or elevate privileges.
