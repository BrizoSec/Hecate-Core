## 1. System Research: How It Works

### Summary
AI systems typically authenticate users or services through the use of access tokens, which serve as digital proof of identity and authorization. These tokens grant permission to interact with APIs and perform actions within an AI environment, but they can be exploited by attackers for unauthorized access and data breaches if proper security measures are not in place.

### Key Findings
- AI systems rely heavily on access tokens for authentication and authorization.
- Token jacking is a significant threat where stolen tokens allow attackers to impersonate legitimate users or services.
- Strong access controls, multi-factor authentication, and regular audits of token usage are crucial defenses against token theft.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
Token jacking involves cybercriminals exploiting exposed credentials to steal access tokens for cloud AI services, leading to unauthorized use of resources and billing issues. Attackers often employ phishing and compromised credentials to gain initial access.

### Key Findings
- Attackers exploit URI hijacking techniques to intercept API tokens and session credentials
- Phishing attacks are commonly used to trick users into revealing their authentication tokens
- Compromised or weakly secured cloud service credentials can be easily exploited by attackers
- Indicators of compromise include unexpected charges for AI services and unauthorized access logs

## 5. Research Synthesis

### Executive Summary
Token jacking represents a significant security threat in AI systems, where adversaries steal access tokens to impersonate legitimate users and gain unauthorized access. This involves various attack vectors such as phishing, URI hijacking, and compromised credentials, leading to unexpected charges and misuse of resources.

### Recommended Hypothesis
> Adversaries use token jacking via compromised credentials or phishing attacks to steal AI resource tokens for illicit access and financial gain on cloud-based AI services.

### Gaps Identified
- There is a lack of comprehensive detection mechanisms specifically tailored to identify and respond to URI hijacking techniques used in token jacking attacks.
- Current telemetry lacks detailed process monitoring data to effectively track the unauthorized use of API keys, secrets, or tokens from non-authorized sources or patterns.

### Key Findings
- Hypothesis: Adversaries use token jacking via compromised credentials or phishing attacks to steal AI resource tokens for illicit access and financial gain on cloud-based AI services.
- Gap: There is a lack of comprehensive detection mechanisms specifically tailored to identify and respond to URI hijacking techniques used in token jacking attacks.
- Gap: Current telemetry lacks detailed process monitoring data to effectively track the unauthorized use of API keys, secrets, or tokens from non-authorized sources or patterns.
- Focus: Develop advanced network traffic analysis capabilities to detect suspicious header parameters indicative of stolen tokens and implement real-time alerting for unusual access patterns in authentication events.
- Focus: Enhance process monitoring tools with AI-driven anomaly detection to quickly identify unauthorized API key usage and enforce strict access controls on token management interfaces.
