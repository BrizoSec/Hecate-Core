## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversary-in-the-Middle (AiTM) techniques, such as rogue access points and ARP cache poisoning, are employed by adversaries like TAG-195 to intercept and manipulate network traffic in real-time. These methods allow for the capture of sensitive data between devices and their destinations, making it crucial for organizations to implement robust encryption protocols.

### Key Findings
- Adversaries use rogue access points or base stations outside a mobile device's environment to capture network traffic.
- Technique T1638 (Mobile Adversary-in-the-Middle) involves intercepting and manipulating data between devices and their intended destinations.
- TAG-195 leverages ARP cache poisoning to redirect network traffic through compromised systems, facilitating the interception of sensitive information.
- Custom DNS tunneling protocols are used for command and control communication as well as exfiltrating data from target networks.
