## 1. System Research: How It Works

### Summary
The DEV#POPPER Remote Access Trojan (RAT) is a sophisticated malware that compromises npm packages to deliver an encrypted payload to targeted systems. Once executed, it communicates with a command-and-control server to download additional malicious payloads and establish remote access.

### Key Findings
- DEV#POPPER initiates communication with its C2 server through specific endpoints like '/$/z1' to retrieve further instructions or payloads.
- The malware utilizes base64 encoding and XOR encryption for securing the data it exchanges with the command-and-control server, making detection more challenging.
- Compromised npm packages are used as vectors for distributing DEV#POPPER, targeting developers who use these libraries in their Node.js projects.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries compromised two beta releases of Joyfill npm packages (@joyfill/layouts and @joyfill/components) to deliver the DEV#POPPER Remote Access Trojan (RAT). The malware uses import-time JavaScript implants that execute when the module is loaded, leveraging blockchain transactions to retrieve mutable payloads.

### Key Findings
- The compromised Joyfill beta packages use import-time JavaScript implants that execute when modules are loaded into Node.js applications.
- Adversaries utilize Tron, Aptos, and BNB Smart Chain transactions to resolve and deliver dynamic malware payloads.
- This attack bypasses npm's --ignore-scripts protections by executing at the time of module import rather than installation.
- DEV#POPPER RAT is delivered through blockchain-powered mechanisms, indicating a sophisticated approach to evade detection.

## 5. Research Synthesis

### Executive Summary
Adversaries compromised two beta releases of Joyfill npm packages to deliver the DEV#POPPER Remote Access Trojan, which uses blockchain transactions and import-time JavaScript implants to bypass detection mechanisms and establish remote access on targeted systems.

### Recommended Hypothesis
> Adversaries use compromised npm package imports to execute stealthy implant scripts that leverage blockchain transactions for dynamic malware delivery in order to evade detection while establishing remote access on targeted systems.

### Gaps Identified
- The current telemetry lacks comprehensive coverage of import-time JavaScript execution events, which are critical for detecting such sophisticated malware distribution mechanisms.
- There is a lack of visibility into the specific endpoints and communication patterns used by DEV#POPPER for data exfiltration and payload delivery, making it challenging to develop effective detection rules.

### Key Findings
- Hypothesis: Adversaries use compromised npm package imports to execute stealthy implant scripts that leverage blockchain transactions for dynamic malware delivery in order to evade detection while establishing remote access on targeted systems.
- Gap: The current telemetry lacks comprehensive coverage of import-time JavaScript execution events, which are critical for detecting such sophisticated malware distribution mechanisms.
- Gap: There is a lack of visibility into the specific endpoints and communication patterns used by DEV#POPPER for data exfiltration and payload delivery, making it challenging to develop effective detection rules.
- Focus: Develop new detection signatures that monitor import-time JavaScript execution events in Node.js applications to identify anomalous behavior indicative of compromised npm package implants.
- Focus: Enhance network monitoring capabilities to detect unusual communication patterns with known C2 endpoints associated with the DEV#POPPER malware, such as '/$/z1', and blockchain-based payload delivery mechanisms.
