## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries can exploit privileged network access to perform adversary-in-the-middle (AiTM) attacks, intercepting and modifying traffic in real-time. This technique allows attackers to go undetected for prolonged periods by continuously testing their ability to evade detection and manipulate security controls.

### Key Findings
- Adversary-in-the-Middle (AiTM) attacks are facilitated by privileged network access, enabling real-time interception and manipulation of traffic.
- Sophisticated adversaries use weaponized documents in spear phishing campaigns to exploit vulnerabilities, often leading to the installation of backdoor web scripts for code execution on servers.
- Organizations must continuously test their security teams with adversary emulation exercises to improve detection and response capabilities against targeted attacks.
- CrowdStrike's Falcon Adversary Intelligence highlights common tactics such as pass-the-hash attacks leveraging ProxyShell vulnerabilities to gain system control.
- Validating security controls through real-world simulation helps identify gaps and enhance defenses against advanced persistent threats (APTs).
- Attackers frequently exploit file upload/email filters, group policy modifications, and services file permissions weaknesses to escalate privileges and maintain persistence.
