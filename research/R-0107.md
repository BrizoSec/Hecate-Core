## 2. Adversary Tradecraft: Attack Techniques

### Summary
Adversaries frequently employ credential theft techniques such as phishing, brute force attacks, and credential dumping to gain unauthorized access to systems. These methods are effective in compromising security due to the widespread use of weak or reused passwords.

### Key Findings
- Phishing remains a prevalent method for initial compromise, tricking users into revealing their credentials.
- Brute-force attacks exploit poorly secured accounts with weak password policies.
- Credential dumping is used to extract stored credentials from compromised systems without the need for direct user interaction.
- Organizations face significant risks from credential stuffing, where attackers reuse stolen credentials across multiple services.

## 3. Telemetry Mapping: OCSF Fields

### Summary
Credential theft or misuse often involves actions like unauthorized access, process injection, and lateral movement. Relevant telemetry would include log entries from Windows Security Event Logs related to user login attempts (Event ID 4624), creation of new processes or modification of existing ones (Event IDs 4688, 4699), and changes in security settings or permissions (Event IDs 4720, 4732).

### Key Fields
- SecurityEventLog.EventID: Event ID logs are crucial for identifying specific security events such as user logins or process creations. Commonly tracked IDs include 4624, 4688, and 4720.
- UserActivity.LoginSuccessTime: Tracks the timestamp of successful login attempts which can indicate if an unauthorized access occurred.
- ProcessExecution.CommandLine: Logs details about executed commands, including process creation commands that might be indicative of credential theft or lateral movement activities.
- FileModification.PermissionChangeTime: Monitors changes in file permissions which could signal a shift in security policies post-compromise.
- NetworkConnection.OutgoingIPAddresses: Tracks external IP addresses involved in network connections from compromised systems, useful for identifying data exfiltration attempts.
