## 1. System Research: How It Works

### Summary
The CLOSEDQUORUM malware operates as an autonomous command-and-control implant that queries up to four commercial AI models (DeepSeek, Qwen, Mistral, and Google Gemini) to determine its next action based on a consensus vote. It transmits host system facts alongside a fixed list of possible actions to these models, executing the most voted option while logging decisions and stolen data to a Discord channel via webhook.

### Key Findings
- The malware utilizes an AI-based consensus mechanism by sending basic host information (Windows version, admin status) to four specific commercial AI services, discarding any responses that do not adhere to a strict output format.
- Decision logic relies on voting among the models for four specific actions: steal, inject, persist, and move; in the event of a tie, DeepSeek's choice takes precedence, and if no usable answer is provided, the malware retries rather than acting by default.
- Operational telemetry includes a Discord webhook used to post every AI decision with its stated reasoning prior to execution, as well as to exfiltrate stolen data such as Windows credentials, browser passwords, and crypto wallet information.
- The public version of the malware is currently non-functional due to placeholder API keys and webhook URLs, indicating that functional variants require valid credentials for both the AI services and the Discord channel during the build process.

## 2. Adversary Tradecraft: Attack Techniques

### Summary
The CLOSEDQUORUM Windows malware autonomously determines post-compromise actions by querying up to four commercial AI models (DeepSeek, Qwen, Mistral, and Google Gemini) via API, executing the action receiving the most votes among 'steal', 'inject', 'persist', or 'move'. This architecture replaces traditional human-operated command-and-control servers with an AI-driven voting mechanism, allowing the attacker to monitor decisions and exfiltrated data through a Discord webhook channel.

### Key Findings
- CLOSEDQUORUM leverages a panel of up to four commercial Large Language Models (DeepSeek, Qwen, Mistral, Google Gemini) to vote on tactical moves rather than receiving direct instructions from an attacker-controlled server.
- The malware transmits basic host telemetry (computer name, Windows version, admin status) alongside a fixed menu of four action types: steal, inject, persist, and move.
- Execution relies on a majority voting system where the action with the most votes is carried out; if no usable answer is received, the malware waits rather than defaulting to a random action.
- Operational security is maintained via a Discord webhook, which posts each AI decision with its rationale and exfiltrates stolen data (Windows credentials, browser passwords, crypto wallet data) to a specific channel.
- The malware requires valid API keys for the AI models and a functional Discord webhook URL; the public version distributed by Talos contains placeholder values, rendering it non-functional without these credentials.
- Evidence suggests the developer may be linked to criminal carding forums from 2025, though the specific delivery method for initial infection remains undisclosed.

## 5. Research Synthesis

### Executive Summary
The CLOSEDQUORUM malware represents a novel threat vector that replaces traditional Command-and-Control (C2) infrastructure with an autonomous, AI-driven consensus mechanism. By querying up to four commercial Large Language Models (DeepSeek, Qwen, Mistral, Gemini) via API and executing the action with the highest vote count among 'steal', 'inject', 'persist', or 'move', adversaries can dynamically adapt post-exploitation tactics without direct human input, exfiltrating results through Discord webhooks.

### Recommended Hypothesis
> Adversaries use an autonomous AI voting mechanism to dynamically determine and execute post-compromise actions (credential theft, persistence, lateral movement) on Windows endpoints while bypassing static C2 detection thresholds.

### Gaps Identified
- Standard network security controls often whitelist legitimate AI API traffic (HTTPS to gemini.google.com, mistral.ai, etc.) and Discord webhooks, masking the malicious payload and command structure embedded within these encrypted streams.
- Existing Endpoint Detection and Response (EDR) signatures rely on known IOCs or static behavior patterns for credential dumping tools (e.g., mimikatz, procdump), failing to detect the dynamic invocation of these tools triggered by the AI's voting outcome rather than a hardcoded script path.
